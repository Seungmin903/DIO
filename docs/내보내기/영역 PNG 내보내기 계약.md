# 선택 영역 PNG 내보내기 계약 (S15P31F106-115)

> 기준일: 2026-10-21 · 구현 대조: develop `f68044a`(!39·!42·!43 포함).
> 현재 구현의 영역 전용 계약이다. 공통 정책은 56을 참조하며 실기기 검증 완료를 뜻하지 않는다.

## 1. 범위와 기준 문서

**내보내기 → 현재 페이지 → PNG → 영역 선택**에서 현재 페이지의 원하는 직사각형 구역을 골라 PNG 한 장으로 저장한다. 프리셋의 비율과 해상도는 DIO의 제품 기본값이다.

- 미디어/페이지 규격·해상도 산식·소재/GIF/폰트/배경·실패·재시도·저장 수명의 단일 기준은 [56번 공통 계약](../로컬%20미디어/MVP1%20미디어%20내보내기%20계약.md)이다. [공통 렌더러](./페이지%20이미지%20렌더러.md)를 재사용하며 이 문서는 영역 좌표·비율·클리핑·프리셋만 정의한다.
- 기존 전체 페이지 PNG의 기본 1배·파일명·사진첩 저장은 유지한다. PDF 고유 정책은 병합된 [PDF 계약](./PDF%20내보내기%20계약.md)의 기준을 따르며 이 작업은 PDF 생성에 의존하지 않는다.
- 사진 요소 자체의 크롭, 올가미/다각형 출력, 여러 영역 동시 출력, 투명 배경, JPEG 출력은 이번 범위에서 제외한다.

## 2. 영역 좌표와 조작

영역은 **적용 속지의 규격·해상도를 기준으로 저장된 페이지**의 왼쪽 위를 원점으로 하는 논리 좌표 `{ x, y, width, height }`다. 호출자는 해당 페이지의 canvasWidth/canvasHeight(pageSize 결과)를 pageWidth/pageHeight로 전달한다. 현재 새 속지는 1024×768이며 서비스 고정 규격이 아니다. 크기 없는 기존 페이지의 1188×840은 호환값이고, 이전 문서의 1280×800이나 API 예시를 신규 속지에 강제하지 않는다. 화면 px·DPR·편집 줌은 문서 좌표가 아니다. 소수 좌표를 유지하고 출력 직전에만 픽셀을 정수화한다. 서버와의 차이는 [56번 2절](../로컬%20미디어/MVP1%20미디어%20내보내기%20계약.md#2-속지-기준-규격과-출력-해상도)을 따른다.

- 두 손가락 사이의 거리와 중심으로 보기 확대·축소와 이동을 처리한다. 보기만 움직일 때 선택 영역의 문서 좌표와 출력 크기는 유지한다.
- 한 손가락으로 선택 틀 안쪽을 끌면 크기와 비율을 유지한 채 페이지 안에서 영역을 옮긴다. 모서리를 끌면 반대 모서리를 고정하고 크기를 바꾼다. 두 조작 모두 시작 배율로 이동량을 문서 좌표에 환산한다.
- 영역을 조정하다 두 번째 손가락을 대면 미완료 변경을 취소하고 보기 조작으로 전환한다. 두 손가락 중 하나를 떼어도 나머지 손가락이 새 영역 조작을 시작하지 않는다.
- 영역은 페이지 안에 두고, 너비와 높이는 각각 32 논리 단위 이상으로 제한한다. 손잡이 터치 영역은 최대 44×44 화면 단위이며, 인접 손잡이가 겹치지 않게 작은 영역에서는 줄인다. 페이지를 확대하면 작은 영역을 더 쉽게 조정할 수 있다.
- API에 전달된 잘못된 영역은 오류로 반환한다. 부동소수 오차 허용치는 0.000001 논리 단위이며 그 이내의 경계 초과만 경계값으로 정규화한다.
- 선택 상태는 화면 임시 상태다. 문서/원본/되돌리기 이력/자동 저장을 변경하지 않는다. 취소하면 출력 없이 이전 도구 상태로 돌아간다. 페이지 이동은 선택 모드를 종료한다.

## 3. 프리셋과 출력 규격

| 프리셋 | 영역 비율 | 출력 픽셀 |
| --- | --- | --- |
| 자유 (기본) | 사용자 선택 | 논리 영역의 2배, 상한 내에서 비율 유지 축소 |
| 정사각형 | 1:1 | 1080×1080 |
| 세로 피드 | 4:5 | 1080×1350 |
| 스토리 | 9:16 | 1080×1920 |

프리셋은 페이지의 일부를 그 비율로 선택하는 기능이다. 페이지 전체를 왜곡하거나 비율 맞춤용 외부 여백을 추가하지 않는다. 스토리 안전 영역/텍스트 위치 보장은 제공하지 않는다.

- 진입 시 자유 비율·전체 페이지 영역을 표시한다. 프리셋 변경은 기존 중심을 최대한 유지하고, 기존 영역 안에 새 비율로 들어가는 가장 큰 사각형을 우선한다. 최소 크기를 만족하지 못하면 같은 중심 기준 최소 유효 크기로 확장한 뒤 페이지 안으로 이동한다. 페이지 자체가 해당 비율의 최소 영역을 담을 수 없으면 선택 불가로 안내한다.
- 고정 비율 크기 조절은 반대 모서리를 기준으로 비율을 유지하고 경계에서 확대를 제한한다. 이동은 크기를 바꾸지 않는다. 자유로 전환할 때 현재 영역을 유지한다. 이미지 출력 픽셀만 정수화하고 선택 좌표를 반올림하지 않는다.
- 자유 출력은 [56번 공통 픽셀 산식](../로컬%20미디어/MVP1%20미디어%20내보내기%20계약.md#2-속지-기준-규격과-출력-해상도)의 W/H에 선택 영역 크기, k에 2를 넣는다. 프리셋은 이 문서 표의 고정 픽셀을 사용한다. 속지 기준 규격 변경과 영역 프리셋 출력 픽셀 변경을 혼동하지 않는다.
- 고정 비율은 **3절 표의 출력 픽셀**을 사용한다. 논리 영역 대비 확대 배율 `m = max(pixelWidth / width, pixelHeight / height)`를 표시한다. `m <= 3`은 일반 안내, `3 < m <= 6`은 화질 경고와 명시적인 계속 진행 확인, `m > 6`은 생성 차단 및 더 넓은 영역 선택 안내다. 예:4:5의400×500은2.7배,200×250은5.4배(확인 필요),160×200은6.75배(차단). 이 값은 초기 제품 품질 기준이며 원본 해상도 보장이 아니다. 원본 사진·스티커가 작으면 확대가 디테일을 복원하지 못한다.
- 픽셀 상한·페이지 준비 제한 시간은 [56번](../로컬%20미디어/MVP1%20미디어%20내보내기%20계약.md)을 따른다. OS 저장 대기는 제외하며 성능/실제 밀도는 실기기 보장이 아니다.
- 영역 선택 화면에 선택 범위, 비율, 예상 출력 픽셀을 표시한다. 같은 크기로 설정한 경우에만 전체 페이지 PNG와 픽셀 동일성을 비교한다.

## 4. 렌더링·요소·배경

선택 영역 크기의 전용 출력 surface에 페이지 합성 결과를 그린다. 페이지 좌표 `(px, py)`는 출력 좌표 `((px-x)*sx, (py-y)*sy)`로 변환한다. `sx=pixelWidth/width`, `sy=pixelHeight/height`이며 정수화 이외의 비율 변형은 하지 않는다. 회전 중심과 개별 크롭은 원래 요소 좌표계를 유지한다.

- 기존 ObjectContent를 공유하고, 페이지 논리 영역으로 먼저 클리핑한 뒤 선택 직사각형으로 클리핑한다. 요소를 선택 프레임 안으로 재배치하거나 개별 이미지를 다시 잘라 저장하지 않는다.
- 회전·그림자 등 시각 효과가 영역에 걸치면 합성된 부분을 그대로 출력한다. 중심점이 영역 밖이라고 제거하지 않는다.
- 118번의 초기 구현은 숨김/투명도0을 제외한 페이지 요소 전체를 준비·검증하므로 영역 밖 소재 오류도 중단할 수 있다. 후속 최적화에서는 회전·선 굵기·테두리·그림자 확장까지 포함한 보수적 시각 경계가 선택 영역과 완전히 분리됨을 증명할 수 있는 요소만 준비 전에 건너뛴다. 경계를 알 수 없으면 포함하고, 중심점/AABB의 원래 비회전 크기만으로 제거하지 않는다. 이 최적화는 후속 범위이며 초기118번의 필수 구현으로 추가하지 않는다.
- 공통 요소·속지·GIF 첫 프레임·텍스트/필기·폰트 준비·표시본 대체/경고는 [56번 4절](../로컬%20미디어/MVP1%20미디어%20내보내기%20계약.md#4-공통-렌더링과-소재-정책)을 그대로 적용한다. 별도 미지원 텍스트 모델을 정의하지 않는다.
- 실제 SVG 속지와 흰 바탕을 포함하고 선택 프레임·마스크·도구 등 편집 UI는 제외한다. 모눈 속지와 보조 격자를 구분한다.
- 영역 출력 배율·요소 크기·크롭 확대가 소재 선택의 필요 픽셀을 결정한다. 122번의 안전한 표시본 대체는 현재 연결돼 있다. 영역 밖 소재의 오류·과도한 화질 경고 가능성은 위의 전체 준비 정책 때문에 남는다.

## 5. 실제 함수 경계와 스냅샷

```js
const { width: pageWidth, height: pageHeight } = pageSize(page)
createRegionExportSnapshot(page, {
  pageWidth, pageHeight, // 속지 기준 크기, 이전 페이지는 pageSize의 호환 규격
  region: { x: 100, y: 80, width: 400, height: 500 },
  preset: 'portrait', // 'free' | 'square' | 'portrait' | 'story'
  title, pageNumber, now,
  upscaleConfirmed: false, // 3배 초과~6배 이하의 해당 영역/프리셋/출력에 대한 확인
})
// -> { pageId, pageWidth, pageHeight, region, preset, width, height,
//      pixelWidth: 1080, pixelHeight: 1350, background, template,
//      objects, fileName }

renderPageImage(snapshot, { signal })
// 공통 렌더러가 같은 snapshot의 region을 반영한다.
// -> { uri, blob?, width, height, dispose() }
// 저장은 기존 savePngFile(result, snapshot.fileName) 재사용
```

- 고정 비율과 영역 비율이 0.000001 상대 오차보다 크게 다르면 입력 오류다. 잘못된 비율을 늘려 맞추지 않는다.
- 공유 진입의 입력 편집 제한은 [56번 4절](../로컬%20미디어/MVP1%20미디어%20내보내기%20계약.md#4-공통-렌더링과-소재-정책)이다. 확정 때 페이지·영역·프리셋·속지 규격·제목·시각을 복사한다. 모든 입력을 자동 확정하는 별도 함수가 있다고 가정하지 않는다.
- 생성 도중 편집·페이지 이동·소재 변경이 있어도 확정한 스냅샷은 바뀌지 않는다. 작업 동안 원본 참조를 보호하고 없어진 소재는 실패 처리한다.
- 반환 width/height는 선택 영역의 논리 크기, pageWidth/pageHeight는 원래 페이지 크기, pixelWidth/pixelHeight는 PNG 크기다. 전체 페이지 스냅샷 의미를 바꾸지 않고 공통 surface에 영역 오프셋을 전달한다. 별도 요소 렌더러를 만들지 않는다.

## 6. 실패·취소·파일명·저장 수명

- 상태는 선택 → 생성 → 저장이다. 영역 확정 후 선택 화면을 닫고 편집기 공용 진행 표시를 사용한다. 실패하면 편집기에서 원인을 알리고 내보내기 메뉴에서 다시 시작할 수 있다.
- 영역 전용 오류: `EXPORT_REGION_INVALID`(좌표·크기·경계), `EXPORT_REGION_RATIO_INVALID`(프리셋 비율), `EXPORT_REGION_UPSCALE_LIMIT`(6배 초과), `EXPORT_REGION_UPSCALE_CONFIRM_REQUIRED`(3배 초과~6배 이하 미확인). 기존 소재/요소/캡처 오류 코드는 원인을 보존한다. 취소는 실패/성공으로 처리하지 않는다.
- 감지된 필수 요소 준비·로드·폰트·캡처 실패 시 저장 버튼을 제공하지 않는다. 문서·미디어는 보존한다. 영역 밖 문제라면 해당 요소를 확인하거나 숨기도록 안내한다.
- 파일명: `DIO_<제목>_p01_region_<프리셋>_<YYYYMMDD_HHMMSS_mmm>.png`. 프리셋은 free/square/portrait/story다. 기존 pngFileName과 같은 제목 정규화·48자 제한·현지 시각·문서 내 페이지 번호를 사용한다. 생성 시작 시 고정하고 재시도에서 유지한다.
- 웹은 다운로드 시작으로 안내한다. 모바일은 기존 PNG 사진첩 저장과 권한 안내를 재사용한다. 인스타로 직접 보냈다고 표시하지 않는다.
- 생성과 저장 중 임시 결과를 유지하고 작업 종료 후 해당 자원만 해제한다. 웹 다운로드 URL은 별도로 소유하고 60초 유예 후 해제한다.
- html-to-image가 오류 없이 소재를 누락하는 기존 한계는 그대로 남는다. 영역 기능이 이 문제의 완전한 해결을 보장하지 않는다.

## 8. 공유 메뉴와 영역 선택의 연결

편집기에서 내보내기 → 현재 페이지 → PNG → 영역 선택으로 연다. 선택 확정 후에는 공용 내보내기 작업이 PNG를 생성해 저장한다.

- 영역 선택 취소는 공유의 내보내기 옵션으로 돌아가고 문서·원본은 바꾸지 않는다. 선택 모드 동안 이전 도구를 임시 보관하고 종료 시 복원한다. 공유 메뉴까지 닫으면 편집 화면으로 복귀한다.
- 영역을 모서리로 조정하는 동안에는 확정을 막고, 손을 떼면 유효한 영역을 확정할 수 있다.
- 생성 확정 전 페이지를 이동하면 영역을 초기화하고 선택 모드를 종료한다. 현재 페이지의 영역을 다른 페이지에 자동 적용하지 않는다.
- 기존 PNG/PDF 선택 뒤 영역을 고르는 순서는 이 공유 메뉴 순서로 대체한다. 자유/1:1/4:5/9:16·출력 해상도·원본 보존·저장 수명은 유지한다.
- 119번은 영역 진입·취소·메뉴 복귀와 현재 페이지 PNG 회귀를 검증한다.

## 9. 확대 화질 안내

- 확대가 6배를 초과하면 저장을 막는다. 3배 초과~6배 이하의 확인은 영역·프리셋·출력 크기가 바뀌면 다시 받는다.
- 메뉴 부가 설명: 현재 페이지 내보내기 PNG는 “전체 페이지 · 기본1배”, 영역 선택은 “선택 구역 · 자유 기본2배 / 프리셋 지정 크기”로 표시한다. 영역에서 전체 종이를 선택해도 동일한 기본 해상도라고 설명하지 않는다.
- 116은 보기와 영역 좌표, 117은 프리셋·확대 배율 3/6 경계, 118은 생성 시 동일 검증과 확대 확인값, 119는 제스처 후 출력과 경계값을 검증한다.
- 공유 메뉴 표는 PDF 계약에만 유지한다. 입력 경계·전체 선택 상한의 과거 후속 제안은 현재 PDF 계약/실제 구현 설명으로 정리했다.
