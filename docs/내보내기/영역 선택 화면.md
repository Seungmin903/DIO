## 동작

- 공유 → 영역 선택으로 진입한다. 별도 모달의 StaticPage 위에서 새 직사각형 드래그·안쪽 이동·네 모서리 크기 조절을 제공한다.
- 좌표는 페이지 원점 기준 논리 단위다. 전용 오버레이의 로컬 좌표/zoom, 드래그 시작 위치+화면 이동량/zoom으로 계산한다. 원본 사진·스티커는 터치를 받지 않는다.
- 페이지 경계를 제한하고 가로·세로 32 미만/비유한/범위 밖 영역은 확정하지 못한다. 경계에 붙은 작은 영역을 조절할 때 최소 크기를 강제하느라 페이지 밖으로 넘치지 않도록 한다. 유효 크기로 만들 수 없으면 확정을 막고 재선택을 안내한다.
- 손잡이는 화면 기준 44×44다. 작은 영역에서 겹칠 때 수치 조정(x/y/너비/높이)으로 보완한다. 보기 확대/축소와 스크롤을 제공한다.
- 취소는 내보내기 옵션으로 복귀한다. 페이지 ID 변경은 영역 선택을 종료한다. 도구·문서 reducer·원본·자동 저장·되돌리기 이력을 변경하지 않으며 메뉴가 열린 동안 편집 키보드 단축키를 등록하지 않는다.
- 확정은 `onConfirm({ pageId, region, preset: 'free' })` 연결점이다. 118번 생성·저장 전에는 파일을 만들지 않고 미연결 안내를 표시한다. 영역 테두리·마스크는 StaticPage 위 UI일 뿐 출력 스냅샷이 아니다.
