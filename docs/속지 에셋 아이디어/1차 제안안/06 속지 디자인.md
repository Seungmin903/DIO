# 6. 속지 디자인 제안 — 20종 × 가로 · 세로

> 작성일: 2026-10-25 · 근거: [03 속지 카탈로그](03%20속지%20카탈로그.md) ★ 1차 추천 + [02 온라인 속지](02%20온라인%20속지.md) 1차 묶음 + 미래 핵심 4종(야구 · 포카 · 독서 · 콘서트)<br>
> 캔버스: 실제 속지 템플릿과 같은 **가로 1024×768 · 세로 768×1024** 논리 좌표. 색은 [디자인 가이드 §2.4 꾸미기 팔레트](../../디자인%20가이드.md)(표지 색 · 테이프 색 · 종이 바탕)만 썼다.<br>
> 원본은 `벡터원본/`(40장)이고 `속지_디자인.py`가 만든다. 그림의 파란 손글씨 · 사진 · 테이프는 **채운 예시**이며 속지 자체는 그 밑의 인쇄선이다.

## 0. 한눈에 보기

| 공통 규칙 | 내용 |
|---|---|
| 여백 | 48. 상단 24에 제목 줄(색 점 + 영문 소제목 + 점선), 오른쪽 끝에 날짜 · 번호 칸 |
| 선 | 인쇄선 `#D9D4C7`, 보조선 `#ECE7DC`. 글은 가리지 않도록 선은 늘 손글씨보다 연하게 |
| 종이 | `#FFFCF6`. 질감은 에셋(P1)으로 얹는다 |
| 강조색 | 속지마다 팔레트 한 색: 노트 페리윙클 · 습관 세이지 · 질문 라벤더 · 무드 로즈 · 빙고 머스터드 · 구분지 카멜 |
| 온라인 칸 | 비어 있음 = 점선 상자, 채워짐 = 흰 카드, 잠김 = 자물쇠 + 점선 테두리, 숨김 = 스크래치 은박. 멤버는 색 원 아바타 |
| 가로 ↔ 세로 | 같은 칸 구성을 **옆으로(가로) / 위아래로(세로)** 다시 배치. 날짜 격자는 가로판은 날짜가 가로, 세로판은 날짜가 세로 |
| 글꼴 | 소제목 나눔고딕, 큰 숫자 · 질문은 명조, 손글씨 예시는 나눔 펜 |

## 6. 다음 단계

1. 이 20종을 디자인 가이드의 **속지 글씨체(마루부리)** 로 바꿔 실제 템플릿 SVG(`frontend/assets/templates`)로 옮긴다. 캔버스 · 여백이 같아 좌표를 그대로 쓸 수 있다.
2. 온라인 속지 4종(빙고 · 질문 릴레이 · 교환일기 · 출석)은 칸 좌표를 **slot 메타데이터**(id · 좌표 · 상태)로 SVG에 함께 넣는다.
3. 세로판은 폰 전용 배치(`docs/화면 배치/폰 태블릿 배치.md`)에서 한 번 더 확인한다.
