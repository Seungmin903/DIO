# 2. ① 일반 속지 — 오프라인에서도 동작

> **한 줄**: 인쇄된 칸. 서버 · 친구 · 시간과 무관하게 혼자서, 비행기 모드에서도 똑같이 쓴다.<br>
> 그룹 6개 · 항목 37개 · 목업 캔버스 1024×768 (가로 · 태블릿 기준, 세로판은 같은 칸 구성을 위아래로 다시 배치) · 조사 근거는 [01 트렌드 조사.md](01 트렌드 조사.md)의 절 번호<br>
> 원본: `스크립트/분류표.py` → `스크립트/카탈로그_생성.py` 가 이 문서를, `스크립트/렌더.py` 가 `목업/` 를 만든다.

종이 속지를 그대로 옮긴 것. 칸은 그려져 있을 뿐 스스로 변하지 않는다. 삼성노트의 페이지 템플릿처럼 **기본 → 플래너 → 트래커 → 일기 → 취향·덕질 → 구조** 순으로 묶었다. 모든 속지는 가로(1024×768, 태블릿) · 세로(768×1024, 폰) 두 판을 만들고, 날짜형(2027)과 만년형을 함께 둔다.
