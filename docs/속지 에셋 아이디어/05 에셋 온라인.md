# 5. ④ 온라인 에셋 — 상태 · 시간 · 사람과 이어진 재료

> **한 줄**: 붙인 뒤에도 바뀌는 에셋. 가리고(숨김) · 찍히고(자동) · 세고(카운터) · 나눈다(방).<br>
> 그룹 4개 · 항목 23개 · 목업 캔버스 640×480 (에셋 카드 · 한 묶음을 한 장에) · 조사 근거는 [01 트렌드 조사.md](01 트렌드 조사.md)의 절 번호<br>
> 원본: `스크립트/분류표.py` → `스크립트/카탈로그_생성.py` 가 이 문서를, `스크립트/렌더.py` 가 `목업/` 를 만든다.

온라인 속지의 칸 상태 4종과 알림 5종을 **종이 소품 모양**으로 보여 주는 재료. 자동 요소는 전광판이 아니라 도장 · 라벨 · 영수증 · 티켓 모양으로 들어와 다이어리 감성을 지킨다. 내 에셋(내 사진 · 내 그림)과 방 나눔(띵)은 캐릭터 IP 없이 가는 길이다.
