# 4. ③ 오프라인 에셋 — 파일 하나로 끝나는 재료

> **한 줄**: 스티커 · 테이프 · 종이 · 사진 틀 · 펜 · 재질. 붙이면 끝, 상태가 없다.<br>
> 그룹 6개 · 항목 33개 · 목업 캔버스 640×480 (에셋 카드 · 한 묶음을 한 장에) · 조사 근거는 [01 트렌드 조사.md](01 트렌드 조사.md)의 절 번호<br>
> 원본: `스크립트/분류표.py` → `스크립트/카탈로그_생성.py` 가 이 문서를, `스크립트/렌더.py` 가 `목업/` 를 만든다.

종이 문방구를 그대로 옮긴 재료. 조사에서 디지털에 가장 빠진 재료로 꼽힌 **글씨 쓰는 스티커(모조지 · 떡메) · 배경용 마테 · 키스컷 · 재질(투명 · 홀로그램) · 찢은 테이프 끝**을 1차에 둔다. 캐릭터 IP(먼작귀 · 산리오)는 라이선스 없이 넣지 않는다.
