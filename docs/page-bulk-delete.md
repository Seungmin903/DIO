# 페이지 목록 다중 선택 및 일괄 삭제 (205)

기준 develop: f6f663b. 브랜치: feature/fe/page-bulk-delete.

## 동작
- 왼쪽 페이지 목록: 편집 버튼으로 선택 모드 진입. 기존 길게 누르기 다중 선택·묶음 이동도 유지.
- 넓게 보기: 편집 → 썸네일 체크 → 선택한 N개 삭제 → 확인. 편집 중에는 페이지 이동/닫기를 수행하지 않는다.
- 삭제 확인 취소는 선택을 유지한다. 해제/완료는 선택 모드를 종료한다.
- 넓게 보기 전체/북마크 필터 변경 시 선택을 초기화한다.
- 선택이 없으면 삭제 비활성화. 전체 페이지 선택 시 최소 한 장 유지 안내와 삭제 차단.
- 삭제는 하나의 removePages 액션으로 수행하여 되돌리기 한 번으로 내용·순서를 복원한다.
- 현재 페이지가 삭제되면 앞쪽의 가까운 생존 페이지, 없으면 첫 생존 페이지로 이동한다.
- readOnly에서는 편집/삭제 진입을 제공하지 않는다.
- 기존 문서 자동 저장 경로를 사용하며 스키마나 미디어 원본은 변경하지 않는다.
