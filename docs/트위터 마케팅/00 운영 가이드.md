# 0. 운영 가이드 — DIO 트위터 계정, 이렇게 운영한다

> 작성일: 2026-10-26 · 담당: 황민희 · 상태: **검토안**. 근거와 조사 과정은 01~08에 있고, 이 문서는 **결론만** 적었다.

## 1. 한 장 요약

| 항목 | 운영 방식 |
|---|---|
| **역할** | 성장 엔진이 아니라 **결과물 카드를 보여 주는 보조 채널**. 소식은 이 계정에서 가장 먼저 알린다 |
| **누가 말하나** | 평소엔 **디오**(해요체 한 문장), 두리는 그림으로만. 공지 · 사과 · 응대는 **[DIO팀]** 사람 말투 |
| **무엇을 올리나** | ① 오늘의 한 장 50% · ② 디오의 하루(만화 · 질문) 30% · ③ 만드는 중 노트 20% |
| **얼마나** | **주 3회**: 월(만드는 중 노트, 격주) · 수(오늘의 한 장) · 금(디오의 하루) |
| **언제** | 첫 6주 평일 12시 vs 21시를 2주씩 바꿔 가며 확인 |
| **어떻게 쓰나** | 이미지 1장 + 한 문장. 본문 링크 · 해시태그 없음. 링크는 프로필 한 곳 |
| **누가 돌리나** | 주 1명 담당 로테이션 + 작성자와 다른 검수자 1명. 위험 게시는 2인 확인 |
| **돈** | 0원 시작. 광고 · 유료 구독은 나중에 |
| **성공 기준** | 팔로워 수가 아니라 ① 결과물 카드 저장 · 공유 ② 소식 받기 가입 ③ 부정 반응 0 |

## 2. 계정 세팅 (개설 전 확인 7개는 06 §8)

- 표시명 `DIO 디오 | 같이 꾸미는 공유 다이어리` · 핸들 `@diodiary_app` · 인장 A2 · 헤더 1 → 5 → 4
- 고정 게시물: "DIO는 하루 한 장의 사진 위에 친구들과 같이 스티커와 낙서를 얹는 다이어리예요. 지금은 만드는 중이에요. 소식은 이 계정에서 가장 먼저 알려요."
- 계정은 팀 공용 이메일 · 팀 소유 번호로 만들고 2단계 인증을 건다. 개인 소유 금지
- 개설 · 첫 게시는 **11/2(월)**. 10/29(이태원 4주기)는 피한다

## 3. 한 주 운영

| 요일 | 하는 일 |
|---|---|
| 월 | 만드는 중 노트 게시(격주) · 주말 멘션 확인 · 인수인계 노트 작성 |
| 수 | 오늘의 한 장 게시 · **게시 후 2시간은 담당이 바로 응대** |
| 금 | 디오의 하루 / 질문 / 릴레이 낙서 · 좋은 이용자 결과물은 **리포스트만** |
| 토 · 일 | 게시 없음 · 부정 반응 확인 1회 |

- 예약은 **일주일 단위**. 애도 · 사고가 생기면 **누구나** 예약을 일괄 중지할 수 있다
- 같은 문장 복붙 금지. 템플릿 3장을 바꿔 끼워 쓴다

## 4. 게시 전 확인 (검수자가 본다)

1. **지금 되는 기능만** 말했나 — 공유 · 초대는 예시 화면 단계라 '같이 만드는 중이에요'로만 쓴다
2. '안전해요 · 비공개예요 · 1위' 같은 근거 필요한 말이 없나
3. 이용자 사진 · 얼굴 · 이름 · 위치가 없나 (재업로드 금지, 리포스트만)
4. 날짜가 추모일 · 수능 · 국가애도기간과 겹치지 않나 (달력은 07 §4)
5. '#디오' · '#DIO' · 'EXO' 언급이 없나 (이름 혼선)
6. 협업이면 첫 줄에 '광고 · 협찬'이 있나
7. 구걸 문구("RT 해주세요", "답글 단 분 모두 팔로우")가 없나

14문항 전체는 03 §6.

## 5. 반응이 왔을 때

| 반응 | 대응 |
|---|---|
| 칭찬 | 한 줄 감사 |
| 질문 | 지금 되는 것만 사실대로 |
| 오류 제보 | "확인해 볼게요 + 언제까지" |
| 비판 | 사실 확인 → 인정 · 조치. **인용으로 반박하지 않는다** |
| 조롱 | 무응대 · 뮤트 |
| 악성 · 괴롭힘 | 증거 저장 → 차단 · 신고 |

- 먼저 찾아가서 멘션하지 않는다. DM은 먼저 보내지 않고, 나이 · 학교 · 연락처를 묻지 않는다
- **터졌을 때**: 1시간 안에 인지 → 6시간 안에 입장 → 24시간 안에 후속. 수정본으로 덮지 않고, 해명보다 사과를 먼저, 말투는 [DIO팀]으로 내린다 (03 §7)

| 단계 | 하는 것 | 아직 안 하는 것 |
|---|---|---|
| 0 만드는 중(지금) | 결과물 카드 · 만화 · 만드는 중 노트 · 소식 받기 모집 | 기능 약속 · 이벤트 · 광고 |
| 1 베타 | 구현된 기능만 이름 붙여 안내 · 베타 모집 · 업데이트 노트 | 정식 출시처럼 말하기 · 경품 이벤트 |

| 3 성장 | 이용자 결과물 리포스트 · 시즌 스티커 팩 · 소액 이벤트(분기 1회) | 이용자 사진 재업로드 |

## 7. 매달 · 분기마다

- **첫 4주**: 게시에 실제로 걸린 시간을 기록해 주기를 조정한다
- **첫 6주**: 링크 위치 · 시간대 · 포맷을 한 번에 하나씩 바꿔 보고 방향만 본다 (07 §6)
- **매월 첫 월요일**: 지난달 반응 · 부정 사례 점검 → 다음 달 달력 확정
- **분기**: X 알고리즘 · 약관 · 법규 변경 확인 (알고리즘 숫자는 10주간 46번 바뀌었다)

## 8. 지켜야 할 것 3가지

1. **약속은 지금 되는 것만.** 가장 큰 위험은 사진 · 기록 사고와 안 되는 기능을 약속하는 문구다
2. **X에만 올인하지 않는다.** 팔로워는 옮길 수 없으니 랜딩 + 이메일 · 카카오 채널에 관심층을 쌓는다
3. **먼저 찾아가지 않고, 부르면 응한다.**

## 9. 팀이 정할 것

1. 아이디 · 인장 · 헤더 확정
2. 담당 로테이션 순서 · 검수자 · 최종 확인자
3. 시간대 실험 승인과 11/18~21 쉼 여부
4. 이벤트 시점과 14세 미만 정책
5. 캐릭터 · 스티커를 직접 그렸는지 생성 도구를 썼는지 확인(AI 표기 정책의 전제, 03 B4)
