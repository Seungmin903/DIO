- **네이버 · 트위터 인장 뜻** — "트위터에서 인장은 계정의 프로필 사진을 의미하는 은어"(AI 브리핑이 SEO 사이트를 인용, 신뢰 낮음). 지식iN · 팩트체크 류 글이 상위, 연관 검색어에 '헤더 뜻' · '뮤트 뜻' · '트위터 용어 정리' — **입문자가 용어를 따로 찾아봐야 하는 폐쇄적 문화**라는 신호
- **네이버 · 트위터 헤더 사이즈 모바일 잘림** — AI 브리핑 "모바일에서 잘리는 현상은 기기별 반응형 레이아웃 차이와 프로필 사진과의 간섭 영역 때문", 블로그 "트위터 인장 헤더 배너 사진 사이즈 가이드 모음"(2025-10-30, 프로필 · 헤더 1500×500 · 이미지 1600×900). **규격은 블로그마다 다르다**(→ §5의 직접 관측)
- **네이버 · 트위터 아이디 닉네임 짓기** — "닉네임은 프로필에 표시되는 이름(표시 이름)과 @로 시작하는 고유 식별자인 아이디"(AI 브리핑), 사용자 이름 생성기 · 변경 방법 · 계정 삭제 질문. 핸들 가용성 조회 도구 · 생성기가 따로 있다

| 용어 | 뜻 · 근거 | DIO가 알아야 할 것 |
|---|---|---|
| **인장** | 프로필 사진. 일본어 '印章'을 가져온 말(나무위키 X 용어, 위키 · 2차). 최소 2018년 이전부터 통용(한국어 학습 블로그의 'Korean Twitter slang' 항목). 어원 정설은 없다 | 공식 문서에 '인장'이라 쓰면 '아는 사람' 신호지만 억지로 쓰면 어색하다. 내부 표기는 '인장(프로필 이미지)' |
| 헤더 | 프로필 맨 위 가로 이미지. 브랜드에는 '대문' · 이벤트 지면 | 올리브영 '헤더 빌려드립니다'(유저가 올라가려 참여, 실시간 트렌드 진입, 2022-11) |
| 표시명 vs 아이디 | 표시명은 바꿔도 @아이디 불변, 이모지 가능 · 중복 가능 / 아이디는 고유 주소 | 이름은 검색 단어, 아이디는 주소 |
| **알계 기피** | 기본 프로필(알 이미지) 계정을 받지 않으려는 경향(나무위키 X 문제점 4.5) | **개설 직후 기본 프로필 상태로 팔로우 · 멘션을 하지 않는다.** 인장 · 헤더 · 소개글을 먼저 채운다 |
| 트친 · 트친소 | 서로 맞팔인 사용자 · '트위터 친구 소개' 양식(취향 · 덕질 칸을 채운 표 이미지 + `#○○계_트친소`). 2026년에도 생성기가 인기(스크린샷 09: 하이큐 · 치이카와 · 블루아카이브 트친소 양식). 올리브영 · 매일유업도 참여 | 호칭은 '엑친'보다 '트친'(고구마팜 2025-03). 'DIO 취향 트친소 양식'은 X 문법에 맞는 참여 카드(→ 07 §3) |
| 비공식 예절 | 초면 멘션은 초면이라 밝히기 · 인용은 조리돌림 연상이라 기피 · 떼멘 금지 · 반말 시비 멘션 싫어함 (나무위키) | 먼저 말 거는 멘션 · 인용은 최소화, **'불러 주면 답하는' 반응형**이 안전 |
| 자캐(OC) 문화 | 직접 만든 캐릭터를 인장으로 쓰고 **인장 커미션** · 픽크루로 그림 인장을 구한다. 타인 자캐의 도용 · 모방은 저격 · 신고 대상 | 디오 · 두리는 'OC형 인장'으로 이미 자연스럽다. 반대로 **유사 · 도용 의혹에 매우 민감**(03) |
| 계정 종류 | 본계 · 비계(비공개) · 부계 · 사담계 · 연성계(창작물 공개) · 비상계 · 총공계 | DIO 공식은 **공개 본계**. 팬이 만드는 인장 · 2차 창작은 '연성계' 문화와 닿는다 |

**→ DIO** 한국 X의 프로필은 '사람 얼굴이 없는 캐릭터 인장 + 3:1 헤더 + 한 줄 화자 선언'이 일반적이며 **로고만 있는 마크는 '광고 같다'는 거리감**을 준다는 서술이 있다(소마코 2022 · 고구마팜 2023). 직접 근거는 얇아(로고 vs 캐릭터 인장의 반응 비교 자료 없음) 추정이다.
