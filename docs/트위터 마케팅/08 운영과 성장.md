## 2. KPI — 현실적인 수준

- **기준선**: 일반 계정 게시물당 노출 중앙값 100 미만(Buffer 2025), 브랜드 주간 팔로워 증가 0.00%(Hootsuite 2026-04)~0.11%(2025-03), 일반 계정 중앙 참여율 2025-03 이후 0%(Buffer). 한국 소규모 · 1020 여성 기준선은 **없다**(04).
- **참여율은 분모를 먼저 정한다**: 팔로워 기준(0.015~0.15%)과 노출 기준(1.6~3.6%)이 100배 이상 다르다. X 분석 화면의 값이 어느 분모인지 확인한 뒤 쓴다.
- 제안 KPI(분기 1~2개, 월 점검 — Buffer · Sprout 권고):

| 단계 | KPI(제안) | 방향값 |
|---|---|---|
| 0 | ① 프로필 링크 클릭 → 랜딩 '소식 받기' 가입 ② 결과물 카드 **저장 · 공유 · 인용** 수 ③ **부정 반응 0**(신고 · 뮤트 징후 · 비판 인용) | 숫자 목표는 첫 6주 실험 뒤에 정한다 |
| 1 | 베타 신청 수 · 응답한 피드백 수 | 사례 기준선: 5인 학생팀 사전예약 약 50명(04) |
| 2 | 설치 · 스토어 리뷰 키워드 · 문의 해결 시간 | iOS 사전 주문 수는 App Analytics에서 소스 유형별로 본다 |
| 3 | 이용자 결과물 리포스트 수 · '활성 팔로워' 대비 반응 | — |

- 팔로워 수는 **허영 지표 vs 성장률** 의견이 갈린다(Hootsuite 비권장 · Sprout · Buffer 사용). 우리는 보조 지표로만 본다.
- 이벤트 전후 '활성 팔로워' 비교로 질을 확인한다(02 T08).

## 3. 운영 모델 — 6명 로테이션

| 역할 | 맡는 일 | 규칙 |
|---|---|---|
| **담당(주 1명, 로테이션)** | 이번 주 3장 제작 · 예약 · 응대 · 모니터링 | 예약은 **일주일 단위**. 담당은 매주 월요일 인수인계 노트에 기록 |
| **검수(담당 외 1명)** | 03 §6 14문항 점검표로 게시 전 확인 | 검수 없는 게시 금지. 위험 게시는 2인 |
| **중지 권한** | **누구나** 예약 일괄 중지(애도 · 사고) | 재개는 담당 1명 |
| **사고 대응 책임** | 03 §7 시간표의 1시간 안 인지 · 판단 | 책임자 1명 + 부책임자 1명 지정, 연락망 |
| **계정 소유** | 팀 공용 이메일 · 팀 소유 전화번호로 개설 | 개인 소유 금지(서울남부지법 2013: 개인 소유로 판단된 사례) |

- **말투 가이드 1장**(05 §2): 디오 한 문장 · [DIO팀] 해요체 · 금지어(03 B1 · B14의 책임 회피 표현).
- **인수인계 노트**: 이번 주 게시 · 반응 · 실험 기록 · 열린 응대 · 다음 주 예약 · 특이사항. 뉴닉처럼 말투를 **문서로** 공유해 담당이 바뀌어도 흔들리지 않게 한다(04).
- **승인 흐름**: 작성(담당) → 점검표(검수) → [위험 게시] 2인 → 게시. 이벤트 · 협업 · 사고 공지는 **팀장 1명**(정한다)의 최종 확인.
- 개인 계정 규칙: 팀원이 개인 계정에서 DIO를 홍보하거나 개인 의견을 말할 때는 이해관계를 표시하고 공식 입장처럼 보이지 않게 한다(03 B6 · B10).

## 4. 계정 보안 · 소유

1. 팀 공용 이메일(여러 명 접근 가능한 그룹) + 팀 소유 번호로 개설, **2단계 인증**(보안 앱), 복구 코드는 팀 금고에.
2. **외부 앱 연동 최소화**: 예약 도구는 X 공식 API 연동만. 비공식 자동화 · 스크립트 금지(02 T09).
3. 피싱 교육: '저작권 침해 경고' · '계정 정지 예정' DM 링크 금지(메가박스 2020 사례, 03 B10).
4. 퇴사 · 담당 변경 시 비밀번호 · 인증 갱신(Hootsuite · Sprout 권고).
5. 계정 개설 전 점검: KIPRIS(상표) · '디오 다이어리' 중복 · X 가입 화면에서 핸들 확인(06 §8).

## 6. 플랫폼 위험 대비

- **X 접속 차단 · 정지 · 청소년 이용불가**(01 §2.5): 2026-10 국감에서 '연말까지 정리 못 하면 접속 차단 포함 조치 검토' 주장(확정 아님), Google Play 19세 미만 신규 설치 제한. **팔로워는 옮길 수 없다** → 랜딩 + 이메일 · 카카오 채널 목록 + 인스타 보조.
- **계정 오탐 정지**(인스타그램 2025 사례 · X 2025-09 이후 '허위 활동' 집단 정지 서술): 백업 연락 채널과 복구 문의 경로를 개설 때 확보. 스팸처럼 보이는 행동(대량 팔로우 · 복붙 · 참여 구걸)을 피한다.
- **정책 변경**: 알고리즘 숫자는 10주간 46회 바뀌었다(02 §5). **분기마다** 저장소 변경 이력 · 규칙 · 약관을 재확인한다.
- **채널 분산의 한계**: 6명 겸임이라 채널을 늘리면 모두 얇아진다. **X 한 곳 + 랜딩 + 이메일**을 기본으로 하고 인스타는 같은 카드를 재사용(05 §6).
