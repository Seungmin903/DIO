# 네모·자유형 올가미 선택

관련 Jira: [S15P31F106-133](https://ssafy.atlassian.net/browse/S15P31F106-133), [S15P31F106-157](https://ssafy.atlassian.net/browse/S15P31F106-157)

## 조작과 표시

- 올가미 도구에서 네모(기본)·자유형을 선택한다. 자유형은 손을 떼면 경로를 닫고 짝홀 채움 규칙을 적용한다.
- 상세 창은 리본 아래에 표시한다. 창·툴바 바깥 터치 또는 오른쪽 ×로 상세 창만 닫고, 도구와 현재 선택은 유지한다. 올가미 버튼을 다시 누르면 창을 다시 열거나 닫을 수 있다.
- 자유형·사각형 범위를 확정하면 그린 경로를 닫힌 점선 윤곽으로 유지한다. 선택 완료 후 단일·다중 선택의 사각 SelectionOverlay·GroupFrame은 숨기고 올가미 점선만 표시한다. 기존 편집 바는 유지하고 크기·회전 핸들이 필요하면 일반 선택 도구로 전환한다.
- 선택 이동의 시작 영역은 객체 외곽 상자가 아니라 표시된 점선 경로의 안쪽(경계 포함)이다. 자유형은 표시와 같은 짝홀 규칙으로 판정하며, 영역 안의 빈 공간에서도 선택 전체를 이동할 수 있다. 점선 밖의 객체 부분은 선택 이동을 시작하지 않고 새 올가미·탭 해제를 처리한다. 추가·제외 버튼으로 다음 범위를 지정할 때는 점선 안에서도 새 범위를 그린다.
- 선택 요소가 같은 거리만큼 이동하면 윤곽도 따라간다. 페이지 논리 좌표로 보관하므로 확대·축소해도 같은 위치를 가리킨다. 추가 선택은 지정했던 윤곽들을 함께 보관한다. 제외할 때 그린 경로는 윤곽으로 표시하지 않고, 남은 선택 요소와 겹치지 않게 된 이전 경로도 지운다. 최종 선택 ID는 기존 합집합·차집합 판정으로 정한다.
- 선택 해제·다른 선택·페이지/도구 전환·삭제 시 윤곽을 해제한다. 형태 선택만 바꾸면 기존 확정 경로와 선택은 유지한다. 개별 크기·회전·반전·서로 다른 이동으로 요소 배치가 달라져도 해제한다. 윤곽은 캔버스의 임시 UI 상태이며 저장·PNG/PDF 내보내기 대상이 아니다.
- 추가 선택·선택에서 제외 두 버튼을 기존 편집 바와 겹치지 않는 별도 행에 제공한다. 새로 선택·선택 완료 버튼은 없다. 메뉴는 기존 앱의 색상·아이콘·둥근 모서리·그림자를 사용한다.
- 기본 모드는 선택 대체, 추가는 합집합, 제외는 차집합이다. 같은 모드 버튼을 다시 누르면 기본 모드로 돌아간다. 형태 변경은 기존 선택을 보존한다.
- 추가·제외 버튼을 누르면 객체 위에서도 다음 한 번의 범위를 지정한다. 범위 확정 뒤 기본 선택 모드와 기존 편집 조작으로 돌아간다. 이후 새 올가미는 기존 선택을 대체한다. 선택이 0개이면 메뉴를 숨긴다.
- 추가·제외 범위를 그리기 전과 도중에도 기존 선택 표시를 유지한다. 범위 지정 중 조절점은 터치를 가로채지 않는다.
- 기본 모드에서 새 올가미를 시작하면 기존 선택 표시를 숨기고 새 범위의 예상 선택만 표시한다. 제스처 취소 시 기존 선택 표시를 복원한다.
- 빈 곳에서 드래그하면 현재 모드의 올가미를 그린다. 빈 곳을 탭하면 현재 선택과 추가·제외 모드를 해제한다. 일반 선택 도구로 전환할 때는 현재 선택을 보존한다.
- 올가미에서 텍스트 도구로 전환하면 현재 선택을 해제한다. 일반 선택 도구에서 텍스트 도구로 전환할 때는 기존 텍스트 서식 변경을 위해 선택을 유지한다.

## 판정과 입력

- 회전을 반영한 객체 외곽 사각형이 영역과 겹치거나 닿으면 선택한다. 이미지 투명 여백과 필기 외곽 상자의 빈 공간도 포함한다.
- 구성 객체 하나가 걸리면 보이는 묶음 구성 객체 전체를 선택·제외한다. 숨김 객체·속지 배경은 제외하고 잠금 객체의 편집 제한은 유지한다.
- 드래그 중 경로·예상 선택만 표시하고, 손을 떼면 selectExact로 한 번 반영한다. 문서·저장 형식·요소 좌표·실행 취소 이력은 선택 작업으로 변경하지 않는다.
- 입력 면의 크기를 명시하고 한 손가락의 화면 좌표 차이를 직접 추적한다. 확대 배율과 현재 페이지 경계를 반영한다. Android 입력에는 웹 마우스 버튼 판정을 적용하지 않는다.
- 화면상 이동 10px 미만 및 면적 없는 경로는 무시한다. 두 손가락은 상위 확대·이동으로 넘기며 진행 중인 올가미를 취소한다. 페이지·도구·형태·모드·배율 전환도 진행 중 경로를 버린다.
- 일반 선택 도구의 기존 영역 지정 방식은 유지한다. 읽기 모드에서는 편집 기능을 제공하지 않는다. 추가 의존성·서버 API·데이터 마이그레이션은 없다.

## 검증 상태와 사용자 확인 항목

### 후속 수정: 확정 윤곽과 이동 시작 영역

- 관련 Jira: [S15P31F106-175](https://ssafy.atlassian.net/browse/S15P31F106-175). 최신 develop 2f68c98에서 분리한 올가미 변경이며 레이어 다중 이동·브랜딩 변경은 포함하지 않는다.

- 자유형·사각형 확정 윤곽과 이동 입력 범위를 일치시켰다. 기존 중앙 스냅·한 번의 Undo 체크포인트·잠금 제한을 사용하며 두 손가락 취소 시 이동을 복원한다. 일반 선택 도구의 입력 영역·회전·크기 조정은 유지한다.
- 이번 변경은 문법·공백만 확인한다. 자동 테스트·빌드·앱 화면·실기기 검증은 수행하지 않았다. 아래 157번 기록은 이전 구현의 검증이며 이번 변경의 검증 결과가 아니다.
- 사용자 확인: 두 형태의 확정 후 사각 조절점 숨김, 점선 안 빈 공간에서 이동, 객체가 점선 밖으로 걸친 부분에서 이동 시작 안 됨, 확대·스냅·Undo/Redo, 추가/제외, 취소·도구 전환.

### 157번 윤곽 유지 수정 검증

- `node --test tests/lasso-outline.test.js tests/lasso-input.test.js tests/element-selection.test.js`: 14개 통과. 자유형/네모형 선택 차이, 단일·다중 윤곽 보존, 마지막 해제 좌표, 공통 이동·되돌리기, 선택·페이지·요소 변형 시 해제, 추가 경로 보존과 제외 경로 미표시를 확인했다.
- 전체 `node --test tests/*.test.js`: 226개 중 220개 통과. 실패 6개(`templates.test.js` 5개, `diary-library.test.js` 1개)는 기준 develop `385460b`에서도 같은 테스트가 실패하며 이번 변경과 무관하다.
- 웹 브라우저(Playwright Chromium, 1280×800, 1024×768 페이지)에서 확인했다. 자유형 확정 후 점선 윤곽 1개 유지(사각 프레임 없음), 선택 요소를 끌면 윤곽도 같은 거리(100.2, 40.9)만큼 이동, 네모 형태로 바꾸면 윤곽 해제, C 선택 → A 추가(윤곽 2개) → A 제외 후 C 윤곽 1개만 남음. pageerror 0건.
- 윤곽은 사용자가 그린 경로를 그대로 보여 준다. 선택 집합의 기하학적 합집합 외곽선을 새로 만들지 않으므로, 한 경로가 제외한 요소와 남은 요소를 함께 감쌌다면 그 경로는 남는다.
- iPad에서 자유형 윤곽 유지·이동·확대·도구 전환을 확인하는 검증은 남아 있으며 Jira는 진행 중이다.

### 기존 133번 검증 기록

사용자 요청으로 에이전트 자동 테스트·번들 빌드·수동 화면 확인·실기기 조작은 수행하지 않았다. Expo Go 연결을 준비하고 사용자 피드백으로 수정했지만 최종 동작 통과를 확인한 것은 아니다. MR은 검토용 Draft로 올리고 Jira 완료로 처리하지 않는다.

- 네모·자유형의 부분 겹침, 경계 접촉, 회전 객체 및 자유형 자기 교차.
- 묶음 선택·제외, 숨김·잠금 처리와 기존 문서 보존.
- 추가·제외 대기 중 선택 표시, 새 범위 지정 및 취소.
- 선택 후 기존 이동·회전·크기 조정·편집 바·키보드 조작.
- 상세 창 바깥 터치·× 닫기·다시 열기, 확대 배율, 페이지 전환, 읽기 모드.

APK 생성은 포함하지 않는다. 커밋·푸시·MR 생성은 사용자의 별도 요청에 따라 진행한다.
