# 툴바 옵션 UI 통일 (S15P31F106-139)

## 공통 기준

- 펜·형광펜·지우개·텍스트·올가미·스티커·마스킹테이프·사진은 클릭한 아이콘의 실제 창 좌표를 측정한다. 창의 가로 중심을 아이콘에 맞추고 편집 영역 좌우 8pt 안으로 제한한다.
- 툴바 아래에 8pt 간격을 두며 하단 조작 영역 64pt를 확보한다. 긴 내용은 기존 ScrollView로 스크롤한다. 고정된 왼쪽/오른쪽 구분은 사용하지 않는다.
- 기본 도구 옵션 폭은 320pt, 모서리는 20pt, 본문 좌우 여백은 16pt다. 스티커·테이프·사진 보관함의 기존 크기 조절과 기억 기능은 유지한다.
- ToolPanelHeader와 toolPanelStyles를 공용으로 사용한다. 제목은 도구 아이콘 18pt + 이름 15pt/700 + 40pt 닫기 버튼이며 섹션 제목은 12pt/700이다. 표면은 불투명 흰색, 같은 테두리·그림자를 사용한다.
- 스티커 목록 편집 버튼은 공통 헤더의 추가 동작 슬롯에 유지한다.
- 내보내기는 상단 내보내기 버튼 아래, 버튼 오른쪽 끝을 기준으로 연다. 페이지 선택을 위해 최대 600pt 폭을 유지하고 창 너비·높이 안으로 제한한다. 헤더·표면·본문 여백은 도구 옵션과 같다.

## 유지하는 기능

- 펜 종류·굵기·색상·프리셋·직선 보정, 지우개 크기, 텍스트 서식, 올가미 형태의 기존 콜백을 유지한다.
- 스티커 검색·분류·목록 편집·삽입, 테이프 구성·자르기, 사진 불러오기 및 보관함 크기 조절 로직을 유지한다.
- 내보내기의 페이지 선택·범위·PDF 생성·PNG 미리보기·저장 정책은 변경하지 않는다. 내보내기 결과·미리보기 화면까지 새로 설계하는 작업은 포함하지 않는다.
- 저장 데이터·서버 API·이미지 원본 처리 형식은 변경하지 않는다.

## 최근 불러온 사진 목록 삭제 (S15P31F106-201)

- 사진 썸네일의 휴지통 버튼을 누르면 목록 삭제 확인 창이 열린다. 취소하면 목록을 유지하고, 확정하면 선택한 항목만 제거한다.
- 목록 삭제는 현재 화면의 최근 사진 목록만 변경한다. 캔버스에 배치한 사진·GIF, 편집 이력과 원본 미디어는 유지한다.
- 마지막 항목을 삭제해도 사진·GIF 불러오기 버튼은 유지한다. 최근 목록의 기존 세션 단위 수명은 변경하지 않는다.
- 삭제 확인·취소·개별/마지막 항목 제거·캔버스 참조 유지·빈 목록 불러오기를 코드 실행으로 검사했다. 기존 미디어 테스트 25개 통과, iOS 개발 번들 HTTP 200 확인. iPad 실기기 QA는 남아 있다.

## 검증

- Windows Chrome 155 / 1280×800 / 격리된 문서에서 8개 도구의 폭·아이콘 기준 세로 위치·화면 안 배치·닫기 각 3회, 총 24회 통과. 내보내기 열기·닫기 3/3 통과.
- 같은 실행에서 필기·부분 텍스트 서식·변형·지우개·Undo/Redo·저장 후 재진입 통합 시나리오 3/3 통과.
- Node 단위 테스트 201개 통과. 웹·Android Expo export 성공. 결과는 qa-editor-integration-results.json을 참조한다.
- Android 실제 터치 위치·키보드와의 가림·보관함 크기 조절·실제 내보내기 파일 저장의 최종 수동 확인은 남아 있다. 브라우저 UI 확인·번들 결과와 구분한다.

- 선 보정은 테두리 버튼 대신 ‘길게 눌러 직선 보정’ 설명과 기본 Switch로 표시한다. 펜·형광펜 리본 아이콘 원래 위치를 유지한 채 아이콘 오른쪽 아래 별도 6pt 원으로 각 도구의 현재 색상을 표시하고 설정 변경 시 즉시 갱신한다. 선택 활성 표시와 독립적으로 유지한다.

- 펜·형광펜은 현재 색상 원으로 직접 색상 피커를 열고 닫는다. 기존 공통 ColorPicker를 재사용하며 HEX 행 표시만 선택 옵션으로 추가해 중복 입력을 생략한다. 다른 도구의 기본 색상 피커 동작은 유지한다.

- 표시 제목은 ‘설정’을 생략한 펜·형광펜·지우개·텍스트·올가미·스티커·마스킹테이프·사진으로 통일한다. 보조기술용 닫기 버튼 이름은 기존 접근성 이름을 유지한다.
