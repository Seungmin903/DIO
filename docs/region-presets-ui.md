# 내보내기 영역 비율 프리셋 (S15P31F106-117)

## 기능

- 영역 선택 화면에서만 자유/정사각형 1:1/세로 피드 4:5/스토리 9:16을 제공한다. 페이지 골라/연속 범위 메뉴에는 추가하지 않는다.
- 프리셋 변경은 기존 중심을 가능한 유지하고 기존 영역 안에 맞는 최대 사각형을 우선한다. 최소 크기를 충족할 수 없으면 확장·이동하고, 페이지가 최소 영역을 담을 수 없으면 비활성화한다.
- 고정 비율 드래그·모서리 조절은 비율과 페이지 경계를 유지한다. 이동은 크기를 바꾸지 않는다. 자유로 전환하면 현재 영역을 유지한다. 경계 근처 작은 영역은 최소값을 강제하다 페이지 밖으로 넘치지 않으며 유효해질 때까지 확정을 막는다.
- 선택 좌표는 소수 논리 단위를 유지한다. 자유 출력 예상치는 2배/4096px/8MP 상한 안에서 비율을 유지해 floor한다. 고정 프리셋은 1080×1080 / 1080×1350 / 1080×1920이다.
- 필요 확대 m=max(pixelWidth/width,pixelHeight/height)가 3 이하이면 일반 안내, 3 초과~6 이하이면 명시적 화질 확인, 6 초과이면 확정 차단이다. 영역/프리셋/출력이 바뀌면 확인을 초기화한다.
- 자유 모드의 피드 권장 목표 0.8~1.91, 스토리 목표 9:16을 안내한다. 비율 경고만으로 선택 확정을 차단하지 않는다. 이는 DIO의 제품 목표이며 외부 플랫폼의 최신 전체 허용 범위 보장은 아니다.
- 원본 요소·문서·되돌리기·저장소는 변경하지 않는다. 확정 콜백은 pageId/region/preset/output/upscaleConfirmed를 전달한다. 실제 PNG 생성·저장은 118번이므로 아직 파일이 생성되지 않는다고 안내한다.
