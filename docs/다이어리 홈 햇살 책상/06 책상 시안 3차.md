### 1안 원목 밝은 쿨톤

요청(같은 날): "원목 상판 하나만 좀 더 밝고 좀 더 쿨톤이게도." 1안의 빈 책상만 색을 옮겼다. 흰색 쪽으로 28% 밝게, 노란 기는 그늘에서 절반 · 창빛에서 1/4만 빼서 햇살 느낌을 남기고, R −2 · B +4로 차갑게 했다. 나뭇결 · 창빛 모양 · 소품 · 배치는 1안 그대로다. 다시 만들기: `python "스크립트/상판 밝은 쿨톤.py" <원본 상판> <결과>` 뒤 합치기(`1안 원목 밝은 쿨톤`).

## 2. 지킨 것

- **시간:** 모두 오후 3시 하나로 고정. 왼쪽 위 십자 창에서 크림빛이 비스듬히 들어와 가운데 다이어리 위로 지나가고, 왼쪽 위 칩 · 제목 쪽에는 잎 그림자만 닿는다. 모든 그림자는 오른쪽 아래로 진다.
- **시점:** 위에서 곧장 내려다본 평면. 두께가 있는 소품(테이프 롤 · 키캡 · 코롯토 · 바인더 클립)은 윗면과 얇은 테두리만 보이게 그렸다. 놓는 자리가 바뀌어도 투시가 어긋나지 않는다. 두께는 그림자 길이로만 나타낸다(두꺼울수록 길고 흐리다).
- **UI는 실제 앱 그대로:** 지금 앱(게스트 · 다이어리 8권)을 1280 × 800으로 찍고 바탕색만 투명하게 뺀 층을 맨 위에 얹었다. 글자 · 버튼 · 표지는 손대지 않았다. 바꾼 것은 둘뿐이다.
  - 옆 다이어리는 투명도 0.36 대신 불투명하게 두고 표지에 흐린 막(52%)을 덮었다. 투명하면 책상 결이 표지를 뚫고 비친다.
  - 표지에 빛과 같은 방향(오른쪽 아래)의 그림자를 넣었다.
- **소품 자리:** 아래쪽 빈 책상 두 곳에만 둔다. 왼쪽 다이어리 이름 아래(레일 옆), 그리고 가운데 휴지통 오른쪽 ~ + 버튼 왼쪽이다. 제목 · 칩 · 보기 전환 · 검색 · 더보기 · 화살표 · 개수 · + 버튼 · 표지와 겹치는지 합치는 스크립트가 픽셀로 검사한다(4안 모두 겹침 0).
- **다이어리가 주인공:** 소품 하나는 가운데 표지 높이의 약 1/3 이하, 안마다 5 ~ 8개다.
- **마스코트:** 코덱스에 최종 시안 그림을 함께 넣고, 팔 · 손이 없다는 것과 모아 몸통 비율(폭이 높이의 약 0.9배)을 프롬프트에 못 박았다. 4안 소품 보드는 두 번 다시 그렸다. 첫 판은 팔이 생겼고, 둘째 판은 모아 코롯토가 길쭉했다.

`책상 시안 3차/소품/<안>/<이름>.png` — 투명 배경, 바르게 세운(회전 0) 원본 크기. 회전 · 크기 · 그림자는 화면에 놓을 때 정한다.

- 2안 '종이 클립 골드', 4안 '마스킹테이프 조각 라벤더'는 시안에 쓰지 않은 여분이다.
- 코덱스는 소품을 순수 마젠타 바탕 위에 그렸고, 스크립트가 마젠타를 지워 덩어리마다 잘랐다. 반투명 아크릴 테두리 · 금속 가장자리에 비친 분홍은 걷어 냈지만, 골드 클립에는 주황빛이 조금 남아 있다.

## 4. 다시 만들기

이 폴더에서:

1. 앱 화면 층: 웹을 내보낸 뒤(`npx expo export --platform web --dev --output-dir .expo/desk-web`, frontend/) `스크립트/앱 화면 찍기.cjs`로 ref · 검은 바탕 · 흰 바탕을 찍고 `스크립트/앱 화면 층.py`로 투명 층(ui.png)을 만든다.
2. 코덱스 작업: `python "스크립트/코덱스 책상 3차.py" make <작업 폴더> <표지 조각.png>` → 폴더마다 codex exec 로 out.png (하나씩).
3. 소품 자르기: `python "스크립트/코덱스 책상 3차.py" split <작업 폴더> <소품 폴더>`
4. 합치기: `python "스크립트/책상 3차 합치기.py" <상판 폴더> <소품 폴더> <ui.png> <결과 폴더>` — 배치는 스크립트의 `LAYOUT`(앱 좌표 1280 × 800)에 있다.

## 5. 정해야 할 것

- 네 안 중 방향 하나. 앱 바탕(`#F1F3F7`)과 가장 가까운 건 3안이고, 가장 '책상'다운 건 1안이다.
- 사이드 메뉴: 지금은 흰 판 그대로다. 책상이 메뉴 뒤까지 이어지는 떠 있는 판으로 바꿀지는 따로 정한다.
- 실제 앱에 넣을 때는 상판을 한 장 그림으로 깔고, 소품은 PNG로 놓는다. 화면 크기마다 소품 자리를 다시 잡아야 한다(폰 · 한눈에는 이번 범위가 아니다).
