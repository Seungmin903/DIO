# 햇살 책상 보관 코드

2026-11-01, 사용자 결정에 따라 다이어리 홈의 '햇살 책상'을 앱에서 완전히 뺐다. 빠진 기능은 다음과 같다.

- 시간대별 창빛
- 노을 · 가로등
- 밤 어둠과 흰 글씨
- 해 방향 표지 그림자
- 내 공간 '홈 책상 실시간 조명' 설정

나중에 되살릴 수 있게 뺄 때의 코드를 그대로 여기에 둔다.

## 들어 있는 것

`frontend/` 아래는 앱 안의 원래 경로 그대로다. 기준은 뺄 때의 develop(`abdf87c6`)이고, `DeskBackdrop.js`만 그 뒤 작업본(창빛을 오른쪽 위 44% · 38% 칸 안에서만 비춤)이다.

- 이 폴더는 앱 번들과 테스트에 들어가지 않는다. Metro는 import로 이어진 파일만 묶고, 테스트는 `frontend/`에서 `node --test tests/...`로 경로를 직접 지정해 돌린다. 저장소에는 jest · ESLint · Prettier 설정이 없다. 나중에 docs까지 훑는 도구를 넣으면 이 폴더를 제외 목록에 넣는다.
- `generate-desk-assets.py`의 `PROPS` 경로(`폴라로이드 디오와 두리 소풍` 등)는 코덱스가 소품을 만들 때의 원래 폴더 이름이라 마스코트 이름 정리에서 바꾸지 않았다. 소품 폴더는 저장소에 없고 실행할 때 인자로 넘긴다.

| 파일 | 하던 일 |
|---|---|

`연결 부분/`에는 뺄 때 고친 파일의 고치기 전 전체본이 들어 있다. 이 폴더는 참고용이므로 통째로 덮어쓰지 말고, 아래 연결 지점만 옮긴다.

- `App.js`
- `Cover.js`
- `OpenBookShelf.js`
- `DiaryCard.js`
- `LibraryScreen.js`
- `ProfileScreen.js`
- `styles.js`

## 연결 지점 (되살릴 때 다시 잇는 곳)

- **App.js**
  - 태블릿 보관함의 작업 영역 뒤에 `<DeskBackdrop anchorRight size={tabletDeskSize} />`를 깔았다.
  - 작업 영역 크기는 `deskSize` · `deskLayout` · `tabletDeskSize`로 쟀다.
  - 내용은 `s.deskAbove`로 감쌌다. 폰은 `DESK_ON_PHONE`으로 잠가 두었다.
  - 지금은 `desk && { backgroundColor: DESK_COLOR }` 단색만 깐다.
- **Cover.js**
  - `sunShadow` prop이 있으면 `useDeskHour`의 시각으로 `coverShadowAt(hour, big, deskLightAt(hour).lamp)` 그림자를 썼다.
  - 조명 모드가 `off`면 스타일의 고정 그림자를 썼다.
- **OpenBookShelf.js**
  - 책 그림자는 `coverShadowAt(...)`로 그렸고, 크기 배율은 `SHADOW_REF` 380 기준이었다.
  - `onDark`일 때 글씨 · 화살표를 흰색으로 바꿨고, 화살표 둘레는 `INK_DARK_HALO`로 그렸다.
- **DiaryCard.js · LibraryScreen.js**
  - `useDeskDark()`가 참이면 제목 · 페이지 수 · 화살표에 `s.onDeskDarkTitle` · `s.onDeskDarkSoft`를 입혔다.
  - LibraryScreen은 카드에 `sunShadow={!compact}`를 넘겼다.
- **ProfileScreen.js**: 태블릿에서 `<DeskLightSetting />`(환경 설정 섹션)을 보였다.
- **styles.js**: `workspaceDesk` · `deskAbove` · `onDeskDarkTitle` · `onDeskDarkSoft`.
- **상판 색**
  - `DESK_COLORS.base`(#F3F3F7)는 지금 `src/diary/constants.js`의 `DESK_COLOR`로 남아 있다.
  - 되살리면 `deskLight.js`의 `DESK_COLORS`와 하나로 맞춘다.

## 되살리는 순서

1. `frontend/` 아래 파일을 같은 경로로 되돌린다. 이 폴더의 사본 대신 git 기록에서 꺼내도 된다(이후 develop 이 바뀌어도 기준이 흔들리지 않는다). `DeskBackdrop.js` 는 그 뒤 작업본이라 이 폴더의 것을 쓴다.

   ```sh
   git checkout abdf87c6 -- frontend/src/diary/components/DeskLightSetting.js frontend/src/diary/utils/deskFx.js frontend/src/diary/utils/deskInk.js frontend/src/diary/utils/deskLight.js frontend/src/diary/utils/deskMask.js frontend/src/diary/utils/deskShadow.js frontend/src/diary/utils/deskTimeStore.js frontend/assets/desk frontend/scripts/generate-desk-assets.py frontend/tests/desk-light.test.js frontend/tests/cover-shadow-size.test.js
   ```

   `연결 부분/` 은 git 기록으로 바꾸지 않았다. 뺄 때의 작업 중 파일이라 `Cover.js` 말고는 어느 커밋과도 같지 않다.
2. 위 연결 지점을 `연결 부분/`의 원본을 보며 다시 잇는다.
3. 테스트 두 개를 되돌리고, 목업 · 테스트의 `deskInk` · `deskMask` 대역을 다시 넣는다. 대역을 쓰는 테스트는 다음 세 개다.
   - `diary-selection`
   - `grid-card`
   - `library-controls`

설계 배경은 이 폴더 상위의 01~06 문서와 `docs/앱 디자인 점검 원 페이저`에 있다.
