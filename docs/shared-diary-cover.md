# 회원 다이어리 표지 공유

회원 다이어리 목록·상세의 `diary.cover`는 표지 디자인이 저장된 경우 제공한다. 소유자는 `PATCH /api/v1/member/diaries/{diaryId}`에 `cover`와 최신 `expectedVersion`을 보내 수정한다. 세부 디자인이 없으면 기존 `coverColor`와 `coverStyle`을 사용한다.

사진과 직접 만든 스티커는 기존 `/media`로 업로드한 뒤 서버 미디어 ID와 `media:<id>` 참조를 저장한다. 기기 파일 경로나 공개 이미지 URL을 전달하지 않는다. 서버는 표지 변경 권한 및 참조할 이미지의 권한을 확인한다. 다이어리에 현재 참여한 사용자는 기존 인증 파일 API로 사진을 읽을 수 있다. 표지에 쓰이는 원본은 다이어리에서 참조가 제거되기 전까지 삭제할 수 없다.

새 다이어리를 만들거나 게스트 다이어리를 가져올 때는 생성 결과를 받은 뒤 표지를 저장한다. 후속 작업 실패 시 같은 다이어리로 재시도하고, 이미 서버에 저장된 표지는 덮어쓰지 않는다. 기존 앱에서 기기에만 저장된 표지는 원본이 있는 소유자 기기에서 다이어리를 다시 열면 업로드한다. 그 기기의 사진 원본을 더 이상 읽을 수 없다면 표지를 다시 선택해 저장해야 한다.

배포에는 `V32__share_diary_cover_design.sql` 마이그레이션과 프론트 업데이트가 모두 필요하다. 공유받은 사람이 보관함을 다시 불러오거나 다이어리를 열면 저장된 표지를 받는다.
