# 요소 선택·이동 (S15P31F106-94)

- 기존 Canvas의 필기·텍스트·사진·스티커 공통 선택·이동 구조를 유지한다.
- 탭은 단일 선택, 길게 누르기 또는 웹 Shift/Ctrl 클릭은 다중 선택에 추가·제외한다. 빈 곳 탭은 기존 근접 선택·해제 방식을 따른다.
- 이동은 화면 이동량을 현재 배율로 나누어 페이지 좌표에 반영하며, 기존 중심선 스냅을 유지한다.
- 잠금·숨김 요소는 이동하지 않는다. 묶음 선택에 숨김 요소 ID가 포함되어 있어도 해당 요소의 저장 좌표는 바꾸지 않는다.
- 일반 선택 도구의 영역 선택 도중 responder가 취소되면 시작 전 선택을 복원한다. 선택 자체는 문서와 Undo/Redo 이력을 변경하지 않는다.
- 팀원의 올가미 판정·사진 자르기·그룹 선택 방식은 변경하지 않는다. 로컬 저장 형식과 서버 API 변경·마이그레이션은 없다.

## 검증

- `node --test tests/element-selection.test.js`: 실제 Canvas 입력 핸들러와 reducer를 연결해 단일·다중 선택, 길게 누르기, 빈 곳 해제, 영역 선택 취소, 숨김·잠금 보호를 확인한다.
- 화면 배율 0.5/1/2.5에서 필기·텍스트·사진·스티커의 동일한 페이지 이동량을 확인한다.
- OS 터치 전달과 실제 Android 에뮬레이터 수동 확인은 별도로 수행해야 한다.

## 크기 조절 (S15P31F106-95)

- 기존 SelectionOverlay를 재사용한다. 필기·텍스트는 모서리·변, 사진·스티커는 비율을 유지하는 모서리, 테이프는 길이 조절 손잡이를 제공한다.
- 회전된 요소의 반대편 모서리·변을 고정하며, 논리 최소 크기는 20이다. 웹 커서는 현재 요소 회전을 반영한다.
- 텍스트의 왼쪽·오른쪽 변은 글씨의 현재 표시 크기를 유지하고 폭·줄바꿈만 바꾼다. 기존 `baseWidth`를 새 폭에 맞춰 조정하며 기존 텍스트 높이 계산으로 줄바꿈 높이를 갱신한다. 회전 상태에서는 반대쪽 윗점을 고정한다. 모서리는 기준 폭을 유지해 박스와 글씨를 함께 확대·축소한다. 펜·형광펜 변형 규칙은 유지한다.
- 드래그 시작 배율로 화면 이동량을 환산한다. 두 손가락 조작 등 responder 취소 시 조절 전 좌표·크기로 복원한다. 회전과 공유하는 핸들 입력에도 동일한 취소 처리가 적용된다.
- 단순 탭이나 최소 크기에서 더 줄이는 등 실제 변화가 없는 입력은 작업 이력을 추가하지 않는다. 실제 크기 변경은 드래그당 한 단계로 기록한다.
- `node --test tests/element-resize.test.js tests/element-selection.test.js`: 10개 통과. 배율 0.5/1/2.5와 회전 0/37/90/225도에서 고정점·좌표·최소 크기·취소 복원·웹 커서 방향·기존 종류별 핸들 규칙을 확인했다.
- Android 및 웹 실제 화면 조작은 별도 수동 확인이 필요하다. 저장 형식·서버 API·마이그레이션 변경은 없다.

## 회전 (S15P31F106-96)

- 기존 공통 회전 핸들과 Canvas 각도 배지를 유지한다. 회전 손잡이를 누르면 현재 각도를 표시하고, 끄는 동안 갱신하며 손을 떼거나 취소하면 배지를 숨긴다.
- 회전 손잡이는 기존 앱 색상의 28px 원 안에 가는 흰색 곡선 화살표 두 개를 표시하여 크기 조절 손잡이와 구분한다. 얇은 테두리·옅은 그림자를 사용한다. 아이콘은 터치를 가로채지 않으며 회전 드래그는 기존 공통 핸들에서 처리한다.
- 저장 각도는 수평 기준 0 이상 360도 미만이며, 배지는 반올림한 정수로 표시한다(360은 0으로 표시). 0/90/180/270도 근처 ±3도에서는 기존 스냅을 유지한다.
- 확대 배율과 기존 회전을 반영하며 요소 중심·크기를 유지한다. 정상 종료 시 회전값을 유지하고 responder 취소 시 원래 각도로 복원한다. 단순 탭은 이력을 추가하지 않는다.
- `node --test tests/element-resize.test.js tests/element-selection.test.js`: 16개 통과. 배율 0.5/1/2.5, 다양한 시작·목표 각도, 직각 스냅, 0도 경계 순환, 값 유지·취소·Undo/Redo를 검증했다.
- 실제 에뮬레이터에서 회전 손잡이·각도 배지·확대 후 회전은 사용자 확인이 필요하다. 저장 형식·API 변경은 없다.
