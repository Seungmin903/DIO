# 계정 삭제 요청 운영 절차 (내부용)

담당자·운영 책임자: 신승민. 공식 접수: dioapp.official@gmail.com. 새 API·테이블 없이 기존 메일과 탈퇴 기능을 이용한다. 이 문서는 공개 HTML/Google Docs에 포함하지 않는다.

## 접수와 기한

- 영업일마다 공식 메일함의 신규 요청·스팸함·진행 요청을 점검한다. 목표는 접수 후 3영업일 이내 접수·본인 확인 안내, 본인 확인 완료 후 10일 이내 삭제 처리·결과 통지다. 법령에 더 짧은 기한이 있으면 그 기한을 우선한다. 추가 확인·법정 제한·장애가 있으면 지연 사유와 다음 안내 예정일을 기한 전에 통지하고 진행 기록에 남긴다.
- 비밀번호·인증번호·Access/Refresh Token·신분증 원본을 이메일로 요구하거나 기록하지 않는다. 등록 메일 회신과 필요한 최소 확인으로 요청자 권한을 확인한다. 원문 정보는 공개 이슈·Git 저장소·단체 채팅에 복사하지 않는다.
- 담당자 부재 전 공식 메일 접근 권한을 가진 적법한 대체 담당자를 지정하고 미처리 건·기한만 제한적으로 인계한다. 지정 가능한 사람이 없으면 운영자가 직접 처리 가능한 일정을 확보해야 하며, 장기 부재 중 신규 가입·외부 공개를 진행하지 않는다. 존재하지 않는 대체 담당자를 문서만으로 지정했다고 간주하지 않는다.

## 최소 진행 기록

접근 제한된 운영 기록에 요청 번호, 접수일, 계정 확인에 필요한 최소 식별값, 본인 확인 결과·시각, 담당자, 처리 기한, 상태·지연 이유, 실제 삭제 범위·실행 시각, 결과 통지 시각을 적는다. 비밀번호·토큰·사진 본문은 기록하지 않는다. 메일 제목/라벨과 접근 제한된 운영 문서를 사용할 수 있으나 신규 외부 서비스로 옮길 경우 해당 위탁·국외 처리도 확인한다.

요청 완료·결과 전달과 필요한 후속 처리 종료 후 관련 메일·첨부·휴지통·진행 기록을 지체 없이 삭제한다. 법적 분쟁 등 별도 보존이 필요하면 근거·항목·목적·기간을 구분해 승인하고 분리 보관한다. 임의의 무기한·1년 보관 규칙을 추가하지 않는다.

## 처리와 검증

1. 본인 확인 및 요청 범위 확인. 단순 앱 삭제를 탈퇴 완료로 보지 않는다.
2. 기존 탈퇴 서비스로 계정 직접 식별정보·자격증명·세션·푸시 연결 정리. 소유권 이전이 필요한 공유 다이어리는 다른 참여자 권리를 확인한 뒤 절차 안내. 운영 DB를 임의 SQL로 고치거나 타인의 작성물을 함께 삭제하지 않는다.
3. 탈퇴 확정 후 해당 계정의 양방향 차단 관계를 [탈퇴 계정 차단 관계 정리 절차](report-retention-operations.md#탈퇴-계정의-차단-관계)에 따라 지체 없이 정리한다. 담당자는 신승민이며, 확인 당일 처리·확인 후 24시간 이내 완료를 운영 기준으로 한다. 앱에서 직접 탈퇴한 계정도 매일 1회 이상(주말·공휴일 포함) 잔존 관계를 조회하고, 정리 후 재조회 결과·건수·실패 재시도 예정 시각을 접근 제한된 최소 운영 기록에 남긴다. 해당 기준과 실패 인계·기록 파기는 연결된 절차를 따른다.
4. 개인 다이어리·참조 없는 미디어·계정 사진의 삭제 대상과 실행 결과 확인. 미디어의 24시간 유예·1시간 주기 등 본문 기준 및 실패 재시도 확인. 다른 공동 작성물에 필요한 최소 참조가 남는 경우 이유와 범위를 기록한다.
5. 결과를 요청 연락처로 통지. 남는 자료·근거·기한·기기/내보낸 사본의 범위를 구분해 안내. 메일 실패 시 반송·재전달을 점검한다.
6. 미처리 요청과 배치 실패·탈퇴 계정 차단 관계 잔존을 매일 점검. 미확인 정리 작업을 성공으로 종결하지 않는다.

## 공개 전 시험

운영자가 관리하는 차단 관계가 있는 테스트 계정으로 앱 외 요청 → 접수 → 본인 확인 → 실제 탈퇴·양방향 차단 관계 등 후속 정리 → 통지를 한 번 수행한다. 앱에서 직접 탈퇴한 계정도 일일 조회로 발견하고 정리되는지, 실패 건은 다음 조회에 남아 재시도되는지 별도로 확인한다. 데이터·로그에 비밀값이 없는지, 메일함 접근과 부재 시 처리가 가능한지 확인한 뒤 `publication-approval.json`의 deletionOperations를 승인한다. 이 절차 파일만 추가한 것은 시험 완료가 아니다.
