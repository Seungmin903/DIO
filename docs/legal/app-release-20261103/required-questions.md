# 남은 최소 확인 사항

2026년 11월 3일 정리. 앞서 적은 7개 질문 모두가 법정 필수 기재 항목이거나 지금 새로 답해야 할 질문이라는 뜻은 아니다. 공개 자료 조사와 구현·게시 작업을 사용자 확인 질문에 섞었던 범위를 아래와 같이 줄인다.

## 실제 운영 사실이어서 남는 확인

1. **이전에 “추가 확인 필요”라고 한 AWS 콘솔 항목만 확인해 주세요. 실제 DB 백업·스냅샷·S3 버전 관리 또는 저장소 밖 로그·분석 수집이 있나요? 없다면 “없음”, 있다면 저장 위치·수집 항목·보관 기간을 알려 주세요.**
   - 이미 콘솔을 확인해 미사용이라고 답한 항목은 재확인하거나 다시 답할 필요가 없습니다. 처음 답변의 '설정 파일에 없음'과 '실제 콘솔 확인 필요' 부분만 남습니다.

2. **일반 접속·오류 로그를 용량 순환 외에 최장 며칠까지 보관하고 어떻게 삭제할지 정해 주세요. 관리자 접속기록은 관련 보존·점검 기준을 충족하는 별도 관리가 가능한가요?**
   - 10MB × 7개는 이미 반영했습니다. 모든 일반 로그에 고정 1년을 요구한다는 뜻이 아닙니다. 운영자가 보유 기준·파기 방법을 정할 부분이며 실제로 적용할 기준만 기재합니다.

## 출시 시 정하면 되는 항목 — 지금 답변 불필요

- 실제 시행일과 최종 공개 URL은 게시·배포 시 확정합니다. 같은 버전으로 이미 동의받은 공개 문서가 있으면 새 문서를 덮어쓰지 않도록 당시 원본을 확인합니다.
- 삭제 요청 메일 접수·본인 확인·삭제·결과 안내는 이미 정한 담당자 신승민과 공식 이메일을 기준으로 운영 절차를 적용·검증합니다. 담당자와 이메일을 다시 묻지 않습니다.
- 푸시는 활성화 예정이라는 답변을 반영합니다. 실제 전달 정보는 코드와 출시 설정을 작성자가 대조하며, 설정 밖 추가 처리가 있을 때만 별도로 확인합니다.

## 작성자가 조사·검토할 부분 — 사용자 추가 질문 아님

Gmail·Expo의 업체명, 공식 소재지/연락 창구, 공개된 처리 국가·보관 설명은 공식 문서로 조사해 처리방침에 반영했습니다. 일반 개인 계정을 쓴다는 이유만으로 별도 DPA·계약 명의 서류를 일괄 제출하라고 요구하지 않습니다. 공개 자료가 밝히지 않은 메일별 국가·고정 보관 일수나 DIO에 적용할 국외 이전 근거는 임의 확정하지 않으며, 작성자가 추가 공식 자료·적용 근거를 검토할 과제로 남깁니다. 이 공개 자료 보완만으로 국외 이전 법적 요건이 모두 충족됐다고 선언하지 않습니다.
