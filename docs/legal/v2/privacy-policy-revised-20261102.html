제1조 개인정보 처리의 기본 원칙

1. DIO는 다이어리를 사진·스티커·마스킹테이프·그림·텍스트·손글씨 등으로 꾸미고 저장·내보내며, 회원 간 다이어리를 공유하고 공동 편집하는 서비스입니다.

2. 기기에만 저장하는 자료와 회원 기능을 이용하면서 서버에 전송·저장하는 자료를 구분합니다. 공유·서버 저장 기능을 이용하는 자료까지 모두 기기에서만 처리하는 것은 아닙니다.

3. 운영자는 기능 제공에 필요한 최소한의 개인정보를 처리하고, 안내한 목적과 적법한 처리 근거를 벗어나 이용하지 않습니다.

4. DIO는 앱 화면에 배너·전면·보상형 광고를 게재하지 않습니다. 광고식별자를 이용해 다른 앱·웹사이트 이용을 추적하는 광고를 제공하지 않습니다.

5. DIO 자체 이벤트·새 기능 등의 홍보 이메일·광고 푸시는 앱 화면의 광고 게재와 구분합니다. 실제 도입 시 별도 선택 동의와 철회 기능을 갖춘 뒤 동의한 범위에서만 제공합니다.

제3조 수집 방법과 처리 근거

1. 회원가입·프로필 등록·파일 업로드·초대·문의 등 이용자가 직접 입력하거나 선택한 자료를 처리합니다. 서비스 이용 과정에서 계정·세션·작업·알림 정보가 생성됩니다.

2. 동의를 근거로 처리하는 정보는 수집 목적·항목·보유 기간·거부권과 영향을 안내하고 동의를 받습니다. 선택 프로필 사진이나 마케팅 이용을 기본 서비스 필수 동의에 포괄하여 포함하지 않습니다.

3. 이용자가 요청한 다이어리 저장·공유·공동 편집 등 계약 체결·이행에 필요한 처리는 개인정보 보호법 제15조제1항제4호 등 해당 근거에 따라 처리합니다. 동의가 필요한 추가 처리까지 계약 이행이라는 이유로 확대하지 않습니다.

4. 법정 열람·정정·삭제·처리정지 등 권리행사 요청은 개인정보 보호법상 의무와 관련 규정에 따라 처리합니다. 문의 답변에 필요한 정보는 이용자가 요청한 상담·서비스 제공 범위에서 처리합니다.

5. 별도 법적 근거로 개인정보를 보존하거나 제공해야 하는 경우에는 해당 법령·목적·항목·기간을 구분합니다. 근거 없이 모든 이용 기록에 일률적인 법정 보관 기간을 적용하지 않습니다.

제4조 기기 내 처리·AI 기능·내보내기

1. 기기에만 저장한 편집 자료는 해당 기기에서 처리합니다. 서버에 저장된 자료와 기기 내부 자료는 별개이므로 앱 삭제만으로 서버 회원정보·공유 다이어리가 모두 삭제되지는 않습니다.

2. 손글씨 폰트 생성은 지원되는 Android 빌드에서 이용자가 입력한 손글씨를 기기 내 모델로 처리합니다. 초안·작업 파일·완성 폰트는 기기에 저장하며, 폰트 생성만을 위해 손글씨를 외부 생성형 AI 사업자에게 자동 전송하지 않습니다. 지원하지 않는 실행 환경에서는 실제 생성 기능이 제한될 수 있습니다.

3. 사진 속 대상을 분리하는 서버 기능을 이용하면 이용자가 선택한 이미지와 분리 요청 정보가 DIO 백엔드를 통해 AI 처리 서버로 전달됩니다. 분리를 위한 임시 이미지·특징 정보와 이용자가 저장하는 결과 파일은 구분됩니다. 현재 처리 코드에서는 이미지와 특징 정보를 프로세스 메모리에 임시 보관하고, 결과 이미지는 메모리에서 만들어 반환합니다. 임시 자료를 영구 파일로 저장하는 경로는 없습니다. 기본 캐시는 최근 사용 사진 최대 32개, 마지막 사용 후 30분이 지난 자료는 후속 조회에서 만료 처리하며 공간 부족 시 오래된 항목을 제거합니다. 주기 타이머로 정확히 30분 뒤 모두 지우는 구조는 아니므로 요청이 없으면 프로세스 종료·교체나 캐시 정리 전까지 메모리에 남을 수 있습니다. 실제 배포값과 처리 서버 위치는 공개 전에 확인합니다.

4. 배경색을 기준으로 스티커를 분리하는 단순 이미지 처리는 손글씨 글자 생성이나 서버 대상 분리와 구분됩니다.

5. 이용자의 다이어리·사진·손글씨를 DIO 홍보물로 재사용하거나 광고 분석·모델 재학습에 사용하는 것은 본 방침으로 허용받는 처리에 포함하지 않습니다. 다른 목적의 처리를 도입할 때는 별도의 적법한 근거와 필요한 안내·동의 절차를 먼저 갖춥니다.

6. PNG·PDF 또는 사용자가 선택한 파일을 사진첩·파일 앱·외부 서비스로 내보내면 해당 내용과 파일명에 포함된 정보가 선택한 위치로 전달될 수 있습니다. 외부에 저장한 사본은 이용자가 해당 위치에서 직접 관리·삭제해야 합니다.

7. PDF 공유용 임시 사본에는 생성·공유 처리 시점을 기준으로 24시간의 만료 시간을 설정하고 앱 시작이나 다음 공유 시 정리합니다. 앱 실행 여부·정리 결과에 따라 더 오래 남을 수 있으므로 정확히 24시간 후의 삭제를 보장하지 않습니다.

제5조 개인정보의 보유·이용 기간

정보보유·이용 기준
회원 계정회원 이용 기간 동안 보유합니다. 탈퇴 완료 시 이메일·로그인 자격증명 등 계정 식별정보를 삭제·익명화합니다. 공유 콘텐츠와 연결된 내부 식별정보는 아래 공동 작업 기준에 따라 최소한으로 처리합니다.
이메일 인증·비밀번호 재설정 검증정보인증번호와 후속 토큰이 모두 만료된 후 24시간이 지난 정보를 정리 대상으로 처리합니다. 배치 실행 시점·처리량·장애에 따라 실제 삭제에는 추가 시간이 들 수 있습니다.
로그인 세션·토큰 회전 이력세션 만료 후 정리합니다. 로그아웃·비밀번호 변경·탈퇴에 따른 폐기와 물리 삭제는 구분하며, 만료 정리 작업에서 세션과 관련 회전 이력을 삭제합니다.
약관 동의이용 기간에 종류·버전·상태·시각을 관리합니다. 같은 버전의 상태가 변경되면 최신 상태로 갱신하며, 현재 탈퇴 처리에서는 해당 계정의 동의 행을 삭제합니다. 탈퇴 후 영구 증빙 보관을 약속하거나 보관하는 정책은 포함하지 않습니다.
다이어리·첨부자료이용자가 저장·관리하는 동안 보유합니다. 휴지통 이동은 30일간 복원할 수 있으며, 이후 정리 대상이 됩니다. 명시적 영구 삭제·마지막 멤버 나가기 등은 복원 대상이 아닙니다.
공유 다이어리의 공동 작업·연결정보다이어리가 유지되는 동안 다른 참여자의 작업·복원에 필요한 공동 작성 내용과 최소 연결정보가 남을 수 있습니다. 탈퇴자의 이메일·개인 별칭·사진을 계속 공개하기 위한 목적은 아닙니다. 불필요해진 연결정보는 정리하며 개인 식별정보 삭제 요청은 별도로 검토합니다.
공동 편집 실행 취소 이력최근 작업의 복원에 필요한 상세 스냅샷을 정리합니다. 중복 요청 방지용 식별 기록과 상세 내용의 수명은 다를 수 있으며, 모든 이력이 일률적으로 80건 또는 80일 후 삭제되는 것은 아닙니다. 최종 메타데이터 정리 기준은 공개 전 확인표에 명시합니다.
계정 사진·서버 미디어사용 중에는 보관합니다. 삭제·탈퇴 후 다른 콘텐츠가 참조하지 않는 자료를 정리하며 파일 삭제 실패는 재시도합니다. 공유 콘텐츠에서 사용 중인 미디어는 함께 보존될 수 있습니다. 현재 기본 삭제 유예는 삭제 표시 후 24시간이며 미디어 자동 정리는 기본 비활성화입니다. 활성화한 경우 기본 1시간 간격으로 정리합니다. 탈퇴 계정 사진은 기본 5분 간격의 별도 작업에서 삭제를 시도하고 실패하면 재시도합니다. 실제 배포의 활성화 여부·설정 변경은 공개 전에 확인하며, 기본값만으로 정해진 시간 내 삭제를 보장하지 않습니다.

선택 마케팅 정보 — 실제 도입 시동의 철회·회원 탈퇴·마케팅 운영 종료 중 먼저 도래하는 때까지 이용합니다. 채널별 동의와 철회가 준비되기 전에는 기존 통합 동의나 기기 알림 허용만으로 광고를 발송하지 않습니다.
서버 로그·백업실제 저장 항목·기간·백업 교체 및 삭제 절차를 제12조 확인표에 확정해 공개합니다.

제6조 삭제·탈퇴·파기

1. 이용자는 앱에서 가능한 자료를 직접 삭제하거나 공식 문의처로 권리행사를 요청할 수 있습니다. 운영자는 목적이 달성되거나 기간이 지난 자료를 복구·재생하기 어렵도록 파기합니다.

2. 다이어리 휴지통 보관 기간이 끝나면 정리 작업에서 관련 자료를 영구 삭제합니다. 실제 실행 지연·파일 삭제 재시도·백업 교체는 화면에서의 삭제와 구분합니다. 다른 다이어리나 소재가 사용하는 파일은 함께 삭제하지 않습니다.

3. 탈퇴 시 본인이 단독 소유한 다이어리는 영구 삭제하며, 다른 참여자가 있는 소유 다이어리는 먼저 소유권을 양도하도록 안내할 수 있습니다. 공유 다이어리에 남아 있는 공동 작업이나 다른 참여자가 내보낸 사본까지 탈퇴로 자동 소멸하지 않습니다.

4. 계정 프로필 사진과 사용하지 않는 개인 미디어는 정리 대상에 포함하되 저장소 삭제 실패 시 재시도합니다. 탈퇴 완료 응답과 모든 저장소·백업의 동시 물리 삭제가 같은 뜻은 아닙니다.

5. 기기 자료는 앱 기능이나 Android의 저장 데이터 삭제·앱 제거, iOS의 앱 삭제 등으로 관리할 수 있습니다. iOS의 ‘앱 정리하기’는 데이터를 남길 수 있습니다. 운영자는 기기에만 있는 자료나 이용자가 외부로 내보낸 사본을 원격으로 회수할 수 없습니다.

6. 휴대폰 사진첩의 원본 사진은 DIO 안에서 자료를 삭제했다는 이유로 삭제하지 않습니다. 법령에 따른 별도 보존이 필요한 자료는 다른 목적에 이용하지 않고 해당 기간 종료 후 파기합니다.

제7조 공유 기능과 외부 전달

1. 참여자가 있는 다이어리의 내용·첨부자료·프로필·참여 상태·편집 정보는 권한 있는 다른 참여자에게 표시됩니다. 초대 링크를 받은 사람도 수락 전 화면에서 제공되는 범위의 다이어리 정보와 정원 상태를 확인할 수 있습니다.

2. 이메일 초대는 입력한 이메일을 통해 가입된 수신자를 확인하고 앱 내 초대·알림으로 전달합니다. 초대 메일을 발송하는 기능과는 다릅니다. 휴대폰 푸시는 별도 등록·권한·발송 설정에 따릅니다.

3. 계정 사진은 공개 조회 주소를 통해 표시될 수 있습니다. 다이어리별 사진은 참여 권한 확인 경로를 사용하지만, 계정 사진을 선택하면 공개 계정 사진 주소의 특성이 적용됩니다. 별칭·사진을 정하지 않은 경우 계정 프로필이 표시될 수 있습니다.

4. 이용자는 공유 범위와 참여자를 고려해 자료를 등록해야 합니다. 원하지 않는 민감한 정보는 업로드·공유하지 않을 수 있으며, 등록한 자료의 삭제·참여자 관리·신고 기능 또는 문의처를 이용할 수 있습니다. 이미 다른 참여자가 저장·내보낸 자료까지 회수되는 것은 아닙니다.

5. 운영자는 이용자 정보를 제휴사 광고 목적으로 임의 제공하지 않습니다. 개인정보 제3자 제공에 해당하는 별도 전달을 도입하면 제공받는 자·목적·항목·기간과 필요한 법적 근거·동의 절차를 갖춥니다. 법령에 따른 적법한 요청은 정해진 절차에 따라 처리합니다.

제8조 기기 접근 권한

사진을 가져오거나 PNG를 사진첩에 저장할 때 운영체제의 사진 선택·저장 기능을 사용하고 필요한 범위의 권한을 요청합니다. PDF 저장·공유에는 운영체제의 파일·공유 기능을 사용합니다. 서비스 푸시를 표시하려면 운영체제의 알림 권한이 필요할 수 있습니다.

이용자는 기기 설정에서 권한을 변경할 수 있습니다. 거부하면 해당 기능이 제한될 수 있으나 그 권한이 필요하지 않은 기능까지 제한하지 않습니다. 알림 권한 허용은 광고성 정보 수신 동의가 아닙니다.

제9조 개인정보 처리업무 위탁 및 국외 이전

운영자는 이메일·서버 저장·파일 전달·푸시 등 업무를 외부 업체에 맡기는 경우 실제 수탁업체와 업무 범위를 공개하고 필요한 관리·감독을 수행합니다. 배포 구성은 PostgreSQL DB와 Amazon S3 파일 저장소를 사용하도록 설정돼 있고, 기본 S3 리전은 서울(ap-northeast-2)입니다. 이는 저장소 구성 확인이며 실제 계약 주체·버킷 리전·복제·국외 접근을 확인했다는 뜻은 아닙니다. 계정 사진과 미디어는 같은 저장소 설정을 사용합니다. 실제 수탁자와 국외 이전 사항은 제12조 확인표에서 확정합니다.

회원가입·비밀번호 재설정 메일은 개인 Gmail 계정의 SMTP를 사용해 수신 이메일 주소·인증번호가 포함된 메일 제목과 본문을 전달합니다. 비밀번호 원문·다이어리 본문·프로필 사진을 인증 메일 내용에 넣지 않습니다. 초대는 앱 내 알림으로 처리하며 초대 이메일을 발송하지 않습니다.

현재 코드에는 Expo Push Service를 통한 초대 푸시 발송·수신 상태 확인과 앱의 기기 등록·클릭 처리가 구현돼 있습니다. 활성화 설정을 갖춘 배포본에서만 사용합니다. Expo로 전달하는 내용은 기기 푸시 토큰, 일반적인 초대 안내 제목·본문 및 초대 식별번호이며, 다이어리 본문·사진·수신자 이메일을 푸시 내용에 넣지 않습니다. 실제 발송 활성화 여부와 Expo 및 하위 전달 서비스의 위탁·국외 처리 정보는 공개 전에 확정합니다.

문의도 개인 Gmail 계정으로 접수합니다. 발신 이메일·문의 내용·첨부자료는 Google LLC의 Gmail 서비스에서 처리되며 서비스 운영에 따라 국외에서 처리될 수 있습니다. 운영자 관리 사본은 처리 완료 후 삭제하지만 Google 시스템 내 사본 삭제에는 추가 시간이 소요될 수 있습니다. Google 개인정보처리방침은 서비스 제공자의 일반 안내이며, DIO의 구체적인 이전 국가·법적 근거·기간 확인을 대신하지 않습니다.

외국 업체 이름이나 S3 기본 리전만으로 실제 이전 국가를 단정하지 않습니다. 국외 저장·처리·접근이 있다면 이전받는 자·연락처, 국가, 항목, 시기·방법, 목적, 기간, 적용 근거와 거부 방법·영향을 확정하고 필요한 고지·동의 등 절차를 먼저 갖춥니다. 일반 가입 동의가 모든 국외 이전 동의를 대신하지 않습니다.

제10조 안전성 확보와 자동 수집

운영자는 권한 있는 담당자만 개인정보를 취급하도록 관리합니다. 서버 비밀번호는 BCrypt 해시값으로 저장하며, 푸시 토큰과 최초 등록 자격증명 응답은 서버 키를 사용하는 AES-GCM 암호문으로 관리합니다. 전체 DB·파일·백업이 모두 같은 방식으로 암호화된다는 뜻은 아닙니다.

앱 잠금을 설정하면 4자리 PIN의 원문 대신 임의값을 결합한 SHA-256 검증값을 계정별 기기 저장소에 보관하고 앱 접근을 확인합니다. 이는 다이어리 파일 전체를 암호화하는 기능이나 휴대폰 자체 보안을 대신하는 기능이 아닙니다. 서버 로그인 토큰은 현재 인증 클라이언트의 메모리에서 관리합니다. 개발 서버 접속용 자격증명은 별도 보안 저장 경로와 구분됩니다.

공용 배포 설정에는 Nginx HTTPS와 TLS 1.2·1.3, HTTP의 HTTPS 전환, 프록시 뒤의 백엔드 연결이 정의되어 있습니다. 실제 서버 적용·인증서 관리·관리자 접근권한·저장소와 백업 암호화는 공개 전에 확인합니다.

앱은 저장·복원·로그인 유지에 필요한 기기 내부 저장소를 이용합니다. 앱 내 광고 게재를 위한 광고식별자 기반 추적은 운영하지 않습니다. 현재 앱의 직접 의존성과 앱 코드에서 Sentry·Firebase Analytics·Google Analytics·Amplitude·Mixpanel 등 이용 행태 분석·자동 오류 보고 도구의 연결은 확인되지 않습니다. 사진·파일·기기 설정은 앱 내부 파일·AsyncStorage 등으로 처리하며 일부 보안 정보는 용도별로 구분합니다. 이는 Expo Go·개발 도구·배포 호스팅 자체의 처리를 모두 조사했다는 뜻은 아닙니다. 실제 배포본에 추가 도구나 웹 쿠키·외부 스크립트가 있는지는 별도로 확인하고, 있다면 항목·목적·외부 전송·기간·거부 방법을 반영합니다.
