# 인프라 담당자에게 추가 확인할 질문

2026-11-03. 이미 받은 서울 리전·백업 없음·용량 로그 순환·푸시 비활성 답변은 다시 묻지 않습니다. 비밀키·비밀번호·토큰·계정번호는 보내지 말고 설정 결과만 알려 주세요.

1. PostgreSQL DB도 앞서 확인한 서울 EC2에서 실행되는 Docker DB가 맞나요? 실제 DB 볼륨이 위치한 EC2 리전도 서울인지 확인해 주세요. AWS 청구서의 서비스 판매·계약 법인명과 계정 보유 주체(개인/학교/회사 중 구분)도 알려 주세요. 한국 계정의 일반 계약 법인은 AWS Korea로 안내되지만 실제 청구서 기준으로 확인하려는 것입니다.
2. 백엔드·Nginx 로그는 Docker 용량 순환 외에 파일 마운트, 호스트 journald, CloudWatch, 에이전트나 다른 로그 수집기로도 저장되나요? 있다면 저장 위치·국가·보관 기간·삭제 방식만 알려 주세요. 없다면 없다고 확인해 주세요.
3. Nginx 오류 로그에는 업스트림 오류 때 원문 URL·쿼리·Referer가 남을 수 있다는 소스 주석이 있습니다. 실제 배포 설정에서도 초대 토큰 등이 남는지 확인해 주세요. 남는다면 오류 로그 접근 제한과 삭제 방법을 어떻게 적용하고 있는지 알려 주세요. 실제 토큰이 포함된 로그 원문은 공유하지 말아 주세요.
4. EC2의 DB·앱 데이터 EBS 볼륨 암호화가 켜져 있나요? S3 기본 암호화는 SSE-S3/SSE-KMS 중 무엇인가요? SSH 접근 허용 범위, DB 포트 외부 차단, 관리자 접근 제한이 실제로 적용돼 있는지도 확인해 주세요. 상세 IP·키 값 없이 적용 여부만 주셔도 됩니다.
5. 현재 실행 중인 서버에서 휴지통 자동 삭제, 미디어 물리 삭제, 푸시 대기열 정리의 활성 여부를 각각 확인해 주세요. 기본값은 꺼져 있는 것으로 받았으므로 실제 배포 값이 다른 경우에만 값과 주기를 알려 주세요. 활성화는 별도 협의 후 진행하며 이 질문 자체로 설정 변경을 요청하는 것은 아닙니다.
6. 현재 실행 앱의 Expo 푸시 토큰 등록도 꺼져 있나요, 아니면 외부 발송만 꺼져 있나요? 클라이언트 토큰 발급·등록 기능이 켜져 있다면 실제 사용하는 Expo 프로젝트·FCM/APNs 경로와 토큰 전송 여부를 담당자가 확인해 주세요. Expo Go 개발 테스트와 배포 앱은 구분해 주세요.

## 인프라 담당자에게 답을 요구하지 않는 우리 쪽 과제

- 새 30일 정리 정책에 필요한 코드·삭제 검증은 우리 개발 과제입니다. 현재 꺼진 작업은 활성화 협의 전 자동 삭제를 약속하지 않습니다.
- Docker 용량 순환만으로 일수 상한이 생기지 않습니다. 로그 목적·최장 기간·필요한 적용 방식은 운영자가 확정할 사항입니다.
- 개인 Gmail의 일반 국가 간 처리와 삭제 안내는 공식 자료로 조사했습니다. 실제 처리 국가가 공개 자료로 특정되지 않는 문제는 인프라 담당자에게 추측을 요구하지 않습니다. 운영자가 제공자 문의 또는 다른 메일 서비스 사용을 검토하고 위탁·국외 이전 근거를 확정해야 합니다.
- 마케팅 증빙 1년 보관의 법적 근거·최소 항목과 이력 저장 구현은 광고 시작 전 운영·개발 검토 과제입니다.
- 시행일·게시 URL·공개 전 내부 메모 제거는 운영·문서 작업입니다.

## 직접 확인한 범위

- infra/compose/compose.prod.yml: DB URL은 내부 db:5432, 인증 세션 정리 기본 활성, 미디어 물리 삭제 기본 비활성, 로그 10m × 7 설정입니다. 실제 서버 상태를 대신하지 않습니다.
- infra/nginx/prod/default.conf 및 dev/default.conf: 접속 로그는 초대 경로·쿼리·Referer를 제한하지만 오류 로그는 별도 주의가 명시되어 있습니다.
- Google 공식 방침: 전 세계 처리와 일반 삭제 과정은 확인 가능하지만 DIO 개인 Gmail의 실제 국가 목록·고정 보관 SLA는 특정하지 못합니다.
- AWS 공식 안내: 계정 국가에 따른 계약 법인과 S3 신규 객체 기본 암호화는 확인 가능하지만 실제 청구 주체·EBS·버킷 설정은 콘솔 확인이 필요합니다.
