# 개인정보 운영 기준 및 인프라 확인표

확인일: 2026년 11월 3일. 담당자·운영자·개인정보 보호책임자: 신승민. 문의: dioapp.official@gmail.com.

이 문서는 내부 적용표다. 인프라 담당자의 제공 답변과 저장소 설정을 구분하여 정리했다. 실제 서버·AWS 콘솔 전체를 직접 점검했다는 의미가 아니다. 보존 기간은 DIO가 채택한 운영 기준이며 업계 평균이나 법정 의무 기간으로 단정하지 않는다. 이번 작업은 문서 수정이며 배치·환경변수·API·DB를 변경하지 않는다.

## 3. 공개 전 남은 확인

1. DB 실제 위치 및 AWS 계약 법인명·계정 주체.
2. 개인 Gmail 사용에 적용되는 위탁·국외 처리 국가, 기간, 연락처, 근거와 거부 시 영향. Google 일반 문서만으로 DIO의 개별 처리 국가를 확정하지 않는다.
3. 로그 최장 보관일과 삭제 절차, 오류 로그의 토큰·개인정보 잔류 여부.
4. 꺼진 삭제 배치 활성화 및 새 보존 정책의 실제 파기 구현·검증. 문서만으로 삭제된다고 공지하지 않는다.
5. SSH/UFW·관리자 접근권한·EBS 및 실제 S3 암호화·저장소 밖 수집 도구.
6. 광고 개시 전 별도 증빙 보존 근거와 간편 거부·채널별 차단, 푸시 활성화 시 실제 외부 처리 사항.

## 4. 공식 참고

- [개인정보 보호법](https://www.law.go.kr/법령/개인정보보호법): 처리·파기·위탁·공개 및 국외 이전의 적용 근거를 실제 처리에 맞춰 검토한다.
- [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko): 전 세계 서버 처리 일반 안내. 개인 Gmail의 DIO별 국가 확정 자료는 아니다.
- [Google 보관 안내](https://policies.google.com/technologies/retention?hl=ko): 삭제 과정·백업의 일반 설명이며 DIO 전용 삭제 보증이 아니다.
- [AWS 데이터 프라이버시](https://aws.amazon.com/compliance/data-privacy-faq/): 리전 선택과 제공자 처리의 일반 안내.
- [S3 저장 암호화](https://docs.aws.amazon.com/AmazonS3/latest/userguide/UsingServerSideEncryption.html): 신규 객체 기본 암호화 안내. 실제 버킷 방식을 콘솔에서 확인한다.
- [Expo 푸시 FAQ](https://docs.expo.dev/push-notifications/faq/): 활성화 전 실제 처리 범위를 다시 확인한다.

## 5. 추가 확인 결과

코드의 배포 기본값과 공식 제공자 문서를 다시 대조했다. AWS 공식 계약 법인 표는 한국 계정에 Amazon Web Services Korea LLC를 안내하지만 이 프로젝트 계정의 실제 계약 주체는 청구서로 확인한다. S3 신규 객체는 공식 기본 암호화 대상이므로 ‘암호화 미설정’으로 기재하지 않는다. EBS 암호화와 실제 버킷 방식은 별도다.

인프라 담당자에게 보낼 질문은 [추가 질문 6개](infra-followup-questions-20261103.md)로 한정했다. Gmail 국외 이전의 적법한 근거, 로그 일수 정책, 마케팅 증빙 근거, 새 삭제 정책 구현은 인프라 담당자에게 법적 판단을 요구하지 않고 운영·개발 과제로 분리한다.

기존 삭제 코드·경계·경합 테스트 결과와 설정 전달 경로는 [검증 결과](deletion-verification-20261103.md)에 기록했다. 정리 기능이 있는 항목과 아직 없는 항목을 구분하며 실 배포 활성화는 하지 않았다.
