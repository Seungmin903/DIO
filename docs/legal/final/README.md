작성 기준일: 2026년 11월 11일.

문안 검토 기준: 원격 release/v2.0.0 `247ed916`. 별도 기능 브랜치는 아래 배포 의존성으로 구분하며 실행 서버 적용을 뜻하지 않는다. 운영자·개인정보 보호책임자·문의 담당자: 신승민. 공식 연락처: dioapp.official@gmail.com.

## 전달 파일

- `index.html`: 문서 목록. 브라우저에서 먼저 확인한다.
- `service.md` / `service.html`: 이용약관, SERVICE v2.
- `privacy-consent.md` / `privacy-consent.html`: 필수 개인정보 수집·이용 동의, PRIVACY v2.
- `privacy-policy.md` / `privacy-policy.html`: 갱신 개인정보 처리방침. 열람 문서이며 별도 필수 동의가 아님.
- `marketing-privacy-consent.md` / `.html`: 선택 마케팅 개인정보 이용, MARKETING_PRIVACY v1.
- `ad-email-consent.md` / `.html`: 선택 광고 이메일, AD_EMAIL v1.
- `ad-push-consent.md` / `.html`: 선택 광고 푸시, AD_PUSH v1.
- `ad-night-push-consent.md` / `.html`: 선택 야간 광고 푸시, AD_NIGHT_PUSH v1.
- `account-deletion.md` / `.html`: 앱 외부 계정·데이터 삭제 요청 안내. 새 동의 항목·새 API가 아님.
- `app-documents.json`: 앱 내 오프라인 열람을 위한 7개 문서와 별도 지원 문서 1개.

수정 원본은 이 폴더의 Markdown이다. 저장소 루트에서 `python docs/legal/build_final.py`를 실행하면 HTML·JSON을 같은 원본에서 다시 만든다. 기존 `v2/` 및 `app-release-20261103/`는 이 빌드가 덮어쓰지 않는다. ZIP은 생성·커밋하지 않는다. 승인 후 전달 파일의 범위는 [게시 체크리스트](../release-checklist.md)를 따른다.

같은 빌드가 `frontend/src/shared/legalContent.json`도 갱신한다. 가입 화면의 기존 보기 버튼은 이 내장본을 읽는 `LegalDocumentScreen`에 연결했다. 문서의 독립된 ‘동의합니다’ 문장은 제거했고 앱의 ‘동의하고 돌아가기’만 해당 체크 상태를 true로 바꾼다. 닫기·Android 뒤로가기는 상태를 바꾸지 않는다. 개인정보 처리방침에는 동의 동작을 제공하지 않는다. 실제 서버 동의 저장은 기존 가입 완료 요청의 agreements를 사용한다. 새 API·테이블은 없다.

## 게시·연결

이 폴더는 **현재 받은 정보에 따른 최종 문안 전달본**이며 배포·법적 요건 충족·스토어 심사 완료 인증이 아니다. HTML은 사용자용 문서로 정리하고 개발 메모·미확정 사항은 이 README에 분리했다. JSON의 `publicationReady=false`는 남은 적용 조건을 임의로 완료 처리하지 않기 위한 표시다.

1. 사용자 지정 시행일은 2026년 11월 11일이며 문서 본문·HTML·JSON의 effectiveDate를 일치시켰다. 스토어 심사 승인일과 문서 시행일은 별개다. 테스트 이용자에게도 적용 문서를 제공하고 필요한 동의를 받으며 실제 시각과 버전을 기록한다. 시행일보다 먼저 테스트 가입을 받는 경우 적용 시점을 먼저 맞춘다. 작성자가 이번 리뷰에서 기존 v2 공개·동의 이력이 없음을 확인해 최초 공개 후보의 v2를 유지한다. 이후 공개·동의받은 버전의 내용은 덮어쓰지 않는다. 확인 내용과 최초 공개 해시 기록은 게시 체크리스트를 따른다.
2. [게시 체크리스트](../release-checklist.md)의 승인 조건을 모두 충족한 뒤 공개 HTTPS HTML 또는 Google Docs 읽기 전용 주소를 스토어에 등록한다. 저장소·검토 묶음 전체를 게시하지 않는다. 가입 화면은 내장 문서를 읽으므로 본문 열람에 네트워크가 필요 없다. 앱 정보의 공개 링크와 스토어 URL 게시, 실제 배포는 별도 확인한다.
3. 문안 검토 기준의 코드에는 초대 7일 만료·완료 초대 및 삭제 알림 정리 구현이 존재한다. 이 브랜치 파일이나 실제 배포와 혼동하지 말고, 실행 서버의 버전·배치·삭제 결과를 게시 전에 확인한다. 푸시·미디어·휴지통 정리도 합의한 정책에 맞게 배포하고 확인한다. 꺼진 정리 배치를 문서 작성만으로 켠 것으로 보지 않는다. 계정 삭제 안내의 공식 메일 접수·본인 확인·실제 삭제·결과 통지도 운영한다.
4. Gmail·Expo는 공식 공개 정책을 조사해 업체·처리 업무·공개된 국외 처리·보유 설명을 반영했다. 공식 자료에 없는 특정 국가·고정 기간이나 DIO의 국외 이전 법적 근거는 임의로 확정하지 않았다. 필요한 구체 고지·근거 검토가 끝나기 전 공개 준비 완료로 간주하지 않는다. 이는 사용자에게 기존 질문을 반복한다는 뜻이 아니다.
5. 문안 검토 기준의 코드에서 백엔드·Nginx 로그가 `json-file`, 최대 `10m × 7개`, 압축·용량 순환인 것을 확인했다. 날짜 기준 정리와 저장소의 백업 자동화는 확인되지 않았다. AWS 콘솔의 실제 미사용까지 코드로 보증하지 않는다. 목적 종료 시 파기·관리자 접속기록 관리는 별도 운영 의무다.

문안에 '백업이 전혀 없다', '모든 개인정보가 서울에서만 처리된다', '심사 통과가 보장된다'는 확인되지 않은 보증을 넣지 않았다. 실제 백업·추가 수집이 확인되면 해당 범위를 반영한다. 같은 내용을 다시 질문하는 별도 서류 제출을 일률적으로 요구하지 않는다.

## 화면 표시·검증

문서는 가로 표·고정 본문 높이 없이 구성했다. HTML은 한국어·UTF-8·시스템 글꼴·기기 너비·최대 본문 너비·큰 글자·다크 모드를 지원하고 외부 글꼴·스크립트 없이 표시한다. 앱에 연결할 때도 세로 스크롤·안전 영역·글자 확대를 유지한다.

데스크톱 브라우저의 반응형 확인과 네이티브 iOS·Android 실기기 검증은 다르다. 제출용 앱에서 최종 문서 열람·스크롤·확대·화면 읽기·회전을 확인한다. 검토용 공개 페이지는 본문이 표시되는지뿐 아니라 로그인 없이 접근 가능한지도 확인한다.

문구 근거와 상세 심사 검토는 이전 묶음의 `review-20261103.md`, 공개 자료 출처는 각 방침의 제공자 링크를 참고한다. 이전 보고서는 점검 시점 기록이며 이 폴더의 게시 준비 상태를 자동 승인하지 않는다.

## 2026년 11월 9일 문안 반영

위 문안 검토 기준에 맞춘 문서 작업이다. 신고·차단, 개인정보 없는 운영자 신고 알림, Google·Apple 소셜 인증의 실제 수집 항목, 보안 저장소 로그인 유지 및 항목별 마케팅 동의 설정을 반영했다. 과거 개인정보 처리방침 원본과 역사 보관 폴더는 변경하지 않았다. 운영자가 기존 문서를 공개·동의 전 초안으로 확인했으므로 SERVICE/PRIVACY v2·선택 항목 v1을 유지한다. 모든 문서의 시행일은 2026-11-11이다(11월 11일 변경). 파일 수정만으로 실제 앱·서버 배포나 공개 승인이 완료된 것은 아니다.

신고 자료는 완료 시각부터 30일 경과 후 정리 대상으로 삼되, 현재 공개 문안은 운영자의 보관 필요성·법적 보존 확인 및 수동 정리를 기준으로 한다. 별도 기능 `feature/be/report-retention-cleanup`에는 `ae000f4a`로 법적 보존 제외·증빙 파싱 실패 시 신고 유지가 보완됐고, `85bf7c6e`로 기본값 false·설정 누락 시 비활성 처리가 반영됐다. 이 별도 구현을 문안 검토 기준 release에 포함된 것으로 간주하지 않는다. V32·V33 적용, 기능 병합·배포와 실제 저장소 정리를 확인하기 전에는 활성화하지 않는다. [신고 정리 전달서](../report-retention-operations.md)에 따라 운영 승인 후에만 true를 명시하고 그때 공개 문구도 실제 운영과 맞춘다. 수동 정리 담당·주기·실행 결과가 준비되지 않으면 공개 승인할 수 없다. 탈퇴 계정의 차단 관계는 별도 수동 정리 대상이다.

## 2026년 11월 12일 저장·공유 안내 보완

최신 release/v2.0.0 `8dc26a6d` 기준으로 이용약관·개인정보 처리방침·계정/데이터 삭제 안내의 세 항목만 보완했다. 공개·동의 전 초안이라는 운영자 확인에 따라 SERVICE/PRIVACY v2와 기존 시행일 2026-11-11을 유지한다.

- 손글씨 폰트 공유 선택의 계정 단위 저장·기기 간 반영·향후 공유 다이어리 적용, 설정 해제 시 추가 공유 중단과 기존 공유 파일 비회수, 탈퇴 시 선택 기록·공유 연결 정리를 안내했다.
- 일반 초대 링크는 참여·로그인 전에도 원본 표지를 볼 수 있고 이메일 초대는 수신 계정 로그인이 필요하다는 점, 표지 미리보기가 내부 페이지 전체 공개와 다르다는 점을 명시했다.

스티커·폰트 생성 개수 제한은 출시에서 제외 예정이라는 요청에 따라 추가하지 않았다. 필수 개인정보 동의와 선택 마케팅 네 문서는 변경하지 않았다. 새 동의 항목·API·화면·제한 기능은 만들지 않았다.

기존 Google Docs 3종을 문단 단위로 수정하고 전체 본문 재조회로 기대 문안, 제목·목록 구조와 링크 보존을 확인했다. 앱 내장 JSON·생성 HTML·원본 Markdown·Google Docs 본문을 대조했다. Google Docs를 포함한 문서 수정은 앱·서버 배포 또는 공개 승인 완료를 뜻하지 않는다.
