# DIO 개인정보 처리방침

문서 버전: v2

시행일: 2026년 11월 11일

운영자: 신승민

문의: [dioapp.official@gmail.com](mailto:dioapp.official@gmail.com)

이 방침은 신승민(이하 “운영자”)이 제공하는 DIO Android·iOS 앱과 계정·저장·공유 서비스에 적용됩니다.

## 1. 적용 범위 및 처리 원칙

DIO는 사진·스티커·마스킹테이프·그림·글·손글씨 등을 배치해 다이어리를 만들고, 회원끼리 공유·공동 편집하거나 파일로 내보내는 서비스입니다. 기기에만 보관하는 자료와 서버에 저장·공유하는 자료를 구분합니다.

필요한 최소한의 개인정보만 처리합니다. 동의를 받는 경우 목적·항목·기간·거부권을 구분해 안내합니다. 이용자가 요청한 저장·공유 등 계약 이행에 필요한 처리는 개인정보 보호법 제15조제1항제4호 등 해당 근거에 따르며, 법령상 의무를 이행하기 위한 처리는 관련 근거에 따릅니다.

앱 화면에 배너·전면·보상형 광고를 게재하지 않으며 광고식별자를 이용한 다른 앱·웹사이트 추적 광고를 운영하지 않습니다. DIO 홍보 이메일·광고 푸시는 별도의 선택 동의 대상으로 구분합니다. 현재 마케팅 발송은 운영하지 않습니다.

## 2. 처리하는 개인정보 항목과 이용 목적

### 회원가입·로그인·비밀번호 관리

이메일 주소, 비밀번호의 해시값, 닉네임, 내부 회원 식별번호, 계정 상태, 가입·수정·로그인 시각을 회원 식별과 계정 관리에 이용합니다. 이메일 인증·비밀번호 재설정에는 인증번호·후속 토큰의 검증값, 유효기간, 시도 횟수와 처리 시각을 이용합니다. 세션·토큰 검증정보는 로그인 유지와 폐기에 이용합니다. 비밀번호 원문은 데이터베이스에 저장하지 않습니다.

소셜 로그인을 선택하면 실제 지원하는 Google·Apple 등 제공자의 계정 식별값, 제공자 종류, 검증된 이메일과 이메일 검증 여부, 인증 토큰의 검증정보를 회원 식별·가입·로그인에 이용합니다. Apple의 이메일 가리기를 선택한 경우 제공된 중계 이메일을 이용합니다. DIO가 제공자의 비밀번호를 수집하지 않으며 소셜 계정의 이름·사진을 자동으로 회원 프로필로 저장하지 않습니다. 앱에서 선택·입력한 닉네임과 선택 프로필 사진을 사용합니다. 제공자의 인증 화면에서 이루어지는 처리는 해당 제공자의 방침을 따릅니다.

### 약관·동의 관리

회원 식별번호, 약관 종류·버전, 동의·철회 상태와 시각을 이용자 선택 반영과 동의 관리에 이용합니다. 선택 마케팅 항목은 이메일·광고 푸시·야간 광고 푸시 등 종류별로 구분합니다. 손글씨 폰트 공유 선택은 회원 식별번호, 선택 상태·버전·변경 시각을 서버에 저장하여 같은 계정의 기기 사이에서 적용합니다. 이 기록은 회원 탈퇴 시 함께 삭제합니다.

### 프로필

닉네임, 선택한 계정 프로필 사진, 다이어리별 별칭·사진과 파일 식별정보를 참여자 표시와 프로필 설정에 이용합니다. 선택하지 않은 다이어리 사진에는 계정 사진이 표시될 수 있습니다. 사진 등록은 선택이며 별칭은 중복될 수 있습니다.

### 다이어리·공동 편집·소재

제목·표지·페이지 내용과 설정·순서, 글·필기·그림, 이미지·스티커·테이프 등의 첨부자료, 요소 위치·크기·회전·배치, 작업자 내부 식별정보·시각·변경 이력을 작성·저장·동기화·실행 취소·복원에 이용합니다. 파일 식별번호·저장 위치·이름·형식·용량·크기·등록 시각·분류·사용 참조를 파일 제공과 정리에 이용합니다. 사진 목록의 미리보기 제공과 반복 전송을 줄이기 위해 원본에서 축소한 썸네일을 만들어 원본과 같은 서버 저장소에 보관합니다. 원본 파일은 변경하지 않으며 썸네일도 조회 시 해당 파일의 현재 접근 권한을 확인합니다.

사진 원본에는 촬영 위치·시각·기기 등 EXIF 정보가 포함될 수 있습니다. 원본을 저장하는 경로에서는 이 정보도 함께 보관될 수 있으므로 공유 전에 확인해 주세요. 사진이나 필기를 생체인증이나 이용자 식별용 생체 분석에 사용하지 않습니다.

### 초대·참여자·앱 내 알림

입력한 수신자 이메일, 초대자·수신자·다이어리 식별번호, 역할·참여 상태, 초대 링크 검증정보, 생성·수락·거절·취소 이력, 알림 내용과 읽음 상태를 초대 전달·참여·권한 관리에 이용합니다. 가입한 활성 회원에게 앱 내 초대로 전달하며 초대 이메일을 별도 발송하지 않습니다.

이전 시점·방법은 가입 인증·비밀번호 재설정 요청 시 서버의 SMTP 전송, 이용자가 공식 문의처로 이메일을 보내거나 운영자가 회신하는 때의 이메일 전송·저장입니다. 이메일 전송·보관 목적에 필요한 수신 주소·인증 안내 또는 문의 내용만 처리하며 비밀번호·로그인 토큰을 이메일로 받지 않습니다. 국외 처리를 원하지 않는 경우 공식 문의처로 중단·삭제를 요청할 수 있습니다. 이메일 인증이 필요한 회원가입·비밀번호 재설정은 해당 이메일 처리를 거부하면 이용이 제한될 수 있습니다.

### 앱 내 사용자 신고·차단

공유 다이어리 멤버 메뉴에서 사용자를 신고하면 신고자·신고 대상의 내부 회원 식별번호, 해당 다이어리 식별번호, 신고 사유, 선택 상세 설명(최대 1,000자), 선택 증빙 사진(PNG·JPEG 최대 3장, 장당 5MiB), 접수·처리 시각과 상태를 처리합니다. 운영자의 검토·조치 내용, 판단 근거·처리 담당자·변경 이력, 중복 접수 방지용 요청 식별번호·검증값과 운영자 알림 발송 상태도 관리합니다. 피해 확인·권리침해 대응·부정 이용 방지에 필요한 범위에서만 사용합니다. 신고 건수만으로 자동 제재하지 않습니다.

증빙 사진은 서버에서 이미지로 검증·재인코딩해 비공개 저장소에 보관하며 검토 권한이 있는 운영자만 확인합니다. 신고와 무관한 제3자의 개인정보, 민감정보·신분증 등은 가리거나 제외해 주세요. 불필요하게 제출된 정보는 검토 과정에서 삭제·축소합니다. 신고 대상자에게 신고자 정보나 증빙을 자동 공개하지 않으며, 법령상 적법한 요구가 있는 경우 해당 범위에서 별도 처리합니다.

차단한 회원과 차단된 회원의 내부 식별번호, 차단 시각을 저장해 초대 제한과 차단 목록·해제 기능을 제공합니다. 차단은 기존 공유 다이어리의 참여 권한이나 공동 작성물을 삭제·숨기는 기능이 아닙니다. 이미 함께 참여 중이면 상대의 작업을 계속 보고 편집할 수 있습니다. 이메일 초대는 양방향 차단 관계에 따라 제한하며, 내가 차단한 회원이 참여 중인 다이어리에 링크로 새로 참여할 때는 경고 확인 후 참여할 수 있습니다.

운영자에게 보내는 신고 알림 이메일은 ‘새 신고가 접수됐습니다’라는 안내만 포함합니다. 신고 번호·사유·회원 정보·접수 시각·설명·사진·증빙 주소는 이메일에 포함하지 않습니다. 실제 신고 내용과 증빙은 데이터베이스·비공개 저장소에서 권한 있는 운영자가 확인합니다.

### 기기 푸시

푸시 기능을 이용하는 경우 앱 설치 식별정보, 플랫폼, 기기 권한·활성 상태, 푸시 토큰과 검증정보, 계정·세션 연결정보 및 필요한 알림 내용을 등록·알림 전달·오발송 방지에 이용합니다. 활성 푸시 토큰은 암호화해 보관합니다. OS 알림 권한은 광고 수신 동의가 아닙니다.

### 사진 분리·손글씨 폰트

사진 속 대상 오리기를 요청하면 선택한 사진, 대상 선택에 필요한 위치·붓질 정보, 마스크와 결과 이미지, 임시 작업 식별정보를 처리합니다. 손글씨 폰트 생성을 요청하면 입력한 글자의 획·샘플, 폰트 이름, 생성 상태·모델 정보 및 생성 파일을 처리합니다. 사진 분리와 폰트 생성은 이용자가 기능을 선택할 때 이루어집니다.

### 문의·신고·접속 정보

공식 Gmail 문의에는 발신 이메일, 문의 내용·첨부자료, 답변과 필요한 최소 본인 확인 정보를 이용합니다. 통신·보안·요청 제한에는 IP 주소·접속 시각·요청 경로·User-Agent·응답 상태 등 접속 정보를 처리합니다.

## 3. 개인정보 수집 방법 및 기기 내 처리

이용자가 직접 입력·선택·업로드하거나 서비스를 이용하면서 생성하는 정보를 처리합니다. 기기에만 저장한 비회원 자료는 이용자가 계정으로 옮기기·공유 등을 선택하기 전까지 서버 자료와 구분됩니다. 옮기기는 자료를 회원 보관함에 저장한 뒤 기기 원본을 삭제하는 방식이며, 옮기지 못한 항목이 있는 다이어리의 원본은 기기에 남습니다.

손글씨 폰트 생성은 모델이 포함된 Android·iOS 앱에서 DM-Font 기반 생성 모델을 이용해 기기 안에서 처리합니다. 입력한 손글씨를 바탕으로 나머지 글자를 생성하며, 이 생성 과정에서 입력 획·샘플을 서버로 보내지 않습니다. 초안, 작업 파일과 생성된 폰트는 기기에 보관합니다. 공유를 선택한 뒤 공유 다이어리에서 해당 폰트를 사용하면 폰트 파일과 연결 정보를 서버에 저장하고, 그 다이어리의 참여자가 같은 글꼴로 표시할 수 있도록 내려받습니다. 공유 선택은 계정 단위이며 다른 기기와 앞으로 참여하는 공유 다이어리에 적용됩니다. 설정의 ‘공유 다이어리에 내 폰트 공유’에서 바꿀 수 있습니다. 끄면 이후의 추가 공유를 중단하며, 이미 공유한 폰트와 다른 참여자가 받은 파일을 일괄 회수·삭제하지는 않습니다. 이 선택을 거부해도 다이어리의 기본 기능은 이용할 수 있습니다.

사진 속 대상 오리기는 DIO 백엔드를 거쳐 같은 AWS EC2 서울 리전의 내부 AI 서버에서 SAM 2 모델로 처리합니다. AI 서버에는 선택한 사진과 대상 선택에 필요한 좌표·작업 식별정보를 전달합니다. 원본 사진은 요청 처리 중 임시로 사용하며 데이터베이스나 S3에 저장하지 않습니다. 업로드 처리 중 임시 파일이 생기면 요청 종료 시 정리합니다. 사진·이미지 특징값·선택 좌표는 로그에 기록하거나 외부 AI 서비스로 보내지 않으며, 모델 재학습에도 사용하지 않습니다. AI 서버는 축소한 사진과 이미지 특징값을, 백엔드는 작업을 해당 이용자와 연결하는 정보를 각각 메모리에 임시 보관합니다. 기본 만료 기준은 마지막 사용 후 30분입니다. 만료된 자료는 후속 처리에서 정리하며, 메모리 보관 한도를 넘으면 오래 사용하지 않은 항목부터 제거합니다. 처리 프로세스가 종료되면 메모리에 남은 임시 자료는 사라집니다. 이용자가 저장을 선택하면 결과 스티커 PNG를 계정의 미디어로 보관하며, 보유와 삭제에는 다이어리·소재 파일 기준을 적용합니다.

이용자 콘텐츠를 DIO 홍보·광고 분석이나 모델 재학습에 사용하지 않습니다. 그러한 목적을 추가할 때는 별도 적법한 근거와 필요한 안내·동의를 먼저 마련합니다.

## 4. 개인정보 보유 및 이용 기간

### 계정·인증·약관

계정은 회원 서비스 제공 기간 동안 보유하고 탈퇴 완료 시 이메일·닉네임·로그인 자격증명 등 식별정보를 삭제하거나 개인을 직접 나타내지 않는 값으로 변경합니다. 인증번호와 후속 토큰이 모두 만료된 인증정보는 만료 후 24시간 경과 시 정리 대상으로 처리합니다. 액세스 토큰 기본 유효시간은 15분입니다. 로그인 유지 세션은 최초 로그인 시 기본 30일 동안 유효하며, 유효한 세션을 정상 갱신할 때마다 갱신 시각부터 기본 30일로 연장하되 해당 기기의 최초 로그인부터 최대 90일을 넘지 않습니다. 로그아웃·탈퇴·세션 폐기 또는 만료 시 로그인 유지를 종료하며, 만료된 세션과 관련 토큰 이력을 정리합니다. 사용 폐기와 데이터베이스 행의 물리 삭제는 구분됩니다.

약관의 종류·버전·동의 상태·시각은 회원 이용 중 관리하고 탈퇴 시 삭제합니다. 마케팅 증빙의 별도 보존은 실제 발송 전에 근거와 기간을 정해 안내하며 임의의 장기 보관 기간을 적용하지 않습니다.

### 다이어리·공동 작업·사진

휴지통으로 이동한 다이어리는 삭제 후 30일 동안 복원할 수 있고 기간 경과 후 영구 삭제합니다. 명시적 영구 삭제와 마지막 참여자의 나가기는 휴지통 복원 대상이 아닙니다.

공동 다이어리에 참여자가 한 명 이상 있으면 페이지·글·그림·사진·스티커와 공동 작업 제공에 필요한 이력을 유지합니다. 실행 취소용 상세 스냅샷은 기능에서 제공하는 보관 개수에 따라 먼저 정리될 수 있어 모든 상세 이력이 무기한 유지되는 것은 아닙니다. 중복 반영 방지를 위한 작업 식별번호·검증값은 필요한 최소 범위에서 다이어리·페이지 삭제 시까지 유지합니다.

다이어리 영구 삭제나 마지막 참여자 이탈 시 다이어리·페이지·캔버스 요소·관련 스냅샷·변경 이력·초대·연결 미디어 참조를 함께 삭제합니다. 다른 문서에서 계속 쓰는 미디어는 해당 사용이 끝날 때까지 보관합니다. 참조가 없는 삭제 대상 미디어는 24시간 유예 후 1시간 간격 정리로 S3 원본과 해당 원본에서 생성한 썸네일을 함께 삭제합니다. 정상 처리 기준 약 24~25시간이 소요되며, 장애로 지연되면 복구·재시도해 처리합니다. 이는 최종 참조가 사라져 삭제 대상으로 표시된 때를 기준으로 하며 모든 파일이 처음 삭제 버튼을 누른 시점부터 25시간 안에 삭제된다는 의미는 아닙니다.

### 초대·알림

수락·거절·취소된 초대 원본은 처리 완료 후 7일 동안 보관한 뒤 영구 삭제합니다. 사용자가 삭제한 앱 내 알림은 삭제 후 7일 동안 보관한 뒤 영구 삭제합니다. 대기 중인 이메일 초대는 발송 후 7일이 지나면 만료 처리하고 영구 삭제합니다. 다시 초대하려면 새 초대를 생성합니다. 이 정책은 읽었지만 삭제하지 않은 앱 내 알림 전체를 7일마다 삭제한다는 의미는 아닙니다.

중복 처리 방지에 필요한 최소 기록은 관련 요청의 재시도 가능 기간까지만 유지하며 초대 내용 전체를 무기한 남기는 데 이용하지 않습니다.

### 푸시 등록정보·발송 기록

활성 푸시 토큰은 등록 기기에 알림을 제공하는 동안 보유합니다. 로그아웃·탈퇴·기기 해제·토큰 무효화 시 즉시 발송 대상에서 제외합니다. 비활성 기기 등록정보·암호화된 토큰·등록 요청 이력은 비활성화 후 최대 30일 이내에 삭제합니다.

발송 대기열은 생성 후 최대 30일, 처리 결과·중복 발송 방지 기록은 최종 처리 후 최대 30일 동안 보관한 뒤 삭제합니다. 만료된 등록 응답 암호문은 별도 만료 정리로 삭제합니다. 기기 차단과 기록 삭제는 구분됩니다.

### 앱 내 신고·차단 기록

미처리 신고는 사실 확인과 필요한 후속 처리 기간 동안 보관하며, 보관 필요성을 정기적으로 점검하고 불필요해진 정보는 지체 없이 파기합니다. 처리 완료 또는 위반 미확인으로 종결된 신고의 원본·증빙·처리 이력·알림 발송 및 중복 접수 방지 기록은 완료 시각부터 30일이 경과하면 정리 대상으로 삼습니다. 현재는 운영자가 정기적으로 보관 필요성과 법적 보존 여부를 확인한 뒤 수동으로 정리합니다. 자동 정리는 보존 제외·증빙 삭제의 안전성을 검증하고 실제 배포한 범위에서만 이용합니다. 목적이 먼저 끝난 자료는 그보다 일찍 파기합니다.

증빙 사진은 비공개 저장소에서 삭제를 시도하며, 저장 위치 확인이나 삭제에 실패하면 운영자가 원인을 점검하고 복구·재시도합니다. 수동 정리 시에는 신고 기록을 지우기 전에 증빙 파일의 저장 위치와 삭제 결과를 확인하고, 실패한 파일의 위치 정보를 잃지 않도록 관리합니다. 검증된 자동 정리를 이용하는 경우 삭제에 필요한 최소 신고 식별번호·파일 저장 키·시도 시각·오류 유형을 대기열에 보관해 재시도하고, 파일 삭제 성공 후 대기열 기록도 삭제합니다. 장애·메타데이터 오류·처리량에 따라 실제 파기가 지연될 수 있으며 운영자는 미삭제 파일을 점검·처리합니다.

법령상 보존 의무 등 별도 근거가 있는 자료는 필요한 항목·근거·기간을 구분해 접근을 제한하고 해당 사유가 끝나면 파기합니다. 신고가 반복됐다는 이유만으로 모든 신고 자료를 무기한 보관하지 않습니다. 차단 관계는 차단 해제 시 삭제하며, 관련 계정 탈퇴를 확인한 경우 운영자가 수동으로 정리합니다. 회원 탈퇴만으로 아직 검토 중이거나 정해진 보유 기간 내인 신고·증빙까지 일괄 삭제되는 것은 아니며, 탈퇴 후 남는 내부 회원 식별값을 완전한 익명정보로 보지 않습니다.

### 로그·문의·법정 보존

일반 백엔드·Nginx 컨테이너 로그는 파일당 최대 10MB, 컨테이너당 최대 7개 파일로 순환 보관하며 용량 초과 시 오래된 파일을 교체합니다. 일수 기준 보관 설정은 아니므로 고정된 최대 보관일을 의미하지 않습니다. 목적이 끝난 로그는 별도로 지체 없이 정리합니다. 운영자 등의 개인정보처리시스템 접속기록은 일반 서비스 로그와 구분하고 적용되는 안전성 확보조치 기준의 법정 보존 기간에 따라 관리합니다.

인증 이메일과 공식 이메일 문의의 보유·파기 기준은 제8조 Gmail 항목을 따릅니다. 앱 내 신고 자료의 보유·파기는 위의 별도 기준을 적용합니다. 분쟁·권리행사 또는 법령 때문에 별도 보존이 필요한 경우 해당 근거·항목·목적·기간을 구분하고 다른 목적으로 이용하지 않습니다. 모든 서비스 기록에 일률적인 3년·5년 보관 기간을 적용하지 않습니다.

## 5. 회원 탈퇴와 공동 작성물

탈퇴 시 이메일·닉네임·계정 사진 등 직접 식별정보와 세션·푸시 연결·개인 설정 등 계정 데이터를 삭제하거나 식별되지 않도록 변경합니다. 계정 사진 파일과 사용하지 않는 미디어 원본의 실제 삭제는 각 정리 절차에 따릅니다.

다른 참여자가 남아 있는 공동 작성물은 해당 다이어리 유지 기간 동안 보존합니다. 작성자는 “탈퇴한 사용자” 등으로 표시하며, 작업 연결·정합성 유지에 필요한 최소 내부 식별값만 제한적으로 남깁니다. 내부 식별값이 남은 자료를 완전한 익명정보라고 단정하지 않습니다. 공동 작성물과 원본 사진에 포함된 개인정보·EXIF는 함께 남을 수 있고 삭제·권리행사 요청은 문의처로 접수할 수 있습니다.

다른 참여자가 남은 소유 다이어리는 소유권 양도 등 필요한 절차를 안내합니다. 개인 다이어리와 마지막 참여자가 나간 공동 다이어리는 영구 삭제 대상으로 처리합니다. 공유 자료의 보존을 이유로 모든 회원정보를 무기한 보유하지 않습니다.

## 6. 개인정보 파기 및 백업

처리 목적·보유 기간이 끝나면 적법한 별도 보존 근거와 공유 참조를 확인한 뒤 전자파일·데이터베이스 기록을 삭제하고, 종이 자료가 있으면 분쇄 등으로 파기합니다. 소프트 삭제·접근 차단과 파일의 최종 물리 삭제를 구분합니다. 장애·일시 실패는 재시도하고 지연된 파기를 정리합니다.

운영 설정상 타국 복제·리전 간 스냅샷 복사·AWS Backup 계획을 사용하지 않습니다. 별도 백업을 도입하거나 백업 구성을 변경하면 저장 위치·주기·보유 기간과 삭제 자료의 잔존 기간을 먼저 안내합니다. 삭제 표시만 한 데이터베이스·S3 객체, 제공자 내부 사본, Gmail 사본과 이용자가 내보낸 사본을 모두 즉시 삭제했다고 간주하지 않습니다.

## 7. 이용자 간 공유 및 제3자 제공

공유 다이어리의 내용·첨부자료·프로필·참여 상태·작업 정보는 권한 있는 참여자에게 표시됩니다. 유효하고 사용 가능한 일반 초대 링크를 가진 사람은 로그인하거나 초대를 수락하기 전에도 다이어리 제목, 사진·스티커·문구 등 원본 표지 꾸밈과 정원 상태를 볼 수 있습니다. 이메일 주소로 받은 초대의 미리보기와 표지 이미지는 초대받은 계정으로 로그인해야 볼 수 있습니다. 초대 미리보기는 내부 페이지 전체를 공개하는 기능이 아닙니다. 링크를 전달하거나 공개하면 의도하지 않은 사람에게도 표지가 보일 수 있으므로 전달 범위를 주의해 주세요.

계정 프로필 사진은 사진 식별 주소를 아는 사람이 로그인 없이 열람할 수 있는 조회 경로로 제공될 수 있습니다. 민감한 사진은 사용하지 않을 수 있습니다. 다이어리별 사진은 참여 권한 확인 경로를 사용하되 계정 사진을 선택한 경우 계정 사진 주소의 특성이 적용됩니다.

운영자는 이용자 정보를 제휴사 광고 목적으로 임의 제공하지 않습니다. 법령에 따른 적법한 요구 또는 별도의 제공을 도입하는 경우 적용 근거와 제공받는 자·목적·항목·기간을 구분해 안내하고 필요한 절차를 갖춥니다.

## 8. 개인정보 처리 위탁 및 국외 처리

### AWS 인프라

Amazon Web Services의 EC2로 백엔드·사진 대상 분리 서버를 운영하고 S3로 사진·소재·프로필 파일과 비공개 신고 증빙을 저장합니다. 확인된 서버와 버킷은 대한민국 서울(ap-northeast-2) 리전입니다. 데이터베이스는 백엔드와 Docker 내부망으로 연결합니다. 타국 복제·백업 경로를 설정하지 않았으며 CloudFront·Transfer Acceleration·Multi-Region Access Point를 사용하지 않습니다.

이 설명은 해당 AWS 저장·처리 구성에 대한 것입니다. Gmail·푸시 등 모든 외부 서비스까지 국외 처리가 전혀 없다는 의미는 아닙니다.

### Gmail

DIO는 Google LLC의 Gmail을 이용하여 회원가입 인증과 비밀번호 재설정 이메일을 발송하고, 공식 문의 주소 dioapp.official@gmail.com으로 받은 문의를 처리합니다.

- **가입 인증·비밀번호 재설정 이메일 발송:** 이용자가 이메일을 요청하면 수신 이메일 주소와 인증번호가 포함된 이메일 내용을 정보통신망을 통해 Google에 전송합니다. DIO는 발송과 필요한 발송 오류 확인에 이메일을 이용하고, 해당 업무가 끝나면 운영 메일함에서 지체 없이 삭제합니다.
- **고객 문의 접수·답변:** 이용자가 공식 주소로 문의를 보내거나 DIO가 답변을 발송할 때 발신 이메일 주소, 문의와 답변 내용, 이용자가 첨부한 파일을 Gmail에서 처리합니다. DIO는 답변과 필요한 후속 조치가 끝나면 운영 메일함과 휴지통의 관련 이메일 및 운영자가 내려받은 첨부파일을 지체 없이 삭제합니다.
- **중요한 개별 통지:** 약관 변경이나 계정 이용 제한 등 개별 안내가 필요한 경우, 운영자가 등록 이메일 주소와 통지 내용을 Gmail을 통해 전송합니다. 발송과 필요한 후속 확인이 끝나면 관련 이메일을 지체 없이 삭제합니다. 법령에 따라 보존해야 하는 정보는 해당 근거와 기간에 한해 별도로 보관합니다.

## 9. 기기 권한·내보내기·로컬 저장

사진 선택·사진첩 저장·파일 공유·알림 등 필요한 기능에서 OS 권한을 요청합니다. 허용하지 않으면 해당 기능이 제한될 수 있으나 관련 없는 기능까지 제한하지 않습니다. 기기 설정에서 권한을 바꿀 수 있습니다.

앱은 설정·작성 자료·복원 정보를 파일과 로컬 저장소에 보관합니다. Android·iOS의 로그인 유지용 리프레시 토큰과 필요한 회원 연결정보는 운영체제의 보안 저장소(Keychain·Keystore 기반)에 보관하고, 기존 인증 API로 세션을 복원합니다. 로그아웃·탈퇴·유효하지 않은 세션 확인 시 해당 저장정보를 정리합니다. 통신·보안 저장소 오류로 정리가 지연되면 재시도 또는 안내를 제공하며 다른 앱이나 일반 로그에 토큰을 공개하지 않습니다. 계정 탈퇴나 서버 삭제만으로 모든 기기 내부 사본을 원격 삭제하지는 않습니다. PNG·PDF 등을 외부 사진첩·파일 앱·서비스로 내보낸 경우 해당 사본은 이용자가 관리합니다. PDF 공유 임시 사본은 만료 기준 24시간을 적용하되 앱 시작·다음 공유 때 정리하므로 앱을 실행하지 않으면 정리가 늦어질 수 있습니다.

사진 목록에서 내려받은 썸네일은 서버 주소·계정별로 구분해 기기나 브라우저에 임시 저장합니다. 저장 시각부터 24시간을 만료 기준으로 삼고 이후 해당 캐시를 조회할 때 정리하거나 다시 받습니다. 저장 공간 정리나 앱 삭제 등으로 먼저 사라질 수도 있습니다. 로그아웃·회원 탈퇴·세션 만료 등으로 해당 기기의 로그인 세션을 종료할 때 썸네일 전용 캐시를 정리합니다. 앱을 실행하지 않거나 저장소 오류가 있으면 정리가 늦어질 수 있으며, 서버에서 파일을 삭제했다고 다른 기기에 저장된 사본까지 즉시 원격 삭제되는 것은 아닙니다.
