# 출시 전 개발자 공통 점검 (총 20건: P0 2, P1 6, P2 9, P3 3)

### [P0] 운영(production) EAS 빌드에 API 주소가 없어 기본값 http://10.0.2.2:8080 (평문 HTTP) 으로 빠짐
- 위치: eas.json:17-23, src/auth/authService.js:10-11, .gitignore:15
- 현상·근거: production 프로필 env에 `EXPO_PUBLIC_PLANNER_TEMPLATES_ENABLED`, `EXPO_PUBLIC_PUSH_ENABLED`만 있고 `EXPO_PUBLIC_API_BASE_URL` 없음. `.env`는 gitignore라 EAS에 안 올라감. 값 없으면 `http://${host}:8080/api`(Android 10.0.2.2, iOS localhost). 로컬 `.env`도 API_BASE_URL이 두 번 선언.
- 영향: 스토어 빌드에서 로그인·동기화·공유·알림 전부 실패. 평문 HTTP는 iOS ATS·Android 릴리스 정책으로 차단. 심사 거절 가능.
- 해결안: eas.json 프로필 env(또는 `eas env:create --environment production`)에 HTTPS 운영 주소 명시. 폴백은 `__DEV__`만. 릴리스에서 값 없거나 `http://`면 빌드·부팅 즉시 실패.

### [P0] 앱 전체에 ErrorBoundary·전역 예외 핸들러·크래시 수집이 없음
- 위치: App.js, index.js:1-5
- 현상·근거: `ErrorBoundary|componentDidCatch|setGlobalHandler|unhandledrejection` 검색에서 src/editor/components/PageBackground.js 한 곳만(부분 경계). Sentry·Crashlytics 류 의존성 없음.
- 영향: 렌더 예외 하나로 흰 화면·종료. 편집 중이면 저장 전 변경 손실, 운영에서 원인 파악 불가.
- 해결안: 루트 ErrorBoundary(복구 화면)+`ErrorUtils.setGlobalHandler`. Sentry RN 또는 Crashlytics(소스맵 업로드). 편집기는 자동 저장 직전 상태를 복구 슬롯에.

### [P1] 로그인 세션이 메모리에만 있어 앱을 껐다 켜면 항상 게스트로 돌아감
- 위치: src/auth/authApi.js:11-12, App.js:99-109
- 현상·근거: 주석 "Tokens stay in memory. Never save tokens in AsyncStorage." SecureStore는 개발 서버 접근 정보·푸시 설치 비밀값에만. 시작 시 무조건 `startGuest()`. refresh 토큰 영속화 없음.
- 영향: 회원이 앱을 닫을 때마다 재로그인. "데이터가 사라졌다" 오해.
- 해결안: refresh 토큰만 `expo-secure-store`(WHEN_UNLOCKED_THIS_DEVICE_ONLY)에 저장, 부팅 시 `refresh()`로 복원. 로그아웃·탈퇴 때 삭제.

### [P1] 로그아웃 시 푸시 설치 해제(unbind)를 호출하지 않음
- 위치: src/auth/authApi.js:469-482, src/notifications/pushInstallationApi.js:31
- 현상·근거: `unbind`는 API 래퍼에만 있고 호출부 없음. 백엔드는 `DELETE /api/v1/push/installations/{id}/binding` 제공(PushInstallationController.java:26).
- 영향: 로그아웃·계정 전환 뒤에도 이전 계정의 초대·알림이 이 기기로 옴. 공유 기기 개인정보 노출.
- 해결안: logout/withdraw 직전 best-effort `unbind`. 서버도 로그아웃 시 바인딩 해제.

### [P1] 앱 잠금 4자리 PIN 을 AsyncStorage 에 소금+SHA-256 으로 저장, 시도 횟수 제한 없음
- 위치: src/shared/appLock.js:7,21-33,40-44
- 영향: 10,000 경우의 수, salt/hash 추출 시 즉시 복구. 무제한 대입. "보안" 표기와 실제 강도 불일치.
- 해결안: 해시·salt를 `expo-secure-store`로. 5회 실패 시 지수 백오프 잠금. `expo-local-authentication` 생체 병행 또는 "화면 가림 용도" 명시.

### [P1] 로컬 문서 스키마 버전이 확인되지 않음 (구버전 문서 열 때 깨질 위험)
- 위치: src/diary/services/guestDiaryImport.js:171,189, src/diary/hooks/useDiaries.js
- 현상·근거: `JSON.parse` 41개 파일. `schemaVersion` 마이그레이션 계층 없음(키 이름 `dio.appLock.v1`에만 버전).
- 해결안: 문서 JSON에 `schemaVersion`+순차 마이그레이션 체인. 상위 버전은 읽기 전용. 파싱 실패 원본 `.corrupt` 보관.

### [P1] 딥링크·유니버설 링크 미설정 — 초대 링크가 앱으로 연결되지 않음
