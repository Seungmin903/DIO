## 2. 안드로이드 공식 규격 (Android 16 · Play 정책 · 대형 화면 가이드)

### 2.1 실기기에서 확인한 것

#### 정정: 태블릿 세로·가로 지원과 편집기 공간
- 제품 의도: 태블릿은 세로와 가로를 모두 지원한다. 세로 화면이 나타나는 것은 결함이 아니다. 점검 당시 코드가 요청한 가로 잠금은 이 의도와 달랐다.
- 현상·근거: 탭 S9 FE(Android 16)에서 `dumpsys window` 값이 `ignoreOrientationRequest=true`. 앱이 LANDSCAPE를 요청해도 **세로로 그대로 그려진다**. Android 16(targetSdk 36)은 최단변 600dp 이상 기기에서 앱의 방향 · 크기 제한을 무시하는 것이 정식 동작이다.
- 영향: 세로 태블릿에서 편집기는 페이지 목록 + 레이어 패널이 기본으로 열려 **캔버스가 폭의 30%**(캡처 25 · 55), 가로 다이어리는 손바닥만 하게 보인다. 보관함은 세로에서도 쓸 만하다(캡처 00).
- 수정: 태블릿은 기기 방향을 따르도록 기본 방향을 요청한다. 세로 태블릿과 폭 600~839dp의 태블릿 창은 페이지 목록과 레이어를 닫고 시작하고 한 번에 하나씩 열어 캔버스 폭을 확보한다. 폭 840dp 이상인 가로 태블릿은 두 패널을 함께 쓸 수 있다. 폰·태블릿 구분은 기존 짧은 변 600dp 기준을 유지한다. Android · iPad 실기기에서 회전과 패널 동작을 재확인한다.

### 2.2 코드에서 확인한 것

#### [P1] expo-media-library 플러그인이 과잉 권한과 `requestLegacyExternalStorage`를 주입 (Play 사진/동영상 권한 정책)
- 위치: `app.json:21-28, 101-103`, `node_modules/expo-media-library/plugin/build/withMediaLibrary.js:40-70`
- 현상·근거: `granularPermissions: []`로 READ_MEDIA_IMAGES는 뺐지만 플러그인은 `READ_EXTERNAL_STORAGE` · `WRITE_EXTERNAL_STORAGE` · `READ_MEDIA_VISUAL_USER_SELECTED`를 항상 추가하고 `android:requestLegacyExternalStorage="true"`도 넣는다. 앱은 사진 **추가**만 한다(`savePngFile.native.js:16`, `gifFileIO.native.js:39` writeOnly). 읽기는 expo-image-picker(시스템 Photo Picker).
- 영향: targetSdk 35+ Play 심사에서 사진/동영상 권한 정책 신고 대상, 핵심 기능이 아니면 반려. WRITE_EXTERNAL_STORAGE는 API 29+ 무의미.
- 해결안: expo-media-library 뒤에 `withAndroidManifest` 커스텀 플러그인으로 세 권한 `tools:node="remove"` + `requestLegacyExternalStorage` 삭제. Android 10+는 MediaStore 추가에 권한이 필요 없으므로 `requestPermissionsAsync(true, [])`는 `Platform.Version < 29`에서만.

#### [P1] 예측형 뒤로가기(Predictive back) 미설정 + 화면별로 흩어진 BackHandler
- 위치: `app.json`(`android.predictiveBackGestureEnabled` 없음), `App.js:411-440`, `EditorScreen.js:1009-1037`(1012 `if (colorPicker) return false`), `AuthScreen.js:243`, `PinScreen.js:34`, `LibrarySearchScreen.js:19`, `EyedropperOverlay.js:45`
- 현상: 리스너 여러 개가 "나중 등록이 먼저 호출" 순서에 기댄다. 로그인 오버레이는 `return false`라 뒤 화면 핸들러가 실행된다(§4 P1).

## 5. 최적화 (심각도 · 현안 및 사유 · 해결안)

#### [P1] 텍스트 글꼴 11종(≈40MB)을 앱 시작 때 전부 등록
