## 전수 QA 미감·경험 우선순위 Top 15

| 우선 | 위치 | 무엇이 왜 어색한가 | 고칠 값·배치 | 기대 효과 |
|---:|---|---|---|---|
| 1 | 내 다이어리·공유 탭 상단 | 종 알림 버튼이 단독으로 너무 큰 수직 영역을 차지해, 핵심 콘텐츠보다 크롬이 먼저 보인다. 숫자 `0`도 아이콘 아래에 떨어져 있어 미완성 상태처럼 보인다. **시각 위계·밀도** 문제. | 상단 안전영역 뒤 헤더를 `72dp`로 고정. 알림은 우상단 `44×44dp` 버튼 안에 배치하고, 0건일 때 배지 숨김. 배지는 있을 때만 우상단 `16dp` 원형, `#B63F7C`. | 첫 화면에서 다이어리와 표지가 주인공이 된다. |
| 2 | 내 다이어리 그리드·스와이프 보기 | 화면별 보기 전환의 결과가 다르게 느껴진다. 스와이프 보기는 옆 표지가 안 보여 캐러셀의 장점이 없고, 펼침 보기는 빈 흰 페이지가 표지보다 먼저 보인다. **콘텐츠 주인공·리듬** 문제. | 스와이프 카드 폭 `320dp`, 다음 카드가 우측에 `44dp` 보이게. 카드 간격 `12dp`. 펼침 보기의 기본 첫 면은 표지, 첫 페이지는 표지를 탭한 뒤 진입. | 보기 방식의 차이가 명확해지고, 표지가 컬렉션의 중심이 된다. |
| 3 | 내 다이어리 카드 | 표지 비율과 카드 정보의 결속이 약하고, 표지 아래 정보가 떠 있다. 별도 표지 밖에 있어 장식처럼 보인다. **정렬·표정** 문제. | 표지 프레임은 `8dp` 라운드, `#D9DCEF` 1px. 즐겨찾기는 표지 우상단 안쪽 `12dp` 여백에 `32×32dp` 반투명 버튼으로 겹침. 제목은 표지 아래 `12dp`, 페이지 수는 `4dp` 간격. | 다이어리가 ‘물건’처럼 보이고, 즐겨찾기가 표지 상태로 인식된다. |
| 4 | 내 다이어리 빈 상태 | 캐릭터와 문구만 있고 만들기 행동까지 시선이 연결되지 않는다. 우하단 `+`는 멀고 맥락이 약하다. **시각 위계·콘텐츠 주인공** 문제. | 빈 상태를 화면 중앙보다 약간 위에 두고, 문구 아래 `16dp` 간격으로 `새 다이어리 만들기` 보조 버튼 추가 (`48dp` 높이, 흰색, `#606BB2` 1px). 기존 우하단 버튼은 `56×56dp`, `+` 아이콘만 유지. | 빈 화면이 실패가 아니라 시작점으로 읽힌다. |
| 5 | 공유 다이어리 빈 상태 | “공유된 다이어리가 없어요”는 정보 전달만 하고 공유의 다음 행동을 제시하지 않는다. 상단 필터·검색은 비어 있는 컬렉션에 비해 과하다. **밀도·표정** 문제. | 빈 상태에서는 `전체 기록 / 즐겨찾기`, 검색, 더보기는 숨김. 캐릭터 아래 `친구의 초대를 기다리거나, 내 다이어리를 공유해 보세요` 한 줄과 `내 다이어리로 이동` 버튼 배치. | 기능의 목적이 이해되고, 빈 화면의 도구 과밀이 사라진다. |
| 6 | 꾸미기 공방 전체 | 페이지명 “꾸미기 공방” 뒤에 탭명과 같은 대제목이 반복되어 첫 화면의 세로 공간을 낭비한다. **시각 위계·리듬** 문제. | 헤더 아래 탭 바로 본문 시작. 선택 탭명은 탭 자체의 선택 상태만으로 표현하고 본문 대제목 제거. 카테고리 설명이 필요할 때만 `14sp` 보조 텍스트를 `12dp` 상단 여백으로 사용. | 작업실이 상점·설정 페이지가 아니라 빠르게 고르는 라이브러리처럼 보인다. |
| 7 | 공방 탭 바·속지·도구 | 6개 탭이 화면 폭을 균등 분할하면서 글자와 여백이 모두 답답하다. 본문은 75% 폭에서 끝나 우측이 비어 보인다. **정렬·밀도** 문제. | 탭 바는 가로 스크롤, 각 탭 좌우 패딩 `20dp`, 높이 `48dp`; 선택 배경 `#DDE0F7`, 하단 2px `#606BB2`. 본문은 좌우 `16dp`를 유지해 전체 폭 사용. | 탭과 콘텐츠의 폭 체계가 통일되고, 도구 컬렉션이 풍부해 보인다. |
| 8 | 공방 폰트 빈 상태·추가 버튼 | “폰트 추가”가 페이지에서 가장 큰 면적을 차지해 실제 콘텐츠보다 CTA가 앞선다. 빈 상태 캐릭터와 버튼의 관계도 멀다. **시각 위계·표정** 문제. | `폰트 추가`는 목록 첫 번째의 `52dp` 행 또는 우측 `+` 아이콘으로 축소. 빈 상태에는 `내 손글씨를 폰트로 만들어 보세요`와 `폰트 추가` 단일 버튼을 캐릭터 아래 `16dp`에 배치. | 기능의 주인공이 버튼이 아니라 만들어질 폰트가 된다. |
| 9 | 마이페이지 게스트 | 방문자 카드 아래가 지나치게 비어 있어 로그인 유도가 화면 상단에 고립된다. 제목 “마이페이지”와 하단 탭 “내 공간”의 명명도 다르다. **리듬·콘텐츠 주인공** 문제. | 탭 명칭을 `내 공간`으로 통일. 게스트 카드 아래 `24dp` 간격으로 “내 기록을 안전하게 보관하세요” 안내와 `최근 본 다이어리`, `만든 항목` 미리보기 2행을 배치. 로그인 버튼은 `52dp` 높이. | 게스트에게도 앱이 쌓이는 공간이라는 인상을 준다. |
| 10 | 설정 화면 | 설정은 뒤로 갈 수 없고, 토글이 한 화면에 과도하게 몰려 있다. 구분선과 행 규칙도 섹션마다 다르게 보여 관리 화면처럼 경직된다. **정렬·밀도** 문제. | 좌상단 `44×44dp` 뒤로 버튼. 행 높이 `56dp`, 섹션 제목 `14sp`·상단 `32dp`, 구분선 `#D9DCEF` 1px. 알림 마스터 토글 아래 세부 알림은 별도 화면으로 이동하고, 현 화면에는 요약값만 표시. | 설정이 짧고 읽기 쉬워지며, 중요한 선택이 분리된다. |
| 11 | 편집기 세로 상단 도구줄 | 도구가 12개 이상 한 줄에 있어 가로 스크롤 사실을 알기 어렵고, 스티커 등 끝 아이콘이 잘린다. 선택 상태와 형광펜의 노란 밑줄도 서로 다른 선택 문법이다. **시각 위계·정렬** 문제. | 상단 바 `52dp`, 도구줄 `50dp` 고정. 핵심 7개만 노출: 선택·펜·형광펜·지우개·텍스트·스티커·더보기. 각 버튼 `48dp`, 선택은 `#DDE0F7` 배경 + `#606BB2` 2px 테두리로 통일. | 도구가 빠르게 읽히고, 선택 상태가 일관된다. |
| 12 | 편집기 세로 하단 시트·되돌리기 | 시트가 올라올 때 되돌리기/저장 바가 캔버스 중간에 겹쳐 페이지를 가린다. 도구별 시트 높이가 크게 달라 캔버스가 흔들리는 느낌이다. **리듬·콘텐츠 주인공** 문제. | 하단 고정 조작 바는 시트가 열리면 시트 상단에 붙여 함께 이동. 기본 시트 높이 `344dp`, 색상·폰트 등 확장형만 `472dp`; 상단 핸들 `36×4dp`. 바깥 탭으로 닫지 않고 닫기 버튼만 사용. | 페이지가 항상 같은 안전 영역을 유지하고, 편집 흐름이 안정된다. |
| 13 | 편집기 선택 객체 메뉴·레이어 | `옵션`과 `더보기`가 모두 `⋯`라 행동을 예측할 수 없다. 작은 “hello”에 비해 선택 손잡이가 너무 커 객체보다 조작 UI가 주인공이 된다. 레이어 이름도 “텍스트/텍스트”라 식별이 안 된다. **표정·콘텐츠 주인공** 문제. | 객체 메뉴는 `서식 / 순서 / 복제 / 삭제`처럼 직접 명명; `옵션` 삭제. 최소 선택 프레임 `24×24dp`, 손잡이 `16dp`, 텍스트 기본 크기 `18sp`. 레이어는 내용 첫 12자 또는 `텍스트 1`, `스티커 1` 자동 명명. | 편집 대상이 중심으로 보이고, 작은 요소도 조작하기 자연스럽다. |
| 14 | 편집기 가로 | 좌·우 레일과 레이어 패널이 캔버스를 둘러싸며 페이지가 작고 멀게 느껴진다. 끝 페이드가 둥근 레일을 넘어 사각형으로 튄다. **시각 위계·정렬** 문제. | 가로 상단 바 `52dp`, 우측 도구 레일 폭 `64dp`만 유지. 좌측은 뒤로·페이지·레이어를 `64dp` 레일에 묶되 레이어 목록은 버튼 탭 시 오버레이가 아닌 좌측 `280dp` 패널로 전환. 페이드는 제거하고 마지막 항목 뒤 `12dp` 여백만 사용. | 태블릿/가로 화면에서도 캔버스가 가장 크게 보인다. |
| 15 | 공유 허브·초대 수락 후 | 초대 수락 뒤 내 다이어리 빈 화면으로 돌아가 성공 경험이 끊긴다. 허브의 “새 초대 없음” 행, 대기 카드 삭제, 실제와 다른 표지·아바타는 공유 공간의 신뢰를 깎는다. 강퇴 오류도 개발 문구다. **표정·콘텐츠 주인공** 문제. | 수락 완료 시 해당 다이어리 상세 또는 편집기로 즉시 이동. 허브 알림 행은 초대가 있을 때만 노출. 대기 초대 카드에는 삭제 대신 `거절`을 2차 행동으로 제공. 표지·아바타는 모든 진입점에서 동일한 서버 자산 사용. 강퇴 시 `더 이상 이 다이어리에 참여할 수 없어요` 안내와 `내 다이어리로` 버튼. | 공유의 결과가 즉시 확인되고, 협업 기능의 신뢰감이 올라간다. |

## 앱 전체 방향

| 구분 | 방향 |
|---|---|
| 지금의 인상 | 차분하고 정돈됐지만, 화면마다 큰 헤더·큰 버튼·빈 여백이 반복돼 다꾸 앱보다 관리 화면처럼 느껴진다. |
| 1020이 갖고 싶게 만들 한 가지 | 모든 목록과 편집 진입에서 “내가 만든 표지와 오늘의 한 장”이 먼저 보이게 하며, 조작 UI는 한 단계 뒤로 물린다. |
| 건드리지 말 강점 | 페리윙클~네이비의 차분한 톤, 흰 카드와 얇은 테두리, 노란 책 모아·파란 디오의 온도는 유지한다. |

## 도안으로 먼저 그려 볼 화면 6개

| 화면 | 레이아웃 스케치 |
|---|---|
| 1. 내 다이어리 — 그리드 | `안전영역 → 72dp 헤더(내 다이어리 / 알림) → 보기 전환 → 필터·검색 → 2열 표지 그리드 → + FAB → 하단 탭`<br>표지 안 우상단에 별, 표지 아래에 제목·페이지 수. |
| 2. 내 다이어리 — 스와이프 | `72dp 헤더 → 보기 전환 → 필터·검색 → 320dp 표지 카드 + 다음 표지 44dp 노출 → 제목·페이지 수·더보기 → + FAB → 하단 탭`<br>첫 카드만 크게, 옆 카드가 컬렉션의 연속성을 보여 준다. |
| 3. 공유 다이어리 빈 상태 | `72dp 헤더(공유 다이어리 / 알림) → 중앙 상단 빈 상태(모아) → 제목 → 한 줄 안내 → 내 다이어리로 이동 → 하단 탭`<br>필터·검색은 숨겨 빈 상태의 목적을 선명하게 한다. |
| 4. 꾸미기 공방 — 도구 탭 | `72dp 헤더 → 가로 탭 바 → 섹션별 도구 카드(펜/형광펜/테이프/글자) → 각 행 팔레트 편집 링크 → 하단 탭`<br>반복 대제목 없이 탭 직후 콘텐츠를 배치한다. |
| 5. 편집기 세로 — 펜 시트 | `52dp 상단 바 → 50dp 도구줄 → 캔버스 → 시트와 함께 움직이는 저장·되돌리기 바 → 344dp 펜 시트`<br>시트 안은 `종류 → 굵기 → 불투명도 → 색상` 순서, 닫기는 우상단 X만 둔다. |
| 6. 공유 수락 완료·공유 관리 | `다이어리 표지·이름 → 참여자 아바타/역할 → 이메일 초대 → 초대 링크 → 참여 해제 → 완료`<br>수락 직후에는 이 화면이 아니라 실제 다이어리 상세/편집기로 진입하고, 이 화면은 공유 버튼을 눌렀을 때만 연다. |
