# 웹 후속 — 전수 QA 2026-11-04

> 웹은 출시 계획이 없어 이번 실기 점검에서 제외했다. 나중에 웹을 열 때 볼 것을 코드 기준으로 모았다. **웹에서 실행해 확인한 것은 없다.**

## 웹을 열면 먼저 볼 것

| 영역 | 볼 것 | 위치 |
|---|---|---|
| 편집기 입력 | 키보드 단축키, 터치 이벤트, 펜 · 마우스 분기 | `EditorScreen.js:761-821,834`, `useStylusTouchBridge.web.js` |
| 필기 표시 | 완료 획 캐시, 연필 렌더가 앱과 같은가 | `WebStrokeCache.web.js`, `PencilSkiaStroke.web.js`, `strokeThumbnailRaster.web.js` |
| 글 편집 | 웹만 `TextActionBar` 말풍선을 씀 (앱은 시스템 메뉴) | `TextActionBar.js`, `TextEditor.js` |
| 내보내기 | PNG · PDF · GIF 저장 경로 | `capturePage.web.js`, `pdfExport.web.js`, `savePngFile.web.js`, `gifFileIO.web.js` |
| 사진 | HEIC 변환, 처리 한도 | `heicDecoder.web.js`, `mediaProcessing.web.js`, `public/vendor/heic-to` |
| 스포이드 | 브라우저 EyeDropper 지원 범위, 미지원 브라우저 대안 | `eyedropper.js`, `components/EyedropperOverlay.js` |
| 확인창 | 브라우저 `confirm` · `alert` 분기 남음. 가이드는 앱 창만 허용 | `shared/dialogs.js` |

| 라이선스 | 웹 고지 목록 검사 `licenses:check:web`, HEIC 벤더 파일 해시 | `scripts/verify-prepared-licenses.cjs` |

## 앱 수정이 웹에 주는 영향

이번 보고서의 F-02 · F-04 · F-05 · F-07 · F-08 · F-10 · F-11과 §5 미감은 공용 코드라 웹도 같이 바뀐다. 다음은 웹에서 다시 확인한다.

- **F-02 세션 유지:** `expo-secure-store`는 웹에서 쓸 수 없어 별도 저장 전략이 필요하다(httpOnly 쿠키 등).
- **F-09 키보드 복원:** 웹은 `visualViewport` 기준으로 동작이 다를 수 있다.
- **뒤로가기(F-25):** 브라우저 뒤로 버튼 · 주소 라우팅이 없다. 웹을 열 때 함께 설계한다.
- **접근성:** 웹은 키보드 초점 이동과 WCAG 대비 검사를 따로 돈다.

## 지난 점검에 있던 참고 자료

iPhone · iPad 뷰포트로 찍은 웹 캡처는 [지난 보고서 §12.2](../QA%20점검%202026-11-04/QA%20점검%202026-11-04.md)에 있다. 레이아웃 참고용이고 실제 iOS 동작을 뜻하지 않는다.
