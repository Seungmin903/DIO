# 선택 영역 PNG 내보내기 계약 (S15P31F106-115)

> 기준일: 2026-10-20 · 기준 develop: `29c4851` · 구현용 초안
> 함수·오류·정책은 신규 제안이다. 영역 출력 구현 또는 실기기 검증 완료를 의미하지 않는다.

## 1. 범위와 기준 문서

오른쪽 공유 버튼의 네 가지 옵션 중 **영역 선택 내보내기**에서 현재 페이지의 원하는 직사각형 구역을 골라 PNG 한 장으로 저장한다. 인스타 게시용 이미지를 만드는 것이 목표이며 인스타 계정 연결·직접 게시·앱 전용 공유는 포함하지 않는다. 아래 비율·해상도는 DIO의 제품 기본값이며 인스타의 최신 필수 규격이나 업로드 무손실 보장을 뜻하지 않는다.

- [공통 페이지 렌더러](./page-export-renderer.md), [GIF 첫 프레임](./gif-first-frame-export.md), [PNG 저장](./png-file-export.md)를 재사용한다.
- 기존 전체 페이지 PNG의 기본 1배·파일명·사진첩 저장은 유지한다. PDF 고유 정책은 병합된 [PDF 계약](./pdf-export-contract.md)의 기준을 따르며 이 작업은 PDF 생성에 의존하지 않는다.
- 사진 요소 자체의 크롭, 올가미/다각형 출력, 여러 영역 동시 출력, 투명 배경, JPEG 출력은 이번 범위에서 제외한다.

## 2. 영역 좌표와 조작

영역은 페이지 왼쪽 위를 원점으로 하는 논리 좌표 `{ x, y, width, height }`다. 현재 develop의 편집기는1280×800을 전달한다. 논리 규격은 호출자가 제공하며1188×840은 기존 생략 기본값/예시다. 페이지 크기를 영역 기능에 고정하지 않는다. 화면 px·DPR·편집 줌을 문서 좌표로 저장하지 않는다. 소수 좌표를 유지하며 출력 직전에만 픽셀 크기를 정수화한다.

- 선택 모드에서는 페이지 전체를 정확히 덮는 전용 입력 오버레이가 터치를 받는다. 아래 사진·스티커·필기 등 자식 요소는 터치 대상에서 제외한다. 오버레이가 받은 로컬 좌표에 한해서 `x = locationX / zoom`, `y = locationY / zoom`을 사용한다. 임의 자식 요소의 locationX/locationY를 페이지 좌표로 해석하지 않는다. 핸들의 좌표는 페이지 원점을 기준으로 별도 변환한다.
- 화면 절대 좌표라면 `x = (screenX - pageOriginX) / zoom`, `y = (screenY - pageOriginY) / zoom`이다. origin은 현재 스크롤·패닝·레이아웃 이동을 반영한 페이지의 화면상 원점이다. 이미 로컬화한 좌표에 origin/scroll을 다시 빼지 않는다.
- 선택 시작 시 좌표계를 고정한다. 제스처 도중 줌/페이지/레이아웃이 바뀌면 진행 중 제스처만 취소하고 유효한 기존 영역을 유지하거나 새 페이지 진입 시 초기화한다. 선택 모드의 드래그가 필기·요소 이동으로 전달되지 않도록 한다.
- 역방향 드래그도 min/max로 정규화한다. 유효 조건은 모든 값이 유한하고, `width >= 32`, `height >= 32`, `0 <= x`, `0 <= y`, `x + width <= pageWidth`, `y + height <= pageHeight`다.
- 32는 논리 단위 최소값이다. 핸들 터치 영역은 시각 크기와 별개로 화면에서 최소 44×44 단위로 확보한다. 작은 영역의 핸들이 겹치면 외부 조절 UI 등으로 조정할 수 있게 한다.
- UI는 드래그 끝점을 페이지 경계로 제한하고 영역 이동 시 크기를 유지한 채 위치를 제한한다. API에 전달된 잘못된 영역은 조용히 잘라내지 않고 오류로 반환한다. 부동소수 오차 허용치는 0.000001 논리 단위이며 그 이내의 경계 초과만 경계값으로 정규화한다.
- 선택 상태는 화면 임시 상태다. 문서/원본/되돌리기 이력/자동 저장을 변경하지 않는다. 취소하면 출력 없이 이전 도구 상태로 돌아간다. 페이지 이동은 선택 모드를 종료한다.

## 3. 프리셋과 출력 규격

| 프리셋 | 영역 비율 | 출력 픽셀 |
| --- | --- | --- |
| 자유 (기본) | 사용자 선택 | 논리 영역의 2배, 상한 내에서 비율 유지 축소 |
| 정사각형 | 1:1 | 1080×1080 |
| 세로 피드 | 4:5 | 1080×1350 |
| 스토리 | 9:16 | 1080×1920 |

프리셋은 페이지의 일부를 그 비율로 선택하는 기능이다. 페이지 전체를 왜곡하거나 비율 맞춤용 외부 여백을 추가하지 않는다. 스토리 안전 영역/텍스트 위치 보장은 제공하지 않는다.

- 진입 시 자유 비율·전체 페이지 영역을 표시한다. 프리셋 변경은 기존 중심을 최대한 유지하고, 기존 영역 안에 새 비율로 들어가는 가장 큰 사각형을 우선한다. 최소 크기를 만족하지 못하면 같은 중심 기준 최소 유효 크기로 확장한 뒤 페이지 안으로 이동한다. 페이지 자체가 해당 비율의 최소 영역을 담을 수 없으면 선택 불가로 안내한다.
- 고정 비율 크기 조절은 반대 모서리를 기준으로 비율을 유지하고 경계에서 확대를 제한한다. 이동은 크기를 바꾸지 않는다. 자유로 전환할 때 현재 영역을 유지한다. 이미지 출력 픽셀만 정수화하고 선택 좌표를 반올림하지 않는다.
- 자유 출력 배율은 `s = min(2, 4096 / width, 4096 / height, sqrt(8000000 / (width * height)))`다. `pixelWidth = floor(width * s)`, `pixelHeight = floor(height * s)`이며 각 값은 최소 1이다. 정수화에 따른 1px 미만 오차는 허용한다.
- 고정 비율은 **3절 표의 출력 픽셀**을 사용한다. 논리 영역 대비 확대 배율 `m = max(pixelWidth / width, pixelHeight / height)`를 표시한다. `m <= 3`은 일반 안내, `3 < m <= 6`은 화질 경고와 명시적인 계속 진행 확인, `m > 6`은 생성 차단 및 더 넓은 영역 선택 안내다. 예:4:5의400×500은2.7배,200×250은5.4배(확인 필요),160×200은6.75배(차단). 이 값은 초기 제품 품질 기준이며 원본 해상도 보장이 아니다. 원본 사진·스티커가 작으면 확대가 디테일을 복원하지 못한다.
- 공통 상한은 긴 변 4096px·총 8,000,000px다. 영역 한 장 생성의 준비·로드·캡처 제한은 기존과 같은 30초다. OS 저장 대기는 제외한다. 시간/성능은 119번 실기기 검증 전의 초기 정책이다.
- 미리보기에 선택 범위, 비율, 실제 출력 픽셀을 표시한다. 자유 출력의 전체 영역 선택은 기존 전체 페이지 PNG보다 2배가 기본이므로 픽셀 수가 다를 수 있다. 같은 크기로 설정한 경우에만 픽셀 동일성을 비교한다.

## 4. 렌더링·요소·배경

선택 영역 크기의 전용 출력 surface에 페이지 합성 결과를 그린다. 페이지 좌표 `(px, py)`는 출력 좌표 `((px-x)*sx, (py-y)*sy)`로 변환한다. `sx=pixelWidth/width`, `sy=pixelHeight/height`이며 정수화 이외의 비율 변형은 하지 않는다. 회전 중심과 개별 크롭은 원래 요소 좌표계를 유지한다.

- 기존 ObjectContent를 공유하고, 페이지 논리 영역으로 먼저 클리핑한 뒤 선택 직사각형으로 클리핑한다. 요소를 선택 프레임 안으로 재배치하거나 개별 이미지를 다시 잘라 저장하지 않는다.
- 회전·그림자 등 시각 효과가 영역에 걸치면 합성된 부분을 그대로 출력한다. 중심점이 영역 밖이라고 제거하지 않는다.
- 118번의 초기 구현은 숨김/투명도0을 제외한 페이지 요소 전체를 준비·검증하므로 영역 밖 소재 오류도 중단할 수 있다. 후속 최적화에서는 회전·선 굵기·테두리·그림자 확장까지 포함한 보수적 시각 경계가 선택 영역과 완전히 분리됨을 증명할 수 있는 요소만 준비 전에 건너뛴다. 경계를 알 수 없으면 포함하고, 중심점/AABB의 원래 비회전 크기만으로 제거하지 않는다. 이 최적화는 후속 범위이며 초기118번의 필수 구현으로 추가하지 않는다.
- 지원되는 사진·스티커·테이프·기본 stroke는 공통 렌더러로 그린다. 부분 텍스트 스타일·폰트·기타 필기는 72번 연결 상태를 따른다. 미지원 요소는 조용히 빼지 않고 실패 처리한다.
- GIF는 원본 0번 프레임을 디코딩하며 재생 시점과 무관하다. 회전·자르기·투명도·겹침 순서는 공통 규칙을 유지한다. 숨김·완전 투명 요소는 제외한다.
- 배경은 불투명 종이색이며 현재 구현은 흰색이다. 실제 내지 지원 시 공통 배경 렌더러를 연결한다. 보조 격자·선택 테두리·마스크·핸들·툴바·커서·패널은 결과에서 제외한다.
- 출력용 소재의 필요 픽셀은 **영역 출력 배율**과 요소 크기·크롭 확대를 반영해 계산한다. 큰 페이지의 기존 1배 표시본을 무조건 자르는 방식으로 대체하지 않는다. 기존 래스터/디코딩 제한은 유지한다.
- **원본 해상도 정책 (122):** 필요 픽셀을 충족하는 표시본을 우선 사용한다. 부족하면 800만 화소 이하 원본을 사용한다. 원본이 상한을 넘고 안전한 표시본이 있으면 원본을 디코딩하지 않고 표시본을 확대해 출력하며 저장 전에 화질 경고를 표시한다. 표시본이 없거나 안전하지 않으면 기존 오류로 중단한다. GIF 제한과 전체 출력 픽셀 상한은 유지한다.
- 선택 영역 밖 요소 제외 최적화와 대형 원본 축소 디코딩·고해상도 파생본 추가는 이번 범위 밖이다. 안전한 표시본이 없는 기존 문서는 실패할 수 있다. 실제 12MP 사진 및 모바일 메모리 검증은 113·119에 남긴다.

## 5. 제안 함수 경계와 스냅샷

```js
createRegionExportSnapshot(page, {
  pageWidth: 1188, pageHeight: 840,
  region: { x: 100, y: 80, width: 400, height: 500 },
  preset: 'portrait', // 'free' | 'square' | 'portrait' | 'story'
  title, pageNumber, now,
  upscaleConfirmed: false, // 3배 초과~6배 이하의 해당 영역/프리셋/출력에 대한 확인
})
// -> { jobId, pageId, pageWidth, pageHeight, region, preset,
//      pixelWidth: 1080, pixelHeight: 1350, background,
//      objects, fileName }

renderPageImage(snapshot, { signal })
// 109번 공통 API의 영역 옵션 확장 (제안)
// -> { uri, blob?, width, height, dispose() }
// 저장은 기존 savePngFile(result, snapshot.fileName) 재사용
```

- 고정 비율과 영역 비율이 0.000001 상대 오차보다 크게 다르면 입력 오류다. 잘못된 비율을 늘려 맞추지 않는다.
- 생성 확정 시 진행 중인 입력을 편집기 경계에서 확정한 뒤 페이지·영역·프리셋·규격·제목·시각을 깊게 복사한다. 확정 불가 시 생성하지 않는다.
- 생성 도중 편집/페이지 이동/소재 변경이 있어도 입력은 바뀌지 않는다. 다시 만들기는 같은 스냅샷, 다른 영역/최신 편집 반영은 새 작업이다. 작업 동안 원본 참조를 보호하고 없어진 소재는 실패 처리한다.
- 기존 createExportSnapshot은 전체 페이지를 위한 현재 계약을 유지한다. 영역 작업의 pixel 크기·논리 크기를 혼동해 전체 페이지 출력이 바뀌지 않도록 109·118번에서 공통화한다. 별도 요소 렌더러를 만들지 않는다.

## 6. 실패·취소·파일명·저장 수명

- 상태는 선택 → 생성 → 미리보기 → 저장이다. 생성 실패는 다시 만들기, 저장 취소/실패는 유효한 PNG로 다시 저장한다. 중복 시작/저장을 차단한다.
- 신규 제안 오류: `EXPORT_REGION_INVALID`(좌표·크기·경계), `EXPORT_REGION_RATIO_INVALID`(프리셋 비율), `EXPORT_REGION_TIMEOUT`(생성 시간 초과), `EXPORT_REGION_UPSCALE_LIMIT`(6배 초과), `EXPORT_REGION_UPSCALE_CONFIRM_REQUIRED`(3배 초과~6배 이하 미확인). 기존 소재/요소/캡처 오류 코드는 원인을 보존한다. 취소는 실패/성공으로 처리하지 않는다.
- 감지된 필수 요소 준비·로드·폰트·캡처 실패 시 저장 버튼을 제공하지 않는다. 문서·미디어는 보존한다. 영역 밖 문제라면 해당 요소를 확인하거나 숨기도록 안내한다.
- 파일명: `DIO_<제목>_p01_region_<프리셋>_<YYYYMMDD_HHMMSS_mmm>.png`. 프리셋은 free/square/portrait/story다. 기존 pngFileName과 같은 제목 정규화·48자 제한·현지 시각·문서 내 페이지 번호를 사용한다. 생성 시작 시 고정하고 재시도에서 유지한다.
- 웹 파일 선택기의 write/close가 완료돼야 저장 완료다. 다운로드 fallback은 다운로드 시작으로 안내한다. 모바일은 기존 PNG 사진첩 저장·권한/설정 안내를 재사용한다. 인스타로 직접 보냈다고 표시하지 않는다.
- 생성·미리보기·저장 중 임시 결과를 유지한다. 닫기/재생성/실패/취소 시 해당 작업의 자원만 해제한다. 늦게 완료된 작업은 결과를 정리하고 현재 UI에 반영하지 않는다. 저장 중 닫기는 기존 정책대로 막는다.
- 웹 다운로드 URL은 미리보기와 독립 소유하고 60초 유예 후 해제한다. 원본·다른 작업의 캐시는 지우지 않는다.
- html-to-image가 오류 없이 소재를 누락하는 기존 한계는 그대로 남는다. 영역 기능이 이 문제의 완전한 해결을 보장하지 않는다.

## 8. 공유 메뉴와 영역 선택의 연결

공유 메뉴 이름·형식·순서의 단일 기준은 [PDF 계약10절](./pdf-export-contract.md#10-공유-버튼의-네-가지-내보내기-옵션)이다. 이 문서에는 영역 전용 동작만 정의하며 메뉴 표를 복제하지 않는다.

흐름은 공유 → 방식 → 대상 선택 → 형식 확인 → 미리보기·저장이다. 영역은 PNG 고정으로 안내하며 PDF 선택이나 다중 페이지 선택을 제공하지 않는다. 페이지 개별 선택과 연속 범위는108번 계약/111번 UI 범위이며 좌표 영역과 혼동하지 않도록 메뉴 이름에 페이지/영역을 명시한다.

- 영역 선택 취소는 공유의 내보내기 옵션으로 돌아가고 문서·원본은 바꾸지 않는다. 선택 모드 동안 이전 도구를 임시 보관하고 종료 시 복원한다. 공유 메뉴까지 닫으면 편집 화면으로 복귀한다.
- 생성 실패 후 다시 만들기는 확정 스냅샷을 사용한다. 영역을 바꾸려면 영역 다시 선택으로 돌아가 새 작업을 만든다. 저장 실패/취소는 완성 PNG로 다시 저장한다.
- 생성 확정 전 페이지를 이동하면 영역을 초기화하고 선택 모드를 종료한다. 현재 페이지의 영역을 다른 페이지에 자동 적용하지 않는다.
- 기존 PNG/PDF 선택 뒤 영역을 고르는 순서는 이 공유 메뉴 순서로 대체한다. 자유/1:1/4:5/9:16·출력 해상도·원본 보존·저장 수명은 유지한다.
- 119번은 네 옵션 중 영역 진입·취소·재선택·메뉴/편집 복귀와 현재 페이지 PNG 회귀를 검증한다.

## 9. 게시 비율 목표·확대 안내·리뷰 반영

- 피드용 DIO 기본 호환 목표는 `0.8 <= width/height <= 1.91`(4:5~1.91:1)다. 자유 비율이 벗어나면 “피드 기본 권장 비율 밖입니다. 게시 시 잘릴 수 있어요”를 표시하고 비율 변경/그대로 저장을 제공한다. PNG 저장 자체는 비율만으로 차단하지 않는다. 이는 보수적인 제품 목표이며 플랫폼의 허용 범위 전체를 뜻하지 않는다.
- 스토리 프리셋은9:16(1080×1920) 목표다. 스토리 목적일 때 피드 경고는 적용하지 않는다. 자유 모드의 안내 목적지는 기본 피드이며 사용자가 스토리 안내를 선택할 수 있다. 자유 모드에서 스토리 목적을 고르면9:16 이외 비율에 잘림/여백 가능성을 안내하되 저장을 막지 않는다.
- 외부 플랫폼의 현재 허용 범위는 바뀔 수 있다. Instagram Help Center https://help.instagram.com/1631821640426723 를 확인할 기준으로 기록한다. 이번 직접 열람은 요청 제한으로 원문 확인이 제한되므로 DIO 목표를 공식 최대 규격으로 단정하지 않는다.
- 확대 경고/차단은 게시 비율 경고와 독립적이다. 비율이 맞아도6배 초과면 저장할 수 없으며3~6배 진행 확인은 영역·프리셋·출력 크기가 바뀌면 다시 받는다. 초기에는 해상도 낮추기 옵션 대신 영역 확대/자유 비율 전환을 안내한다.
- 메뉴 부가 설명: 현재 페이지 내보내기 PNG는 “전체 페이지 · 기본1배”, 영역 선택은 “선택 구역 · 자유 기본2배 / 프리셋 지정 크기”로 표시한다. 영역에서 전체 종이를 선택해도 동일한 기본 해상도라고 설명하지 않는다.
- 116은 전용 오버레이 위 사진/스티커 위치에서 시작한 드래그 좌표,117은 게시 비율·확대 배율3/6 경계 안내,118은 생성 시 동일 검증 강제 및 확대 확인값,119는 경계값·메뉴 설명을 검증한다.
- 공유 메뉴 표를 PDF 계약으로 통합하고 README는 PDF/영역 두 링크를 모두 보존했다. 108번의 입력 경계/전체 선택 상한 후속 수정은110·111번에서 별도로 처리한다.
