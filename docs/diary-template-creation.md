# 다이어리 생성 시 속지 구성

관련 Jira: [S15P31F106-148](https://ssafy.atlassian.net/browse/S15P31F106-148)

## 생성 흐름

- 최신 develop의 책 표지 미리보기·색상·패턴 디자인과 모달 내부 입력 상태 관리를 유지한다. 첫 페이지 단일 선택 대신 두 번째 단계에서 월별 속지 구성을 제공한다. 새 생성의 세로형은 준비 중으로 비활성화하며 기존 세로형 문서는 변경하지 않는다.
- 기존 보관함 생성 창을 이름·표지 → 속지 구성 → 내지 색상의 세 단계로 제공한다. 취소하면 새 다이어리를 만들지 않는다. 기존 다이어리 수정은 이름·표지 색상만 변경한다.
- 2026년 가로형 카탈로그를 사용한다. 기본값은 표지 1장, 월 구분지 12장, 먼슬리 12장, 블록 위클리 53장의 기존 78페이지다.
- 먼슬리·위클리·데일리·표지·월 구분지의 포함 여부를 고른다. 위클리는 블록형/저널형 하나를 선택한다. 먼슬리는 기존 단일 양식을 사용하고, 데일리는 플래너·일기·포토/스크랩을 여러 종류 선택한다.
- 표지 다음 1~12월을 월별로 구성한다. 각 월은 구분지 → 먼슬리 → 위클리 → 데일리 → 공용 노트 순서다. 주간 페이지의 월 배정은 기존 연간 목록을 따르며, 첫 주(2025-12-29)는 1월에 한 번만 포함한다.
- 데일리는 플래너·일기·포토/스크랩의 종류별 포함 여부와 매월 장수를 지정한다. 같은 구성을 모든 월에 반복한다. 기본적으로 데일리는 제외하고, 데일리를 켜면 플래너 매월 1장이 선택되어 있다. 각 양식을 새로 켜면 기본 매월 1장이다.
- 공용 속지는 무지·줄·모눈·도트 노트다. 여러 종류를 골라 매월 장수를 지정하고 동일한 구성을 각 월의 데일리 뒤에 배치한다. 포함 시 기본 매월 1장이고 공용 메뉴 순서를 따른다. 데일리를 제외해도 공용 노트를 매월 추가할 수 있다.
- 데일리·공용 속지 양식은 위클리처럼 좌우로 넘기는 미리보기 카드로 고른다. 위클리는 단일 선택, 데일리·공용 속지는 여러 카드의 체크를 켜고 카드별 매월 장수를 입력한다.
- 장수는 양의 정수이며 잘못된 값은 생성 전에 안내한다. 총 페이지 수를 표시하고, 모두 제외하면 속지 없는 기존 규격 빈 페이지 1장으로 만든다.

## 저장과 호환

- templateConfig를 다이어리 목록과 새 문서에 보관한다. version: 2의 포함 여부, 위클리 양식, dailyTemplates(플래너·일기·스크랩), reusable(공용 노트)의 종류별 포함 여부·매월 장수를 포함하며 SVG 문자열은 저장하지 않는다.
- 실제 페이지는 기존 backgroundAssetId·templateVersion·canvasWidth·canvasHeight와 독립 페이지 ID, 빈 objects 배열을 사용한다.
- 생성은 문서 저장 → 보관함 저장 → 편집기 진입 순서다. 저장 중 중복 클릭·취소를 막고 실패 시 입력과 생성 ID를 유지하여 재시도한다. 문서만 저장된 경우 기존 보관함 복구 흐름으로 복구 가능하다.
- 기존 문서는 읽을 때 저장 페이지를 그대로 복원한다. 설정 없는 기존 생성 호출은 기본 78페이지다. 기존 문서에 속지를 자동 적용하거나 페이지를 덧붙이지 않는다.
- 이전 단일 데일리 설정은 월별 플래너 장수로 해석한다. 이전 맨 뒤 공용 속지 설정은 legacyEndPages로 별도 보존하여 매월 12번 복제하지 않는다. 저장된 실제 페이지는 재구성하지 않는다. 새 생성 화면은 version: 2의 월별 구성만 만든다.
- 설정값은 초기 생성용이며 편집기에서 사용자가 추가·삭제한 페이지를 재구성하는 근거로 사용하지 않는다. 저장 키·기존 요소 좌표·서버 API·속지 자산은 변경하지 않는다.

## 검증 상태

사용자 요청에 따라 에이전트는 테스트·빌드·앱 화면·실기기 검증을 실행하지 않았다. 커밋·푸시·MR의 결과는 별도 MR 본문에 기록한다.

사용자 확인 항목:

- 기본 78페이지와 원래 순서, 위클리 양식 변경 및 주차 중복 없음.
- 포함·제외 조합, 데일리 여러 양식의 매월 장수, 공용 노트 여러 종류·매월 장수·배치와 총 페이지 수.
- 모두 제외 시 빈 페이지 1장, 장수 오류, 이전 단계 이동·취소 및 저장 실패 재시도.
- 생성 직후 재실행 복원, 기존 다이어리·사용자 요소 보존, 이름·색상 수정 시 페이지 불변.
- 편집·썸네일·내보내기의 같은 속지 표시.

## 최신 develop 충돌 통합 (2026-10-21)

- develop 9315d0a의 휴지통·복원·영구 삭제, 편집기 제목 동기화와 문서·속지 미리 읽기를 유지했다.
- 생성 모달은 월별 다중 속지 구성과 저장 실패·중복 생성 방지를 유지한다. 새 문서를 저장한 뒤 편집기 캐시도 같은 문서로 갱신한다.
- 사용자 승인에 따라 첫 속지 1장·날짜 선택 화면은 사용하지 않으며, migrateUntouchedAnnualDoc는 저장 문서를 그대로 반환한다. 비어 있는 기존 78페이지와 사용자 구성 문서 모두 재진입 시 축소하지 않는다.
- 테스트·빌드·앱 화면·실기기 조작은 실행하지 않았다. 충돌 표시와 diff 공백 검사만 확인한다.
- develop의 frontend/tests/templates.test.js에는 기본 1페이지 생성, 빈 연간 문서 1페이지 축소, 기본 문서에 한 장 추가 후 총 2페이지를 기대하는 항목이 있다. 현재 승인된 월별 구성·기존 문서 보존 동작과 기대값이 다르다. 이번 충돌 해결에서는 테스트를 수정·실행하지 않았으며 후속 검증 시 기대값 정리가 필요하다.
- develop의 세로형 메타데이터 강제 변환도 적용하지 않았다. 기존 portrait 값은 보존하고 신규 선택만 비활성화한다.

## 내지 색상 선택

- 속지 구성 다음 단계에서 배경색·레이아웃 색을 각각 선택한다. 배경 추천 6종(화이트·크림·세이지·로즈·아이스 블루·웜 그레이), 레이아웃 추천 6종(차콜·네이비·브라운·포레스트·플럼·슬레이트)을 제공한다.
- + 버튼으로 기존 색상 팔레트(색상·채도·밝기와 HEX 입력)를 열며 첫 페이지 대표 미리보기에 즉시 반영한다. 이전 단계로 돌아가도 구성·색상은 보존하고 취소 시 문서를 만들지 않는다. 첫 페이지 속지가 없는 구성은 빈 페이지 배경색을 미리 보여 준다.
- paperAppearance: { backgroundColor, layoutColor }를 목록·문서·생성 페이지에 저장한다. 값은 6자리 HEX이며 잘못되었거나 없는 값은 흰 배경(#FFFFFF)·기존 레이아웃(#292929)을 사용한다. SVG 원본과 기존 문서는 수정하지 않는다.
- 흰 종이 사각형만 배경색으로 바꾸고 레이아웃의 6가지 색은 선택한 색과 배경 사이에서 기존 농도 차이를 유지해 변환한다. opacity는 유지한다. 사용자 글자·사진·필기 색상은 바꾸지 않는다.
- 편집·읽기·썸네일은 공통 PageBackground에 적용하고 PNG/PDF는 동일한 규칙으로 준비 XML에 적용한다. 원본 AST 캐시를 변경하지 않는다. 빈 페이지 출력도 선택한 배경색을 쓴다. 문서에 새로 추가하는 속지도 같은 배색을 따르며 페이지 복제 시 해당 페이지 배색을 유지한다.
- 사용자 요청에 따라 기능 테스트·웹/네이티브 빌드·화면·실기기 확인은 실행하지 않았다. 수정한 JavaScript 9개 파일의 문법 해석만 확인했다.
- 사용자 확인: 추천색/+ 팔레트 실시간 표시, 첫 페이지와 생성 결과 일치, 이전 단계/취소, 재시작 후 색상 복원, 추가·복제 페이지, 편집/읽기/썸네일 및 PNG/PDF 결과, 기존 문서 색상 불변.

### 팔레트 입력 보정

- 색상 선택 시 별도의 직접 지정 칸을 삽입하지 않고 + 칸에 선택색을 표시한다. 드래그 도중 줄바꿈으로 팔레트가 아래로 이동하지 않게 배치를 고정한다.
- 팔레트의 화면상 위치·크기를 측정하고 실제 터치의 화면 좌표를 0~1 범위로 환산한다. 누적 드래그 거리와 로컬 시작점을 섞지 않으며 경계 밖은 가장자리로 제한한다.
- 팔레트는 전용 responder로 입력을 유지한다. 생성 모달은 팔레트 드래그 중 세로 스크롤을 잠그고, 손을 떼거나 시스템 취소·팔레트 해제 시 다시 허용한다. 웹 팔레트 영역은 touchAction: none을 적용한다.
- 수정한 JavaScript 3개 파일의 문법 해석만 확인했으며 기능 테스트·빌드·실기기 조작은 실행하지 않았다.

- 직접 지정 버튼의 + 기호 뒤 흰 배경을 없애고, 선택색 밝기에 따라 기호 색만 조정한다.
- 단계 뒤로가기는 하단 다음/생성 버튼 왼쪽에 배치한다. 속지 구성에서는 이름과 표지, 내지 색상에서는 속지 구성으로 돌아간다. 입력값과 색상은 유지한다.
