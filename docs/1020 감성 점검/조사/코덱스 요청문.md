## 대상 앱
DIO: 하루 한 장 사진/페이지를 캔버스 삼아 친구들과 함께 꾸미는 공유 다이어리(다꾸) 앱. React Native(Expo) + 태블릿(가로 1280×800 기준)과 폰(390×844). 마스코트는 노란 작은 캐릭터 '모아'(몸 색 #FEF0BF), 기본 프로필은 primaryStrong 동그라미에 흰 눈·입.
첨부 이미지: 지금 앱 화면들(파일 이름 = 기기 + 순번 + 화면). tab = 태블릿, phone = 폰.

## 지켜야 하는 것 (이것만 지키고 기존 디자인 가이드는 무시해도 된다)
1. 색: 브랜드 UI 색상 계열(H≈232°, 페리윙클~네이비) + 포인트 버터 노랑 계열만. 그 밖의 색상각(핑크·민트·빨강·초록 등)은 제안하지 않는다. 지금 토큰: primary #818AC3, primaryStrong #606BB2, primaryText #525FAD, secondary #ABB1D8, text #0B1766, lavender100 #DBDCF9, surfaceMuted #F0F1F9, cardBorder #D9DCEF, butter #FEF0BF, butterTape #FBE5A3, butterStrong #B98208. 이 BI 색값 자체는 바꾸지 않는다(파생 단계 추가는 가능, 반드시 같은 색상각 계열).
2. 버튼 · 탭 · 타일을 누를 때 반짝임 · 크기 변화 · 깜박임 · 내려앉음 · 색 바뀜 같은 눌림 효과 금지.
3. 가운데 뜨는 모달 팝업은 최대한 지양(누른 자리 옆 말풍선 또는 전체 화면).
그 밖(글꼴 · 크기 · 모서리 · 레이아웃 · 말투 · 아이콘 · 장식 · 화면 구성)은 전부 바꿔도 된다.

## 조사 요약 (팀이 웹 조사로 확인한 것)
- 1020은 "정돈된 완성품"보다 "내 손길이 닿은 것(꾸밀 맛)"을 좋아한다. 브랜드는 놀이터(판)를 깔아준다.
- 매끈한 기업풍(대칭, 매끈한 그라디언트, 스톡 일러스트, 범용 UI 키트)은 "AI 룩/기업 룩"으로 촌스럽게 본다. 반대로 손맛·종이·테이프·스티커·컷아웃·살짝 기울인 배치가 감성.
- 장식은 콘텐츠 '주변'에, 컨트롤 위에 얹지 않는다. 손글씨체는 짧은 이름표·빈 화면 한 줄에만, 본문·설정은 산세리프.
- 말투: 짧게, 한 문장 한 메시지, "~하기" CTA, 쿨한 척/과한 유행어는 역효과(NN/g). 토스식 군더더기 제거.
- 즐거움은 눌림 효과 대신 "결과의 연출"(스티커 착지, 테이프 붙음, 도장 찍힘), 수집이 눈에 보이게 쌓임(압박 없는 누적), 개인화(프로필·공간 꾸미기), 친한 소수 서클.
- 문방구 소품 → UI: 인덱스 탭(선택 탭은 패널과 같은 면으로 이어지고 아래 선 없음, 오목 플레어로 패널과 연결), 마스킹테이프(섹션 머리 · 사진 고정), 견출지/라벨 스티커(섹션 제목 · 칩), 포스트잇(빈 화면 · 메모), 영수증/티켓(저장 완료 알림 · 공유 카드, 톱니/노치), 도장(완료 · 뱃지), 절취선(구분선), 펀칭 구멍/바인더 링(카드 가장자리), 클립(첨부 표시), OPP 봉투(스티커 보관함). 과하면 키치 · 혼잡 · 대비 실패 · 콘텐츠 소품과 UI 소품이 섞임 → UI 소품은 한 단계 정돈된 평면 + 단색, 한 화면 1~2개, 노랑은 표지판 하나에만.
- 인덱스 탭 참고: 실물 문방구 인덱스는 윗모서리만 둥근 직사각이 다수, 브라우저/바인더는 사다리꼴. 터치 타깃 48dp 이상.
- 지금 꾸미기 공방 인덱스: 사다리꼴(아래 넓음, SLANT 12, 위 모서리 8), 폭 128(폰 100), 높이 42 · 선택 50, 이웃과 14 겹침, 탭마다 색 다름(lavender100 · butter · #C9CDEE · butterTape · #E7E8F8), 아래 6px 선택 탭 색 띠. 사용자는 "인덱스 모양 좀 개선"을 원한다.
- 지금 글꼴: 시스템 산세리프(웹은 Noto Sans 계열), 제목 22~30/800, 본문 15/700 위주(굵은 글씨가 많음).

## 할 일
1) **화면별 점검표**: 첨부 화면을 하나씩 보고 1020 감성에 안 맞는 곳(올드함 · 관공서/업무용 느낌 · 촌스러움 · 밋밋함 · 과함)을 모두 찾는다. 표: 화면 | 문제 | 왜 1020에게 안 맞는지 | 바꿀 방향 | 심각도(상/중/하). 최소 35개. 좌표·수치는 첨부를 정확히 재지 말고 "어디의 무엇"으로 쓴다.
2) **전체 방향 제안 2안**: 예) A "문방구 서랍"(소품 악센트 중심), B 다른 방향 하나. 각 안의 한 줄 콘셉트, 글꼴(실제 한국어 무료 글꼴 이름과 쓰임: 제목/본문/숫자/이름표), 크기·굵기 단계, 모서리, 그림자, 바탕(종이 결 여부), 아이콘 선 굵기/스타일, 말투 예시 5개(지금 문구 → 바꿀 문구), 장점/위험. 그리고 추천안 하나.
3) **문방구 소품 악센트 체계**: 소품마다 앱의 어느 자리에(구체적 화면/요소), 어떤 모양(수치: dp, 반경, 각도, 색 토큰), 한 화면 최대 몇 개, 하지 말 것. 최소 10개 소품.
4) **꾸미기 공방 인덱스 탭 개선안**: 2~3개 시안을 수치로(경로 모양, 폭, 높이, 선택/비선택 높이차, 겹침/간격, 위 모서리, 오목 플레어, 탭 면 색(규칙 안), 글자, 라벨 스티커 여부, 아래 패널 연결 방식, 폰 크기). 추천 하나와 이유.
5) **우선순위 로드맵**: 1단계(가장 효과 큰 10개), 2단계, 3단계. 각 항목 작업 크기(소/중/대).
6) 지키기 어려운 것이 있으면(예: 노랑을 큰 면에 써야만 예쁨 등) 솔직히 적는다.
