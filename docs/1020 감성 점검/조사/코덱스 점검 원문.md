## 총평

지금 DIO는 색과 일러스트는 이미 친근하지만, 화면 구조가 “정돈된 업무용 UI”에 더 가깝습니다. 1020이 좋아할 만한 다꾸의 손맛은 표지와 빈 화면 캐릭터 정도에만 있고, 실제 탐색·꾸미기·공유 경험은 탭/세그먼트/카드가 매우 반듯하고 균일합니다.

핵심은 “더 꾸미기”가 아니라, **앱 UI는 한 단계 정돈하고 사용자의 기록물만 더 자유롭게 보이게 하는 것**입니다. 노랑은 넓게 칠하지 않고, 중요한 한 곳을 가리키는 표지판처럼만 쓰는 편이 좋습니다.

# 2. 전체 방향 제안 2안

## A안 — “문방구 서랍”

한 줄 콘셉트: **정돈된 책상 위에, 내가 고른 라벨과 테이프로 기록을 꺼내 보는 다이어리.**

가장 추천하는 방향입니다. 앱 구조는 차분하고 빠르게, 내 기록물과 수집 요소만 종이·테이프·라벨의 손맛을 갖습니다.

| 항목 | 제안 |
|---|---|
| 제목 글꼴 | `Gowun Dodum` 700. 화면 제목, 다이어리 이름, 빈 상태 한 줄 |
| 본문 글꼴 | `Pretendard` 400~500. 입력, 설명, 설정, 초대 |
| 숫자 | `Pretendard` 600 + tabular 숫자. 페이지 수·날짜·알림 수 |
| 이름표 글꼴 | `Nanum Pen Script` 400은 사용자가 만든 표지·짧은 라벨에만. 시스템 본문에는 금지 |
| 제목 단계 | 30/800: 태블릿 화면 제목, 24/750: 모바일 화면 제목, 20/700: 섹션 제목 |
| 본문 단계 | 16/500: 기본 본문, 14/500: 보조 설명, 12/600: 메타·페이지 수 |
| 모서리 | 종이 카드 16dp, 도구 바 14dp, 버튼 12dp, 라벨 6dp |
| 그림자 | 카드만 `#0B1766` 8%의 y 8 / blur 20. 버튼은 그림자 없이 테두리 또는 면으로 구분 |
| 바탕 | `surfaceMuted #F0F1F9` 기반의 평면. 종이 결은 2% 이하의 아주 약한 노이즈만, 입력·편집 캔버스에는 사용하지 않음 |
| 아이콘 | 1.8dp 단색 선 아이콘, 끝은 round. 선택 상태도 아이콘 색/외곽선만 고정해 표현 |
| 포인트 색 | 기본은 `text #0B1766`, `primaryStrong #606BB2`, `lavender100 #DBDCF9`. 버터 `#FEF0BF`는 한 화면의 중요한 표지 하나에만 |

말투 예시:

| 지금 문구 | 바꿀 문구 |
|---|---|
| DIO에 오신 걸 환영해요 | 오늘의 한 장을 시작해요 |
| 게스트로 시작하기 | 먼저 둘러보기 |
| 아직 만든 폰트가 없어요 | 만든 글씨가 아직 없어요 |
| 아직 스티커 폴더가 없어요 | 스티커를 모아 볼까요? |
| 휴지통이 비어 있어요 | 지운 기록이 없어요 |

장점은 DIO의 다꾸 정체성이 가장 자연스럽게 드러나고, 이후 스티커·표지·폰트 수집 구조를 확장하기 쉽다는 점입니다. 위험은 테이프·라벨·펀칭 요소를 많이 쓰면 빠르게 키치해진다는 점입니다. 따라서 **한 화면 UI 소품은 최대 2개**가 원칙입니다.

## B안 — “사진부 아카이브”

한 줄 콘셉트: **친한 사람들과 하루 한 장을 차곡차곡 보관하는, 차분한 사진 기록함.**

A안보다 더 절제된 방향입니다. 다꾸보다 사진과 관계성, 공유 기록의 아카이브 감각을 강조합니다.

| 항목 | 제안 |
|---|---|
| 제목 글꼴 | `SUIT` 800. 제목과 다이어리명 |
| 본문 글꼴 | `Noto Sans KR` 400~500. 긴 설명, 설정, 초대 |
| 숫자 | `SUIT` 700. 날짜·페이지·알림 |
| 이름표 글꼴 | `Gowun Dodum` 700. 카드 표지·공유 다이어리 이름에만 |
| 제목 단계 | 28/800, 22/750, 18/700 |
| 본문 단계 | 16/450, 14/500, 12/600 |
| 모서리 | 카드 12dp, 사진 프레임 8dp, 버튼 10dp |
| 그림자 | 거의 없음. 사진 카드에만 `#0B1766` 6%의 y 6 / blur 16 |
| 바탕 | `#F7F8FD`에 가까운 아주 옅은 페리윙클 종이. 질감 없음 |
| 아이콘 | 2dp 단색 선, 작은 격자·레이어·앨범 메타포 중심 |
| 포인트 색 | 공유/알림은 `primaryStrong #606BB2`, 수집/완료는 `butterTape #FBE5A3` 한 곳만 |

말투 예시:

| 지금 문구 | 바꿀 문구 |
|---|---|
| 모든 다이어리 | 전체 기록 |
| 즐겨찾기 | 자주 보는 기록 |
| 공유 다이어리 | 함께 쓰는 기록 |
| 다이어리 초대 | 같이 기록할까요? |
| PDF 불러오기 | PDF에서 시작하기 |

장점은 덜 유행을 타고, 공유 다이어리·사진 기록의 신뢰감이 높다는 것입니다. 위험은 DIO가 다른 사진 보관 앱과 비슷해 보일 수 있고, “꾸밀 맛”이 약해질 수 있습니다.

### 추천: A안 “문방구 서랍”

DIO의 핵심은 단순 기록이 아니라 “친구들과 한 장을 꾸미는 것”입니다. 그래서 앱의 구조까지 시끄럽게 꾸미지는 않되, **사용자가 눌러 만든 결과가 쌓이는 장소**라는 정체성을 분명하게 만들어야 합니다.

- 일반 화면: UI 소품 최대 2개.

# 4. 꾸미기 공방 인덱스 탭 개선안

현재 사다리꼴 탭은 색과 기울기가 반복되어 무겁고, 선택 탭이 패널과 이어진다는 느낌도 약합니다. 특히 모바일에서는 탭이 잘릴 때 “가로 스크롤 가능한 도구”가 아니라 “레이아웃이 부족한 화면”처럼 보일 수 있습니다.

## 시안 A — 바인더 등 라벨형

가장 차분하고 제품 완성도가 높은 안입니다.

| 항목 | 수치 |
|---|---|
| 기본 경로 | 상단은 둥근 직사각형, 측면은 수직, 하단 양끝만 6dp 안쪽으로 들어가는 오목 플레어 |
| 태블릿 폭 | 선택 116dp, 비선택 108dp |
| 모바일 폭 | 선택 96dp, 비선택 92dp |
| 높이 | 선택 50dp, 비선택 42dp |
| 겹침 | 이웃 탭과 8dp 겹침 |
| 위 모서리 | 10dp |
| 아래 연결 | 선택 탭 하단은 0dp 간격으로 패널 면에 연결. 선택 탭 아래 선 없음 |
| 패널 | 상단 1dp만 `cardBorder #D9DCEF`, 선택 탭 아래의 선은 끊김 |
| 색 규칙 | 기본 탭은 `lavender100 #DBDCF9` 또는 `surfaceMuted #F0F1F9`; 선택 탭은 해당 섹션의 같은 면 색. 버터 탭은 스티커 또는 속지 중 하나에만 |
| 글자 | `Pretendard` 15/700, 선택은 `text #0B1766`, 비선택은 `primaryText #525FAD` |
| 라벨 | 별도 라벨 스티커 없음 |

장점: 실물 바인더·파일 탭에 가깝지만 유치하지 않고, 선택 상태가 매우 명확합니다.

# 6. 솔직히 말하면 지키기 어려운 점

- 버터 노랑을 넓은 배경이나 여러 탭에 반복해서 쓰면, 처음에는 귀엽지만 빠르게 유아용·키치한 인상으로 갈 가능성이 큽니다. `#FEF0BF`, `#FBE5A3`는 **한 화면의 안내 표지 하나**라는 규칙을 지키는 편이 더 세련됩니다.
- 종이 질감, 테이프, 손글씨체를 동시에 많이 넣으면 1020이 좋아하는 “꾸밀 여지”가 아니라 브랜드가 사용자의 기록을 대신 꾸민 느낌이 됩니다.
- 눌림 효과를 쓰지 않는 대신, 선택 상태는 색 변화가 아닌 **고정된 구조 차이**로 충분히 구분해야 합니다. 예를 들어 선택된 인덱스 탭은 패널과 이어지고, 선택된 도구는 테두리와 작은 색 점으로만 표시합니다.
- 편집기에서는 소품보다 캔버스 면적이 우선입니다. 다꾸 감성은 툴바가 아니라 사용자가 만든 페이지에서 나와야 합니다.
