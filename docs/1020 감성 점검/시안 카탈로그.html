DIO 1020 시안 카탈로그

앱 전체 화면 45장과 웹 조사 두 갈래(검색 67회)를 코덱스가 함께 보고 낸 시안입니다. 탭 견본은 눌러서 바꿔 볼 수 있습니다. 글꼴은 웹에서 쓸 수 있는 것으로 대신 보여 줍니다(Pretendard → Noto Sans KR, SUIT → IBM Plex Sans KR).

  • UI 색: 페리윙클 계열 + 버터 노랑만
  • 눌림 효과 없음
  • 가운데 모달 지양

서랍 4

문방구 소품 견본

한 화면에 UI 소품은 최대 2개, 노랑은 한 곳만 씁니다. 버튼 · 입력칸 위에는 얹지 않고, 사용자가 붙인 스티커와 섞이지 않게 평면 단색으로 둡니다.

서랍 6

지금 화면에서 고칠 곳

코덱스가 찾은 63곳 가운데 심각도 '상'을 화면별로 묶었습니다. 회색 글은 Claude가 화면과 지난 지시를 대조한 메모입니다.

홈
  • 카드가 가운데 떠 있어 빈 공간이 더 큼 → 제목 아래로 당기기
  • 표지가 다 비슷해 템플릿 목록 같음 → 최근 편집 · 공유 중 견출지
꾸미기 공방
  • 사다리꼴 반복이 무거움 → 서랍 1
  • 프리셋 색 점이 체계 없이 나열 → 내 조합 · 최근 · 기본

프리셋 동그라미는 지난번에 되살린 모양이라 바꾸기 전에 다시 여쭙니다.

내 공간
  • 운영체제 설정 화면 같음 → 2분절 대신 스위치, 프로필 도장 · 한 줄 소개

"알림 · 보안 접기, 앱 정보 별도 화면"은 정해 주신 한 단 구조와 부딪혀 보류했습니다.

편집기
  • 위 · 도구 · 아래 바가 모두 떠 있는 흰 카드 → 위는 얇은 바, 도구만 필통 바
  • 글자 패널이 길어 캔버스를 덮음 → 글꼴 · 크기 · 색 · 정렬만 먼저

코덱스는 "가운데 팝업"으로 읽었지만 실제로는 도구 아래 붙는 패널입니다.

편집기(폰)
  • 도구가 빽빽하고 캔버스가 작음 → 자주 쓰는 5개 + 더보기 서랍
홈(폰)
  • 아래 탭과 떠 있는 + 가 같은 자리에서 경쟁 → 만들기 진입 하나로

빈 화면에 "30일 보관" 같은 설명을 더하자는 제안과 첫 진입 스와이프 힌트는 안내 멘트 금지 지시와 부딪혀 넣지 않았습니다.

정해 주실 것
