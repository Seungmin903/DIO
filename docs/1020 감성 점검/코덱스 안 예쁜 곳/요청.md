## 할 일
첨부한 DIO 앱 화면(공유 다꾸 다이어리 앱, 태블릿 1280×800 · 폰 390×844)을 보고, **전반적으로 안 예쁜 부분**을 찾아 PDF 한 개로 만든다.
- **한 페이지에 한 세트**: ① 안 예쁜 부분(해당 화면에서 그 부분을 잘라낸 그림, 빨간 네모로 표시) ② 왜 안 예쁜지(2~4문장) ③ 어떻게 고쳤으면 좋겠는지(구체적인 수치 · 색 hex · 크기 · 배치. 가능하면 고친 모습을 간단한 그림으로 나란히).
- 최소 20세트, 가장 눈에 띄는 것부터. 첫 페이지는 표지(제목 · 날짜 2026-10-31 · 세트 목록).

## 화면 파일
- 화면 원본 폴더: `../지금 화면/` (파일 이름 = 기기 + 순번 + 화면). 첨부 이미지와 같은 파일이다. 잘라낼 때는 이 원본을 쓴다(PIL 등).
- 이 화면들은 2026-10-31 오전 기준이다. 지금 개발 중인 변경(아래)과 이미 겹치는 지적이면 "진행 중"이라고 표시한다.

## 지켜야 할 조건(제안도 이 안에서만)
1. 색: 브랜드 UI 색상 계열(H≈232°, 페리윙클~네이비) + 포인트 버터 노랑 계열만. 토큰: primary #818AC3, primaryStrong #606BB2, primaryText #525FAD, secondary #ABB1D8, text #0B1766, lavender100 #DBDCF9, surfaceMuted #F0F1F9, cardBorder #D9DCEF, butter #FEF0BF, butterTape #FBE5A3. 이 값은 바꾸지 않는다.
2. 누를 때 반짝임 · 크기 변화 · 깜박임 · 색 바뀜 같은 눌림 효과 없음. 결과 연출(스티커 착지 · 도장 등)도 넣지 않는다.
3. 가운데 모달 팝업은 지양(누른 자리 옆 말풍선 또는 전체 화면).
4. 사용법 · 결과를 미리 알려 주는 안내 문구는 넣지 않는다.
5. 속지 · 특수 속지 · 사용자가 캔버스에 쓴 글자는 정해진 글꼴을 그대로 쓴다(앱 UI 글꼴로 바꾸지 않는다).

## 이미 정해져 지금 개발 중인 방향(이와 맞게 제안)
- 전체 방향 "사진부 아카이브": 바탕 #F7F8FD 옅은 페리윙클 종이(질감 없음), 그림자 거의 없음(사진 · 표지 카드만 6% y6 blur16), 모서리 사진 틀 8 · 버튼 10 · 카드 12, 테두리 칩(흰 면 + #D9DCEF 테두리, 고르면 #606BB2 테두리), 켬/끔은 52×32 스위치.
- 글꼴은 Pretendard 하나. 굵기: 제목 20↑ 700~800, 16~19는 500~700, 16 미만 본문 400~500 · 작은 이름표 500~600.
- 꾸미기 공방 인덱스 탭: 견출지 스택형(위 모서리 8 직사각, 폭 104, 높이 40/48, 6 간격, 고른 탭 lavender100이 2 내려와 선을 덮음, NEW 라벨 없음).

## 만드는 법
- 이 폴더(현재 작업 폴더)에 `crops/`(잘라낸 그림), `안 예쁜 곳.html`, 최종 `코덱스 안 예쁜 곳.pdf`를 만든다.
- HTML은 A4 가로 한 쪽에 한 세트(`page-break-after: always`), 글꼴은 시스템 한글 글꼴, 색은 위 토큰.
- PDF는 크롬/엣지 헤드리스로 만든다: `"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --disable-gpu --no-pdf-header-footer --print-to-pdf="<절대경로>.pdf" "file:///<절대경로>.html"` (경로는 절대 경로, Python 실행 시 `PYTHONIOENCODING=utf-8`).
- 다 만들고 PDF 쪽수와 세트 목록을 마지막에 출력한다.
