> 지킨 조건 셋: ① UI 색은 브랜드 색상 계열(H≈232°) + 포인트 버터 노랑만 ② 누를 때 반짝임·크기 변화·깜박임 같은 눌림 효과 없음 ③ 가운데 모달 팝업은 최대한 피함. 그 밖의 기존 디자인 가이드 규칙은 이번 점검에서 따지지 않았다.

**조사의 한계.** 한국 1020이 "UI가 촌스럽다"고 느끼는 것을 직접 잰 공신력 있는 설문은 찾지 못했다. 대학내일20대연구소·캐릿 일부 글은 유료라 본문을 못 읽었다. 그래서 아래 근거는 대부분 기사·디자인 회사 글·NN/g 연구이며 "방향성 근거"로 본다. 확정 전에 10~20대 12~20명에게 5초 첫인상 테스트를 해 보길 권한다.

## 1. 한 줄 결론

**앱 UI는 한 단계 더 차분하고 덜 굵게, 사용자가 만든 기록만 더 손맛 있게.** 지금 DIO는 색과 캐릭터는 친근하다. 하지만 탭·세그먼트·카드·버튼이 모두 같은 둥근 부품이라 "정돈된 업무용 UI"처럼 읽힌다(코덱스 총평). 문방구 소품은 "탐색 표지판" 자리에만 한 화면 1~2개 넣는다. 사용자의 스티커·테이프와 섞이지 않게 평면·단색으로 둔다.

## 2. 조사에서 나온 것

**1020이 좋아하는 것**
- **꾸밀 맛(내 손길이 닿은 것)**: 다꾸·폰꾸·폴꾸의 이유는 "나를 찾고 보여주고 소유하고 싶은 욕구"다. 브랜드는 완성품 대신 판(놀이터)을 깐다(위픽 레터).
- **날것·손맛**: 포토덤프·B컷·종이 질감·테이프·컷아웃이 감성으로 읽힌다. 반대로 매끈한 그라디언트, 완벽한 대칭, 스톡 일러스트는 "AI 룩·기업 룩"이다(디자인 트렌드 글, 근거 데이터는 약함).
- **작은 서클**: 70%가 친한 친구 범위의 자기표현을 선호한다(Snap 호주 조사). Locket·BeReal처럼 지표를 숨기고 소수와 나눈다.
- **결과가 쌓이는 재미**: 책장이 채워지거나 탑승권이 쌓이는 식이다. 연속 기록으로 압박하지 않고 누적으로 보여 준다.

**촌스럽거나 업무용으로 느끼는 것**
- 긴 글, 다 같은 무게의 굵은 글씨, 쿨한 척하는 말투와 과한 유행어(NN/g 18~25세 연구).
- 범용 UI 키트처럼 모든 부품이 같은 모양인 것, 장식이 조작을 가리는 것, 건너뛸 수 없는 긴 안내.
- 익숙한 버튼 위치가 한꺼번에 바뀌는 업데이트. 그래서 리뉴얼은 단계로 나눈다.

**문방구 소품을 UI로 옮길 때**
- 인덱스 탭의 핵심은 **고른 탭이 패널과 같은 면으로 이어지는 것**이다. 고른 탭은 아래 선이 없고, 오목한 플레어로 패널에 붙는다. 실물 문방구 인덱스는 위 모서리만 둥근 직사각형이 많고, 사다리꼴은 브라우저·바인더 계열이다.
- 장식은 화면이 밀도 높은 곳(도구 바·설정)에서는 빼고, 빈 화면·주요 표지에만 쓴다(Clay). 색을 못 늘리니 모양·간격·굵기로 위계를 만든다.
- RN에서 종이 결 필터(`FeTurbulence`)는 지원 목록에 없다. 쓰려면 작은 타일 그림을 아주 옅게 반복한다.

## 3. 화면별 점검 요약

코덱스가 화면별로 문제 63개를 찾았다(전체는 [원문](조사/코덱스%20점검%20원문.md) 1장). 심각도 '상'만 추리면 아래와 같다. **오른쪽 열은 Claude가 화면과 지시를 대조한 결과다.**

| 화면 | 문제(코덱스) | 바꿀 방향(코덱스) | 대조 |
|---|---|---|---|
| 홈(태블릿) | 카드가 화면 가운데 떠 있어 빈 공간이 더 큼 | 시작 위치를 제목 아래로, 카드 사이에 기록 맥락 | 맞음 |
| 홈(태블릿) | 표지가 모두 비슷한 정면 직사각형이라 템플릿 목록 같음 | 사진 모서리 · 이름 라벨 · 최근 편집 같은 사용자별 차이 | 맞음 |
| 홈(폰) | 아래 탭과 떠 있는 `+`가 같은 자리에서 경쟁 | 만들기 진입을 하나로 | 맞음 |
| 새 다이어리 | 왼쪽 단계 메뉴가 설정 마법사 같음 | 표지 고르기 → 속지 고르기 → 이름 붙이기의 창작 순서 | 맞음 |
| 공방 인덱스 | 넓은 사다리꼴의 반복이 무겁고 오래된 폴더 탭 같음 | 고른 탭과 패널이 한 면으로 이어지게 → 4장 | 맞음 |

| 편집기 스티커 | 패널이 캔버스 가운데를 크게 가림 | 아이콘 아래 좁은 앵커 패널 | 맞음 |

| 편집기(폰) | 도구가 빽빽하고 캔버스가 작음 | 자주 쓰는 5개 + 더보기 서랍 | 맞음 |

| 전 화면 | 카드 · 세그먼트 · 버튼이 같은 둥근 문법 | 종이 · 라벨 · 도구를 역할별 모양으로 | 맞음 |

**채택하지 않을 제안(지시와 충돌).**
- 빈 화면에 "30일 보관" 같은 설명 덧붙이기, 휴지통 캐릭터 아래 안내, 첫 진입 스와이프 힌트는 '안내 멘트 금지' 지시와 부딪힌다. 빈 화면은 지금처럼 캐릭터와 한 줄로 둔다.
- 버튼·아이콘의 정적인 아래 깊이선(Duolingo식)은 눌림 효과가 아니지만, 조사 ②가 "눌려 보이는 입체는 쓰지 않는 쪽이 일관된다"고 했다. 지금 채움 버튼의 2px 아래 선도 함께 검토 대상이다.

**코덱스 추천은 A안이다.** 실물 바인더 인덱스에 가깝지만 유치하지 않고, 고른 탭이 종이 한 장으로 이어져 지금 어느 서랍을 보는지 바로 보인다. 폰에서는 한 줄에 억지로 넣지 않는다. 좌우 여백 18의 가로 스크롤로 두고 다음 탭이 20쯤 보이게 한다. 지난번에 "인덱스마다 색이 달라도 귀엽겠다"고 하셨으니, A안에서 탭마다 색을 남길지(코덱스는 버터 한 칸만 권함)는 고르실 때 함께 정해 주세요.

## 5. 문방구 소품 체계

![문방구 소품 견본](이미지/문방구%20소품%20견본.png)

**공통 규칙**
- 한 화면에 UI 소품은 최대 2개, 버터 계열은 한 곳(표지판)만 쓴다.
- 버튼·입력칸·도구 바 위에는 테이프·스티커를 얹지 않는다.
- 소품은 누르는 것과 누르지 않는 것을 섞지 않는다. 라벨·탭 모양은 누를 수 있는 것에만 쓴다.
- 모든 터치 대상은 48 이상이다. 그림이 작으면 터치 영역으로 채운다.
- 편집 캔버스 안의 사용자 스티커·테이프는 화려하게 두고, UI 소품은 평면 단색으로 구분한다.

| 소품 | 자리 | 모양 · 크기 | 색 |
|---|---|---|---|
| 인덱스 탭 | 꾸미기 공방 종류 | 4장 | `surfaceMuted` · 흰색 · 버터 한 칸 |
| 견출지 라벨 | 다이어리 카드 상태(최근 편집 · 공유 중) | 높이 24, 반경 6 | `lavender100`, 버터 하나 |
| 마스킹 테이프 | 새 다이어리 표지 미리보기, 사진 고정 | 48×18, ±3° | `butterTape` 또는 `lavender100` |
| 포스트잇 | 빈 화면 한 줄 | 144×92, 반경 4, -2° | `butter` |
| 영수증 | 저장 · 내보내기 · 공유 완료 알림 | 폭 220, 위아래 톱니 6 | 바탕 `#F7F8FD`(H 230°), 선 `secondary` |
| 도장 | 초대 수락 · 완료 표시(튀는 연출 없음) | 지름 28~36 | `primaryStrong` |
| 절취선 | 공방 구역 · 초대 상태 구분 | 점 3, 간격 4 | `cardBorder` |
| 바인더 링 | 페이지 목록 · 다이어리 상세 가장자리 | 지름 12, 간격 24, 3개 이하 | `secondary` |
| 종이 클립 | PDF로 시작한 다이어리, 첨부 표시 | 선 아이콘 18~20 | `primaryText` |
| OPP 봉투 | 내 스티커 폴더 | 96×72, 겹친 면 2장 + 위 접착 띠 | `surfaceMuted` · `secondary` |
| 사진 모서리 | 홈 첫 표지, 초대 썸네일 | 18 삼각 2개 | `lavender100` |
| 책갈피 | 페이지 목록 · 즐겨찾기 | 12×20 리본, 터치 48 | `primaryStrong` |

**즐거움은 눌림 대신 결과로.** 스티커가 착지하거나, 테이프가 붙거나, 도장이 찍히는 결과를 짧게 한 번 보여 준다. 진동은 완료·붙임·저장 같은 순간에만 쓴다. 다만 이것도 "반짝임·깜박임"으로 보일 수 있어 지시 범위를 확인받은 뒤 넣는다.

| 공유 다이어리 | 함께 쓰는 기록 |

**글꼴을 바꿀 때의 비용.** Pretendard와 Gowun Dodum을 앱에 넣으면 글꼴 파일만큼 앱이 커진다. Pretendard는 굵기마다 한글 전체가 1~2MB다. 글꼴은 1단계에서 굵기 단계만 먼저 정리하고, 글꼴 교체는 크기를 재 보고 정하는 편이 안전하다.

## 7. 로드맵 (코덱스 안 + 대조)

**1단계 — 효과가 가장 큰 것**

| 작업 | 크기 | 메모 |
|---|---|---|
| 전 화면 글씨 굵기 단계 정리(제목 700~800, 본문 400~500) | 중 | 가장 싸고 효과가 크다 |
| 꾸미기 공방 인덱스를 고른 안으로 교체 | 소 | `StudioTabs` 한 파일 |
| 홈 카드: 첫 카드 완전히 보이게, 최근 편집 · 공유 중 견출지 | 대 | 홈은 팀원 담당 영역이라 협의 필요 |
| 폰 홈의 `+`와 아래 탭 정리 | 중 | |
| 편집기 글자 패널: 자주 쓰는 것만 먼저, 나머지 더보기 | 중 | |
| 폰 편집기 도구: 자주 쓰는 5개 + 더보기 서랍 | 대 | |
| 편집기 보조 패널은 한 번에 하나 | 소 | |
| 내 공간: 2분절을 스위치로, 프로필 도장 · 한 줄 소개 | 중 | 한 단 구조는 유지 |
| 프리셋: 내 조합 · 최근 · 기본 | 중 | 테이프 모양은 다시 확인 |
| 문방구 소품 부품(라벨 · 영수증 · 도장 · 절취선) 만들기 | 중 | |

**2단계**: 새 다이어리 창작 순서 재배치(대), 초대함 전체 화면 · 상태별 묶음(중), 저장 · 수락 · 내보내기 결과를 영수증 · 도장으로 통일(중), 스티커 폴더를 OPP 봉투로(중), 프로필 개인화(중).

**3단계**: 최근 쓴 스티커 · 테이프 · 글꼴 누적(대), 협업 친구의 마지막 편집 흔적(중), 결과 연출 모션 가이드(중), 접근성 점검(중).

## 8. 정해 주실 것

1. 전체 방향: **A 문방구 서랍**(추천) / B 사진부 아카이브 / 섞기
2. 공방 인덱스 탭: **A 바인더 등 라벨형**(추천) / B / C. 탭마다 색을 남길지
3. 글꼴: 굵기 단계만 먼저 / Pretendard · Gowun Dodum 교체까지
4. 결과 연출(스티커 착지 · 도장 찍힘)과 진동을 넣어도 되는지. 눌림 효과 금지 범위 안인지
5. 1단계 중 팀원 담당 영역(홈 · 편집기 · 알림)까지 손댈지, 공방 · 내 공간부터 할지
