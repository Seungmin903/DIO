# handwriting-native-spacing

관련 태스크: [S15P31F106-396](https://ssafy.atlassian.net/browse/S15P31F106-396) (손글씨 폰트 기능·Android 배포 지원)

새 Android TTF 한글 advance는 `xMax-xMin+32`, 왼쪽 여백은 16이다. 128px 입력 기준 좌우 각 1px이며 윤곽선·높이·기준선·공백 폭은 유지한다. 가변 hmtx와 관련 폭 통계·head 플래그를 갱신한다. 모델·입력 전처리는 바꾸지 않는다.

간격 버전은 `ink-bounds-v1`이며 지원 상태·작업 상태에 기록한다. 기존 `.gly`는 재사용하고 `font-ink-bounds-v1.ttf`로 완성하여 구 `font.ttf`를 덮어쓰지 않는다. 기존 완성 폰트·ID·문서는 자동 변경하지 않는다. 기존 JS 간격 보정도 유지한다. Android는 새 빌드가 필요하다.

검증은 PC Java 생성기와 JS 보정의 한글 11,172자 폭·윤곽선·매핑·공백·기준선·체크포인트 재개 비교다. Android/iPad 실기기·모델 전체 생성·발열은 이번 MR의 범위 밖이다.

실행 결과(2026-11-03): 합성 시험 폰트 11,172자를 PC Java 생성기와 JS 보정으로 비교하여 advance·LSB·윤곽 좌표·컨투어·공백·기준선이 같았다. 혼합 체크포인트 재개 결과가 바이트 단위로 같고 완료 파일 덮어쓰기를 거부했다. 128px의 11,172자 렌더는 위치 보정 후 모두 같았다. 24px 표본 21자 중 7자는 소수점 위치에 따른 래스터 차이가 있었으며 48/256px 표본은 같았다. 손글씨 회귀 53개 통과. Java 컴파일·PC 폰트 검증이며 Android Kotlin 빌드·실기기 폰트 로드는 실행하지 않았다.

MR !330 WARN 수정(2026-11-04): 빈/폭 없는 글리프는 문자 매핑을 유지한 공백(advance 1024, LSB 0)으로 제작한다. 경계 밖 윤곽선은 보존하고 메트릭 계산만 0~2048로 제한한다. 빈·퇴화·경계 밖 체크포인트 회귀와 정상 11,172자 PC Java/JS 비교가 통과했다. 손글씨 회귀 53개 및 diff 검사 통과. INFO 항목과 실기기 검증 범위는 변경하지 않았다.
