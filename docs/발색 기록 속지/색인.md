# 발색 기록 속지 (잉크 발색표)

만년필 잉크를 한 칸에 하나씩 적어 두는 속지. 칸마다 **잉크병 그림 · 이름 줄 · 색 값 셋**(잉크 · 글리터 · 테)이 있고, 병을 그 잉크로 칠하면 색 값이 **저절로** 채워진다. 세로 2×3, 가로 3×2 — 어느 쪽이든 한 장에 여섯 칸이다.

- 바탕이 되는 그림: 잉크병 메모지 2종(각진 병 · 둥근 병). 같은 모양 코드를 속지에서 그대로 쓴다.
- 이름: 잉크 모음 → 잉크 서랍 → 잉크 기록 → **발색 기록**(사용자 2026-11-11). 실제 만년필 사용자들이 쓰는 「발색지 · 발색표」에서 왔다.
- 선례: [여행 노선 속지](../여행%20노선%20속지/색인.md) — 서버 등록 · 배포 순서 · 플래그를 그대로 따랐다.

## 왜 저절로 채워지나

유리펜 획은 이미 색 셋을 들고 있다 — `color`(잉크) · `inkGlitterColor` · `inkSheenColor`. 고르지 않았으면(「맞춤」) 잉크색에서 계산하는데, 편집기 색 칸(`EditablePalette` 의 `glassResolved`)이 쓰는 **같은 함수**(`glitterColorOf` · `sheenAutoColor`)를 쓴다. 그래서 종이에 찍히는 값과 팔레트에 보이는 값이 어긋나지 않는다. 그림에서 색을 뽑아내거나 글씨를 알아볼 필요가 없다.

## 결정 (2026-11-11, 사용자)

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| 여러 번 칠했을 때 | **마지막에 그은 획**의 색 | 덧칠해 고치는 것이 자연스럽다 |
| 펜 종류 | 가리지 않는다. 유리펜이면 색 셋이 다 차고, **다른 펜은 잉크만** 찬다 | 볼펜 · 형광펜에는 글리터 · 테가 없으니 값을 지어내지 않는다 |
| 칠한 모양 | **보정하지 않는다**. 삐져나오든 덜 칠했든 사용자가 한 그대로 둔다 | 손으로 칠하는 맛이 사라진다 |
| 칠했다는 판정 | 네모가 아니라 **병 윤곽** 안에 획의 점이 하나라도 들면 | 어깨 옆 빈자리까지 병으로 치면 엉뚱한 칸이 찬다 |
| 지우기 | 획을 지우면 값도 같이 사라진다 | 저장하지 않고 **그때그때 획에서 읽기** 때문에 저절로 그렇다 |
| 손으로 고치기 | 값 줄 위에 직접 쓰면 그 자리는 자동 값을 찍지 않는다 | 사용자가 고친 것이 이긴다 |
| 빈칸 안내 글씨 | 없다(「이름」 같은 플레이스홀더를 두지 않는다) | 인쇄물처럼 보이게 |

### 바탕은 파일, 덮개만 따로

스터디 · 데일리 · 여행 노선 플래너는 바탕까지 코드로 그리지만, 이 속지는 **바탕이 SVG 파일**이고 자동으로 채우는 미리보기 네모 · `#RRGGBB` 만 덮개로 올린다. `plannerFor` 가 돌려주는 어댑터에 `fileBase: true` 를 두어, 내보내기(`pageExport`)가 `svg()` 로 바탕을 갈음하지 않고 **파일을 읽은 뒤 덮개를 그 안에 끼워 넣게** 했다. 이 표시가 없으면 내보낸 그림에서 바탕이 통째로 사라진다.

값은 `page.planner` 에 저장하지 않고 그때그때 `page.objects` 에서 읽는다(테이스팅 속지와 같은 방식). 화면 쪽은 값 문자열이 같으면 덮개를 다시 만들지 않으므로, 병 바깥에 그은 획은 덮개를 건드리지 않는다.

### 글꼴

인쇄 글자는 모두 **글자 윤곽**(`<g aria-label><path transform="translate scale">`)이라 속지 글꼴을 바꾸면 자동으로 채운 HEX 여섯 자까지 함께 바뀐다. 색은 속지 팔레트 색만 쓴다 — 구조선 `#bfc1c4`, 진한 틀 `#aeb3b8`, 옅은 줄 `#d7d9dc`, 글자 `#292929`(디자인 가이드). 그래야 속지 색 설정이 그대로 먹는다.

## 서버 등록

`V45__add_ink_record_templates.sql`(V34 · V36 과 같은 insert-only 패턴, category `INKRECORD`, display_order 296~299), 선택 플래그 `EXPO_PUBLIC_INK_RECORD_TEMPLATES_ENABLED`(eas.json preview · production 은 0).

배포 순서는 V27 · V36 과 같다: ① 플래그 0 인 프런트 배포(그리기만) → ② V45 적용 → ③ 플래그 1 인 빌드. 플래그가 0 이면 이미 만든 페이지는 그대로 열리고 새로 고르기만 막힌다.

서버 속지 수는 296 → **300**. [속지 코드 배포 전 확인.sql](../다이어리%20저장/속지%20코드%20배포%20전%20확인.sql) 목록에도 네 코드를 넣었다.

## 남은 것

- 속지 글꼴을 **글자표가 아니라 진짜 글꼴**로 쓰는 작업은 따로 간다(`feature/fe/paper-font-real-text`). 지금은 글자표에 없는 글자가 생기면 `paper-font-coverage` 검사가 먼저 잡는다.
- 대표 그림(썸네일)은 속지 SVG 를 그대로 쓴다. 따로 그린 스케치는 없다.
