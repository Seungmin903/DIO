# 06 편집 화면으로 이어지기 · 만들기

## 다이어리를 열 때

<figure class="wide"><img src="이미지/모음%20전환%20스토리보드.jpg"><figcaption>① 책상 · ② 집어 들기 · ③ 펼치기 · ④ 편집기</figcaption></figure>

| 단계 | 시간 | 무엇이 바뀌나 |
|---|---|---|
| ① 누름 | 0 | 가운데 다이어리가 살짝 눌린다(크기 0.98). |
| ② 집어 들기 | 0 → 180ms | 다이어리가 커지며(1.2배) 떠오르고 그림자가 깊어진다. **세계 층이 흐려지고**(흐림 · 밝아짐) 옆 다이어리 · UI 층이 사라진다. |
| ③ 펼치기 | 180 → 380ms | 표지가 왼쪽으로 넘어가며 첫 장(마지막으로 본 페이지)이 보인다. 바탕이 편집기 바탕 `#F1F3F7`로 덮인다. |
| ④ 편집기 | 380 → 480ms | 펼친 오른쪽 페이지가 편집기 종이 자리로 미끄러지고, 상단 바 · 리본 · 실행 취소 바가 나타난다. |

- 전체 0.5초 안. 머티리얼의 컨테이너 전환과 같은 구조: **누른 물건이 다음 화면의 주인공이 된다.**
- 편집기 쪽은 하나도 바꾸지 않는다. 편집기 탭의 색 띠(다이어리 색)가 '방금 그 다이어리'라는 마지막 연결 고리다.
- 돌아올 때는 거꾸로(종이 → 표지 → 책상 위 제자리). 편집기에서 바꾼 마지막 페이지가 있으면 그 다이어리 위에 펜이 놓인다(05 표지 디테일 4번).
- 동작 줄이기 켜짐: ②③을 빼고 바로 편집기(지금과 같음).
- **1단계 단순판:** 펼치기(③)가 어렵다면 ② 다음 바로 바탕을 `#F1F3F7`로 덮고 편집기를 띄워도 연결감의 70%는 온다.

## 만들기 메모 (React Native · iOS와 Android 모두)

| 부분 | 방법 | 주의 |
|---|---|---|
| 세계 층 | **정적 그림 한 장**(태블릿 · 폰 각각, webp)을 `expo-image`로 깐다. 소품을 하나씩 컴포넌트로 만들지 않는다. | 안전 영역까지 깔고, 창 크기에 맞춰 가운데 기준으로 잘라 쓴다(`contentFit="cover"`). 계절 · 공유 탭은 그림을 바꿔 끼운다. |
| 세계 층 접근성 | `accessibilityElementsHidden` · `importantForAccessibility="no-hide-descendants"` | 화면 읽기가 소품을 읽지 않게. |
| 페이지 두께 · 그림자 | 표지 뒤 `View` 두 개(두께 줄무늬, 그림자). 그림자는 `boxShadow`(최근 카드 버튼 그림자 수정과 같은 방식) | 안드로이드 `elevation` 회색 번짐 문제를 피한다. |
| 옆 다이어리 회색 (1안) | 표지 위에 **회색 덮개 View**(바탕색, 투명도 0 → 0.55)를 얹고 지금 `carouselMotion`의 보간에 투명도만 추가 | RN의 `filter: grayscale`은 플랫폼마다 지원이 달라(iOS 제한) 쓰지 않는다. 덮개 방식은 완전한 흑백은 아니지만 '빛이 빠진' 효과는 같다. 네이티브 드라이버로 움직인다. |
| 기울기 | 지금 `carouselMotion`에 `rotate` 보간 추가(−3.5° ↔ 0 ↔ 3°) | 지금 코드는 위 기준 축소라 기울기 축을 가운데로 바꿔야 한다(주석에 적힌 문제와 같은 원인). |
| 정보 카드 | 지금 `cardInfoCarousel` 내용을 흰 카드로 감싼다 | 휴지통 버튼 자리 · 크기는 그대로(44 이상). |
| 전환 ②③ | `Animated`로 표지 크기 · 위치, 세계 층 투명도, 바탕 덮개 투명도 | 흐림 라이브러리가 없으니 흐림 대신 **밝아짐 + 투명도**로. 펼치기는 표지 `rotateY`(원근 포함). |
| 5안 원근 | 원근 그림 + 옆 다이어리 `rotateX` | 비용이 크다. 태블릿 2차. |
| 끄기 | 설정 `책상 꾸미기` → 세계 층 그림만 빼고 바탕 `#F1F3F7` | 6안과 같은 화면이 된다. |

## 단계

| 단계 | 내용 | 결과 |
|---|---|---|
| 1 | 물건 층 · UI 층: 두께 · 두 겹 그림자 · 기울기 · 정보 카드 · 새 다이어리 비닐 포장 | 6안. 편집기와 충돌 0, 감성 30% |
| 2 | 세계 층: 1안 연필 책상 그림(태블릿 · 폰) + 옆 다이어리 회색 덮개 + 한눈에 놀링 배치 | 1안. 레퍼런스 감성 대부분 |
| 3 | 전환 ②③ · 표지 디테일(끈 · 펜 · 이름 테이프 · 도장) · 빈 책상 · 공유 탭 소품 | 홈 ↔ 편집기 연결 |
| 4 | 계절 · 시간대, (다크 모드 채택 시) 4안 | 시즌 운영 |

## 정해야 할 것

- [ ] 기본 방향: **1안 연필 책상**(추천) / 3안 작업 매트 / 6안 최소
- [ ] 흑백 세계가 '쓸쓸함'으로 읽히는지 — 팀 몇 명에게 1안 · 2안 기본 그림을 보여 첫인상 확인
- [ ] 한눈에 보기: 놀링(같은 책상) / 진열 선반(2안)
- [ ] 다이어리 열기 전환을 1단계 단순판으로 할지, 펼치기까지 할지
- [ ] `책상 꾸미기` 끄기 설정을 둘지
- [ ] 책상 그림을 누가 그릴지 — 시안의 소품 SVG를 다듬어 쓸 수 있다(`목업/소품.js`). 손그림으로 다시 그리면 레퍼런스에 더 가까워진다.
