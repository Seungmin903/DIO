# 회원정보 수정·회원탈퇴

> 2026-10-29 목업 갱신: 통계 없는 서비스형 마이페이지의 화면 정보 구조와 API 연결 경계는 [마이페이지 목업 구성·API 메모](./마이페이지-목업-구성.md)를 기준으로 한다. 이 문서는 그 구조를 따르는 현재 React Native 구현의 회원정보 수정·탈퇴 동작을 기록하며, 목업 이미지와 다른 부분은 이 문서를 따른다.

## 기준 목업

Figma 파일 `9gy5UQdNJxL67XLZS1VDPg`, MVP2의 `소셜 회원정보 수정`(101-36), `회원 탈퇴 확인`(101-34, 101-30), `저장하지 않고 나가기`(101-32)를 기준으로 한다. 프레임 이름과 관계없이 카카오·구글·애플·이메일 계정을 지원한다. 목업의 사이드바 다이어리 생성 +는 기존 결정에 따라 추가하지 않는다.

## 화면·상태

- 내 공간의 회원정보 수정 버튼으로 바로 진입한다. 별도의 계정 설정 메뉴 화면은 두지 않는다. 로그아웃은 기존 내 공간에 유지한다.
- surfaceSoft 배경 위 최대 폭 880 흰 카드(radius.xl)에 프로필 정보, 사진, 닉네임, 이메일(있는 계정), 로그인 방식, 비밀번호 변경(이메일 계정)을 배치한다. 태블릿은 라벨 왼쪽·입력 오른쪽, 폰은 라벨 위·입력 아래다.
- 카드 하단 구분선 아래 왼쪽 회원탈퇴, 오른쪽 취소·변경사항 저장을 배치한다. 폰은 저장 동작 행과 탈퇴 링크를 줄바꿈하고 세로 스크롤한다.
- 사진 연필은 원 하단에 고정하고 기본 이미지 복구도 같은 자리를 유지해 사진 삭제 전후 입력칸이 밀리지 않는다. 갤러리 취소는 현재 선택을 유지한다. 기본 이미지 복구의 터치 폭은 글자 너비로 제한하고 높이 44는 유지해 오른쪽 빈 공간을 눌러도 초기화되지 않게 한다.
- 변경 중인 사진·닉네임은 임시값이다. 닉네임은 중복 허용이며 형식만 검사한다. 사진만 바꿔도 저장할 수 있다.
- 저장하면 내 공간의 계정 프로필을 갱신한다. 저장한 값을 새 기준으로 삼아 이후 이탈 시 불필요한 경고를 표시하지 않는다.
- 취소·상단 뒤로가기·Android 뒤로가기·사이드바(폰은 좌측 바)·알림 이동으로 화면을 나갈 때 변경사항이 있으면 `변경사항을 저장하지 않았어요` 확인창을 연다. `계속 수정하기`와 X는 임시값을 유지한다. `저장하지 않고 나가기`는 변경을 버리고 요청한 경로로 이동한다.
- 탈퇴는 별도 안내 페이지/체크박스가 아니라 기존 수정 화면 위 확인창이다. `탈퇴합니다`를 정확히 입력한 경우에만 탈퇴하기를 활성화한다. 앞뒤 공백도 허용하지 않는다. 닫기·취소 후 다시 열면 확인 문구를 비운다. 취소는 수정 중인 프로필을 유지한다.
- 이메일 회원의 비밀번호 항목은 마이페이지에서 `비밀번호 재설정`으로 표시되고, 미저장 확인을 거쳐 인증번호 기반 재설정 흐름(`PasswordResetScreen`)으로 이동한다. 재설정 화면을 연결하지 않은 진입에서는 현재 비밀번호·새 비밀번호·확인을 받는 대화상자를 연다. 소셜 계정에는 표시하지 않는다. 입력을 버릴 때도 미저장 확인을 제공한다.
- 로그인되지 않은 상태에서는 다이어리·회원정보 수정·탈퇴 기능에 진입할 수 없다.

## API 경계와 데이터 영향

체험 계정·메모리 회원정보 서비스는 사용하지 않는다. 회원정보 수정은 로그인한 실제 계정의 `authService`만 호출하며, 서버 API가 준비되지 않은 동작을 로컬 값으로 성공한 것처럼 처리하지 않는다. 닉네임·사진 변경은 `PATCH /api/v1/me`, 회원 탈퇴는 `DELETE /api/v1/me`에 연결한다. 탈퇴 성공 시 계정은 `WITHDRAWN`으로 처리되고 모든 로그인 세션을 폐기한 뒤 로그인 화면으로 돌아간다.

계정 프로필 변경 시 공유 런타임은 유지한다. 기존 공유 다이어리의 닉네임·사진·참여 상태·편집 문서는 변경하지 않는다. 이후 새 다이어리에 복사할 기본 계정 프로필만 갱신한다.

게스트 진입(`게스트로 시작하기`·`LocalDiaryApp`)을 제거하면서 게스트가 기기에 저장한 개인 다이어리와 `guestProfile`은 의도적으로 폐기한다. 앱은 이 데이터를 더 이상 읽지 않으며, 계정으로 가져오기·내보내기 경로는 제공하지 않는다. 앱이 직접 지우지도 않으므로 앱 데이터 삭제나 재설치 전까지 기기 저장소에 남는다. 저장 형식 자체에는 변경이나 마이그레이션이 없다. 릴리스 노트에 "게스트 모드 종료, 기존 게스트 기록은 앱에서 열 수 없음"을 명시한다.

OAuth·사진 업로드/영구 보관·실제 탈퇴 시 데이터 처리 정책은 후속 연결 범위다. 화면에 서버 삭제 완료를 주장하는 문구는 추가하지 않는다.

## 추가 점검 보완

- Android 시스템 뒤로가기는 App의 단일 리스너가 등록된 프로필 핸들러에 위임한다. 프로필 화면은 별도 BackHandler 리스너를 등록하지 않는다. 미저장 확인창이 열렸을 때는 계속 수정하기와 같은 동작으로 닫는다. 공유·초대 창은 React Native Modal의 onRequestClose에서 먼저 처리하므로 모달 뒤 프로필 화면이 닫히지 않는다.
- 탈퇴 실패 후에는 확인 문구·수정값을 유지하고 재시도할 수 있다. 사진 선택 실패와 언마운트 후 늦은 결과가 기존 프로필을 변경하지 않는지 검증한다.
- 배포 웹 검증은 로그인 전에는 다이어리 화면으로 진입할 수 없는지와, 실제 이메일 계정의 비밀번호 항목만 표시되는지를 포함한다.

- 내 공간 진입 배치: 프로필 영역에 프로필 수정(접근성 이름: 회원정보 수정), 앱 정보 카드 아래 여백 20·높이 48·같은 폭의 별도 테두리 로그아웃 버튼을 둔다. 폰은 프로필 수정 동작을 이름 아래에 배치해 긴 닉네임과 겹치지 않게 한다.

위 문서의 닉네임 중복 확인·재확인 설명은 폐기한다. 계정 닉네임은 중복을 허용하고 확인 버튼 없이 형식이 유효하면 가입·저장할 수 있다. 사진·필수 약관·이메일 인증·저장 중 연타 방지 동작은 유지한다.
