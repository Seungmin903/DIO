# 태블릿 상단 툴바 시안 비교 (2026-11-03)

**결정(2026-11-03): A. 상단 바 52 + 꽉 찬 도구 줄 50.** 추천은 D였으나 사용자가 A를 골랐다. 페이지 목록 · 레이어 구성과 폭은 그대로 둔다.

**후속 결정(2026-11-03): 작업창을 도구 줄 · 패널 · 화면 끝까지 채우고 페이지 둘레 여백을 8로 줄였다.** 아래 표와 그림은 이 변경 전 값이다. 적용 뒤 1280×800 가로 용지는 패널 둘 다 796×563, 패널 없음 965×682다.

작업 화면을 넓게 쓰면서 페이지 목록 · 레이어 창의 영향을 줄이는 배치를 찾으려고, `develop` 반영본(438588ef)에 시안을 임시로 넣어 웹에서 쟀다.

| 시안 | 구성 |
|---|---|
| 지금 | 상단 바 64 + 작업창 안에 떠 있는 도구 카드 |
| A | 상단 바 52 + 폰처럼 꽉 찬 도구 줄 50, 패널은 그 아래 |
| B | 한 줄 56에 홈 · 페이지 · 지금 탭 · 도구 · 공유 · 레이어 · 내보내기 |

## 코덱스 검토

- D를 추천. 1280 미만 창은 패널을 닫고 시작하고, 여러 다이어리 탭은 지금 탭 이름을 누르면 열리는 드롭다운으로 처리한다.
- 수치: 바 56, 도구 44 · 아이콘 20 · 간격 4, 바 경계 알파 12%, 겹침 패널 그림자 `0 8px 24px rgba(30, 42, 90, 0.10)`. 시안 A · B · D의 도구 줄과 D의 패널에 넣었다.
- 기각: 겹침 패널 바탕 4% 투명. 페이지 글자가 비쳐서 불투명 `surfaceSoft`로 바꿨다.
