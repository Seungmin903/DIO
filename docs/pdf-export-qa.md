# PDF 생성·저장 QA (113)

## 환경·재현

- 2026-10-20 Windows 10.0.26200 / 번들 Chromium 156.0.8078.4. 제품 기준 develop ef17b49 + 112번 로컬 변경. 앱 코드와 QA는 같은 feature/fe/pdf-file-export 브랜치다.
- frontend에서 pnpm install 후 pnpm exec playwright install chromium. pnpm qa:pdf로 웹 번들부터 생성한다. 변경 없는 동일 번들 재사용은 pnpm qa:pdf --skip-build다. localhost 가용 포트와 별도 컨텍스트를 쓰고 종료 시 정리한다.
- pnpm qa:pdf는 기존 서버/브라우저를 사용하지 않는다. 실행기 코드는 run-region-qa.mjs의 공통 서버를 suite=pdf로 재사용한다.
- 원시 결과·화면은 Git 제외 qa/.out/pdf/pdf-results.json 및 *.png다. 문서에는 이번 실행 요약을 남기고 이후 실행 시 원시 결과는 갱신된다.

## 결과

- 전체 node 자동화 139개 통과. 브라우저 PDF QA 7개 통과, 각 시나리오 pageerror 0·문서 저장 문자열 불변. 기존 영역 PNG QA 11개도 통과했다.
- 생성된 PDF를 pdf-lib로 원본 메타데이터 변경 없이 읽었다(updateMetadata:false). 기본 load는 Producer를 바꾸므로 초기 계측 코드를 수정했으며 제품 결함으로 등록하지 않았다.
- 1024×768 합성 페이지, 사진 원본 32×32와 GIF 4×4를 사용했다. 첫 면은 사진·GIF·스티커·무지 테이프·기본 문자열·펜 획이다. 실제 카메라 사진 성능을 대표하지 않는다.

### 내용·범위

- 현재 1페이지, 개별 1·3·5페이지, 범위 2~6페이지, 전체 20페이지의 실제 PDF 면 수와 색상으로 문서 순서를 확인했다.
- 모든 PDF 면이 A4 가로이고 RGB 이미지에 SMask가 없음을 검사했다. 제목 PDF QA, Author 공란, Producer DIO를 확인했다. PDF 텍스트 검색 가능성을 보장하지 않는다.
- GIF는 첫 빨간 프레임, 스티커 빨강, 테이프 청록, 펜 획 보라의 픽셀과 기본 텍스트의 어두운 픽셀을 확인했다. 초기 fixture의 무지 테이프 색상을 fg 규칙에 맞춰 수정했다. 부분 스타일·사용자 폰트/입력 확정 등 72번 전체 검증을 대체하지 않는다.
- 파일명은 current p01, 개별 selected03, 범위 p02-p06, 전체 all 접미사를 유지한다. 개별 파일명에 페이지 번호 전체를 나열한다고 가정하지 않는다.
- 21페이지 문서의 전체 선택은 비활성화됐고, 중간 2페이지 소재 실패는 부분 PDF 저장 버튼을 제공하지 않았다. 생성 취소는 성공으로 안내하지 않고 재시도 진입점을 유지했다.
- 빈/중복/삭제된 ID·역전 범위·픽셀/용량/시간 한도·늦은 취소의 자원 해제는 기존 PDF 단위 테스트 범위다. 모든 경계를 브라우저로 재현했다고 간주하지 않는다.

### 저장

- 웹 picker mock: 취소 1회, ENOSPC 실패 1회, 재시도 성공 1회. 연속 두 번 클릭해도 picker/write 각 1회였고 저장 중 닫기·페이지 재선택은 비활성화됐다. 재시도 전후 같은 result URI와 파일명을 유지했다. 실제 OS 대화상자/디스크 저장 검증은 아니다.
- 브라우저 다운로드 fallback 1회: 실제 download 이벤트·파일명·failure=null을 확인했다. 사용자의 영구 디스크 보관 여부는 보장하지 않는다.
- 네이티브 공유 불가·확인 가능한 취소·공유 반환·복사 실패·원본 보호·24시간 캐시 정리는 테스트 mock으로 확인했다. 실제 공유 시트/최종 외부 앱 저장 완료를 확인한 것은 아니다.

## 상태·남은 검증

- 웹 검증 범위에서 새 제품 결함은 발견하지 않았다. 제품 결함 발견 시 재현 절차와 qa 라벨을 갖춘 별도 작업으로 등록한다.
- 실제 iPhone/iPad/Android 파일 저장·공유·OS 취소/권한·강제 종료와 외부 앱의 파일 소비·캐시 수명은 미검증이다.
- 실제 HEIC/12MP/48MP, 대용량 혼합 문서 성능·네이티브 메모리, 확대 출력 품질과 122번 정책 적용 검증은 남아 있다.
- 부분 스타일 텍스트·폰트·다양한 필기/회전/자르기 전체 검증은 72번 후속이다. 이번 PDF는 명확한 색상 oracle을 사용했고 회전/크롭/겹침의 정밀 비교는 이전 영역 PNG QA/단위 테스트의 증거와 구분한다.
- 따라서 113번은 진행 중으로 유지하며, 구현과 웹 QA 기록을 같은 MR로 검토한다.
