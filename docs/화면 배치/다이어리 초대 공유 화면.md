# 다이어리 초대·공유 화면 (224)

## 화면과 동작

- 태블릿 상단 공유 버튼, 폰 세로 도구 막대, 폰 가로 왼쪽 레일에서 공유 설정을 연다. 보관함 알림에서도 받은 초대를 확인한다. 파일 내보내기 버튼과 구분한다.
- 공유 옆에 원형 프로필 최대 2개와 나머지 인원 `+N`을 표시한다. 폰은 1개와 나머지 수를 표시한다.
- 원 묶음을 누르면 참여자 이름·나 표시·편집 중/자리 비움 목록을 연다. 바깥 터치·시스템 뒤로가기·회전으로 닫으며, 낮은 화면에서는 목록을 스크롤한다.
- 공유 설정은 참여자 목록·참여 해제·초대 링크·참여자 내보내기 허용을 제공한다. 소유자 외에는 모두 함께 편집하며 보기 전용 권한은 없다.
- 링크는 한 줄 고정 높이 48로 표시한다. 복사는 링크 바탕 안 오른쪽, 재생성은 바깥 오른쪽에 배치한다. 생성 후 동작 영역을 아이콘 폭으로 줄여 불필요한 간격을 없앤다.
- 알림 조회·읽음·전체 읽음·삭제·카운트·페이지 조회는 기존 notifications API/스토어를 재사용한다. 기존 연결 시험 화면은 유지한다.
- 초대 수락 버튼은 표지와 다이어리 이름이 보이는 닉네임 설정을 연다. 입력 왼쪽에는 프로필, 오른쪽에는 닉네임 입력과 중복 확인을 둔다. 취소/수락은 왼쪽/오른쪽 가로 배치다.
- 닉네임 수정은 중복 확인을 초기화한다. 최종 수락 때 만료·취소 여부를 다시 검사하며, 설정 취소만으로 참여하지 않는다.
- 공유 창 바깥 터치는 닫기로 처리하고 카드 내부 터치는 유지한다. 중복 제출·닫힌 화면의 늦은 응답을 차단한다.
- EditorModal의 공통 방향 정책, 안전 영역·스크롤·키보드 회피를 적용한다. 키보드 표시 후 입력칸 실제 위치를 재측정한다.

## 다이어리별 프로필

- 닉네임과 사진은 다이어리별 참여자 정보다. 계정 프로필을 초기값으로 복사하되 이후 한 다이어리의 변경은 다른 다이어리와 계정에 영향을 주지 않는다.
- 사진이 없으면 닉네임 첫 글자 대신 기본 사람 아이콘을 표시한다. 상단 원·참여자 팝업·공유 설정·초대 닉네임 화면에서 같은 MemberAvatar 컴포넌트를 쓴다.
- 초대 설정의 프로필 원을 눌러 사진을 선택하거나 기본 프로필로 복구한다. 최종 수락 전에는 임시 선택이며 취소하면 참여 정보에 저장하지 않는다.
- 참여 후에는 공유 설정에서 내 프로필 원을 눌러 사진·닉네임을 함께 수정한다. 닉네임 변경 시 중복 확인을 다시 수행하고 저장 시점에 재검사한다. 저장 전 사진·닉네임은 임시값이며 취소하면 버린다. 다른 참여자의 프로필은 변경하지 않는다.
- 사진 선택은 기존 시스템 사진 선택기를 재사용한다. 선택 취소 시 기존 값을 유지한다. 사진 메뉴는 기존 공유 모달 내부에서 열어 네이티브 모달 닫기와 사진 선택기 열기가 충돌하지 않게 한다.

## API 연결 경계

- sharingPreview는 예시 초대 4개와 예시 참여자를 제공하는 메모리 서비스다. 실제 공동 작업 상태가 아니다.
- `https://dio.example/invite/...`는 복사 동작 확인용 임시 문자열이다. 실제 발급·전송·딥링크·서버 권한·동기화·푸시는 후속 API 연결 범위다.
- 수락한 다이어리는 보관함에 공유 표시와 함께 나타난다. 수락 후 다이어리 열기 또는 보관함 카드로 캔버스에 진입하며 검색·정렬·즐겨찾기를 지원한다. 표지 수정·개인 휴지통·일괄 삭제 대상에서는 제외한다.
- 예시 공유 문서는 세션 메모리에만 저장한다. 같은 세션에서 다시 열면 편집 내용이 유지되며 참여 해제·로그아웃 때 카드·탭·문서를 제거한다. 기존 개인 다이어리 목록과 문서의 영구 저장 경로는 유지한다. 실제 공동 편집 동기화는 API 연결 후 구현한다.
- 내보내기 허용은 임시 공유 모델에만 적용한다. 기존 캔버스를 실제 서버 권한처럼 제한하지 않는다.
- 초대·참여·사진 변경은 앱 재시작/로그아웃 시 초기화된다. 계정 프로필 사진과 기존 로컬 다이어리 저장 데이터는 변경하지 않는다. 사진 영구 업로드/정리는 후속 API 작업이다.

- diary-sharing-state.test.js: 늦은 응답·중복 수락·취소·키보드 스크롤·접근성·참여자 팝업·사진 선택 취소와 초기화.
- diary-sharing-browser.cjs: Expo 테스트 서버 8096에서 1280×800/1024×768/390×844/320×568/844×390 화면과 주요 흐름 확인.
- 이전 배포 웹 앱에서 태블릿/폰 게스트 진입 → 받은 초대 열기/닫기를 확인했다. 새 사진 선택 기능의 iOS/Android 실기기 갤러리·취소·회전은 별도 확인이 필요하다.

- 받은 초대 카드는 표지 메타데이터를 유지해 기존 Cover의 축소 미리보기로 표시한다. 태블릿은 표지·이름·거절/수락·삭제를 같은 행에 두고, 폰은 제목 아래에 좁은 폭용 액션을 배치한다. 공유 설정의 링크 설명 문장은 표시하지 않는다.

- 초대 목록 도구는 한 행으로 묶는다. 왼쪽에 받은 초대 제목, 오른쪽에 새로고침 아이콘과 체크 아이콘/모두 읽음을 배치한다. 두 동작의 터치 높이는 44 이상을 유지한다.

## 마무리 점검 보완

- 다른 초대 수락·참여 해제 후 뒤로가기는 처음 공유를 연 다이어리의 최신 정보를 복원한다.
- 입력 취소/화면 이동 때 키보드와 예약 스크롤을 함께 정리해 다음 화면에 적용하지 않는다.
- 참여자 위치 측정은 요청 번호를 검사한다. 공유 창 진입·회전·언마운트 후 도착한 이전 측정은 무시한다.
- 참여자 팝업 위치·최대 높이는 노치와 홈 영역을 제외한 안전 영역 안으로 제한한다.
- 표지 정보 재등록은 제목뿐 아니라 색·무늬·templateConfig도 갱신하고 개별 프로필·공유 설정은 보존한다.
- 세션 종료 후에는 이미 시작한 비동기 설정 변경도 최종 반영 전에 거부한다.
- 좁은 폰의 긴 프로필 화면 제목을 짧게 표시해 불필요한 여러 줄을 줄인다.

- shared-library.test.js / shared-library-browser.cjs: 초대 수락 → 공유 보관함 → 캔버스 페이지 추가 → 재진입 → 참여 해제 및 개인 저장 데이터 보존을 검증한다.

## 보관함 공유 카테고리
- 상단 카테고리는 모든 다이어리·즐겨찾기·공유 다이어리 순서다. 공유에는 다른 참여자가 있는 내 다이어리와 초대를 수락한 다이어리를 함께 표시한다. 모든 다이어리에도 계속 표시한다.
- 공유 목록에서도 검색·정렬·즐겨찾기를 지원한다. 마지막 참여자가 나가면 소유한 다이어리는 공유 목록에서 빠지고 전체 목록에는 남는다. 수락한 다이어리에서 참여 해제하면 보관함에서 제거한다.
- 공유 카테고리에는 새 다이어리 생성 카드를 표시하지 않는다. 기존 서버 목록 검증 경로는 서버가 지원하는 기존 필터를 유지한다.

- 공유 표시는 표지 위 배지 대신 표지 아래 제목 오른쪽의 사람 아이콘을 사용한다. 긴 제목은 말줄임하고 아이콘은 유지한다. 접근성 안내에도 공유 여부를 포함한다.
- 일반 로컬 다이어리는 공유 창 최초 등록 시 소유자 한 명만 둔다. 창 열기·초대 링크 생성만으로 예시 참여자를 추가하거나 공유 목록에 넣지 않는다. 받은 초대의 예시 참여자는 해당 초대 다이어리에만 둔다.
