# 폰·태블릿 화면 배치

> 관련 Jira: S15P31F106-77<br>
> 참고 목업: `dakku-mockup-iphone.html`(393×852, iOS HIG 반영), 태블릿은 `dakku-mockup-palette.html`

DIO는 기기 종류가 아니라 **지금 창 크기**로 폰 배치와 태블릿 배치를 고른다. 데이터·상태(`useDiaries`, `useEditor`, `editorDocs`)는 두 배치가 함께 쓰고, 화면 구성만 나뉜다. 다크 모드는 다루지 않는다.

## 1. 판단 기준

| 항목 | 기준 | 코드 |
|---|---|---|
| 폰 / 태블릿 | 창의 짧은 변이 600dp 이상이면 태블릿, 아니면 폰 (Android `sw600dp`와 같은 기준) | `frontend/src/shared/layout.js` `formFactorFor` |
| 가로 / 세로 | 창 너비 > 높이면 가로 | `frontend/src/shared/useFormFactor.js` |
| 태블릿 프레임 | 안전 영역을 제외한 현재 창 전체 폭·높이를 사용한다. iPad 1024×768, Android·웹 1280×800은 디자인 검증 기준 크기다 | `TABLET_FRAME_SPECS`, `fitTabletFrame` |
| 폰 프레임 | 프레임 없이 화면 전체를 쓰고, 노치·다이내믹 아일랜드 아래부터 그린다 | `App.js` |

창 크기로 판단하므로 iPad Split View, 접이식 폰, 웹 창 크기 조절에도 배치가 바로 바뀐다.
플랫폼별 값은 UI 프레임 기준일 뿐이며, 다이어리 저장·내보내기 좌표계는 기존 1280×800을 공통으로 유지한다.

## 2. 화면 방향

| 기기 | 홈·휴지통·내 공간 | 편집기 |
|---|---|---|
| 폰 | 세로 고정 | 가로 허용. 상단 바·왼쪽 막대의 ↻ 버튼으로 세로(간편 편집)·가로(정밀 편집)를 직접 고정할 수 있다. 편집기를 새로 열면 다시 기기 방향을 따른다. |
| 태블릿 | 모든 방향 | 모든 방향 |

- `app.json`의 `orientation`은 `default`이고, 잠금은 `expo-screen-orientation`으로 앱에서 한다(`frontend/src/shared/useOrientationLock.js`).
- iOS는 `supportsTablet: true`, `requireFullScreen: false`로 iPad Split View를 허용한다.
- 웹은 전체 화면이 아니면 방향을 잠글 수 없어 잠금과 ↻ 버튼을 쓰지 않는다.
- 방향 잠금 모듈은 네이티브 모듈이라 개발 빌드(dev client)를 다시 만들어야 동작한다. 모듈이 없는 예전 빌드에서는 잠그지 않고 앱만 연다.

## 3. 폰 배치

터치 영역은 iOS HIG 기준 44pt 이상으로 둔다.

### 홈

- **하단 탭 대신 좁은 좌측 바**(`SideRail compact`, 2026-11-01 코덱스 설계): 접힘 폭 60(안쪽 8, 항목 44×44, 고른 항목 = `#E9EBF6` 둥근 사각 12), 위에서부터 삼선 메뉴 · 알림 종(접힌 동안에도 보이고 알림 점은 종에) · 내 다이어리 · 공유된 다이어리 · 꾸미기 공방 · 휴지통, 맨 아래 프로필(내 공간). 접힌 상태에는 라벨이 없다(접근성 이름은 유지). 삼선을 누르면 폭 236으로 본문 위에 겹쳐 펼쳐지고(로고 · 종 · 삼선 줄, 행 44, 라벨 13/600, 프로필 옆 닉네임) 본문은 scrim 32%로 가려지며 바깥을 누르거나 뒤로 가기를 하면 닫힌다. 바는 흰 면 + 오른쪽 1px 선이고 본문 폭은 바를 연 채로 바뀌지 않는다. 새 다이어리 시트 · 알림 시트는 바까지 덮는다.
- 본문은 좌우 여백 14, 제목 24/800(줄 44), 보기 전환 3칸 34×34(터치 44는 hitSlop) · 간격 4, 검색 · 더보기 40×40, FAB 52×52(오른쪽 16 · 아래 16), 한눈에 보기 첫 줄 위 20 · 줄 간격 20. `공유된 다이어리`처럼 제목이 길면 360폭에서 보기 전환이 다음 줄 오른쪽으로 내려간다.
- 제목이 짧으면 보기 전환(스와이프/한눈에)과 한 줄, 길면 보기 전환이 다음 줄 오른쪽으로 내려간다.
- 캐러셀은 화살표 없이 밀어서 넘기고, 한눈에 보기는 2열 카드로 줄인다.
- 새 다이어리·다이어리 수정은 아래에서 올라오는 시트로 연다(표지 미리보기 칸 없음).
- 다이어리 삭제는 수정 시트 안이 아니라 각 표지 아래 오른쪽 휴지통 아이콘으로 실행하며, 확인 후 휴지통으로 옮긴다.

### 휴지통 · 내 공간

- 휴지통은 태블릿과 같은 카드형 목록이다. 각 카드에 복원·영구 삭제 버튼을 항상 표시하고, 폰에서는 같은 카드를 2열로 줄여 배치한다.
- 내 공간은 태블릿과 같은 구성에 여백만 줄인다.

### 편집기 — 세로(간편 편집)

- 상단 바: 홈(‹ DIO) · 페이지 목록 · 이름과 `PAGE n / m` · ↻ 가로 전환 · 레이어
- 상단 도구 막대(제목 바 아래): 손바닥 · 선택 · 올가미 · 펜 · 형광펜 · 지우개 · 텍스트 · 스티커 · 테이프 · 사진·GIF · 격자 가이드를 한 줄에 두고 좌우로 스크롤한다. `…` 더보기 시트와 집중 편집 버튼은 이 막대에 두지 않는다.
- 페이지 목록·레이어는 닫힌 채 시작하고, 열면 작업창 위에 띄운다. 둘 중 하나를 열면 다른 하나는 자동으로 닫히며, 가로 편집에서는 두 패널 모두 왼쪽에서 열린다.
- 도구 설정 창은 작업 영역 안쪽에 띄우고 되돌리기 바를 가리지 않는다.
- 되돌리기·다시 실행·자동 저장 막대는 왼쪽 아래에 두되, 왼쪽에서 열리는 패널(페이지 목록, 가로의 레이어)이 열리면 오른쪽 아래로 옮긴다.
- 객체 선택 바(스티커·테이프·사진·여러 요소): 자르기·링크·그룹 뒤에 태블릿과 같은 순서(순서 · 옵션 · 잠금 · 복사 · 붙여넣기 · 복제 · 삭제)로 페이지 너비에 들어가는 만큼만 보이고, 넘치는 동작은 `더보기` 메뉴로 보낸다. 더보기 메뉴는 버튼 바로 아래 오른쪽에 열리고(아래에 자리가 없으면 바로 위), 되돌리기 막대와 겹치지 않는 높이 안에서 항목을 위아래로 끌어 스크롤한다. 메뉴는 페이지가 아니라 작업창(stage) 위에 그려 페이지 밖으로 나간 항목도 눌린다. 올가미로 고른 선택에는 추가 선택·선택 제외 메뉴를 태블릿과 같게 보인다.
- 가로 편집 전환은 도구 버튼으로 제공하고 별도 권유 문구는 표시하지 않는다.

### 편집기 — 가로(정밀 편집)

- 왼쪽 막대: 홈 · 페이지 목록 · ↻ 세로 전환 · 레이어 · 내보내기 · 집중 편집
- 오른쪽 막대: 모든 도구(손바닥·선택·올가미 / 펜·형광펜·지우개·텍스트 / 스티커·테이프·사진). 화면이 낮으면 안에서 스크롤한다.
- 확대·축소는 두 손가락으로 하고 −/+ 버튼은 두지 않는다. 확대된 상태에서만 오른쪽 아래에 '화면에 맞춤' 버튼을 보인다(세로와 같음).
- 되돌리기 막대와 객체 선택 바·더보기 메뉴는 세로와 같은 규칙을 따른다.

### 집중 편집

페이지·레이어 같은 보조 막대는 숨기되 편집 도구 막대와 "집중 모드 종료" 버튼은 남긴다. 세로에서 시작하면 가로로 전환한다(네이티브만).

### Android 시스템 뒤로가기

- 폰과 태블릿 등 모든 화면 규격에서 동일하게 동작한다.
- 생성 시트와 내보내기·설정 창이 열려 있으면 먼저 닫는다.
- 편집기에서는 자르기·내보내기·링크·도구 설정·집중 모드·요소 선택·페이지 목록·레이어 패널을 차례로 닫은 뒤 보관함으로 돌아간다.
- 내 공간·휴지통·즐겨찾기에서는 기본 다이어리 보관함으로 돌아가며, 기본 보관함에서 한 번 더 누르면 시스템 종료 동작을 따른다.

## 4. 태블릿 배치

사이드 메뉴·리본바·페이지 목록·레이어 패널의 기존 구성을 유지하면서 앱 바깥 프레임은 현재 안전 영역 전체를 채운다. 화면 비율이 달라도 흰 사이드바 바깥에 파란 여백을 만들지 않는다. 속지는 기존 canvasWidth/canvasHeight를 유지하고 가로·세로에 동일한 zoom으로 화면 안에 맞춘다. 속지 가장자리의 작업 공간 여백은 허용하며 속지를 늘려 채우지 않는다. 폰은 프레임 없이 좌측 바(위 3장)를 쓴다.

## iOS 편집 옵션 보완

- 모바일에서 페이지 넓게 보기는 편집 화면의 겹침 순서에 영향을 받지 않는 네이티브 Modal로 연다. SafeAreaView 안에 페이지 격자와 닫기 버튼을 배치하고, 닫기·페이지 선택·시스템 닫기 요청에서 종료한다.
- 모바일에서 공통 Slider의 숫자 입력은 % 단위를 제외하고 가운데 정렬한다. % 값은 기존 오른쪽 정렬을 유지한다.
- 아이폰 실제 화면에서 열기·닫기·페이지 이동과 숫자 입력 확인이 필요하다.

- 위 모달·헤더/목록 가운데 배치·숫자 스타일 수정은 useFormFactor의 isPhone일 때만 적용한다. 태블릿은 기존 View 오버레이·헤더/격자 여백·숫자 오른쪽 정렬과 글꼴 크기 입력 스타일을 유지한다.

## 보조 설명 정리 (S15P31F106-185)

홈의 새 기록 안내·스와이프 안내, 카드의 반복 설명, 생성 화면의 표지·속지·색상 설명, 내 공간의 TIP과 개인정보 링크 보조 문구를 제거한다. 내보내기 메뉴의 중복 사용 설명도 제거한다. 제목·버튼·선택 항목·진행 단계·개수·날짜, 오류와 삭제/출력 제한 안내는 유지한다. 편집기의 물음표 도움말·사진/테이프 자르기 사용 설명·사진 업로드 규격 보조 문구·가로 편집 권유도 제거한다. 오류·저장 상태·품질 경고·PDF 분할 안내와 도구 자체의 선택 항목은 유지한다.


## 모바일 속지 확대 범위

- 모바일 편집기는 화면 맞춤(100%) 기준 50~400% 확대·축소를 지원한다. 핀치와 확대 버튼은 동일한 한도를 사용한다.
- 태블릿은 50~300% 확대·축소를 지원한다. 사진 자르기의 이미지 확대 한도와 저장된 페이지 크기는 변경하지 않는다.
- 실제 기기에서는 200%를 넘는 핀치·확대 버튼, 400% 상한, 화면 맞춤 복귀와 확대 상태의 입력 좌표를 확인한다.


## 모바일 세로 내보내기 진입 위치

- 세로 화면은 내보내기를 가로 스크롤 도구 막대에서 제거하고, 상단 흰색 제목 바의 레이어 버튼 오른쪽 맨 끝에 배치한다.
- 모바일 가로 화면은 기존 왼쪽 바의 내보내기를 유지한다. 태블릿 진입 위치와 생성·저장 처리도 유지한다.
- 공통 exportEnabled 설정과 읽기 전용 화면의 내보내기 지원을 유지한다.

- 편집기 모달은 공통 EditorModal에서 폰·태블릿 모두 세로·가로 지원 방향을 지정한다. 새 다이어리 창(DiaryCreateModal)도 같다. iOS 새 아키텍처 Modal의 기본값은 세로 전용이라, 가로로 고정한 iPad에서 기본값으로 열면 앱이 종료됐다(iPad 실기기 Ad Hoc 빌드에서 새 다이어리 창 확인). 실제 방향은 useOrientationLock이 정한다.

## 텍스트 복제와 붙여넣기

- 선택 도구로 텍스트 상자를 고르면 빠른 편집 바의 `복제`로 문자열·서식·크기·회전을 유지한 상자를 복제한다. 기존 요소 복제와 같은 위치 오프셋·Undo/Redo·저장 경로를 사용한다.
- 텍스트를 수정 중에는 시스템 클립보드에 텍스트가 있을 때만 `붙여넣기` 버튼을 표시한다. 텍스트가 없고 문자열 선택도 없으면 편집 바를 숨긴다. 커서 위치에 삽입하고 선택 문자열이 있으면 해당 범위를 교체한다. 문자열을 선택하면 기존 `복사`·서식·삭제도 제공한다.
- 클립보드의 텍스트 존재 여부는 편집 진입·클립보드 변경·앱 복귀 시 확인하고, 실제 내용은 붙여넣기 버튼을 누를 때만 읽는다. 빈 클립보드·접근 실패를 안내하고, 읽는 동안 편집 위치가 바뀌면 다시 시도하도록 안내한다.
- iPad에서는 화면 키보드와 붙여넣기 바가 함께 보이는지, 한글·여러 줄·이모지의 삽입/교체, 시스템 붙여넣기 허용/거부, 편집 완료 후 Undo/Redo·저장 복원을 실기기로 확인한다.

- 모바일 사진·테이프 자르기 창은 화면 높이와 상하 안전 영역 안에서 스크롤한다. 태블릿의 기존 카드 배치는 유지한다.

## 모바일 세로 내보내기 창 배치

- 모바일 세로 내보내기 창은 모달 내부 전체 높이를 채우는 컨테이너에서 가운데 정렬한다. 카드의 최대 높이는 모달의 실제 레이아웃 높이를 기준으로 제한한다.
- 모바일 가로의 기존 중앙 배치와 태블릿의 버튼 기준 말풍선 배치는 유지한다.

## 모바일 페이지 추가 창

- 모바일은 페이지 목록 오른쪽에 추가 창을 열고, 편집 화면에 남는 너비에 맞춰 창과 미리보기 크기를 조절하고 속지 목록을 줄바꿈한다. 화면 높이를 넘는 목록은 스크롤하며 제목과 닫기 버튼은 카드 상단에 유지한다.
- 태블릿은 페이지 목록 오른쪽의 기존 앵커 위치와 속지 그룹 배치를 유지한다. 속지 선택·페이지 추가·저장 형식은 변경하지 않는다.

## 좁은 화면의 테이프 규격 선택

- 테이프 자르기 카드 너비가 480 미만이면 규격 라벨 아래에 세 옵션을 동일한 폭으로 배치한다. TapeOptions와 동일하게 규격 이름과 mm를 별도 Text로 나누고 mm는 10px 보조 글씨로 표시해, 카드 밖으로 와이드 옵션이 밀려나지 않도록 한다.
- 넓은 화면은 기존 한 줄 배치를 유지한다. 자르기 값·규격 선택·확정과 저장 형식은 변경하지 않는다.
- S15P31F106-202: 사용자 Galaxy S26 Ultra 실행에서 잘림 해결 및 10px 보조 글씨로 통일한 표시를 재확인했다. OS 버전은 미확인이다.
