# 편집기 기본 손 도구 (S15P31F106-253)

develop b610333(로그인·페이지 수 표시 병합)을 반영한 상태에서 EditorScreen의 초기 activeTool을 select에서 hand로 변경했다. 폰과 태블릿은 같은 상태를 사용한다. 레이어 패널·페이지 이동에서 초기화하는 코드는 추가하지 않았다. 사진·꾸미기 추가 등 기존 명시적 select 전환은 유지한다. 저장 데이터 및 API 변경은 없다.

## 검증

- 초기 viewport·viewport-input 테스트 14개 통과. 최신 develop 통합 후 auth-routing을 포함한 관련 테스트 16개 통과.
- git diff --check 통과.
- iOS 개발 번들 생성 성공. 실기기 실행 결과와는 별개다.
- iPad 실기기: 사용자가 기본 손 도구 선택, 펜 선택 후 레이어 열기·닫기 및 페이지 이동 시 펜 유지, 홈에서 재진입 시 손 도구 복귀를 모두 정상 확인했다. 기기 모델·iPadOS 버전은 미수집이다.
- Android 실기기 및 iPad의 나머지 이동·사진 추가 시나리오는 미확인이다.

## 실기기 확인 순서

1. Reload 후 다이어리를 열어 손 아이콘이 선택되어 있는지 확인한다.
2. 확대 후 캔버스를 한 손가락으로 이동한다.
3. 펜으로 바꾼 뒤 레이어를 열고 닫아 펜 선택이 유지되는지 확인한다.
4. 페이지를 이동해도 현재 도구가 유지되는지 확인한다.
5. 홈으로 나왔다가 다시 들어가 손 도구로 시작하는지 확인한다.
6. 사진·스티커 추가 후 기존 선택·이동 동작이 유지되는지 확인한다.

마스킹테이프 마지막 설정 유지는 후속 작업이다.
