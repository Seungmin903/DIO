# 피칭용 시장 근거

**최신본: [2024년 이후 근거로 개정한 발표 7장·조사 7쪽](./최신자료%20개정/색인.md)** — 출처 발행일은 모두 2025~2026년. 아래는 이전 판으로, 과거 실적이 포함되어 있다.

2026-10-27 추가 조사. 기기 보유·실제 판매·회사 매출·플랫폼 제휴·IP 상품화를 중심으로 외부 피칭용 설명을 구성했다. 텐바이텐·위버딩을 대표 사례로 유지한다.

- [피칭용 PPT 7장](./결과물/DIO_피칭용_시장분석_7장.pptx): 본편 6장 + 질문 대응 별첨 1장, 편집 가능한 차트 2개·표 3개, 출처·발표자 노트 포함.
- [발표 PDF 7쪽](./결과물/DIO_피칭용_시장분석_7장.pdf): 장표 확인용. 수정은 PPT에서 한다.
- [상세 조사 Markdown](./피칭용%20시장%20조사.md): 신규 핵심 근거, 출처 15개, 발표 문구·채택 판단·질문 대응.
- [상세 조사 PDF 9쪽](./결과물/피칭용%20시장%20조사.pdf): 같은 Markdown 원본의 차트·상품 이미지 포함.
- [이전 15개 그룹 검색 조사](../디지털%20다꾸%20시장%20심층%20조사/색인.md): 원자료 보존. 검색 감소를 거래·매출과 구분해 질문 대응에서 활용.

현재 보유율은 2025년 조사, 회사 매출·판매는 2021~2024년 실적이다. 과거 성장 사례를 2026년 시장 전체 성장률로 해석하지 않는다. 이번에 확인한 핵심은 디지털 문구 상업화의 존재와 초기 고객의 기기 기반이다. DIO의 유지·구매 효과는 검증 전이다.

PPT 파일 구조·차트 데이터·최종 장표 렌더와 PDF 전체를 확인했다. PowerPoint 실제 앱에서 편집·저장 후 재열기 테스트는 수행하지 않았다.

시각 자료의 대학생 보유율·회사 매출 차트는 문서의 원수치로 제작했다. 마이멜로디 이미지는 Goodnotes 공식 추천 상품 이미지이며 원본 비율로 사용했다. 본편의 텐바이텐·위버딩 이미지는 이전 조사 폴더의 출처 자료를 재사용하며 해당 출처는 발표자 노트와 상세 조사에 명시했다.
