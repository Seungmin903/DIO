# 디지털 다꾸 시장 심층 조사

후속 조사: [피칭용 시장 근거](../피칭용%20시장%20근거/색인.md)에서 이 자료가 충분히 다루지 못한 실제 판매·운영사 매출·국내 대학생 보유율을 추가했다. 아래 자료의 ‘미확보’는 당시 조사 범위이며 최신 근거와 피칭 구성은 후속 문서를 우선 참조한다.

2026-10-27 기준. 원본 멘토링 7페이지의 시장 분석을 확장한 자료다. 텐바이텐·위버딩 비교, 실제 검색 추이, 소비 경향, 유료 소재·가격, 공동 기록 연구를 다룬다.

- [발표 PowerPoint 12장](./결과물/DIO_디지털다꾸_시장분석_12장.pptx): 기존 양식 유지, 표 6개와 차트 5개 편집 가능, 발표자 노트에 출처·해석 포함.
- [발표 PDF 12쪽](./결과물/DIO_디지털다꾸_시장분석_12장.pdf): 발표 화면 확인용.
- [상세 조사 Markdown](./디지털%20다꾸%20시장%20심층%20조사.md): 17절, 출처 24개, 계산식·키워드·한계·검증 제안.
- [상세 조사 PDF 14쪽](./결과물/디지털%20다꾸%20시장%20심층%20조사.pdf): 같은 원본의 차트·상품 이미지·비교표 포함.
- [원자료와 이미지 출처](./원자료/자료%20안내.md): 네이버 공식 다운로드 3개, 1,035행 CSV, 분석 JSON, 시각 자료.

핵심 결과는 네이버 소재 검색 감소와 유료 상품 공급의 동시 존재다. 검색 지수·공급 수·앱 전체 이용자·표시가격을 시장 매출이나 구매자 수로 합산하지 않는다. 상세 수치와 기준은 조사 문서에서 확인한다.

발표 PDF는 렌더링 화면이며 수정은 PPT에서 한다. PowerPoint 실제 앱에서 편집·저장 후 재열기 테스트는 수행하지 않았고, 파일 구조·차트 데이터·최종 화면을 확인했다.
