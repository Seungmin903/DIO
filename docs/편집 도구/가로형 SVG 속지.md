# 114 가로형 SVG 속지

관련 이슈: [S15P31F106-114](https://ssafy.atlassian.net/browse/S15P31F106-114)

## 사용자 동작

해당 다이어리에 저장 문서가 없으면 2026 연간 속지 문서를 표지 → 월 구분지 → 먼슬리 → 해당 월의 블록형 위클리 순서로 78페이지 생성한다. 연초 주간은 2025-12-29, 마지막 주간은 2026-12-28에 시작한다. 날짜를 런타임에서 다시 계산하지 않고 납품 목록을 사용한다.

페이지 추가 버튼은 데일리·일기·포토/스크랩·무지/줄/모눈/도트 노트 7종을 보여 준다. 선택한 속지를 현재 페이지 다음에 삽입하고 이동한다. 취소는 문서를 바꾸지 않는다. 추가·삭제는 기존 실행 취소/다시 실행 및 자동 저장 흐름을 사용한다. 읽기 모드에서는 추가·삭제를 숨긴다.

## 저장 호환과 좌표

보관함에서 전달한 다이어리는 develop의 `dio:editor:doc:v4:<diary.id>` 키로 저장한다. ID·제목·표지 색상은 보관함의 값을 사용하고, 신규 문서에 연간 78페이지를 생성한다. 다이어리 지정 없이 편집기를 여는 기존 호출자는 `dio:editor:doc:v4`를 계속 사용한다. 각 키에 저장된 페이지가 있으면 그대로 읽으며 연간 페이지를 덧붙이거나 기존 요소 좌표를 변환하지 않는다. 편집 이후 자동 저장하는 흐름을 유지한다.

기존 단일 문서를 새 보관함에 자동 등록하거나 다른 키로 옮기는 기능은 추가하지 않았다. 기존 키의 데이터는 그대로 남는다. 보관함 목록의 자동 저장과 다이어리별 문서 복구는 최신 develop의 구현을 유지한다. 이 복구는 기존 단일 저장 키를 보관함에 자동 이관하는 기능과 구분한다.

새 페이지의 저장 필드:

| 필드 | 값/의미 |
| --- | --- |
| id | 페이지 인스턴스별 기존 createId 방식의 독립 ID |
| backgroundAssetId | 납품 카탈로그의 안정적인 속지 ID |
| templateVersion | 1.0.0 |
| canvasWidth / canvasHeight | 1024 / 768 |
| objects | 기존 사용자 요소 배열 |

배경 XML·절대 파일 경로는 문서에 저장하지 않는다. pageSize(page)는 크기 정보가 없는 이전 페이지를 1188×840으로 읽는다. 화면 맞춤 배율, 삽입 중심, 중앙 스냅, 페이지 기준 정렬, 선택 도구 위치, 썸네일 및 출력에 이 크기를 사용한다.

## 리소스와 오류

가로형 138개를 정적 require 매핑으로 번들한다. 세로형은 파일·카탈로그·UI에 포함하지 않는다. 저널형 SVG는 등록하지만 양식 전환 UI는 제공하지 않는다. 원본 파일은 수정하지 않는다.

expo-asset으로 번들 위치를 해석하고 웹 fetch 또는 네이티브 File.text로 읽는다. react-native-svg로 형식과 viewBox를 검사한 후 SvgXml로 사용자 요소 아래에 표시한다. SVG 배경은 편집 레이어 및 선택 대상이 아니다. 페이지 목록은 FlatList로 가상화하며 XML 캐시는 16개 LRU이고 실패한 요청은 캐시하지 않는다.

페이지 속지 로딩 실패는 재시도 UI를 제공한다. 내보내기는 화면과 별개의 스냅샷에 속지 ID·버전·크기를 고정하고, XML 준비와 실제 렌더 커밋 및 사용자 이미지 로딩을 모두 기다린다. 누락된 ID·버전, 잘못된 SVG, 읽기·렌더링 실패는 출력 오류로 처리한다. 실패 상태에서는 저장 버튼을 제공하지 않는다. 출력 재시도는 새 준비/렌더 단위로 실행한다.
