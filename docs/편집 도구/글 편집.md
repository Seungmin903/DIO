# 텍스트 생성·한글 입력·재편집 (S15P31F106-91)

## 선택 요소 빠른 편집 바 추가 요청

- 펜 목업의 가로형 편집 바를 기준으로 필기·텍스트의 종류 라벨, 색상, 복제·삭제·복사·잘라내기·정렬/보정을 제공한다. 텍스트는 내용 편집·서식을 바로 연다. 좁은 화면에서는 바 내부를 가로로 스크롤하며 페이지 밖으로 버튼을 내보내지 않는다.
- 텍스트 빠른 색상은 전체 문자열에 적용하므로 기존 부분 색상 범위를 지운다. 기존 Undo로 부분 색상까지 복원된다. 내용 편집 중 일부 문자열 팔레트와 글꼴 설정창 자체는 이번 요청에서 변경하지 않는다.
- 복사·잘라내기는 기존 편집기 내부 클립보드와 연결한다. 사진·테이프·스티커 및 잠긴 요소는 기존 편집 바를 유지한다. 저장/API 형식 변경은 없다.
- 최신 검증 결과는 [통합 QA](./편집기%20통합%20QA.md)를 참고한다.

- Jira 완료 기준: 텍스트 생성, 한글 조합·줄바꿈·삭제, 기존 텍스트 재편집 결과 유지.
- 텍스트 도구 선택 후 캔버스에서 드래그해 폭을 정하면 캔버스 안에 입력 상자를 연다. 별도 모달 없이 기기 키보드로 직접 입력하며 별도의 임시 서식 바는 표시하지 않는다. 입력 완료는 Enter 또는 기기 키보드 완료를 사용한다. T 도구로 기존 텍스트를 누르거나 선택 도구에서 선택한 텍스트를 다시 누르면 같은 자리에서 재편집한다. 잠긴 요소와 읽기 모드는 편집하지 않는다.
- 웹·iOS 입력은 `defaultValue`로 시작하며 children은 null이다. Android는 부분 색상 표시를 위해 styled children을 사용하며 defaultValue/value를 함께 전달하지 않는다. 입력 중 문서 저장·문자열 정규화는 하지 않고 웹에서는 조합 중 완료 처리를 막는다.
- 완료 시 한 번 추가/수정해 Undo/Redo 한 단계로 기록한다. 취소는 문서를 변경하지 않는다. 신규 공백 입력은 추가하지 않고 기존 내용을 모두 지워 완료하면 해당 요소를 삭제한다.
- 저장은 `type: text`, `text`, `baseWidth`, `color`와 기존 위치·크기·회전 필드를 사용한다. 줄바꿈은 완료 시 LF로 통일하고 공백·한글·자모는 보존한다. 서버 API 변경과 기존 데이터 마이그레이션은 없다.
- 초기 너비 320, 기본 시스템 글꼴 28, 줄 높이 38이다. 내용에 따라 높이를 확보하며 선택·이동·크기 변경·복제·저장은 기존 구조를 사용한다. 폰트·부분 문자열 색상 설정은 이번 태스크 범위가 아니다.
- 공통 ObjectContent에 텍스트 표시를 연결해 캔버스·썸네일·출력이 같은 문자열을 사용한다. 출력 스냅샷에서 문자열과 기준 너비를 검증한다. 플랫폼별 글꼴/줄바꿈·네이티브 캡처 품질은 별도 실기기 확인이 필요하다.

## 텍스트 전체 서식 설정 (S15P31F106-92)

- T 버튼 아래 목업 배치의 설정 팝오버를 제공한다. 글꼴 목록은 내용을 밀어내지 않는 겹침 드롭다운이며 글자 크기(8~96), B/I/U, 좌·중·우 정렬, 목업의 6색 전체 색상을 제공한다.
- 선택한 잠기지 않은 텍스트 하나에 적용한다. 선택이 없으면 편집 화면 세션의 다음 텍스트 기본값으로 유지한다. 일부 문자열 선택 및 부분 색상 변경은 93번 범위다.
- 글꼴은 현재 시스템 고딕(sans)·명조(serif)·고정폭(mono)으로 제공한다. 별도 폰트 파일·외부 다운로드·추가 의존성은 사용하지 않는다. 목업의 개구체·고운 바탕과 같은 파일이 아니며 한글 시스템 폴백에 따라 글꼴 차이가 작을 수 있다.
- 신규 기본값은 크기 18·고딕·#1D1D1F다. 서식 필드가 없는 이전 텍스트는 기존 크기 28을 유지한다. font, fontSize, bold, italic, underline, textAlign을 기존 text 요소에 추가하며 color는 기존 필드를 사용한다. 기존 데이터 마이그레이션·서버 API 변경은 없다.
- 캔버스·재편집 입력·썸네일·출력은 같은 서식 계산을 사용한다. 서식 변경 시 문자열·좌표·너비를 보존하고 글자 크기에 맞춰 높이를 계산한다. 출력에서 잘못된 크기·글꼴·정렬은 EXPORT_GEOMETRY_INVALID로 거부한다.
- 검증 명령: node --test tests/text.test.js tests/text-settings.test.js tests/page-export.test.js tests/pdf-export.test.js — 26개 통과. Android Expo export 성공.
- 사용자가 Android 태블릿 에뮬레이터에서 설정창, 글꼴·크기·색상·B/I/U·정렬·재편집·Undo/Redo·재진입 후 유지가 정상임을 확인했다. 실제 태블릿·iOS·네이티브 출력 글꼴 품질은 미검증이다.

## 선택 문자열 색상 (S15P31F106-93)

- 편집 중 문자열을 선택하면 선택 글자 색상 팔레트를 제공한다. Android는 TextInput의 styled children으로 선택 범위 색상을 즉시 표시한다. 웹·iOS 입력창은 단색을 유지하며 부분 색상은 편집 완료 후 캔버스에 표시한다. value prop은 함께 전달하지 않는다. 중복 본문 미리보기는 표시하지 않는다.
- 동일 서식의 비표시 Text로 줄 배치를 측정해 선택 끝 글자의 줄 아래 6pt에 팔레트를 배치한다. 창 좌표에서 실제 stage View의 원점을 빼고 편집 영역 경계 안으로 제한한다. Android 기본 선택 메뉴는 유지한다.
- 상자 밖 터치로 문자열과 범위를 함께 한 번 저장한다. colorRanges: [{start, end, color}]는 TextInput과 동일한 UTF-16 [start,end) 범위다. 범위는 정렬·비중첩·인접 동일 색상 병합 규칙을 따르며 필드가 없으면 전체 색상만 사용한다.
- 겹친 범위에 색상을 적용해도 선택 밖 색상은 유지한다. 편집 시 앞뒤 공통 문자열을 기준으로 추가·삭제 범위를 이동하며 삽입한 새 글자는 바로 왼쪽 글자의 색상(기본색 포함)을 따르며 문서 맨 앞에서만 오른쪽 색상을 따른다. 선택 문자열 교체는 교체되는 첫 글자 색상을 보존한다. 줄바꿈도 한 코드 단위로 처리하고 서로게이트 쌍 중간 선택은 이모지 전체로 확장한다.
- 전체 색상 변경은 부분 범위를 비워 전체를 새 색으로 덮는다. 글꼴·크기·굵기·정렬 변경은 부분 색상을 유지한다. 서버 API·기존 데이터 마이그레이션은 없다.
- 캔버스·썸네일·출력은 같은 부분 색상 렌더러를 사용한다. 출력 스냅샷은 잘못된 범위·색상·겹침을 EXPORT_GEOMETRY_INVALID로 거부한다.

## 통합 QA 후 텍스트 빠른 편집 바 (S15P31F106-98)

- 텍스트 상자 선택과 편집 중 일부 글자 선택에 같은 바를 사용한다. 색상 6개 / 글씨 축소·확대 / 복사·삭제 / 링크이며 ‘텍스트’ 종류 표시는 생략한다. 상자 선택 시 전체에, 부분 선택 시 선택 글자에만 적용한다. 내용 편집은 선택된 상자를 다시 눌러 시작한다.
- 크기 버튼은 2씩, 8~96 범위에서 조정한다. 전체 크기 변경은 부분 크기도 같은 양만큼 바꾼다. 부분 삭제는 나머지 문자열·색상·크기·링크 범위를 유지한다. 복사는 expo-clipboard로 실제 시스템 클립보드에 문자열을 기록한다.
- styleRanges: [{start, end, fontSize?, href?}]는 UTF-16 비중첩 범위다. 기존 colorRanges와 독립적으로 병합해 캔버스·썸네일·출력을 그린다. 기존 데이터는 styleRanges가 없어도 동일하게 읽으며 마이그레이션은 없다. 입력·삭제 시 범위를 이동하고 새 글자는 크기만 상속하며 URL은 자동 상속하지 않는다.
- 링크 창에서 URL 입력·수정·제거·열기를 제공한다. 부분 선택이 없으면 전체 문자열에 연결한다. http(s) 주소만 허용하며 도메인만 입력하면 https를 붙인다. 편집 중 링크 창을 열 때 blur로 편집이 종료되지 않도록 보존한다. 읽기 모드에서는 연결된 글자를 눌러 URL을 연다.
- Android 입력은 styled children으로 부분 색상·크기를 표시한다. 웹·iOS의 기본 입력창은 편집 완료 후 캔버스에 부분 서식을 표시한다. 링크는 밑줄로 표시하며 PNG/PDF는 정적 표시만 보존한다. 클릭 가능한 PDF 링크는 범위에 포함하지 않는다.
- 글자 높이는 기존 보수적 추정 방식에 최대 부분 크기를 반영한다. 실제 글꼴별 정밀 측정은 포함하지 않는다.
- 단위·실제 웹 검증은 [통합 QA 기록](./편집기%20통합%20QA.md)을 따른다. Android 부분 크기·선택 유지·URL 열기의 실제 조작 확인은 별도로 필요하다.

- 텍스트 설정창은 펜 설정과 동일하게 상단 고정 제목 ‘텍스트 설정’과 우측 닫기 버튼을 사용한다. 상단 말풍선 화살표는 제거했다.
