# 지우개 입력·획 삭제 (S15P31F106-135)

## 범위

- 기본은 닿은 획 전체를 지우며, 설정에서 닿은 부분만 지우는 영역 지우기로 전환할 수 있다. 아래 최신 설정·꼬리 처리 규칙을 따른다.
- 기존 리본바의 지우개 아이콘을 활성화하고 크기 설정 팝오버를 제공한다. 기본 지름은 24이며 펜·형광펜과 같은 슬라이더로 8~80 범위에서 조절한다. 원형 미리보기와 실제 삭제 반경에 동일한 값을 사용하며 화면 표시에는 확대 배율을 반영한다. 크기는 현재 편집 화면 세션에서 도구를 전환해도 유지되고 앱 재실행 시 기본값으로 시작한다.
- 사진·텍스트·스티커·테이프, 잠금·숨김 획은 삭제하지 않는다. 읽기 모드는 기존 Canvas 입력 차단을 사용한다.

## 입력·접촉 판정

- `EraserInput`은 기존 `usePan`으로 단일 포인터 입력을 받는다. 화면 이동량을 zoom으로 나누어 페이지 좌표로 변환한다.
- `eraser.js`는 획의 원래 좌표에 현재 크기·반전·중심 회전을 반영한다. 원래 샘플 점뿐 아니라 두 지우개 이벤트 사이의 경로도 검사해 빠른 드래그의 누락을 줄인다.
- 볼펜·연필·형광펜의 몸통·끝 모양과 단일 점을 구분한다. 붓펜·만년필은 기존 렌더러가 만든 윤곽을 재사용한다. 원은 24개 점, 이차 곡선은 구간당 6개 점으로 접촉용 다각형을 근사한다. 경계의 서브픽셀 차이는 생길 수 있다.
- 실제 획에서 떨어진 경계 상자 내부의 빈 공간은 지우지 않는다. 지우기 시작 시 접촉 도형을 준비하고, 획·도형의 경계로 먼저 후보를 줄인다.

## 이력·저장

- 드래그 중 삭제 후보는 Canvas 그림 층에서만 숨긴다. 원본 문서·히스토리·썸네일은 확정 전 바꾸지 않는다.
- 손을 떼면 한 번의 `removeObjects` 액션으로 확정하므로 여러 획을 지워도 Undo/Redo 한 단계다. 빈 곳 입력은 액션을 보내지 않는다.
- 두 손가락 제스처 전환·responder 취소·도구/페이지/배율 변경에 따른 입력층 해제 시 미리보기를 버린다. 원본 문서를 수정하지 않았으므로 취소 중 기존 이력은 보존된다.
- 기존 로컬 저장 계층에 삭제된 문서를 저장한다. 저장 스키마·서버 API·데이터 마이그레이션 변경은 없다.

## 지우는 방식·대상과 꼬리 처리 (2026-10-28)

- 설정은 **지우는 방식** `획 전체 / 닿은 부분`, **지울 대상** `전체 / 펜 / 형광펜` 두 줄로 나눈다. 그 아래에 기존 안내와 크기 슬라이더를 둔다. 기본값은 획 전체·전체이며 편집 화면 세션 동안 도구를 바꿔도 선택을 유지한다.
- 펜은 만년필·펠트펜·붓펜·연필과 이전 볼펜을 포함한다. 대상 필터는 획 전체/영역 지우기 모두 적용하며 잠금·숨김 획과 다른 객체는 기존처럼 보호한다. 대상 변경으로 입력층이 교체되면 진행 중 지우기는 취소한다.
- 종류 정보가 없는 스터디 플래너 셀 기록은 `전체`에서만 지운다. 펜/형광펜 선택에서는 보존한다. 기존 셀을 임의로 펜이나 형광펜으로 분류하지 않는다.
- 영역 지우기는 펜촉 반경과 필압을 반영해 샘플 사이의 절단 위치를 찾는다. 현대 펜의 표시 곡선을 먼저 표본화하고 남은 조각은 해당 재질 렌더러로 마감하므로 구간을 단순 사각형으로 자르지 않는다. 만년필·붓펜·펠트펜의 색·굵기·필압·재질 seed와 누적 거리를 유지하며 형광펜은 선택한 round/square 펜촉을 유지한다.
- 구버전 만년필·붓펜 조각에는 선택적인 `eraserCaps: { start, end }`를 저장해 새로 잘린 끝만 필압에 맞는 둥근 마감을 추가한다. 원래 끝과 지우지 않은 획의 경로·렌더 버전은 바꾸지 않는다. JSON 저장·출력 스냅샷에 이 필드를 보존하며 기존 문서 마이그레이션·DB 스키마 변경은 없다.
- 미리보기 조각과 확정 조각을 동일하게 사용하고 하나의 replaceObjects 액션으로 기록한다. Undo는 원본을, Redo는 동일 조각을 복원한다.

검증: `tests/eraser-settings.test.js`, `tests/eraser-target-tail.test.js`, `tests/eraser-input.test.js`와 기존 영역 지우기·재질·캐시·출력 회귀를 실행한다. `node qa/eraser-tail-browser.cjs <산출물 폴더>`는 실제 StrokeContent SVG를 브라우저에서 렌더해 구버전/현대 펜 5종의 둥근 끝·사각 모서리 부재·JSON 복원 일치를 확인한다. 실기기 필기감·설정 창 터치·네이티브 캡처/공유는 미검증이다.
