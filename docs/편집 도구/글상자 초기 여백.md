# 새 텍스트 입력창 하단 여백 (S15P31F106-261)

기준 develop: 7bc53a9. 최신 공개 원격 이력에서 대응 후속 수정을 찾지 못했다. 기존 입력창은 초기값과 내용 크기 이벤트 모두 최소 40 화면 px를 강제했다. 기본 글씨 18px·축소 배율에서는 실제 줄보다 입력 프레임이 과도하게 컸다. 완료 후 저장 높이는 이미 실측 값을 사용하는 구조였다.

새 입력창은 글꼴 크기·줄간격·부분 서식 최대 크기·화면 배율로 최소 높이를 계산한다. 내용 측정값으로 여러 줄을 수용한다. 기존 상자를 편집할 때는 수동 확장한 높이를 보존하며 180번의 최소 내용 높이 제한과 저장 데이터 형식은 변경하지 않는다. 최초 드래그 사각형은 내용 높이로 전환한다.
