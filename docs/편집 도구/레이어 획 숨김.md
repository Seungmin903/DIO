# 펜·형광펜의 레이어 목록 숨김

관련 Jira: [167](https://ssafy.atlassian.net/browse/S15P31F106-167)

## 범위

- `type: stroke`인 펜·형광펜 획을 레이어 패널의 표시 행에서 제외한다. 캔버스 요소와 저장 JSON, 요소의 `hidden` 속성은 변경하지 않는다.
- 획만 있는 그룹은 목록에서 제외한다. 혼합 그룹의 펼친 자식 목록에서는 획만 제외한다.
- 혼합 그룹의 `members`는 원본 그대로 유지한다. 그룹 선택·이동·순서·잠금·숨김은 기존처럼 획을 포함한 그룹 전체에 적용되며, 그룹 개수도 전체 멤버 수다.
- 사진·텍스트·스티커·테이프 등의 기존 표시 순서를 유지한다. 행이 없으면 목록에서 필기를 숨겼다는 안내를 표시한다.
- 지우개·올가미·Undo/Redo·내보내기 및 저장 형식은 변경하지 않는다. 레이어 패널의 도움말에 혼합 그룹 동작을 안내한다.
