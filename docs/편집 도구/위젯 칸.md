# 위젯 칸 · 스티커 정리 · 마테 폭 늘리기

2026-11-01. 편집 도구줄의 도형 버튼을 빼고 그 자리에 **위젯** 칸을 넣었다. 외부 출처 기본 스티커는 모두 없앴고, 마스킹테이프는 규격을 고르는 대신 붙인 뒤 폭을 직접 늘이고 줄인다.

## 나누는 기준

보관함 칸은 **붙인 뒤 어떻게 움직이느냐**로 나눈다. 생김새가 아니라 동작이 기준이다.

| 칸 | 붙인 뒤 |
|---|---|
| 스티커 | 그림 한 장. 모서리로 크기만 바꾼다 |
| 위젯 | 안에 글 · 값 · 사진이 들어간다 (메모, 디데이, 사진 틀, 앞으로 날씨 · 날짜) |
| 마스킹테이프 | 무늬가 반복되는 띠. 끝으로 길이, 위아래로 폭을 바꾼다 |
| 사진 | 보관함 없이 바로 앨범을 연다 |

- 도구줄: 스티커 · 위젯 · 마스킹테이프 · 사진 (태블릿 리본, 폰 도구줄 모두 같은 자리).
- 위젯 아이콘은 Lucide `blocks`(1.66.0)다. 홈 · 페이지 목록이 이미 네 칸 격자(`layout-grid`)를 써서, 머티리얼 '위젯' 아이콘처럼 한 칸이 떨어져 나온 모양을 골랐다.
- 레이스는 마테 칸에 그대로 둔다. 사진을 담는 빈 틀(폴라로이드 · 필름 · 우표 · 티켓 4종 · 네컷 2종)은 위젯의 '사진 틀' 칩으로 옮겼다. 그림 도장 · 장식 실링왁스는 그림이 생기면 스티커 폴더로, 날짜 · 날씨 도장은 위젯의 '모양'으로 넣는다. 봉인 · 개봉이 있는 실링왁스는 온라인 속지 기능이라 범위 밖이다.

## 위젯 칸

- 칩은 기능 하나에 하나: **메모 · 디데이 · 사진 틀**. 모양 차이는 칩 안의 칸으로 고른다. 기능이 늘면 칩이, 모양이 늘면 칩 안 칸이 는다. 마지막으로 고른 칩은 보관함을 닫았다 열어도 남는다(앱을 다시 켜면 메모).
- **메모**: **앱에 기본으로 들어 있는 메모지** 8종(사용자 결정: 단색 종이 + 무늬 하나, 글자 · 장식 · 두 번째 색 없음, 하트 · 구름 같은 모양 장식 없음) + 사용자 시안 3종(아래 표 끝), 모두 11종.
  - 그림: 코덱스가 실제 메모지 제품을 참고해 메모 한 장을 SVG 한 장으로 그렸다(`frontend/src/editor/widgets/memoArt.js`). 앱은 `SvgXml` 로 그대로 그리고, 색 자리 `{paper}` · `{line}` 만 메모의 채우기(종이 색) · 테두리 색(무늬 색)으로 바꾼다. 렌더를 코덱스에 다시 보여 준 검수 결과 수정 없음.
  - 붙이면 도형 요소(`type: 'shape'`, `art`)라 두 번 눌러 글을 쓴다. 그림이라 **모서리로만** 크기를 바꾸고(비율 고정), 글자도 종이와 같은 배율로 커진다. 줄 있는 종이는 글 한 줄 높이를 줄 간격에 맞추고 첫 줄을 첫 밑줄 위에 둔다. 옵션 창에는 '종이 색 · 무늬 색'만 나온다(무늬 색 칸은 마테 무늬색 7색 + 글 남색).

| 이름 | 무늬 · 바깥 모양 | 종이 / 무늬 색 | 참고 제품 (코덱스) |
|---|---|---|---|
| 무지 메모 | 없음, 아주 둥근 모서리 | 크림 / 남색 | 3M 포스트잇 3×3in 무지 |
| 줄 메모 | 줄(간격 26) | 딸기 | 3M 포스트잇 줄 · 미도리 MD 줄 블록 |
| 모눈 메모 | 5mm 모눈 | 하늘 | 미도리 MD 메모 블록 |
| 도트 메모 | 5mm 도트 | 라벤더 | 로디아 도트패드 |
| 체크 메모 | 줄마다 네모 칸(간격 26) | 올리브 | 모트모트 체크리스트 떡메 |
| 인덱스 카드 | 줄(간격 24), 가로형 | 흰 / 남색 | 옥스퍼드 인덱스 카드 3×5in |
| 영수증 | 줄(간격 24), 아래 톱니 | 버터 | 영수증 메모패드 |
| 뜯은 노트 | 줄(간격 26), 왼쪽 찢긴 구멍 자국 | 민트 | 코쿠요 캠퍼스 스프링 노트 |
| MEMO 메모 | 위쪽 MEMO 머리글, 무지 | 크림 / 회색 | 사용자 시안(모아 · 디오 메모에서 캐릭터를 뺀 것) |
| 모아 메모 | MEMO 머리글 + 오른쪽 아래 모아 | 연보라 | 사용자 시안 |
| 디오 메모 | MEMO 머리글 + 오른쪽 아래 디오 | 버터 | 사용자 시안 |

  - 뒤 3종은 사용자가 직접 정한 예외로, 머리글 글자와 캐릭터가 있다. 캐릭터(`character: true`)는 정해진 색이라 종이 · 무늬 색을 바꿔도 그대로다.

  - Claude가 고친 것: ① 코덱스 그림의 종이 바탕에 걸린 농도(0.52~0.86)가 채우기까지 옅게 해 바탕이 비쳐서, 선에만 걸리게(`stroke-opacity`) 바꿨다. ② 이름 '포스트잇'(3M 상표) → '무지 메모', 띄어쓰기 정리. ③ 코덱스 출력에 섞여 나온 인쇄 글자 있는 모눈 메모 1장은 원칙에 어긋나 뺐다.
  - 고른 과정: 처음엔 귀여움 섞인 8종(하트 · 구름 · 테이프 메모 등)을 도형 + 무늬로 만들었으나, 사용자가 '실제 제품 참고해 다시, 단색에 무늬만, 기본 메모지 컨셉'으로 정해 지금 그림으로 바꿨다. 그때 만든 모양 · 무늬 코드는 지웠다.
  - 11종 낱장 PNG(투명 바탕, 실제 앱 렌더 5배): [메모 위젯 PNG](./메모%20위젯%20PNG/)
- **디데이**: 스티커 안 '위젯' 칩에서 옮겨 왔다. 저장 형식(`type: 'sticker'`, `widget`)은 그대로다.
- **사진 틀**: 기본(폴라로이드 · 필름 · 우표) · 티켓 · 네컷 소제목으로 나눈다. 누르면 빈 틀이 붙고 캔버스의 + 로 사진을 채운다. 저장 형식은 그대로다.

## 사진 버튼

- 사진 칸(보관함)을 없앴다. 사진 버튼을 누르면 바로 앨범이 열리고, 고른 사진은 틀 없이 붙는다. 고르는 창이 떠 있는 동안 다시 누르면 무시한다. 원본을 저장하는 동안 보이던 '원본을 저장하고 있어요…' 표시는 없어졌다.

## 도형

- 도형 버튼과 도형 고르기 창을 뺐다. 이미 붙어 있는 도형은 그대로 그리고, 선택 → 옵션의 채우기 · 테두리 · 글 서식도 그대로 쓴다(`EDITOR_SHAPES` 와 출력 검사는 유지).

## 스티커

- Fluent Emoji · Noto Animated Emoji · Twemoji 기본 스티커와 썸네일, `generate-sticker-thumbs.py`, 콘텐츠 라이선스 항목을 지웠다. 스티커 칸에는 즐겨찾기 · 최근 · 내 폴더만 남는다. 표지 스티커도 같다.
- 예전 문서에 남은 기본 스티커(`asset` id)는 캔버스에 점선 자리(`없어진 스티커`)로만 보여 찾아 지울 수 있게 하고, 내보내기(PNG · PDF · GIF)에서는 뺀다. 저장된 문서는 바꾸지 않는다.
- 예전 즐겨찾기 · 최근 기록에 남은 기본 스티커 · 디데이는 스티커 칸에 보이지 않는다.
- GIF 처리 테스트가 쓰던 Noto GIF 두 장은 `frontend/tests/fixtures/gifs/` 로 옮겼다(배포물에는 들어가지 않는다, CC BY 4.0 원문 함께 둠).
- 배포 고지(`public/licenses`, Android `dio_licenses` 의 THIRD_PARTY_NOTICES.txt)의 콘텐츠 부분에서 세 출처를 뺐다. 다음 고지 재생성 때 `contentLicenses.json`(빈 목록)으로 다시 만든다.

## 마스킹테이프 폭

- 규격(슬림 · 기본 · 와이드) 고르기를 보관함과 사진 테이프 자르기 화면에서 뺐다. 새 테이프는 늘 기본 폭(180 × 34)으로 붙는다.
- 붙인 테이프는 양 끝 동그라미로 길이, **위아래 동그라미로 폭**을 바꾼다. 폭은 11(예전 슬림)부터 136(와이드의 두 배)까지. 얇은 테이프에서는 위아래 손잡이가 겹치지 않게 바깥으로 벌린다.
- 폭을 바꿔도 **무늬 크기는 그대로, 줄 수만** 는다. 무늬 기준 높이 `unitH` 를 같은 비율로 바꿔 저장하고, 무늬는 `h / unitH` 배율로 그린다. 예전 테이프는 규격 높이가 기준이다(`tapeUnitH`). 레이스는 띠라서 폭에 맞춰 함께 커진다. 사진 테이프는 한 조각 길이(`segmentW`)도 같은 비율로 바꿔 그림이 찌그러지거나 잘리지 않는다.
- 저장된 `size` 값은 그대로 읽는다(예전 문서 호환). 서버는 요소 필드를 검사하지 않아 백엔드 변경은 없다.
