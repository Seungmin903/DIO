# 도형 삽입·스타일·텍스트 (S15P31F106-226)

## 사용 흐름

- 태블릿 리본과 모바일 세로/가로 도구 막대의 도형 버튼으로 연다. 사진의 도형 자르기와는 별도 기능이다.
- 전체 및 기본·다각형·별·화살표·말풍선·기호 분류에서 총 74종을 고른다. 분류는 기존 도구와 같은 회색 바탕·흰색 선택 칸의 한 줄 가로 스크롤 세그먼트로 표시하고, 도형 목록은 별도 세로 스크롤을 지원한다. 별도 도형 미리보기 없이 펜 옵션과 같은 크기/선택 테두리의 한 줄 색상 팔레트를 사용한다.
- 색상 줄 맨 앞의 빗금 원으로 채우기 없음을 선택하거나 채우기 색, 테두리 색·두께 0~16·실선·점선·짧은 파선·파선·긴 파선·일점쇄선·이점쇄선 7종을 고르고 캔버스에 추가한다. 두께 0은 테두리 없음이며 테두리 색상과 모양 선택을 비활성화한다. 두께를 올리면 기존 색과 모양을 다시 사용할 수 있다. 색상 직접 선택을 제공한다.
- 추가 버튼은 옵션 스크롤과 별도로 패널 하단에 고정한다. 낮은 가로 화면에서도 설정을 스크롤하며 추가 버튼에 접근한다.
- 삽입하면 선택 도구로 돌아간다. 기존 선택·이동·여덟 방향 크기 변경·회전·복사·복제·그룹·레이어 순서·잠금·삭제 흐름을 사용한다.
- 모양은 삽입할 때 선택한다. 삽입한 도형의 선택 바 → 옵션은 기존 공용 꾸미기·배치 창으로 연다. 꾸미기에서 채우기·테두리·불투명도·그림자를, 배치에서 반전·각도를 조절한다. 모양 목록과 추가 버튼은 표시하지 않으며 잠긴 도형은 수정하지 않는다.
- 도형을 두 번 눌러 내부 글을 입력한다. 바깥을 누르면 저장한다. 글을 모두 지워도 도형은 유지하고 글 길이로 도형 크기를 바꾸지 않는다.
- 선택 편집 바의 서식에서 텍스트박스와 같은 공용 설정 창으로 글꼴, 글자 색·크기 8~96, 굵게·기울임·밑줄·취소선, 좌/중/우/양쪽 정렬, 자간·줄 간격을 바꾼다. 입력 중 글자를 선택하면 선택 바에서 색·크기 변경, 복사·삭제·붙여넣기를 사용한다. 긴 글은 도형 밖으로 이어서 표시하며 도형·글자 크기를 자동 변경하지 않는다. 키보드가 표시될 때 긴 입력창은 가용 화면 높이 안에서 스크롤한다.

## 데이터와 출력

- 기존 문서의 `pages[].objects`에 `type: shape` 요소를 추가한다. 공통 ID·좌표·크기·회전·그룹·숨김·잠금 필드를 사용한다.
- 추가 필드: `shape`, `fill`(HEX 또는 none), `borderColor`, `borderWidth`, `borderStyle`, `text`, `color`, `font`, `fontSize`, `bold`, `italic`, `underline`, `strike`, `align`, `textAlign`, `letterSpacing`, `lineSpacing`, `colorRanges`, `styleRanges`.
- 생성 기본값: 둥근 사각형, 연노랑 채우기, 테두리 없음, 빈 글. 가로 220 논리 좌표이며 타원·일부 화살표/기호는 고유 초기 비율을 사용한다.
- 캔버스·레이어 미리보기·페이지 썸네일·내보내기는 공통 ShapeContent 렌더러를 사용한다. 출력 스냅샷에 도형을 허용하고 도형 ID·색·수치·스타일을 검증하며 웹 글꼴 준비에도 포함한다.
- 실제 저장은 기존 자동 저장을 사용한다. 단일 설정은 Undo 한 단계, 슬라이더/직접 색상 선택은 시작 checkpoint와 연속 변경으로 묶는다. 텍스트는 입력 완료 시 한 번 저장한다.
- 기존 사진 프레임 경로와 저장 키는 바꾸지 않으며 데이터 마이그레이션은 필요 없다. 새 도형이 있는 문서는 도형을 지원하는 버전에서 열어야 한다.

- 키보드가 캔버스를 위로 이동시킨 뒤 입력창 화면 좌표를 다시 측정한다. 부모 transform 이동은 입력창 onLayout 없이도 일어나므로 렌더 커밋 후 프레임에서 측정하며 레이아웃 변경도 반영한다.

## 실기기 키보드 표시 영역 보정

- 도형 전체 높이를 키보드 위로 이동시키지 않고 실제 글 내용 높이로 입력창 높이를 정한다. 긴 글은 툴바 하단~키보드 상단의 가용 높이로 제한하고 입력창 내부에서 스크롤한다. 도형 크기/저장 좌표는 바꾸지 않는다.
- 키보드가 보인 뒤 측정한 입력창 상단이 툴바 뒤에 있으면 캔버스를 아래로 이동하고, 하단만 가려졌으면 필요한 만큼 위로 이동한다. 키보드 프레임/숨김 및 캔버스 커밋 후 좌표를 갱신한다.
- 큰 도형에 짧은 글이 있는 경우의 과도한 이동, 툴바 뒤 입력창 복구, 긴 글의 가용 높이 제한을 재현 테스트로 확인했다. 같은 도형으로 실기기 재확인이 필요하다.
