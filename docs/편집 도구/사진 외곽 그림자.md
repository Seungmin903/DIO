# 사진 특수 외곽 그림자 (S15P31F106-262)

기준 develop: 7bc53a9. `photoSupportsShadow`가 하트·별·우표를 제외하여 옵션에도 그림자가 없고 실제 렌더러에서도 꺼졌다. 최신 공개 원격 이력에서 대응 후속 수정을 찾지 못했다.

기존 하트·별·우표를 지원 대상으로 포함하고 SVG 경로를 재사용한다. 기존 도형 렌더러에서도 사용하는 SVG Filter·Gaussian blur로 바깥 그림자를 그리고, 역마스크와 클리핑으로 안쪽 그림자를 표현한다. 색·거리·방향·퍼짐·흐림·불투명도는 공통 그림자 설정을 사용한다. 하트·별의 반전 외곽을 반영하고 그림자 여백과 고유 ID를 확보한다. 일반 사각·라운드·원형·폴라로이드·필름·액자의 기존 경로는 유지한다.

기존 그림자 속성을 그대로 사용하며 저장 스키마·API·DB 변경은 없다. 이전 문서에 저장된 해당 효과도 이제 표시된다. 새 프레임 종류를 추가하지 않는다.
