# 마스킹테이프 마지막 설정 유지 (S15P31F106-260)

## 범위

최신 develop b610333 기준. 새 테이프 도구의 규격·색상·무늬를 `dio:editor:tape-preferences:v1`에 저장한다. 사용자 지정 바탕색·무늬색 쌍도 복원한다. 기기 공통 설정이며 계정별 서버 동기화는 제공하지 않는다. 기존 문서·사진 테이프·배치한 테이프의 끝선·불투명도는 변경하지 않는다.

처음 사용할 때 규격은 기본, 색상·무늬는 무선택이다. 색상을 고르지 않고 무늬를 누르면 실제 삽입한 기본색(핑크)을 기억한다. 복원 자체는 테이프를 붙이지 않으며 같은 무늬를 다시 누르면 한 장 더 붙인다.

## 저장과 오류 처리

- 패널 재마운트에서는 공유 메모리 설정을 즉시 사용한다. 앱 재실행에서는 저장소 복원 뒤 도구 입력을 제공한다.
- 비동기 복원보다 먼저 들어온 변경은 필드별로 우선하고 저장은 직렬화한다.
- 허용 목록의 규격·무늬·색상 및 유효한 사용자 HEX 색상 쌍만 복원한다. 위치·미디어 참조는 저장하지 않는다.
- 읽기 실패·잘못된 값은 기본값으로 복구한다. 조회만으로 저장 데이터를 덮어쓰지 않는다.
- 쓰기 실패 시 현재 실행의 설정과 새 테이프 삽입은 유지한다. 실패 토스트를 안내하고 다음 선택에서 저장을 재시도한다.

## 검증

- `node --test tests/tape-preferences.test.js tests/tape-drawer.test.js`: 9개 통과. 복원·재구독·재실행, 느린 조회/빠른 저장 경합, 손상된 값, 실패 후 재시도, 실제 보관함의 무늬 삽입·복원 중 입력 차단·실패 안내를 검증했다.
- iOS·웹 개발 번들 생성 성공. 실기기 실행 성공을 의미하지 않는다.
- `node qa/tape-preferences-browser.cjs`: Edge 전용 origin·컨텍스트의 1280×800·412×892에서 색·규격·무늬, 닫기·삽입 후 재진입·Reload 복원을 확인했다. pageerror 0건.
- 브라우저 QA는 `npx expo export --platform web --dev --output-dir .expo/tape-preferences-web --max-workers 2` 생성 후 실행한다. 개인 자료는 사용하지 않는다.
- iPad·Android 실기기 미검증. QA 순서는 전달했으며 결과 보고를 기다리는 상태로 Draft MR에서 리뷰한다.

## iPad QA 순서

1. Reload 후 로그인 화면에서 게스트로 시작하기 → 다이어리 열기 → 마스킹테이프를 연다.
2. 와이드·스카이 색을 선택하고 패널을 닫았다 열어 유지되는지 확인한다.
3. 도트 무늬를 눌러 한 장 삽입한다. 다시 열어 색·규격·무늬가 유지되는지 확인한다.
4. 같은 도트 무늬를 다시 눌러 한 장 더 추가되는지 확인한다.
5. 펜으로 전환했다가 테이프를 열고, 다른 다이어리에서도 같은 설정이 나오는지 확인한다.
6. 내 색상에서 바탕색·무늬색을 다르게 지정하고 테이프를 삽입한다. 패널 재진입과 Expo Reload 후 두 색이 유지되는지 확인한다.
7. 기존 테이프의 색·규격·끝선·불투명도가 바뀌지 않았는지 확인한다.
8. 앱을 완전히 종료 후 재접속해 설정을 확인한다. 복원만으로 테이프가 추가되지 않아야 한다.
