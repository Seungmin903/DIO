# 형광펜 (S15P31F106-90)

## 범위와 동작

- 근거: `MVP1 화면 명세.md`의 `11-highlighter-settings`와 팔레트 적용 목업.
- 리본의 형광펜 버튼으로 설정을 열고, 라운드/스퀘어 끝 모양·굵기·색상을 선택한다. 기본값은 스퀘어, 굵기 18, `#FFE066`이다. 굵기는 목업과 같은 8~40, 0.5 단위이며 7색 팔레트와 HEX 입력·기존 색상 프리셋을 제공한다.
- 펜과 형광펜의 설정은 편집 화면 세션에서 따로 유지한다. 설정 변경은 다음 획과 미리보기에만 반영한다. 앱 재실행 시 도구 설정은 초기값으로 돌아간다.
- 기존 `PenInput`으로 입력하고 손을 뗄 때 한 획을 확정한다. 취소된 입력은 저장하지 않는다. 페이지·배율·도구 전환 시 입력 상태를 초기화하며 읽기 모드에서는 입력과 설정을 숨긴다.
- 기존 선택·이동·회전·크기 변경·레이어 순서·자동 저장·Undo/Redo 구조를 재사용한다.
- 사용자 추가 요청에 따라 형광펜은 끝점에서 600ms 동안 머무르면 시작점과 끝점을 잇는 직선으로 보정한다. 정지 허용 반경은 화면 기준 6px, 시작·끝 최소 거리는 16px이다. 보정 후 손을 떼기 전에는 끝점을 움직일 수 있으며, 손을 뗄 때 한 획으로 저장한다. 짧은 탭과 입력 취소에는 적용하지 않는다. 일반 펜에는 적용하지 않는다.

## 저장과 렌더링

- 기존 `type: 'stroke'` 요소에 `penKind: 'highlighter'`, `lineCap: 'round' | 'square'`를 저장한다. 기존 펜 데이터의 변경이나 마이그레이션, 서버 API 변경은 없다.
- `StrokeContent`의 단일 SVG Path에 불투명도 0.42를 적용한다. 한 획 안에서는 선분별로 투명도가 누적되지 않고, 별개 획끼리는 문서 레이어 순서대로 겹쳐진다. multiply 합성은 사용하지 않는다.
- 스퀘어 끝이 대각선에서 잘리지 않도록 기준 경계에 추가 여백을 둔다. 짧은 탭도 점으로 남긴다.
- 캔버스·썸네일·출력은 같은 렌더러를 사용한다. 출력 스냅샷은 끝 모양과 좌표를 복사하고 잘못된 형광펜 끝 모양은 `EXPORT_GEOMETRY_INVALID`로 거부한다. PNG 문서 자체는 수정하지 않는다.
- 통합 과정에서 `ObjectView.js`의 `StrokeContent` import 누락을 확인해 복구했다. 사용하지 않는 `strokePath` import만 교체했다.

## 검증

- `frontend`에서 `node --test tests/highlighter.test.js tests/pen-settings.test.js tests/strokes.test.js tests/page-export.test.js tests/gif-first-frame.test.js tests/png-file-save.test.js`: 43개 통과.
- 설정과 기존 획의 분리, 대각선·단일 점의 스퀘어 경계, 저장·출력 시 끝 모양·변형·순서 유지, 잘못된 끝 모양 거부를 검증한다.
- 가상 타이머로 정지 후 직선 보정·미세 떨림·끝점 이동·빠른 해제와 취소·확대 배율별 화면 픽셀 감도를 검증한다. 입력 종료와 컴포넌트 해제 때 타이머를 취소한다.
- Android Expo export 성공. 최초 샌드박스 실행의 Hermes 임시 파일 쓰기가 거부되어 승인된 권한으로 재실행했다. 번들 성공은 실제 화면 검증과 구분한다.
- Android 태블릿 에뮬레이터에서 사용자가 형광펜 동작과 끝점 길게 누르기 직선 보정의 정상 동작을 확인했다. 실제 태블릿·스타일러스·네이티브 PNG 출력은 미검증이다.
