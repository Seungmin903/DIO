# 다이어리별 마지막 열람 페이지 복원

관련 태스크: S15P31F106-227

## 동작

- 캔버스 상단의 다른 다이어리 탭을 눌렀다가 돌아오면 마지막으로 열어 본 페이지를 복원한다. 편집 여부와 관계없이 페이지 선택을 기록한다.
- 보관함에서 다시 열거나 앱을 재실행해도 개인 다이어리의 열람 페이지를 복원한다. 기록이 없거나 해당 페이지가 삭제됐다면 남은 첫 페이지를 연다.
- 페이지 이동은 문서 내용·수정 시각·Undo/Redo 이력에 포함하지 않는다. 확대 배율·캔버스 이동량·선택 요소는 이번 복원 범위가 아니다.

## 저장과 수명

- `editorViewState`가 `dio:editor:view:v1:<편집 문서 저장 키>`에 페이지 ID만 별도로 저장한다. 문서 검색·복구에 사용되는 키 접두사와 분리하며 기존 문서 형식은 변경하지 않는다.
- 같은 문서의 연속 쓰기는 순서를 유지하며 메모리는 즉시 갱신한다. 늦은 저장소 읽기가 최신 열람 위치를 덮어쓰지 않는다. 저장 실패가 편집 문서 저장을 막지 않으며 디스크 기록이 없으면 다음 실행에서 첫 페이지로 돌아갈 수 있다.
- 임시 공유 다이어리는 기존 `session-doc:` 저장 범위 안에서만 열람 위치를 기억하며 참여 해제·세션 종료 시 문서와 함께 제거한다. 서버·다른 기기와 동기화하지 않는다.
- 열람 읽기 실패는 기록 없음으로 대체하며 문서 편집 저장을 막지 않는다. 쓰기 예외도 실패 값으로 흡수하여 다음 쓰기가 계속 실행되게 한다.
- 개인 다이어리 영구 삭제·30일 만료 정리는 진행 중인 열람 쓰기가 끝난 후 열람 기록을 먼저 삭제하고, 성공한 경우에만 문서·목록·미디어를 정리한다. 기록 삭제가 실패하면 문서와 삭제 표식을 유지하여 재시도 때 미디어 참조를 다시 읽는다. 메모리 캐시는 최대 128개이며 초과 시 디스크에서 다시 읽는다.
- `forgetEditorDoc`은 기존 문서 캐시 무효화 역할을 유지하고 개인 열람 기록을 삭제하지 않는다. `forgetViewedPage`는 영구 삭제 경로에 별도 연결한다. 일반·세션 문서의 `forgetEditorDoc` 반환은 모두 동기 boolean이다.
- 휴지통 이동은 복원 가능하므로 열람 위치를 유지한다. 현재 계정 로그아웃·임시 회원탈퇴도 기기의 개인 다이어리를 보존하는 정책에 맞춰 개인 열람 기록을 유지한다. 공유 세션 기록은 기존 세션 종료 처리로 제거한다. 실제 계정별 서버 저장 연결 시 계정별 범위를 다시 확인한다.
- 진입 전에는 마지막 열람 페이지의 속지를 준비한다. 준비 시간 제한 때문에 직접 진입한 경우에도 열람 기록을 읽기 전 임시 첫 페이지를 기록하지 않는다.
