# 알림 보기 설계안 (다이어리 공유 대비)

> 작성일: 2026-10-23 · 기준: [디자인 가이드](../디자인%20가이드.md), `feature/fe/layer`<br>
> 맥락: 다이어리 공유 기능을 넣기 전에 알림을 어떻게 보여 줄지 정한다. 공유 창(편집기 상단 '공유' → "다이어리 공유")은 시안 이미지로만 있고 아직 코드에는 없다.<br>
> 보는 법: 왼쪽이 **지금**, 오른쪽이 **N안 시안**이다. 빨간 번호 상자가 새로 생기는 곳이다. 시안은 우리 디자인 토큰으로 그린 HTML이고, 눌러 볼 수 있다 — [1안](목업/1안.html) · [2안](목업/2안.html) · [3안](목업/3안.html) · [4안](목업/4안.html) (주소 뒤에 `?phone=1`을 붙이면 폰 화면).

## 0. 요구사항과 가정

| 요구사항 | 이 문서에서 |
|---|---|
| 알림 창 맨 위에, 인스타그램 '팔로우 요청'처럼 **새로 공유받은 다이어리를 모아 보는 입구** | 모든 안의 ② — 맨 위 한 줄(또는 줄 · 카드). 누르면 **모달 안에서** 옆으로 밀리며 '공유 요청' 화면으로 넘어가고, 왼쪽 위 `‹`로 돌아온다(전체 화면으로 바뀌지 않음) |
| 리스트 화면 왼쪽 메뉴에 **종 버튼** | 모든 안의 ① — 안마다 자리를 달리해 비교 |
| 2026 UI/UX 흐름 · 우리 디자인 규칙 | 아래 3장 공통 규칙 |

가정

- "다이어리 공유 창의 상단부"는 **알림 창(공유 소식이 모이는 창)의 맨 위**로 읽었다. 편집기의 "다이어리 공유" 창은 한 다이어리의 참여자 · 권한을 다루는 곳이라, 받은 초대를 모으는 입구는 알림 창이 맞다고 봤다. 공유 창 위쪽에도 넣어야 한다면 4장 끝의 "덧붙일 수 있는 것"을 본다.
- 알림 종류와 문구는 공유 기능 기획 전의 **예시**다(공유 초대 · 초대 수락 · 페이지 추가 · 스티커 · 권한 변경 · 내보내기 허용 · 링크로 참여 · 나가기).

## 3. 모든 안에 공통인 규칙

- **창 안에서 넘어가기**: 알림 → '공유 요청'은 같은 창 안에서 오른쪽에서 밀려 들어온다(0.28초). 왼쪽 위 `‹`, Esc, 안드로이드 뒤로 가기는 알림으로 돌아가고, 한 번 더 누르면 닫힌다. 창 위에 창을 띄우지 않는다.
- **맨 위 입구**: 받은 공유 요청이 있을 때만 보인다. 표지(또는 보낸 사람) 3개까지 겹쳐 보이고 개수를 빨간 배지로. 요청이 없으면 줄 자체가 사라진다.
- **공유 요청 카드**: 표지 · "○○님이 함께 쓰자고 했어요" · 다이어리 이름 · 권한(편집 가능 / 보기 가능) · 몇 명이 쓰는지 · 언제 → **거절 / 수락**. 수락하면 그 자리에서 "보관함에 넣었어요 · 열기"로 바뀐다. 거절해도 상대에게 알리지 않는다(인스타그램과 같음).
- **알림 목록**: 오늘 / 이번 주 / 이전으로 묶는다. 한 줄 = 사람(종류 아이콘을 작은 원으로 겹침) + 문장 + 시간 + 오른쪽에 그 다이어리 표지나 페이지 썸네일. 누르면 그 다이어리의 그 페이지로 간다. 읽지 않은 줄은 왼쪽에 파란 점.
- **묶기**: 같은 다이어리에서 같은 종류가 이어지면 "하루님 외 1명이 페이지 3장을 더했어요"처럼 한 줄로.
- **배지**: 종의 빨간 숫자 = 읽지 않은 알림 + 대기 중인 공유 요청. '모두 읽음'을 누르면 알림 쪽만 0이 되고, 공유 요청은 처리할 때까지 남는다.
- **빈 화면**: "새 알림이 없어요 · 친구가 다이어리를 꾸미거나 나를 초대하면 여기에 알려 드려요." / "받은 공유 요청이 없어요 · 친구가 다이어리에 초대하면 여기에 모여요."
- **디자인 규칙**: 종 아이콘은 `Icon.js`와 같은 24 격자 · 선 1.8. 창은 공유 창과 같은 흰 바탕 · 큰 모서리 · `scrim` 덮기 · 제목 22/900. 누르는 곳은 모두 44 이상. 수락 같은 채운 버튼은 대비를 맞춘 진한 파랑(`#4F74AE`, [디자인 트렌드 검토](../디자인%20트렌드%20검토/색인.md) 1번).

| 알림 종류 | 아이콘 | 예시 문장 |
|---|---|---|
| 초대 수락 | 사람 + | 모아님이 **메모장** 초대를 수락했어요. |
| 페이지 추가(묶음) | 펜 | 하루님 외 1명이 **2026 다이어리**에 페이지 3장을 더했어요. |
| 스티커 · 꾸밈 | 하트 | 소연님이 내 페이지에 스티커 2개를 붙였어요. |
| 권한 변경 | 열쇠 | 소연님이 **메모장**에서 내 권한을 **편집 가능**으로 바꿨어요. |
| 내보내기 허용 | 내려받기 | **메모장**에서 내보내기를 허용했어요. 이제 이미지·PDF로 저장할 수 있어요. |
| 링크로 참여 | 링크 | 초대 링크로 2명이 **위클리 플래너**에 들어왔어요. |
| 나가기 | 문 | 모아님이 **위클리 플래너**에서 나갔어요. |

## 4. 1안 — 가운데 모달 + 한 줄 요청 (인스타그램 방식)

① **종은 메뉴 맨 위**: 접힘에서는 메뉴 버튼 바로 아래, 펼침에서는 로고 오른쪽 메뉴 버튼 옆. 어느 상태에서도 같은 자리라 찾기 쉽다. 폰은 제목 오른쪽 위 둥근 버튼. ② 알림 창 맨 위 **'공유 요청' 한 줄**: 보낸 사람 얼굴 3개 + "하루님 외 2명이 다이어리를 함께 쓰자고 했어요" + 개수 + `›`. ③ 날짜별 알림. 창은 공유 창과 같은 가운데 모달(560 × 680).

## 5. 2안 — 메뉴 항목 + 종 옆에 붙는 패널

① **종을 메뉴 항목 '알림'으로**: 새 다이어리 아래 '소식' 묶음에 넣고, 펼침에서는 오른쪽에 개수 알약, 접힘에서는 빨간 점. 폰은 아래 탭에 '알림'을 하나 더 둔다(5칸). ② 맨 위 줄은 사람 대신 **받은 다이어리 표지 3장**을 겹쳐 보여 준다. ③ 창은 화면 가운데가 아니라 **메뉴 바로 옆에 붙는 패널**(폭 440, 위아래 꽉 참, 작은 꼬리). 뒤를 옅게만 덮어 리스트가 보인다.

## 7. 4안 — 오른쪽 시트 + 요약 카드

① **종은 새 다이어리 버튼 옆**(펼침에서는 같은 줄, 접힘에서는 바로 아래). 자주 누르는 두 버튼을 한곳에. ② 맨 위가 **요약 카드**: 표지 3장을 부채꼴로 + "새로 공유받은 다이어리 3개" + `확인하기` 버튼. ③ 전체 / 읽지 않음 필터. 창은 **화면 오른쪽에서 나오는 시트**(폭 460, 위아래 꽉 참) — Material 측면 시트.
