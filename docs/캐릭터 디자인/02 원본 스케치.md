# 2. 원본 스케치 — 10장에서 읽은 것

> 원본: `원본/` (01 마커 스케치 3024² → 1600 jpg, 02 파란 디지털 스케치 692×879, 03~10 노란 다이어리 시안 1254² → 1024 png 투명 + 흰 바탕 jpg).<br>
> 읽는 법: 그림마다 **보이는 것 → 가져오는 것 → 바꾸는 것** 세 줄. 가져오는 것은 04 의 어느 시트로 갔는지 적었다.

## 0. 한눈에 보기

| 스케치 | 핵심 | 04 로 간 것 |
|---|---|---|
| 01 마커 · 둘이 함께 | 네모(작음) + 둥근 머리(큼) 가 바닥선 위에 서고, 큰 쪽이 작은 쪽 어깨에 팔. 키 ≈ 6.5 : 10 | C-1 둘이 함께, C-2 비율, B-5 안아 주기 |
| 02 파란 · 목도리 친구 | 돔 머리 · 세로 타원 눈 · 입 없음 · 빗금 목도리 왼쪽으로 늘어짐 · 사다리꼴 코트 · 단추 둘 · 가는 다리 | B-1 해부도, B-2, B-4 색 |
| 03~10 노란 · 감정 8장 | 둥근 네모 노란 책 + 오른쪽 흰 속지 + 진갈색 먹선 + 점 눈 · 작은 입 + **감정은 표지 스티커가 말한다** | A-1 해부도, A-3 감정 8종, A-6 스티커 33종 |

## 1. 마커 스케치 — 둘이 함께 (원본/01)

<figure class="sheet half"><img src="원본/01 스케치 마커 둘이.jpg" alt="마커 스케치: 네모 친구와 둥근 머리 친구"><figcaption>01 · 마커 스케치. 왼쪽 작은 네모 친구(점 눈 · 다리 둘 · 한 팔에 막대), 오른쪽 큰 둥근 머리 친구(점 눈 · 둥근 몸 · 다리 둘). 큰 친구의 팔이 네모 친구 위로 둥글게 넘어간다. 위에는 지운 낙서(초록 형광펜) 와 가로선, 아래는 바닥선. 오른쪽 가장자리에 세 번째 둥근 친구 일부.</figcaption></figure>

- **보이는 것**: 네모 친구는 세로가 긴 둥근 사각, 몸 아래 바로 다리(발은 바깥 꺾임), 왼팔은 막대(펜 또는 깃발) 를 들었다. 둥근 친구는 머리와 몸이 분리된 두 덩어리, 머리는 원에 가깝고 몸은 둥근 사다리꼴. 둘 다 눈은 점 둘, 입 없음(네모 친구는 희미). 바닥선 하나를 공유한다. 큰 친구의 왼팔 호가 네모 친구의 머리 위를 지나 어깨에 닿는다.
- **가져오는 것**: ① 둘의 **키 비율 ≈ 6.5 : 10**(네모 윗변이 둥근 친구의 가슴 높이) → C-2. ② **안아 주기** 포즈(팔이 위로 호를 그려 상대 어깨에) → B-5 · C-1. ③ 네모 친구의 **발 꺾임** → 디오 · 두리 공통 'ㄴ' 발. ④ 네모 친구의 막대 → A-4 '펜 들기'. ⑤ 바닥선 공유 → 모든 턴어라운드 · 라인업.
- **바꾸는 것**: 둥근 친구의 머리를 완전한 원이 아니라 **돔(아래가 평평)** 으로 — 스케치 2 와 맞추고 목도리가 자연스럽게 걸리게. 네모 친구의 막대는 기본형에서 뺀다(들고 있으면 '펜 든 포즈' 로만).

## 2. 파란 디지털 스케치 — 목도리 친구 (원본/02)

<figure class="sheet half"><img src="원본/02 스케치 목도리 파랑.jpg" alt="파란 스케치: 목도리 두른 친구"><figcaption>02 · 파란 디지털 스케치(#7088F8 한 색). 돔 머리, 세로 타원 눈 둘, 입 없음. 빗금 목도리가 목을 감고 왼쪽 아래로 길게 늘어진다. 사다리꼴 코트에 단추 둘, 가는 다리 둘과 발.</figcaption></figure>

- **보이는 것**: 머리 너비가 키의 절반 가까이 되는 **2.5등신**. 눈은 세로로 긴 타원이고 머리 위쪽(눈 높이 ≈ 머리의 55%) 에 있다. 목도리 띠는 머리 아랫변을 완전히 덮어 입 · 턱이 없다. 띠 안에 빗금(-55° 정도) 이 빽빽하고, 꼬리는 왼쪽으로 흘러내려 끝이 둥글다. 코트는 위 38 → 아래 56 으로 벌어지는 사다리꼴, 단추 두 개는 세로 한 줄. 다리는 가늘고 발은 바깥 꺾임.
- **가져오는 것**: ① 돔 머리 · 세로 타원 눈 · **입 없음** → B-1 ②③. ② 빗금 목도리 + 왼쪽 꼬리 → B-1 ④⑧, 빗금 간격 8.5 · 굵기 2.6. ③ 사다리꼴 코트 + 단추 둘 → B-1 ⑤⑥. ④ 팔이 안 보임 → '팔은 평소 코트 속, 포즈 때만' 규칙.
- **바꾸는 것**: ① 한 색 선화 → **먹선 + 브랜드 색 면**(머리 흰색, 코트 primary, 목도리 accent + surfaceSoft 빗금) — 요청대로 브랜드 컬러. ② 가는 다리 → 디오와 같은 굵은 'ㄴ' 발(굵기 7) 로 통일. ③ 머리 너비를 72 로 조금 더 넓혀(스케치 1 의 둥근 머리) 아이콘 · 작은 크기에서 얼굴이 남게.

- **보이는 것 (공통)**: 몸 = 세로 90 : 가로 74 의 둥근 사각, 색 **#F8D860**(측정값). 오른쪽 · 아래로 어긋난 **흰 속지 묶음**이 '책' 임을 말한다. 먹선은 진갈색 **#3A1200** 한 굵기(몸 너비의 약 3.5%), 끝 둥글게. 눈은 작은 점, 입은 작다. 팔은 굵고 손가락 없음(벙어리장갑), 다리는 짧고 발은 바깥 꺾임. **스티커는 흰 테두리(die-cut) + 단색**, 먹선 없음 — 몸과 구별된다. 감정이 바뀌어도 몸 · 눈 자리 · 비율은 고정이고 **스티커 세트 + 팔 자세 + 눈썹 · 입**만 바뀐다.
- **가져오는 것**: 위 공통 규칙 전부 → A-1 해부도 ①~⑨. 8가지 감정과 스티커 짝 → A-3 그대로(재구성). 스티커 식별 가능한 것 전부 → A-6 33종(원본 26종 + 앱용 7종 추가: 오늘의 사진 · 마테 조각 · 도트 · 체크 · zzz · 느낌표 · 물음표). 볼 홍조가 스티커인 것 → '볼은 감정 때만' 규칙.
- **바꾸는 것**: ① 먹선 색을 **#242424(로고 ink)** 로 통일 제안 — 로고 D · 두리 · 디오가 같은 선. 진갈색을 고르면 두리도 진갈색으로 맞춘다(README 정해야 할 것 5). ② 노랑은 1안 원본 #F8D860 또는 2안 머스터드 #EBC56F(A-5). ③ 원본의 미세한 그라데이션 · 종이 질감은 뺀다(단색) — 작은 크기 · 아이콘 · 애니메이션을 위해. ④ 눈을 세로 타원(rx 2.9 · ry 3.4) 으로 — 두리의 세로 타원 눈과 한 계열.

## 4. 두 스케치가 서로에게 준 것

| 디오 → 두리 | 두리 → 디오 |
|---|---|
| 굵은 'ㄴ' 발, 벙어리장갑 손 | 세로 타원 눈 |
| 먹선 + 단색 면 | 입을 더 작게(두리는 아예 없음) |
| 감정은 몸이 아니라 '얹은 것'(스티커) 으로 | 감정은 몸이 아니라 '두른 것'(목도리 높이 · 꼬리) 으로 |
