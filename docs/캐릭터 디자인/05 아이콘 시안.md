# 5. 서비스 아이콘 시안 — '크레페처럼 단색 바탕 + 흰 형체' 검토

> 질문: "아이콘은 크레페처럼 단색에 흰색으로 형체만 있는 느낌을 생각 중인데 어떤지 봐 줘."<br>
> 답: **맞다.** 지금 한국 1군 앱(카카오 · 토스 · 당근 · 네이버) 과 크레페 · 하루콩 · 듀오링고가 모두 '한 색 + 형체 하나' 이고, iOS 26 리퀴드 글래스 · Android 테마 아이콘 모두 **단순한 단색 형체를 그대로 통과**시킨다(01 §2.1). DIO 에 맞게 하려면 형체를 로고 D 가 아니라 **모아 실루엣**으로 하고, 눈 · 입을 바탕색 구멍으로 파면 크레페의 '따옴표 눈' 과 같은 문법이 된다. 바탕은 primary `#6E92C6`.

## 0. 한눈에 보기

| 항목 | 결론 |
|---|---|
| 단색 + 흰 형체 | 채택. 그라데이션 · 그림자 · 글자 없음 |
| 형체 | **모아 실루엣**(표지 + 속지 + 팔 · 다리), 눈 · 입은 바탕색 구멍 — C안 ★ |
| 바탕색 | primary `#6E92C6`. 네이비 `#0B1957`(D안) 은 더 구분되지만 iOS 다크 모드에서 가라앉아 보류 |
| 로고와의 관계 | 로고 D 는 앱 안(상단 바 · 홈 레일) 에서 그대로. 아이콘만 캐릭터. 당근(아이콘 = 로고 형체, 캐릭터 따로) 과 반대 선택이지만 크레페(아이콘 = 마스코트) 와 같다 |
| 29px 가독성 | 눈 · 입 구멍과 속지 단차가 29px 에서도 남는다(I-2). 팔은 29px 에서 사라져도 된다 |
| iOS 26 · Android | 흰 형체 한 레이어라 다크 · 클리어 · 틴트 · monochrome 을 따로 그릴 필요 없음 |

## 1. 8안 비교

<figure class="sheet"><img src="시안/아이콘 1 8안 비교.jpg" alt="아이콘 8안"><figcaption>I-1 · A 지금(흰 바탕 + 로고) · B 흰 D · C 모아 실루엣 ★ · D 모아 네이비 · E D + 테마 원 · F 모아 얼굴만 · G 둘이 · H 풀컬러 모아(대조군). 각 안 아래 60 · 40 · 29px.</figcaption></figure>

| 안 | 바탕 + 형체 | 좋은 점 | 걸리는 점 | 판단 |
|---|---|---|---|---|
| A 지금 | 흰 + 로고(먹 D + 하늘 원) 50% | 로고 그대로. 가이드 1.3 과 일치 | 흰 바탕은 홈 화면에서 가장 약하다(흰 아이콘 많음). 캐릭터와 안 이어진다 | 기준점 |
| B 흰 D | primary + 흰 D(글줄 포함) | 가장 보수적인 '단색 + 흰 형체'. 로고와 1:1 | 'D' 한 글자라 다른 D 앱과 섞인다. 캐릭터의 친근함이 없다 | 2순위 |
| **C 모아 실루엣 ★** | primary + 흰 모아, 눈 · 입 구멍 | 형체가 '얼굴 있는 네모 책' 이라 파랑 아이콘 사이에서도 구분. 크레페식 구멍 얼굴. 29px 에서 얼굴이 남는다 | 로고 D 와 다른 형체 — 앱 안 로고와 아이콘이 다르다(크레페 · 듀오링고도 같다) | **추천** |
| D 모아 네이비 | text 네이비 + 흰 모아 | 대비 최대, 가장 구분 | iOS 다크 모드 · 검은 배경화면에서 가라앉는다 | 보류 |
| E D + 테마 원 | primary + 흰 D + 하늘 원 | 로고 2색을 지킨다 | 하늘 원이 primary 위에서 안 보인다(대비 1.5:1) | 탈락 |
| F 모아 얼굴만 | primary + 표지 윗부분 확대 | 얼굴이 크다 | 책(속지) 이 잘려 '노트' 가 안 읽힌다. 네모 얼굴만 남아 MOODA 와 비슷해진다 | 탈락 |
| G 둘이 | primary + 모아 · 디오 흰 실루엣 | 서비스의 '함께' 를 말한다 | 40px 아래에서 두 덩어리가 뭉친다. 아이콘은 형체 하나 원칙 | 홍보 · 스토어 그래픽용 |
| H 풀컬러 모아 | 하늘 + 원색 모아 | 캐릭터 그대로 | 먹선 · 노랑 · 흰 속지가 29px 에서 뭉개지고, iOS 26 클리어 · 틴트에서 먹선이 남아 지저분 | 탈락 |

## 2. 추천안 C 를 자리별로

<figure class="sheet"><img src="시안/아이콘 2 크기별.jpg" alt="추천안 크기별"><figcaption>I-2 · iOS 180~29px, Android 원 · 둥근 네모 · 스퀴클(안전 영역 66% 점선), iOS 26 다크 · 클리어 · 틴트, 홈 화면 주변 앱 사이.</figcaption></figure>

| 자리 | 확인한 것 |
|---|---|
| iOS 180 → 29 | 눈 · 입 · 속지 단차가 29 에서도 남는다. 팔 · 다리는 40 아래에서 흐려지지만 형체(책) 는 유지 |
| Android 원 마스크 | 모아를 62% 로 줄여 안전 영역(66%) 안. 팔 끝이 잘려도 된다 |
| iOS 26 다크 | 바탕 `#1C1C1E` + 모아 `#8FA8D6`(primary 를 밝힌 값). 시스템이 자동 생성하는 값과 비슷 |
| iOS 26 클리어 | 흰 형체 + 반투명. 먹선이 없으므로 깨끗 |
| iOS 26 틴트 | 연한 바탕 + 진한 형체로 반전돼도 읽힌다 |
| 홈 화면 | 파랑 바탕은 흔하지만 '얼굴 있는 네모' 형체가 드물어 형태로 구분된다 |

## 3. 로고와 캐릭터를 함께 쓰는 법

<figure class="sheet"><img src="시안/아이콘 3 로고와 캐릭터.jpg" alt="로고와 캐릭터"><figcaption>I-3 · 로고 옆(가로): 로고 높이 = 모아 높이의 85%, 간격 = 로고 높이의 25%. 세로(시작 화면): 모아 위 · 로고 아래. 워드마크 'DIO' 는 시스템 서체 900 · 자간 -1.</figcaption></figure>

- 로고 D 는 색 · 비율 · 여백 규칙(가이드 1.2) 을 그대로 지킨다. 캐릭터가 로고 안에 들어가거나 로고를 들고 있지 않는다.
- 아이콘이 C안으로 바뀌면 **앱 안 로고와 아이콘이 다른 형체**가 된다. 괜찮은 이유: 크레페(워드마크 CREPE + 아이콘 구름), 듀오링고(워드마크 + 아이콘 Duo), 당근(아이콘 당근 + 캐릭터 당근이) 모두 그렇다. 사용자는 아이콘으로 앱을 찾고, 앱 안에서는 로고로 '홈' 을 찾는다.
- 워드마크 'DIO' 와 캐릭터를 나란히 둘 때 캐릭터 높이 = 글자 높이의 1.6배, 간격 = 글자 높이의 0.4배.

## 4. 제작 규격 (채택 뒤)

| 파일 | 크기 | 내용 |
|---|---|---|
| `아이콘/아이콘 C 모아실루엣.png` (이 폴더) | 1024² | 마스터. 모서리 없음(플랫폼이 마스크) |
| `frontend/assets/images/icon.png` | 1024² | 마스터 그대로 (iOS 는 Xcode 가 크기 생성) |
| `frontend/assets/images/adaptive-icon.png` | 1024² | **전경 레이어**: 투명 바탕 + 흰 모아 높이 62% 가운데. `backgroundColor` 를 `#FFFFFF` → `#6E92C6` 으로 |
| `frontend/assets/images/splash-icon.png` | 512² | 투명 바탕 + **원색 모아**(머스터드 · 먹선) 높이 50%, 배경 `#CED9EE` 유지 (C-4 시작 화면) |
| `frontend/assets/images/favicon.png` | 64² | primary 바탕 + 흰 모아 76% |
| (추가) monochrome | 1024² | Android 13+ 테마 아이콘: 흰 모아만 투명 바탕에. C안은 이미 단색이라 전경 레이어와 같은 파일 |

규칙: 아이콘에는 그라데이션 · 그림자 · 글자 · 먹선을 넣지 않는다. 스티커도 넣지 않는다(29px 에서 점으로 뭉갠다). 모아 실루엣은 `스크립트/시트만들기.py` 의 `moa_silhouette()` 가 원본이다 — 눈 rx 4.2 · ry 5, 입 굵기 4.5, 속지 단차 4, 팔다리 굵기 14(모두 상자 100 기준, 본체보다 굵게 — 작은 크기 보정).

## 5. 디자인 가이드에 고칠 곳

- 1.3 앱 아이콘 표: "흰 바탕, 로고 높이 50%" → "primary 바탕, 흰 모아 실루엣 76%". 마지막 줄 "아이콘을 다시 만들 때는 반드시 `dio-logo.svg` 에서" → "`아이콘/아이콘 C 모아실루엣.svg` 에서".
- `app.json`: `android.adaptiveIcon.backgroundColor` `#FFFFFF` → `#6E92C6`, `monochromeImage` 추가.
- 1.2 로고 규칙에 한 줄: "앱 아이콘은 로고가 아니라 캐릭터(모아) 를 쓴다. 로고는 앱 안에서만."
