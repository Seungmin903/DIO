# 3. DIO 브랜딩 분석 — 캐릭터가 지켜야 할 것

> 기준: [디자인 가이드](../디자인%20가이드.md) 2026-10-22 판, `frontend/assets/brand/dio-logo.svg`, `frontend/app.json`.<br>
> 읽는 법: 브랜드의 요소마다 **지금 → 캐릭터에 요구하는 것** 을 적고, 마지막에 캐릭터가 들어갈 자리와 비슷한 서비스와의 자리 차이를 정리했다.

## 1. 이름 · 한 줄 소개가 정하는 것

DIO 의 한 줄은 세 조각이다 — **하루 한 장의 사진**(시간 · 재료), **캔버스 삼아**(그 위에 얹는다), **친구들과 함께 꾸미는**(관계). 캐릭터는 이 셋을 몸으로 보여 줘야 한다.

- '다이어리' 를 캐릭터로 만들면(모아) **얹는 대상**이 생긴다. 모아 표지 = 캔버스. 친구들이 붙인 스티커가 모아의 표정이 된다 — 서비스의 핵심 동작이 캐릭터의 감정 표현 방식과 같다.
- '친구' 를 캐릭터로 만들면(디오) **얹는 주체**가 생긴다. 디오는 사용자 쪽에 선다. 그래서 디오는 말을 적게 하고(입 없음) 모아를 본다(곁눈질).
- '하루 한 장' 은 리셋 규칙이다. 모아의 스티커는 날마다 새로 붙는다. 어제의 슬픔이 오늘로 넘어오지 않는다(06 §6).

## 2. 로고에서 가져오는 것

| 로고 요소 | 값 | 캐릭터로 |
|---|---|---|
| D 심볼 선 색 | `#242424` | **먹선 색** — 모아 · 디오 · 스티커 테두리(흰) 외 모든 윤곽 |
| D 의 둥근 마감 | 선 끝 · 이음 모두 둥글게 | 팔 · 다리 · 발 · 눈썹 · 입 모두 둥근 끝 |
| 테마 원 | `#9FB6D9` | 디오 **목도리** 색. 로고의 '한 점 포인트' 가 디오에게는 목도리 |
| D 안의 두 줄 | 다이어리 글줄 | 모아 '옆' 뷰의 속지 줄, 뒤표지 라벨의 선 |
| 로고 여백 | 높이의 25% | 로고 옆 캐릭터 간격도 로고 높이의 25% |
| 로고 크기 | 32 · 30 · 24 | 로고와 같은 줄에 설 때 캐릭터 높이 = 로고 높이 ÷ 0.85 |

## 3. 색에서 가져오는 것

| 토큰 · 팔레트 | 값 | 캐릭터 |
|---|---|---|
| `surfaceSoft` 앱 배경 | `#CED9EE` | 캐릭터가 가장 자주 서는 바탕. **노랑 모아**가 여기서 가장 잘 보인다(보색). 디오 목도리 빗금 색 |
| `primary` | `#6E92C6` | 디오 **코트**, 아이콘 바탕(C안), 해부도 번호표 |
| `secondary` 로고 테마 원 | `#9FB6D9` | 디오 **목도리** |
| `text` 네이비 | `#0B1957` | 캐릭터 옆 글자. 아이콘 D안 바탕(보류) |
| `surface` | `#FFFFFF` | 디오 **머리**, 모아 **속지**(#FFFCF6 종이색), 스티커 흰 테두리 |
| 표지 팔레트 머스터드 | `#EBC56F` | 모아 **추천 색**. 이미 토큰 안에 있어 새 값 없이 쓴다 |
| 표지 팔레트 로즈 | `#F0B0AA` | 모아 · 디오 **볼** |
| 펜 · 형광펜 · 테이프 팔레트 | 2.4 표 | **스티커 33종의 색**은 여기서만 고른다 |
| `danger` | `#E5484D` | 캐릭터에 쓰지 않는다(오류는 글자 · 아이콘만) |

규칙 "primary 는 선택 상태와 CTA 에만, 넓은 면을 파랗게 채우지 않는다" 와의 관계: 디오 코트는 캐릭터 안의 면이지 UI 면이 아니므로 예외다. 단 디오를 화면에 크게(높이 200 이상) 쓰지 않는다 — 큰 파란 면이 CTA 를 흐린다.

## 4. 성격 · 말투에서 가져오는 것

- "차분함": 모아 · 디오 모두 **눈이 작고 입이 작다**. 큰 눈 · 큰 입 · 과장은 X (04 C-3).
- "손글씨 같은 따뜻함": 선은 정돈돼 있지만 **끝이 둥글다**. 자를 댄 듯한 직각 · 날카로운 끝 X.
- "꾸미는 재미": 모아의 재미는 표지 스티커, 디오의 재미는 목도리 움직임. 몸 자체는 바뀌지 않는다.
- "화면은 조용하게": 캐릭터는 **콘텐츠가 없는 자리**에만. 캔버스 · 썸네일 · 편집기 위에 캐릭터를 띄우지 않는다.
- 해요체: 캐릭터가 말하는 문구도 "오늘 사진 한 장으로 시작해 볼까요?" 처럼 짧은 해요체. 캐릭터 이름을 넣은 문구("모아가 기다려요") 는 1차에서 쓰지 않는다 — 이름은 확정됐고 온보딩이 생기면.

## 5. 캐릭터가 들어갈 자리 (가이드와 충돌하지 않는 7곳)

| 자리 | 누가 | 크기 | 가이드 근거 |
|---|---|---|---|
| 앱 아이콘 | 모아(흰 실루엣) | 1024 마스터 | 1.3 — 바꾸면 규칙도 수정 |
| 시작 화면 | 모아(기본) + 로고 | 모아 150, 로고 90 | 1.3 splash 배경 #CED9EE 유지 |
| 빈 화면 (홈 · 북마크 · 휴지통) | 모아(손 흔들기 · 기본) | 제목 글자 × 4 (116) | 8장 빈 화면 문구 "다이어리가 없어요" 위 |
| 토스트 · 진행 알약 | 모아(윙크 = 완료, 걷기 = 진행) | 28 | 9장 알약 높이 36, 11장 작은 진행 알약 |
| 알림 목록 | 디오(공유 · 초대 · 참여), 모아(다이어리 상태) | 48~56 | `알림 설계/` 안과 결합 |
| 온보딩 카드 | 모아 · 디오 번갈아 | 120 | 새 화면 — 체크리스트 12장 적용 |
| 스티커 팩 '모아 감정' | 스티커 33종 (캐릭터 없이 스티커만) | 캔버스 에셋 | 2.4 꾸미기 팔레트, `속지 에셋 아이디어` ③ |

쓰지 않는 자리: 편집기 캔버스 위, 리본 · 도구 패널, 페이지 썸네일, 다이어리 카드 표지(사용자 사진 자리), 확인 대화상자.

## 6. 비슷한 서비스와의 자리 차이

| 서비스 | 마스코트 형체 | 감정 표현 | 아이콘 | DIO 와 다른 점 |
|---|---|---|---|---|
| MOODA | 둥근 얼굴 덩어리 여러 색 | 내가 고른 감정 = 얼굴 색 · 입 | 색 덩어리 겹침 | 모아는 **친구들이 붙인 것**이 감정. 얼굴은 거의 고정 |
| 하루콩 | 초록 콩 얼굴 | 내가 고른 기분 = 콩 표정 | 흰 바탕 + 초록 콩 | 같음: 단색 형체 아이콘. 다름: 모아는 사물(책) 이라 '기록 그 자체' |
| Finch | 새(펫) | 돌봄 정도 = 성장 | 새 얼굴 풀컬러 | 디오 · 모아는 성장하지 않는다. 하루 단위 리셋 — 죄책감 없음 |
| Duolingo | 부엉이 | 사용자 습관에 반응 | 초록 단색 + 얼굴 | 같음: 캐릭터가 알림 · 토스트까지 말함. 다름: 모아는 재촉하지 않는다(차분함) |
| 크레페 | 보라 구름 | 거의 없음(마스코트 역할 작음) | 보라 단색 + 흰 구름 + 따옴표 눈 | 아이콘 문법은 같게(단색 + 흰 형체 + 구멍 얼굴), 본문에서는 원색 캐릭터 |
| 당근 | 흰 토끼 당근이 | 이모티콘 · 웹툰 | 주황 단색 + 흰 당근(캐릭터 아님) | 당근은 아이콘 = 로고 형체, 캐릭터 따로. DIO 는 아이콘 = 캐릭터 형체, 로고 D 는 앱 안에서 유지 |

빈자리: **'기록물 자체가 캐릭터' + '친구가 붙인 것이 표정' + '단색 + 흰 형체 아이콘'** 셋을 다 가진 서비스는 없다.
