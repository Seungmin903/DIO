# 1. 레퍼런스 조사 — 아이콘 · 감정 마스코트 · 그림체 (2026-10-26)

> 조사일: 2026-10-26 · 방법: 네이버(통합 · 이미지) · 구글 이미지 · App Store · Apple HIG · Android 개발자 문서를 크롬 헤드리스로 캡처하고(§1), 걸린 기사 · 블로그 · 스토어 페이지 본문을 읽어 사실만 추렸다(§2).<br>
> 읽는 법: 그림 아래 **굵은 제목**이 검색어 · 출처, 그 다음이 그 화면에서 읽은 것. 스크린샷은 `스크린샷/`, 다시 찍는 법은 `스크립트/스크린샷찍기.py`. 구글 이미지 검색은 봇 차단(reCAPTCHA)이 걸려 두 장만 성공했고 나머지는 네이버 이미지로 대신했다.

## 2. 읽은 것 (본문)

### 2.1 아이콘 — '단색 + 흰 형체' 는 지금 가장 안전한 선택이다

- Apple HIG App icons: 단순한 아이콘이 이해 · 인식이 쉽고, 지나친 세부는 작은 크기에서 흐려진다. 배경은 주요 이미지를 강조하도록 단순하게. 텍스트는 꼭 필요할 때만 ([HIG](https://developer.apple.com/design/human-interface-guidelines/app-icons), [번역 정리](https://hingumingu.oopy.io/6119744b-3ce6-4ec3-8c4c-cdb16e14feae)).
- iOS 26 리퀴드 글래스: iOS 7 이후 처음으로 모든 시스템 아이콘을 다시 그렸고, 기본은 겹친 유리 레이어, 사용자가 '클리어(색 제거 · 반투명)' · 틴트를 고를 수 있다. **"단순한 디자인이 단색 바탕에 있는 앱은 업데이트가 필요 없다 — 이미 리퀴드 글래스처럼 보인다"**. 1024×1024 마스터 한 장에서 Xcode 가 크기를 만든다. Apple Store 앱 아이콘도 '파란 바탕 + 흰 쇼핑백' 으로 바뀌었다 ([designcompass](https://designcompass.org/en/2025/08/04/liquid-glass-vs-flat/), [MacRumors](https://www.macrumors.com/guide/ios-26-home-screen), [igeeksblog](https://www.igeeksblog.com/apple-store-liquid-glass-redesign-ios-26/)).
- AppTweak: 어떤 크기에서도 **하나의 명확한 아이디어**, 색 대비가 가시성 · 차별화를 결정, 파랑은 신뢰 · 집중이라 금융 · 생산성에 흔하다 ([AppTweak](https://www.apptweak.com/ko/aso-blog/how-to-design-an-app-icon)). → 파랑 바탕은 흔하므로 **형체(얼굴 있는 책)** 로 구분해야 한다.
- Android 적응형 아이콘: 마스크(원 · 둥근 네모 · 스퀴클) 는 OEM 이 정하고 안전 영역은 66%. Android 13+ 테마 아이콘은 monochrome 레이어 ([Android](https://developer.android.com/develop/ui/views/launch/icon_design_adaptive?hl=ko)).
- 크레페: 쿠키플레이스(구 ccoli, 2023-01 사명 변경) 의 커미션 플랫폼. 2026-10-21 iOS 정식 출시, 안드로이드 사전 등록 중, 13+ ([App Store](https://apps.apple.com/kr/app/%ED%81%AC%EB%A0%88%ED%8E%98-crepe/id6753073065), [X](https://x.com/CREPE_CM/status/2112748239342784881), [나무위키](https://namu.wiki/w/CREPE)). 아이콘은 보라 단색 + 흰 구름 + 따옴표 눈 — 형체 하나 · 색 하나 · 구멍으로 얼굴.

### 2.2 마스코트 — 로고가 아니라 '캐릭터' 로 설계한다

- Duolingo 리디자인 리드: "Duo 를 로고가 아니라 **캐릭터**로 생각했고, 수년을 버티도록 표정 · 자세를 수없이 시험했다". 당황 → 흥분 → 기쁨까지 감정 범위를 갖고, 애니메이션하기 쉽게 단순화했고, 사용자 행동(연습 습관)에 **반응**해 애착을 만든다. 앱 · 광고 · SNS · 밈까지 '독립된 미디어 캐릭터' ([uxdesign.cc](https://uxdesign.cc/why-mascots-like-duo-are-powerful-pieces-of-ux-e378f4da327f), [Creative Bloq](https://www.creativebloq.com/news/duolingos-redesigned-mascot-is-a-hoot), [Kepler](https://keplerdesign.substack.com/p/duolingo)). 부엉이가 문화권마다 뜻이 달라 재고한 적도 있다 — 사물(책) 은 이 문제가 없다.
- Finch: 돌봄 의존(새가 나를 필요로 함) 이 체크리스트를 관계로 바꾼다. 반대로 못 들어가면 불안 · 죄책감을 느끼는 사용자도 있다 ([Pratt 비평](https://ixd.prattsi.org/2025/09/design-critique-finch-ios-app-2/), [ScreenWise](https://screenwiseapp.com/media/finch-app)). → 디오는 '안 꾸미면 슬퍼한다' 를 **하루 단위로 리셋**해 죄책감을 쌓지 않는다(06 §6).
- MOODA: 9가지 감정, 기록 직후 무다가 대답, MOODA BALLS 로 한 달 돌아보기, 친구와 일기 공유 ([디투데이](https://ditoday.com/?p=43881), [App Store](https://apps.apple.com/KR/app/id6449689589)). 하루콩: 콩 이모티콘으로 기분 · 활동 기록, 2021 출시, 누적 1천만 다운로드, 해외 80%, 디즈니 IP 라이선스 ([Tech42](https://www.tech42.co.kr/%ea%b0%90%ec%a0%95-%ea%b8%b0%eb%a1%9d-%ec%95%b1-%ed%95%98%eb%a3%a8%ec%bd%a9-1%ec%b2%9c%eb%a7%8c-%eb%8b%a4%ec%9a%b4%eb%a1%9c%eb%93%9c-%ea%b8%b0%eb%85%90-%ec%9c%a0%ec%a0%80-%ec%82%ac/)).

### 2.3 그림체 — 먹선 · 단색 · 점 눈 · 작은 입

- 라이언: "점 두 개와 굵은 선 두 개 — 미니멀리즘의 극치. 선입견이 안 생기고 오래 봐도 안 질린다". 카카오 IP 팀장: "친근하거나 조금 허술해 보이는 'B급 정서' 가 중요, 채팅창에서 이용자가 캐릭터에 자기 이야기를 투영" ([Vogue](https://www.vogue.co.kr/?p=83186), [kakao](https://www.kakaocorp.com/page/detail/9348?lang=ENG)).
- 헬로키티 디자이너 야마구치 유코: "보는 사람이 감정을 투영하려면 캐릭터의 표정이 없어야 한다" ([이투데이](https://www.etoday.co.kr/news/view/1248162)). → 두리는 입이 없고, 디오는 입을 아주 작게.
- 망그러진 곰: 삐뚤빼뚤한 테두리와 간단한 이목구비의 '하찮음' 이 Z세대에게 귀여움. 두산 콜라보 13분 완판, 팝업 대기 200명 ([Careet](https://www.careet.net/934), [웹툰가이드](https://www.webtoonguide.com/ko/board/news-column/25475)).
- 치이카와: 2026-09 캐릭터 인기 1위(35.1%). 귀여움 뒤의 세계관(생존 · 노동) 이 팬덤을 만든다 (네이버 AI 브리핑, 나무위키 인용).

### 2.4 시사점 → 우리 선택

| 읽은 것 | 디오 · 두리에 적용 |
|---|---|
| 형체 하나 · 색 하나 · 얼굴은 구멍 (크레페 · 당근 · 토스) | 아이콘 C안: primary 바탕 + 흰 디오, 눈 · 입은 바탕색 구멍 (05) |
| 단순한 형체는 iOS 26 · Android 테마에 그대로 통과 | 아이콘에 그라데이션 · 그림자 · 글자 금지 (05 §4) |
| 파랑 바탕은 흔하다 | 형체(얼굴 있는 네모 책) 로 구분. 네이비 D안은 다크 모드에서 가라앉아 보류 |
| 로고가 아니라 캐릭터로 — 표정 · 자세 세트 | 디오 감정 8 · 포즈 8, 두리 감정 8 · 포즈 4 (04) |
| 사용자 행동에 반응해야 애착 | 디오 표지 스티커 = 친구들이 실제로 붙인 것 (06 §4) |
| 돌봄 죄책감 주의 | 하루 단위 리셋, '슬픔' 은 하루만 (06 §6) |
| 점 눈 · 작은 입 · 먹선 한 굵기 | DIO 라인 O/X 규칙 6가지 (04 C-3) |
| 입 없는 캐릭터가 더 오래 간다 | 두리 입 없음, 목도리로 가림 (04 B-1) |
| 캐릭터 스티커가 다꾸 재료 | 디오 감정 스티커 33종을 앱 스티커 팩으로 (04 A-6) |
| 턴어라운드 → 굿즈 → 콘텐츠 | A-2 · B-2 턴어라운드, 06 에피소드 |
