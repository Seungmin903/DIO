## 폴더

```
캐릭터 디자인/
├── 캐릭터 디자인.pdf · .html   ← 결과물 (빌드.py)
├── 색인.md · 01~06 md            ← 원본
├── 빌드.py                        md → html → pdf (크롬 헤드리스)
├── 원본/                         원본 스케치 10장 (jpg 표시용 · png 투명 원본 축소본)
├── 스크린샷/                    레퍼런스 스크린샷 23장 (스크립트/스크린샷찍기.py)
├── 시안/                       컨셉 시트 18장 jpg (모아 · 디오 · 둘이 · 아이콘), 벡터원본/ 원본
├── 아이콘/                          아이콘 단품 5종 1024 png + 캐릭터 단품 png(투명), 벡터원본/ 원본
└── 스크립트/
    ├── 캐릭터_도형.py                    모아 · 디오 · 스티커 SVG 라이브러리 (부위 좌표 · 색 · 선 규칙의 단일 원본)
    ├── 시트만들기.py                   컨셉 시트 18장 + 아이콘 단품 생성
    ├── 렌더.py                   svg → jpg/png (크롬 헤드리스 2배)
    └── 스크린샷찍기.py                    검색 스크린샷
```

다시 만들기: `python 스크립트/시트만들기.py` → `python 스크립트/렌더.py` → `python 스크립트/렌더.py --icons` → `python 빌드.py` (이 폴더에서).

| 왜 이 둘인가 | 원본 스케치 1에 둘이 함께 있고, 노란 시안 8장은 모두 '표지에 붙은 스티커로 감정을 말한다' — 이것이 DIO 의 핵심 동작(사진 위에 친구들이 스티커를 얹는다)과 정확히 같다 (02 · 03) |
| 그림체 | **DIO 라인**: 먹선 #242424(로고 D 와 같은 색) 한 굵기 · 단색 면 · 세로 타원 점 눈 · 둥근 끝 손발 · 스티커는 흰 테두리에 먹선 없음. 누가 그려도 같게 O/X 6가지 (04 C-3) |
| 모아 색 | 추천 **머스터드 #EBC56F** (표지 팔레트에 이미 있어 새 토큰 불필요, 앱 파랑의 보색이면서 한 톤 차분). 1안 원본 노랑 #F8D860 도 가능 (04 A-5) |
| 디오 색 | 추천 **코트 primary #6E92C6 · 목도리 accent #9FB6D9 + 빗금 #CED9EE** = 로고 색 체계 그대로 (04 B-4) |

## 정해야 할 것 (팀 검토)

1. **이름**: 확정 — 노란 책 모아 · 파란 친구 디오 (06 §2).
2. **모아 색**: 2안 머스터드(추천) / 1안 원본 노랑.
3. **디오 색**: 1안 로고 색(추천) / 2안 목도리가 주인공.
4. **아이콘**: C안 모아 실루엣(추천) / B안 흰 D / G안 둘이. 아이콘을 바꾸면 디자인 가이드 1.3 의 '로고에서 뽑는다' 규칙도 함께 고친다.
5. 먹선 색: #242424(추천, 로고와 같음) / 원본 시안의 진갈색 #3A1200.
