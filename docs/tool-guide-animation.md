# 지우개·올가미 사용법 애니메이션

관련 이슈: S15P31F106-263

## 적용

기존 EraserSettings와 LassoSettings의 모드 선택 아래에 ToolGuideAnimation을 표시한다. 앱 소스에서 지우개 stroke/area(획 지우기/영역 지우기), 올가미 rectangle/freeform(네모형/자유형)을 확인했다. 준비 450ms, 동작 1550ms, 결과 1600ms로 반복한다. 예시는 높이 120이며 문구·캡션·재생 버튼·드래그 입력은 없다. 지우개 크기는 기존 슬라이더와 숫자로 조절한다.

안내용 정적 좌표만 사용한다. 문서 상태·저장·선택·Undo/Redo에는 연결하지 않는다. 확정된 올가미 점선은 유지하고, 실제 앱처럼 개별 요소 조절 프레임은 추가하지 않는다. 패널을 열면 현재 모드로 시작하고 다른 모드를 고르면 새로 시작한다.

## 수명 및 접근성

설정 패널이 닫히거나 컴포넌트가 사라지면 requestAnimationFrame과 구독을 정리한다. 앱 백그라운드·웹 비표시 시 정지하고 복귀 시 처음부터 시작한다. 동작 줄이기는 네이티브 AccessibilityInfo와 웹 미디어 쿼리로 확인하며 정지 결과를 제공한다. 비동기 초기 조회가 최신 변경 이벤트를 덮어쓰지 않는다. 스크린리더에는 모드별 한 문장으로 설명하고 프레임마다 알림을 발생시키지 않는다.

작은 SVG만 최대 30fps로 갱신한다. 낮은 화면에서는 패널 내용 스크롤로 크기 슬라이더에 접근한다. 저장 형식·API·의존성 변경과 마이그레이션은 없다.

## 검증

- 리뷰 반영: 올가미 입력 영역의 스크린리더 문구도 `네모형`으로 통일했다. 안내 애니메이션의 지우개 크기는 고정으로 유지한다.
- node --test tests/tool-guide.test.js tests/lasso-input.test.js: 7개 통과. 안내 전용 테스트 4개로 획 삭제 순서·결과 유지, 자유형 경로 닫힘, 동작 줄이기의 정지 결과, 반복 경계 초기화를 확인했다.
- 기존 지우개·영역 지우개·지우개 입력·올가미 입력·올가미 윤곽 검사: 25개 통과.
- pnpm exec expo export --platform web: 성공 (1171 modules).
- 웹 화면: 1280×800 태블릿, 412×892 폰 세로, 892×412 폰 가로에서 모드 선택·배치·크기 컨트롤 접근 확인.
- 실제 앱 DOM 관찰: 획 3개 삭제 후 다음 주기에 3개 복원, 영역 마스크 경로 증가, 자유형 닫힌 윤곽 후 초기화, 패널 닫기 시 예시 제거 확인.
- 동작 줄이기·백그라운드 자원 정리는 구현 및 코드 검토 완료. OS 설정 전환을 통한 실행 검증은 미실시.
- iOS/Android 실기기 재생·동작 줄이기·백그라운드 복귀: 미검증.
