# handwriting-safe90

관련 태스크: [S15P31F106-396](https://ssafy.atlassian.net/browse/S15P31F106-396) (손글씨 폰트 기능·Android 배포 지원)

36자 각각의 128px 래스터에서 최소 4px 여백과 중심 오차 0.2px 이하인 최대 안전 배율을 탐색하고 그 90%를 사용한다. 양자화로 조건이 어긋나면 배율을 줄여 재검사한다. 원본 획은 보존하고 전달 좌표·굵기를 함께 조정한다. 기존 96px 목표와 0.8~1.6배 제한은 사용하지 않는다. 90%는 기존 평가에 기반한 임시 기본값이며 새 사용자의 최적 유사도를 보장하지 않는다.

버전은 `dio-ink-safe90-margin4-fp32-v2`다. JS·Android·manifest·변환기·모델 준비 스크립트를 함께 맞춘다. 구 번들 준비 시에도 설치 manifest는 현 버전으로 기록한다. 가중치·모델 버전은 그대로며 구 전처리 미완료 작업·특징 캐시는 새 작업과 혼용하지 않는다. 기존 완성 폰트·문서·입력 원본을 보존한다. Android는 새 빌드가 필요하다.

검증: 손글씨 Node 회귀 54개, 모델 계약 2개 통과. 원본·중심·여백·1.6배 초과·결정성·구 작업 거부를 포함한다. 새 정책의 추론 품질·Android/iPad 실기기 검증은 이번 MR에서 하지 않았다.
