# 새 다이어리 · 다이어리 수정 · 새 페이지 리뉴얼 검토안 (3차)

> 작성일: 2026-10-23 · 기준: [디자인 가이드](../디자인%20가이드.md)<br>
> 2차 의견 반영: 1안(작업대) · 4안(세로 카테고리) 방향을 바탕으로 **네 안을 다시 짰다.** 방향은 표지 · 속지에 모두, 표지 · 속지는 순서 없이 오가며, 고치는 것만 미리보기, 숫자 · 색은 직접 입력, 표지는 선택 사항, 표지 요소는 하나씩 따로, 사진 표지는 꾸밈 요소만, 스티커는 편집기와 같게.<br>
> 보는 법: 각 안은 **새 다이어리 · 다이어리 수정 · 새 페이지** 세 화면이 같은 틀이다. 빨간 번호가 핵심 부분.<br>

## 2. 네 안이 함께 쓰는 규칙

### 2.1 구역 (병렬 · 어디로든)

| 구역 | 내용 | 미리보기 |
|---|---|---|
| 기본 | 이름 · **방향(세로 / 가로)** | 표지와 첫 속지를 **나란히** — 방향이 둘 다에 적용되는 걸 보여 준다 |
| 표지 | 표지 없음 / 색 · 패턴 / 사진 + 요소 | **표지만** |
| 속지 | 세로 묶음(노트 · 플래너 · 일기 · 덕질·취미 · 시즌 한정) → 속지 + 필요한 옵션 | **속지만** |
| 속지 스타일 | 종이 색 · 선 색 · 글씨체 | 속지만 |

- 수정: `기본(방향은 잠금) · 표지 · 속지 스타일` — 속지 종류와 기간은 바꾸지 않고 "새 페이지에서 이어 붙여요"로 안내. 표지는 **빼기 · 다시 더하기** 가능.
- 새 페이지: `속지 · 속지 스타일`만. 미리보기는 **지금 페이지 · 새 페이지(점선) · 다음 페이지**.

### 2.2 표지 요소 (하나씩 따로)

| 요소 | 1겹 (늘 보임) | 2겹 (요소를 고르면) | 사진 표지 |
|---|---|---|---|
| 바탕 | 요약(색 · 패턴) | **바탕색**(견본 + HEX) · **패턴 7종 + 없음** · 패턴 색(어둡게 / 밝게) | → **사진**(내 사진 · 예시) 로 바뀜. 색 · 패턴 없음 |
| 고무줄 | **스위치** | 방향(세로 / 가로) · 자리(오른쪽·아래쪽 / 가운데) · 색(견본 + HEX) | 그대로 |
| 제목 | 글씨체 요약 | 글(다이어리 이름 쓰기 / 직접) · 글씨체 6종 · **크기 숫자** · 색 · **위치 9칸** | 그대로 |
| 소제목 | **스위치** | 글 · 크기 숫자 · 색 — 제목 아래에 붙음 | 그대로 |
| 라벨 | 요약 | 종이 라벨 / 띠지 / 없음 — 제목 뒤 판 | 그대로 (기본 없음) |
| 스티커 | 개수 | **편집기와 같은 스티커 보관함**, 표지 위에서 끌어 옮기기 · 모서리로 크기 · ✕ 삭제 | 그대로 |

### 2.3 속지 옵션 (고른 속지에 필요할 때만)

| 묶음 | 생기는 옵션 | 숨기는 것 |
|---|---|---|
| 노트 (무지 · 줄 · 모눈 · 도트) | **장수** `− [50] + 장` + 10 · 30 · 50 · 100 | 기간, 글씨체(인쇄 글씨 없음), 무지는 선 색 |
| 플래너 📅 | **연도 · 시작 달 · 기간(개월)** 직접 입력 + 3 · 6 · 12, 주간이면 **주 시작** | 장수 (기간으로 정해짐) |
| 일기 | 장수 + **날짜 적기** 스위치 | 기간 |
| 덕질 · 취미 · 시즌 | 장수 | 기간 |
| 새 페이지 | 날짜형 → **날짜 + 개수**(자리는 날짜 순서로 자동), 그 밖 → **자리(뒤 · 맨 끝 · 앞) + 장수** | — |

## 5. 목록 — 가로 · 세로 다이어리를 함께

공통: 표지를 **자르지 않는다**(꾸민 결과를 지킨다) · 표지가 없으면 첫 장을 보이고 `표지 없음` 작은 표시 · 이름 줄은 늘 같은 높이.

| A 선반 — 같은 칸, 아래 맞춤 (추천) | B 판 — 같은 칸, 회색 판 위 가운데 |
|---|---|
| ![](이미지/목록%20A%20격자.jpg) | ![](이미지/목록%20B%20격자.jpg) |

| C 줄 높이 맞춤 | 스와이프 — 높이 고정 + 아래 맞춤 |
|---|---|
| ![](이미지/목록%20C%20격자.jpg) | ![](이미지/목록%20A%20캐러셀.jpg) |

| | A 선반 | B 판 | C 줄 높이 맞춤 |
|---|---|---|---|
| 방법 | 같은 정사각 칸, 표지 바닥을 선에 맞춤 | 같은 칸의 회색 판 위 가운데 | 줄마다 높이를 같게, 폭은 비율대로 |
| 좋은 점 | 순서 · 훑어보기 쉬움, 책장 느낌 | 가장 정돈됨, 표지 색이 판 위에서 잘 보임 | 빈 곳이 적고 모든 표지가 같은 높이 |
| 아쉬운 점 | 가로 표지가 작아 보일 수 있음 | 칸 안 여백이 많음 | 열이 안 맞고, 추가 · 회전 시 배치가 바뀜 |

- 근거: 같은 칸 격자가 훑어보기 · 순서에 유리하고 메이슨리는 순서가 흐트러진다([Clickbooq](https://support.clickbooq.com/hc/en-us/articles/211263283-Using-the-Grid-Gallery-Style)) · [Apple 사진의 정사각 ↔ 원래 비율 보기](https://support.apple.com/guide/ipad/browse-your-photo-library-ipad99c6ed03/ipados) · [Flickr 양쪽 맞춤 줄](https://code.flickr.net/2015/03/) · [NN/g 캐러셀](https://www.nngroup.com/articles/designing-effective-carousels/)(다음 항목이 살짝 보이게).
- 스와이프는 **높이를 고정하고 아래를 맞춘다** — 가로 다이어리는 넓게, 세로는 좁게 보인다.

## 6. 다른 연도 · 속지 글씨체 · 테마 속지 (데이터)

- 지금 속지는 2026년 날짜와 글자를 **선으로 그린 SVG**라 연도 · 글씨체 · 방향 변경이 안 된다. 목업의 속지는 **날짜 없는 레이아웃 + 앱이 날짜 글자를 얹는 방식**으로 그렸고, 세로 · 가로도 같은 규칙으로 다시 배치했다.
- `templateConfig`에 `year · startMonth · months · weekStart · paperFont · pack`, 다이어리에 `cover`(null 이면 표지 없음, `kind · color · pattern · band · plate · title · subtitle · stickers`)를 둔다. 표지를 '빼기'는 `cover.enabled = false`로 꺼 두어 다시 켜면 그대로 돌아온다.
