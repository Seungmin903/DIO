# 회원 삭제 시 외부 프로필 사진 정리 — 후속 작업

현재 구현에는 회원 탈퇴·물리 삭제 처리에 연결된 외부 파일 삭제가 없다. DB의 ON DELETE CASCADE는 사진 메타데이터만 지우므로 로컬/S3 파일이 남을 수 있다. 이 문서는 후속 이슈 등록용이며, Jira 등록이나 자동 정리가 완료되었다는 의미는 아니다.

회원 탈퇴 담당 작업에서 다음을 함께 구현한다.

- 서비스의 탈퇴 사진 보관 기간을 확정하고 개인정보처리방침과 맞춘다. 현재 자동 보관 만료가 구현되어 있지 않으며 보관 기간도 확정되지 않았다.
- DB 참조 삭제 전에 저장소 종류와 객체 키를 삭제 작업에 기록한다. 트랜잭션 롤백 시 정상 사용자의 파일이 지워지지 않도록 커밋 이후에 ProfilePhotoStorage.delete를 실행한다.
- 삭제 실패는 영속 작업 큐 또는 outbox로 재시도한다. 이미 없는 객체 삭제는 성공으로 처리한다.
- 기존 고아 객체는 DB 참조와 대조하고, 보관 정책과 유예 기간을 확인한 후 정리한다. 활성 회원 파일은 삭제하지 않는다.
- 로컬 저장소와 S3 대체 저장소 테스트에서 커밋·롤백·삭제 실패 재시도·중복 실행을 확인한다.

이번 로그인 제한 수정에서는 기존 마이그레이션과 회원·사진 데이터를 변경하지 않는다.
