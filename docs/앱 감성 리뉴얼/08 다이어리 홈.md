# 08 다이어리 홈 — 표지가 주인공, 도구는 가장자리로

> 홈의 **바닥 · 창빛 · 소품(햇살 책상)은 별도 작업**([다이어리 홈 햇살 책상](../다이어리%20홈%20햇살%20책상/색인.md))이라 여기서 다시 설계하지 않는다. 이 문서는 그 위의 머리 · 칩 · 표지 · 라벨 · 버튼 · 빈 책상만 다룬다. 시안의 책상 바닥은 앱 에셋(`desk-wood.jpg` · `window-light.png`)을 CSS로 근사한 것이다.

## 한 줄 결론

**표지 위에 상시 얹힌 별 · 편집 · 삭제를 걷어내고, 표지 아래 정보를 키운다.** 감성 앱은 도구를 장면 바깥에 둔다(MOODA: 위쪽 선 아이콘 줄뿐, 다욜: + 버튼 하나와 하단 탭, [03](03%20레퍼런스%20앱.md)). 지금 DIO는 가장 감성적인 자산인 표지를 UI 도구가 덮고 있다. 도구는 **길게 누르면** 표지 바깥에 나타난다(C는 탭 후 하단 시트). 코덱스 검수는 발견성 문제를 짚어 혼합안에서는 **선택 표지에 `⋯` 한 개를 상시** 두고 탭하면 별 · 편집 · 삭제를 시트로 여는 방식을 권했다. 색은 [색 규칙 v2](06%20감성%20방향%203안.md)(UI 색상 계열 + 캐릭터 노랑)다 — 다색 표지는 사용자 콘텐츠라 건드리지 않고, **머리 · 칩 · 레일 · 탭 · FAB · 선택 프레임 · 그림자를 UI 색으로 고정**해 장면의 지배색이 페리윙클로 읽히게 한다.

- **선택 표지 프레임(혼합안)** — 모든 표지에 흰 테두리를 상시 두면 선택 상태가 모호하다는 코덱스 지적에 따라, 비선택은 얇은 라벤더 프레임, 선택만 흰 프레임 + 그림자다.
- **빈 책상** — 캐릭터가 색 규칙에 가장 자연스러운 그림이라 세 안 모두 캐릭터를 둔다. A는 `둘이`(디오 + 두리) + 버터 테이프 1개, B는 `둘이` + 폴라로이드 틀 + 라벤더 테이프(**혼합안이 쓰는 구도**), C는 두리 + 규칙선 한 줄. "다이어리가 없어요"는 가이드의 빈 화면 문구 그대로이고 정서 문구는 넣지 않았다. 디오 · 두리의 노출은 **빈 상태에만** 한정했다([06](06%20감성%20방향%203안.md) 가드레일 '조건부').

## 근거와 연결

- **도구는 장면 바깥** — 조사 B 패턴 3 · 홈 3.2. 지금의 "선택 카드의 별 · 편집 · 삭제가 표지 위에 상시 얹힘"과 직접 대비된다.
- **표지 아래 2단 정보(제목 + 쪽수)** — 다욜 "My Journal / 7Page"와 같은 구조(DIO는 이미 이 구조).
- **친구의 흔적은 숫자가 아니라 얼굴로** — Locket 20명 · 반응 미집계, BeReal 얼굴 반응, 조사 A의 '전시 · 평가 피로'([02](02%20타깃%20조사.md) §4). B의 아바타 3개는 이 방향이다. 단 B는 '유치함 위험'이 중간이라 A · C의 도구 숨김과 **조합**하는 쪽을 권한다.
- **한눈에 보기**는 표지 색 칩 모자이크로 감성 장치를 삼을 수 있다(하루콩 · MOODA · Daylio) — 이번 시안 범위 밖, 후속 과제.

## 접근성 · 구현

- **길게 누르기는 발견성이 낮다.** 도구를 숨기면 편집 · 삭제 위치를 모르는 사용자가 생긴다. 안내 멘트는 쓸 수 없으니 코덱스는 **선택 표지에 `⋯` 한 개를 상시** 두는 방식을 권했고 혼합안에 반영했다. 폰에서는 길게 누르기만으로 숨기지 않는다. 접근성(키보드 포커스 · 스크린 리더 이름은 유지)과 첫 사용 학습은 실제 기기에서 검증해야 한다.
- **표지 라벨 띠 · 그림자 변경은 표지 렌더를 건드린다.** 표지는 사용자 콘텐츠라 색 규칙의 예외인데, 라벨 띠의 웜 오프화이트(`#F3F1EC`)를 흰색으로 바꾸는 것은 `Cover.js` 렌더 변경이다. 코덱스가 권한 선택 사항이며 결정 칸에 별도로 둔다.
- **표지 색상표에 UI 계열 + 버터를 추가**하는 안([12](12%20공통%20시스템과%20가이드%20변경.md) §5)은 홈의 체감 지배색을 UI 색으로 끌어오는 가장 직접적인 방법이다(사용자 선택지 확장, 기존 표지는 그대로).
- 표지 모서리 · 그림자 값 변경은 `Cover.js`와 홈 카드 스타일만 건드리는 **1단계**다. 아바타 · 테이프는 2단계다.
- 큰 블러 · 오버레이는 쓰지 않는다. 책상 위 UI 뒤 흐린 막은 두지 않는다(햇살 책상 원본 그대로).

## 하지 않는 것

- 표지 위에 편집 · 삭제 · 즐겨찾기를 상시 노출하지 않는다.
- 소품 · 테이프를 표지마다 붙이지 않는다(중앙 표지 1개 한도).
- 표지가 다색이라는 이유로 레일 · 라벨 · 그림자까지 다색화하지 않는다.
- 좋아요 수 · 친구 기여도 같은 수치를 홈에 두지 않는다.
