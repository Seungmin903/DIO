# 14 로드맵과 결정 — 무엇부터 하고, 무엇을 팀이 정해야 하나

## 한 줄 결론

**1단계(값만 바꿔서 되는 것)로 먼저 체감 변화를 만들고, 새 라이브러리가 필요한 것은 뒤로 미룬다.** 추천은 **혼합안** — B 포토부스 콜라주를 주안으로 A의 로그인 빛만 섞은 2안화(로그인 A · 홈 B 프레임 · 공방 B 보드 · 내 공간 B + C 띠 · 휴지통 C + B 칩). 색은 팀의 **색 규칙 v2**(UI 색상 계열 메인 + 캐릭터 노랑 보조)를 지킨다. 이 제안은 구현이 아니라 **결정을 위한 자료**이고, 아래 결정 칸을 팀이 채운 뒤 가이드를 먼저 고치고 구현한다.

- 혼합안은 **BI · CI를 하나도 바꾸지 않는다.** 로고 · 페리윙클 · 네이비 · 시스템 서체 · 선 아이콘 · 안내 멘트 금지 · 해요체가 그대로다. 버튼 · FAB 색 `#606BB2`도 그대로다(코덱스의 `#525FAD` 교체 제안은 채택하지 않았다, [12](12%20공통%20시스템과%20가이드%20변경.md) 보정 #12).
- **색 규칙 v2 검사 결과** — 시안 색 190개 모두 UI 계열 · 캐릭터 노랑 · 무채색이고(이탈은 사용자 표지 샘플 1개), 표지 없는 화면에서 노랑은 1% 안쪽이다([06](06%20감성%20방향%203안.md) §1.1).
- 장식은 화면마다 국소 요소 3개 이하이고, 로그인 폼 안 · 휴지통 · 설정에는 장식이 없다(휴지통은 빈 상태에만). 홈 선택 표지의 프레임과 `⋯` 버튼이 B의 물성을 맡는다.
- 디오 · 두리는 이번 판에서 **빈 상태(빈 홈 · 빈 휴지통)에 처음 등장**한다 — 캐릭터 자체가 버터 노랑 + 라벤더라 색 규칙에 가장 자연스러운 그림이기 때문이다. 로그인 폼 안에는 넣지 않았고(조사: 156장 중 0곳), 코덱스의 이전 판단은 "첫 다이어리 생성 완료 장면에 80~96px"도 있다. 노출량은 조건부로 두고 아래 검증 항목에 넣었다.

## 3. 검증 — 감성은 숫자로 정답이 없다 (영역 J · K)

**성공 기준은 "예쁘다"가 아니라 행동이다**([02](02%20타깃%20조사.md) §3: 예쁨이 설치 · 유지에 주는 영향의 한국 수치는 없다).

| 색 인상(질문 1개씩) | "이 앱의 대표 색은 무엇인가" / "노란색이 어디에 쓰였나" | 메인이 UI 색으로 읽히는지, 노랑이 캐릭터와 이어지는지(홈은 표지가 다색이라 특히) |

**에셋 운영(영역 J)** — 코덱스의 질문: "초기 에셋만 충분하면 감성이 유지된다"는 가설은 반증 대상이다. 감성의 적시소비 흐름(조사 A: 제철 · 시즌 한정)을 보면 시즌 속지 · 스티커 · 프레임의 **제작 · 검수 주기를 누가 맡는지**가 정해져야 한다. 이 제안은 속지 · 에셋 아이디어([속지 에셋 아이디어](../속지%20에셋%20아이디어/색인.md))의 4분류 카탈로그와 이어서 정한다.

## 4. 계획 대비 — 반증하려던 가설은 어떻게 됐나

| 영역 | 가설 | 결과 |
|---|---|---|

## 6. 이 제안이 하지 않는 것 · 한계

- **코드를 바꾸지 않았고 디자인 가이드도 고치지 않았다.** 결정이 난 뒤 가이드를 먼저 고친다.
- 시안은 웹에서 그린 HTML이라 실제 React Native 구현과 다를 수 있다. 특히 `filter` · 종이결 · 그림자 색 · 길게 누르기는 구현 방법을 따로 정해야 한다. 안드로이드 태블릿(Expo Go)과 iOS에서 모두 동작해야 한다.
- 시안의 홈 책상 바닥은 앱 에셋 근사다(진행 중인 햇살 책상을 대체하지 않는다). 바닥은 옅은 라벤더 틴트라 색상각이 UI 계열(232°)보다 약간 보라 쪽(HTML 근사 렌더 약 250° · 실제 앱 캡처 약 240~249°, 픽셀 측정이라 오차 ±10° 안팎)일 수 있다. 별도 작업에서 확인할 일이다.
- **색 조합 근거가 약하다.** 라벤더 + 버터 노랑을 짝지은 앱 · 브랜드 사례와 그 감성을 직접 잰 자료는 찾지 못했다(검색 4회, [04](04%20원리와%20트렌드.md) §3.1). 버터 노랑은 2025~2026년 유행색이라 주기가 있다는 보도가 있으나 DIO의 노랑은 캐릭터 색이다. 홈은 사용자 표지가 다색이라 수치로는 UI 색이 메인이어도 체감이 경계선이다(코덱스 검수) — 표지 색상표 확장(결정 1-3)이 가장 직접적인 보완이다.
- 코덱스는 이번 라운드에서 웹 검색 실행기가 시작되지 않아 조사 항목을 수행하지 못했고, 해당 조사는 클로드가 직접 했다.
- 10대와 20대의 선호 차이, '유치함'의 허용선, 색 · 서체 선호는 근거가 없어 **검증 항목**으로 남겼다.
- 로그인 후 내 공간(회원 상태), 새 다이어리 · 편집기 · 알림 화면은 이번 범위가 아니다.
