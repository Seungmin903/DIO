# 10 내 공간 — 로그인 유도 배너 대신 '나의 기록'이 보이게

> 시안: 태블릿 1280 × 800 · 폰 390 × 844, 왼쪽 위부터 지금 · A · B · C. 수치는 코덱스 명세다. 환경 설정 · 앱 정보 목록은 세 안 모두 기능 그대로 두고 카드 모양만 바꿨다(설정은 감성화하지 않는다).

## 한 줄 결론

**진한 네이비 배너가 화면에서 가장 무거운 면이고, 프로필보다 '로그인 유도 광고'처럼 읽힌다.** 사용자의 취향 · 기록 흔적은 숫자 두 개(6 · 0)뿐이다. 감성 앱의 프로필은 **풀블리드 사진 + 스티커 + 이름**(카카오톡) 또는 **숫자 대신 '모아 보기' 시각물**(BeReal 사진 달력 · Widgetable 병 속 구슬 · 하루콩 월간 콩 달력)이다([03](03%20레퍼런스%20앱.md)). 세 안은 이 방향을 다른 세기로 번역한다.

## 근거와 연결

- **프로필 배경에 사진 · 스티커** — 카카오톡 프로필은 구름 배경 사진 + 스티커 + 이름이다. DIO도 **공방에서 만든 스티커가 내 공간을 꾸미는 고리**를 만들 수 있다(이번 시안은 한 점만).
- **숫자 대신 모아 보기** — "쌓이는 모양"이 감성을 만든다. A의 표지 두 권, B의 폴라로이드 겹침이 이 방향이다. 월별 표지 사진 달력 · 병 속 스티커처럼 더 쌓이는 형태는 후속 과제다.
- **설정은 설정답게** — Day One · Goodnotes는 설정을 흰 목록으로 절제한다. 문제는 설정이 설정 앱 같다는 것이 아니라 **프로필 영역에 감성이 없다**는 것이므로, 목록은 기능 그대로 두었다.
- **압박 수치를 키우지 않는다** — 조사 A: 전시 · 평가 · 연속 기록 압박은 거부감 요인이다. 그래서 통계는 줄이는 방향(B 칩, C 축소)이 있고, A는 숫자를 시각물에 붙여 위계를 낮춘다. **'즐겨찾기 0'** 같은 빈 수치가 '부족함'으로 읽히지 않는지는 확인할 항목이다.

## 접근성 · 구현

- **로그인 버튼 색** — `#606BB2` 위 흰 글자 대비는 4.95:1(통과)이나 코덱스가 "작은 글자는 16px/700 이상 또는 별도 검증"을 요구했다. 시안은 14/800이다. 구현 때 확인한다.
- **게스트 / 회원 상태** — 시안은 게스트(로그인 유도) 상태만 그렸다. 로그인 후에는 이름 · 사진 · 프로필 편집 진입이 바뀐다. 회원 상태 시안은 후속 과제다.
- 통계의 작은 표지 두 권은 실제 데이터(가장 최근 다이어리 · 가장 최근 즐겨찾기 표지)를 쓰는 구현이어야 하고, **데이터가 없으면 `bookmark` · `sticker-heart` 같은 빈 상태**가 필요하다(2단계).
- 환경 설정 · 앱 정보는 기존 컴포넌트 모양만 바꾼다(1단계).
- 통계 카드의 작은 표지 두 권은 사용자 표지라 색 규칙의 예외다. 표지 색상표에 UI 계열 + 버터를 추가하면([12](12%20공통%20시스템과%20가이드%20변경.md) §5) 이 화면의 체감 색도 더 UI 쪽으로 모인다.

## 하지 않는 것

- 네이비 배너를 다른 진한 면으로 바꾸지 않는다(가장 무거운 색 면을 걷어내는 것이 목적).
- **버터 노랑으로 배너를 채우지 않는다**(노랑은 큰 면 금지 — 포인트만). 빈 영역을 색으로 메우지 않는다.
- 통계에 순위 · 연속 일수 · 좋아요 같은 압박 수치를 더하지 않는다.
- 설정 · 앱 정보 목록에 장식을 넣지 않는다.

## 코드에 반영된 설계 (2026-10-31, 위 시안과 다르다)

사용자가 "꼭 현안처럼 가져갈 필요 없다, 처음부터 다시 검토해 달라"고 해서 코덱스가 위 시안(혼합안)을 **전제하지 않고 다시 설계**했고, 그 안이 앱 코드에 들어갔다. 위 표의 배너 · 폴라로이드 묶음 안과 다른 점은 다음과 같다.

| | 위 시안(혼합안) | 코드에 반영된 설계 |
|---|---|---|
| 프로필 | `#F0F1F9` 배너 + 폴라로이드 두 장 + 로고 카드 | **흰 카드**(경계 `#D9DCEF`) + 사진 또는 `D` 아바타 60×60 + **사진 윗변 테이프 한 조각**(장식은 이것뿐) |
| 통계 | 작은 표지 두 권(카드 안) | 표지 한 권 · 책갈피 한 개 **소품 + 라벨 + 숫자**(압박 수치 없음) |
| 폰트 만들기 카드 | 시안에 있음 | **삭제**(꾸미기 공방이 단일 진입점) |
| 환경 설정 · 앱 정보 | 세로 목록 | 태블릿 **2열**(앱 정보 / 환경 설정 + 로그아웃), 폰 한 열(환경 설정 없음) |
| 로그아웃 | 목록 아래 단독 | 오른쪽 열의 흰 카드 한 칸(폰은 앱 정보 아래) |
| 캐릭터 · 정서 문구 | 없음 | 없음(내 공간의 주인공은 사용자의 사진과 기록 — 코덱스 판단) |

코덱스가 낸 치수 중 `프로필 카드 136`, 폰 `y116` 같은 절대 좌표는 RN의 흐름 배치(패딩 · 간격)로 바꿔 구현했다. 새 문구는 0개다. 상세 규칙은 디자인 가이드 "내 공간 (2026-10 감성 리뉴얼)".
