# 다이어리 생성 시 내지 구성

만년형 옵션 Jira: [S15P31F106-192](https://ssafy.atlassian.net/browse/S15P31F106-192). 추천 구성 개선 [S15P31F106-184](https://ssafy.atlassian.net/browse/S15P31F106-184)와 한 MR에서 통합한다. 최신 develop의 일반 보조 안내 문구 정리는 유지하고, 선택에 필요한 기간·실제 장수·추천 설명은 남긴다.

## 만년형·날짜형 선택

- 이름·표지 다음 내지 구성 화면에서 `날짜형 · 1년` / `만년형 · 1개월`을 선택한다. 날짜형이 기본값이며 추천·직접 구성에 모두 적용한다. 전환해도 직접 지정한 양식·장수·색상을 초기화하지 않는다.
- 날짜형은 기존 2026년 연간 순서와 장수를 유지한다. 만년형은 첫 장 표지 1장 다음에 한 달만 생성한다. 월별 구분 페이지 1장, 월간 달력 1장, 주간 계획 6장 중 포함한 항목과 직접 지정한 하루 기록·자유 노트 장수를 한 번만 넣는다. 달력은 어느 달에도 기입할 수 있는 6주 칸이며, 주간은 4열 블록형·저널형 모두 지원한다.
- 시작 요일은 날짜형 원본과 동일하게 월간 달력은 일요일, 주간 계획은 월요일이다. MR !100 리뷰의 시작 요일 질문을 확인한 뒤 사용자 결정에 따라 만년형도 이 디자인을 유지한다.
- 추천 구성의 실제 총 장수는 날짜형 일정 관리용/일기용/자유 기록용이 78/37/49장, 만년형이 9/4/5장이다. 첫 장 표지와 구분 페이지가 포함된 수치다. 하루 기록 기본 장수는 기존과 같이 각 월 1장이고, 직접 구성에서 늘릴 수 있다.
- `frontend/scripts/generate-undated-templates.py`로 기존 날짜형 SVG에서 연도·월·날짜 경로만 제거해 가로·세로 각 5종을 만든다. 요일·격자·메모·글꼴 출처는 유지한다. 원본 276개와 원본 폴더는 변경하지 않는다. 날짜를 직접 기입할 빈 제목란을 제공한다.
- 만년형 에셋은 별도 폴더 `frontend/assets/templates/undated/`와 정적 매핑 `undatedAssets.js`를 사용한다. 내지 카탈로그·공통 로더에 연결해 미리보기·편집·읽기·썸네일·PNG/PDF 출력에서 같은 참조를 사용한다. 기존 배경·레이아웃 색상 처리도 공유한다.
- 저장 설정에 `templateConfig.dateMode` (`dated` / `undated`)를 추가했다. 값이 없는 기존 설정은 날짜형으로 해석한다. 문서에는 에셋 ID·버전·크기를 저장하고 만년형의 `year`는 `null`이다. 기존 저장 문서·페이지·객체를 재생성하거나 변환하지 않는다. 보관함과 표지 편집 미리보기의 만년형 표기도 구분한다.

## 추천 구성으로 시작

- 추천 카드의 3열 배치는 카드 한 장의 계산 너비가 150px 이상일 때 사용한다. 그보다 좁으면 한 줄에 한 카드로 표시해 제목·구성 안내의 과도한 줄바꿈을 줄인다. 두 배치 모두 제목·추천 칩은 위쪽에, 미리보기는 카드 안쪽 가로폭에 맞춰 표시하며 내지 방향 비율을 유지한다.
- MR !114 리뷰 반영에서 JSX 구문 검사와 공백 검사를 통과했다. 이번 수정의 자동 테스트·빌드·앱 화면·실기기 검증은 미실행이다. 리뷰어가 이전 버전에 기록한 391개 테스트·웹 번들·화면 측정 결과와 구분한다.

- 이름·표지·방향 다음에 “어떻게 기록할까요?” 화면을 제공한다. 일정 관리용을 기본 선택하고 추천 배지·테두리·체크로 표시한다. 카드 배치는 위의 실제 너비 기준에 따르며 대표 내지를 미리 보여 준다.
- 일정 관리용: 월간 달력 12장 + 주간 계획 53장 + 첫 장 표지 1장 + 월별 구분 페이지 12장 = 78페이지.
- 일기용: 월간 달력 12장 + 일기 매월 1장(연간 12장) + 첫 장 표지 1장 + 월별 구분 페이지 12장 = 37페이지.
- 자유 기록용: 무지·줄·모눈 자유 노트를 각각 매월 1장(연간 36장) + 첫 장 표지 1장 + 월별 구분 페이지 12장 = 49페이지. 기존 기본값의 표지·구분 페이지와 매월 각 1장 기준을 유지한다.
- 카드 안내와 선택 요약은 기존 생성기와 같은 정규화·연간 목록으로 계산한다. 실제 문서 생성은 createDefaultDoc/configuredPageIds를 재사용하며, 가로·세로 모두 같은 장수다.
- “이 구성으로 시작”은 세부 설정이나 색상 화면을 거치지 않고 저장 후 편집기를 연다. 색상은 기존 흰 배경·차콜 기본값이며 “내지 색상 변경 (선택)”에서만 바꾼다. 색상 화면에서도 바로 생성할 수 있다.
- “직접 구성하기”는 처음 진입할 때 선택한 추천 구성을 가져온다. 이후 추천 화면·이름과 표지·색상 화면을 왕복해도 수정한 포함 여부·양식·장수를 보존한다. 다른 추천 카드를 고르더라도 이전 직접 구성 값을 덮어쓰지 않는다. 방향만 바꾸면 장수는 보존하고 참조 ID의 방향만 변환한다.
- 직접 구성 요약은 내지 종류별 연간 장수와 매월 반복 장수를 구분한다. “매월 적용되는 장수”는 하루 기록·자유 노트 합계이며, “전체 페이지 수”에는 연간 월간 달력·주간 계획·표지·구분 페이지도 포함한다.
- 사용자 표시명은 월간 달력·주간 계획·하루 계획·일기·사진·스크랩·자유 노트·첫 장 표지·월별 구분 페이지·내지 구성으로 통일한다. 원본 카탈로그와 저장 식별자는 유지하고 조회 계층에서 표시 이름만 변환한다. 작은 노트 미리보기는 기존 페이지 추가 창의 방식처럼 선 간격과 대비를 보강한 예시이며, 실제 내지 SVG는 변경하지 않는다.

## 한 달 구성 미리보기 보강

- 추천 구성 화면의 큰 화면 왼쪽 영역은 책 표지 대신 선택한 구성의 한 달 내지를 실제 순서로 보여 준다. 1월부터 시작하고 이전/다음 달 버튼으로 1~12월을 확인한다. 첫 장 표지는 월별 미리보기에서 제외하며 포함 안내를 별도로 표시한다. 월별 구분 페이지·월간 달력·해당 월에 배정된 주간 계획·하루 기록·자유 노트는 실제 생성 규칙을 공유한다.
- 추천 카드 전환 시 미리보기도 바뀌며, 고른 배경·레이아웃 색상을 썸네일에 적용한다. 휴대폰에서는 같은 미리보기를 추천 카드 위의 접기/펼치기 영역으로 제공한다.
- 월별 내지는 두 열 격자 대신 세로 한 줄로 표시한다. 각 내지는 스크롤바 여백을 제외한 미리보기 영역 전체 너비를 사용하고 실제 방향의 가로·세로 비율을 유지한다. 이 최종 배치는 아래 분리 브랜치 검증에서 큰 화면·휴대폰 너비의 브라우저 확인을 추가했다. 실기기는 미검증이다.
- “내지 색상 변경”은 카드 아래에서 모달 상단의 고정된 강조 버튼으로 이동했다. 현재 배경·레이아웃 색상 점 두 개와 선택 사항 안내를 표시해 색상 변경 없이 바로 생성하는 흐름도 유지한다.
- `pnpm test:creation`: 44개 통과. 추가 8개는 가로·세로 추천 3종의 12개월 미리보기 합계·순서와 실제 연간 생성의 일치, 구분 페이지가 없는 구성·구형 마지막 추가 내지 제외, 월 입력 범위를 검증했다. 기존 36개 회귀도 통과했다.

## 직접 구성의 생성 규칙

- 최신 develop의 책 표지 미리보기·색상·패턴 디자인과 모달 내부 입력 상태 관리를 유지한다. 첫 페이지 단일 선택 대신 두 번째 단계에서 월별 속지 구성을 제공한다. 새 생성에서 가로형·세로형을 선택한다. 기존 문서의 방향과 좌표는 변경하지 않는다.
- 기존 보관함 생성 창을 이름·표지 → 추천 구성의 두 단계로 제공한다. 직접 구성과 내지 색상은 선택 사항이다. 취소하면 새 다이어리를 만들지 않는다. 기존 다이어리 수정은 이름·표지 색상만 변경한다.
- 2026년 가로형(1024×768)·세로형(768×1024) 카탈로그를 사용한다. 기본값은 표지 1장, 월 구분지 12장, 먼슬리 12장, 블록 위클리 53장의 기존 78페이지다.
- 먼슬리·위클리·데일리·표지·월 구분지의 포함 여부를 고른다. 위클리는 블록형/저널형 하나를 선택한다. 먼슬리는 기존 단일 양식을 사용하고, 데일리는 플래너·일기·포토/스크랩을 여러 종류 선택한다.
- 표지 다음 1~12월을 월별로 구성한다. 각 월은 구분지 → 먼슬리 → 위클리 → 데일리 → 공용 노트 순서다. 주간 페이지의 월 배정은 기존 연간 목록을 따르며, 첫 주(2025-12-29)는 1월에 한 번만 포함한다.
- 데일리는 플래너·일기·포토/스크랩의 종류별 포함 여부와 매월 장수를 지정한다. 같은 구성을 모든 월에 반복한다. 기본적으로 데일리는 제외하고, 데일리를 켜면 플래너 매월 1장이 선택되어 있다. 각 양식을 새로 켜면 기본 매월 1장이다.
- 공용 속지는 무지·줄·모눈·도트 노트다. 여러 종류를 골라 매월 장수를 지정하고 동일한 구성을 각 월의 데일리 뒤에 배치한다. 포함 시 기본 매월 1장이고 공용 메뉴 순서를 따른다. 데일리를 제외해도 공용 노트를 매월 추가할 수 있다.
- 데일리·공용 속지 양식은 위클리처럼 좌우로 넘기는 미리보기 카드로 고른다. 위클리는 단일 선택, 데일리·공용 속지는 여러 카드의 체크를 켜고 카드별 매월 장수를 입력한다.
- 장수는 양의 정수이며 잘못된 값은 생성 전에 안내한다. 총 페이지 수를 표시하고, 모두 제외하면 속지 없는 기존 규격 빈 페이지 1장으로 만든다.

## 저장과 호환

- templateConfig를 다이어리 목록과 새 문서에 보관한다. version: 2의 포함 여부, 위클리 양식, dailyTemplates(플래너·일기·스크랩), reusable(공용 노트)의 종류별 포함 여부·매월 장수를 포함하며 SVG 문자열은 저장하지 않는다.
- 실제 페이지는 기존 backgroundAssetId·templateVersion·canvasWidth·canvasHeight와 독립 페이지 ID, 빈 objects 배열을 사용한다.
- 생성은 문서 저장 → 보관함 저장 → 편집기 진입 순서다. 저장 중 중복 클릭·취소를 막고 실패 시 입력과 생성 ID를 유지하여 재시도한다. 문서만 저장된 경우 기존 보관함 복구 흐름으로 복구 가능하다.
- 기존 문서는 읽을 때 저장 페이지를 그대로 복원한다. 설정 없는 기존 생성 호출은 기본 78페이지다. 기존 문서에 속지를 자동 적용하거나 페이지를 덧붙이지 않는다.
- 이전 단일 데일리 설정은 월별 플래너 장수로 해석한다. 이전 맨 뒤 공용 속지 설정은 legacyEndPages로 별도 보존하여 매월 12번 복제하지 않는다. 저장된 실제 페이지는 재구성하지 않는다. 새 생성 화면은 version: 2의 월별 구성만 만든다.
- 설정값은 초기 생성용이며 편집기에서 사용자가 추가·삭제한 페이지를 재구성하는 근거로 사용하지 않는다. 저장 키·기존 요소 좌표·서버 API·속지 자산은 변경하지 않는다.

## 내지 색상 선택

- 추천 구성과 직접 구성 화면의 “내지 색상 변경 (선택)”에서 배경색·레이아웃 색을 각각 선택한다. 배경 추천 6종(화이트·크림·세이지·로즈·아이스 블루·웜 그레이), 레이아웃 추천 6종(차콜·네이비·브라운·포레스트·플럼·슬레이트)을 제공한다.
- + 버튼으로 기존 색상 팔레트(색상·채도·밝기와 HEX 입력)를 열며 첫 페이지 대표 미리보기에 즉시 반영한다. 이전 단계로 돌아가도 구성·색상은 보존하고 취소 시 문서를 만들지 않는다. 첫 페이지 속지가 없는 구성은 빈 페이지 배경색을 미리 보여 준다.
- paperAppearance: { backgroundColor, layoutColor, font? }를 목록·문서·생성 페이지에 저장한다. 값은 6자리 HEX이며 잘못되었거나 없는 값은 흰 배경(#FFFFFF)·기존 레이아웃(#292929)을 사용한다. font(속지 글꼴: gowun-batang · gowun-dodum · nanum-pen · poor-story)는 고른 때만 들어가고 없으면 원본 글꼴(마루부리)이다. 꾸미기 공방의 기본 속지 설정(`dio:diary:paper-style-default:v1`)은 새 다이어리의 처음 값일 뿐이라 이미 만든 다이어리 · 페이지의 값은 바꾸지 않는다. SVG 원본과 기존 문서는 수정하지 않는다(글꼴이 없는 기존 속지는 그대로 마루부리로 그린다).
- 흰 종이 사각형만 배경색으로 바꾸고 레이아웃의 6가지 색은 선택한 색과 배경 사이에서 기존 농도 차이를 유지해 변환한다. opacity는 유지한다. 사용자 글자·사진·필기 색상은 바꾸지 않는다.
- 편집·읽기·썸네일은 공통 PageBackground에 적용하고 PNG/PDF는 동일한 규칙으로 준비 XML에 적용한다. 원본 AST 캐시를 변경하지 않는다. 빈 페이지 출력도 선택한 배경색을 쓴다. 문서에 새로 추가하는 속지도 같은 배색을 따르며 페이지 복제 시 해당 페이지 배색을 유지한다.
- 배색 최초 구현 당시에는 사용자 요청에 따라 수정한 JavaScript 9개 파일의 문법 해석만 확인했다. 이번 추천 구성 검증에서 추가로 수행한 자동 테스트·웹 빌드·화면 검증은 위의 날짜별 기록을 따른다. 네이티브·실기기는 미검증이다.

### 팔레트 입력 보정

- 색상 선택 시 별도의 직접 지정 칸을 삽입하지 않고 + 칸에 선택색을 표시한다. 드래그 도중 줄바꿈으로 팔레트가 아래로 이동하지 않게 배치를 고정한다.
- 팔레트의 화면상 위치·크기를 측정하고 실제 터치의 화면 좌표를 0~1 범위로 환산한다. 누적 드래그 거리와 로컬 시작점을 섞지 않으며 경계 밖은 가장자리로 제한한다.
- 팔레트는 전용 responder로 입력을 유지한다. 생성 모달은 팔레트 드래그 중 세로 스크롤을 잠그고, 손을 떼거나 시스템 취소·팔레트 해제 시 다시 허용한다. 웹 팔레트 영역은 touchAction: none을 적용한다.
- 수정한 JavaScript 3개 파일의 문법 해석만 확인했으며 기능 테스트·빌드·실기기 조작은 실행하지 않았다.

- 직접 지정 버튼의 + 기호 뒤 흰 배경을 없애고, 선택색 밝기에 따라 기호 색만 조정한다.
- 뒤로가기는 하단 주요 버튼 왼쪽에 배치한다. 추천 구성에서는 이름과 표지로, 직접 구성에서는 추천 구성으로 돌아간다. 내지 색상에서는 진입했던 내지 구성 화면으로 돌아간다. 입력값과 색상은 유지한다.
