# iPad 움직이는 스티커 효과 (193)

## 문제와 수정

기존 스티커 렌더러는 원본 GIF와 윤곽선·그림자 실루엣마다 별도의 `expo-image` 재생기를 사용했다. 설치된 expo-image의 iOS 색 입히기는 `withRenderingMode(.alwaysTemplate)`를 사용한다. 애니메이션 색 입히기와 여러 재생기의 장면 일치는 실제 iPad에서 보장되지 않았으며 사용자가 GIF 스티커의 효과 오류를 제보했다. 이 경로를 원인 후보로 확인했으며 수정 후 실기기 재검증은 대기 중이다.

iOS에서 움직이는 스티커에 윤곽선 또는 그림자가 켜져 있으면 GIF를 투명 PNG 장면으로 준비하고 한 시계가 선택한 같은 장면을 원본과 효과 레이어 모두에 전달한다. 정지 PNG는 기존 RN Image의 tintColor로 실루엣을 그리므로 애니메이션 이미지의 template tint 경로를 사용하지 않는다. 효과를 꺼도 원본 GIF는 그대로 재생한다. 정지 스티커·Android·웹·`still` 출력은 기존 렌더링 경로를 유지한다.

- 준비 중에는 같은 첫 장면을 본체와 효과에 사용한다. 실패 시 오류 안내를 표시하고 효과를 껐다 켜거나 화면에 재진입해 재시도할 수 있다.
- GIF disposal 2/3, 투명 픽셀, 장면별 시간, 반복 횟수를 보존한다. 앱이 배경으로 가면 재생을 일시정지한다.
- 같은 소재를 사용하는 복제 스티커는 준비된 파일을 공유한다. 마지막 사용자가 사라지면 준비 작업·타이머·임시 파일을 정리한다. 종료 후 늦게 끝난 준비 결과도 정리한다.
- 기본 `n-glowstar.gif`는 첫 스트림 종료자 대신 두 번째 GIF 헤더가 붙어 있어 omggif 전체 읽기에 실패했다. 블록 경계에서만 첫 스트림을 닫아 프리뷰에 사용한다. 원본 파일·가져오기·출력 서비스는 수정하지 않는다.

## 프리뷰 자원 제한

소재당 최대 60장, 긴 변 256px, 전체 2,097,152픽셀로 효과용 프리뷰를 제한한다. 60장보다 긴 GIF는 전체 재생 시간을 유지하며 장면을 샘플링한다. 큰 GIF는 원본보다 프리뷰가 부드럽지 않거나 확대 시 덜 선명할 수 있다. 효과 없는 GIF에는 적용되지 않는다. 저장된 GIF 원본·문서 형식·PNG/PDF 첫 프레임 출력은 변경하지 않는다. 디코딩은 기존 50MiB·800만 화소 제한을 재사용하고 장면 사이에서 JS 실행을 양보한다.

## 검증

- `node --test tests/sticker-effects-render.test.js tests/sticker-playback.test.js tests/gif-export.test.js tests/gif-first-frame.test.js tests/editor-history.test.js tests/export-content.test.js`: 35개 통과.
- 기본 움직이는 스티커 36개 모두 1,077개 프리뷰 장면으로 PNG 준비 성공. 원본 바이트 불변·임시 자원 해제·픽셀 상한 확인.
- Windows Node 별도 측정: 36개 전체 디코드·PNG 인코드·PNG 헤더 재검사 약 1,644ms, PNG 합계 3,849,805바이트, 단일 소재 최대 983,040픽셀. 실제 파일 IO·iPad 렌더링 시간이나 메모리 측정 결과는 아니다.
- 실제 ObjectView의 iOS 분기에서 모든 원본·효과 레이어에 같은 source와 `animated=false` 전달을 확인했다. 테스트는 네이티브 UIKit 렌더링을 대체하지 않는다.
- iPad 통합 QA 서버에서 iOS 개발 번들 생성 및 수정 코드 포함 확인. 사용자가 이 버전에서 193번 iPad QA 완료를 확인했다. 기기 모델·iPadOS·스티커·항목별 결과는 별도로 전달되지 않았다.

## iPad QA 확인 목록

사용자 완료 보고를 받은 확인 목록이다. 항목별 상세 결과나 실제 메모리·입력 지연 수치를 별도로 측정한 것으로 간주하지 않는다.

1. 일반 GIF와 glowstar·snow를 각각 추가하고 윤곽선/그림자를 개별·동시 적용한다. 색·두께·거리·방향·흐림을 변경하며 한 바퀴 이상 관찰한다.
2. 효과가 현재 장면을 따라오는지, 검은 사각형·첫 장면 잔상·깜빡임이 없는지 확인한다.
3. 효과 끄기/재켜기, 회전·반전·확대, 복제·삭제·Undo/Redo·저장 재진입을 확인한다.
4. 앱 배경/복귀와 효과가 켜진 GIF 여러 개에서 입력 지연·메모리 종료 여부를 확인한다. 긴 애니메이션은 전체 시간과 반복 횟수도 확인한다.
5. 모델·iPadOS·스티커·설정·실패 화면을 기록한다.
