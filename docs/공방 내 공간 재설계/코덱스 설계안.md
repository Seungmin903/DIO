# DIO 꾸미기 공방 · 내 공간 재설계안

## 1. 배치 방향 비교와 추천

### 꾸미기 공방

| 안 | 구성 | 조사 근거 | 장점 | 단점 |
|---|---|---|---|---|
| A. 공방 대시보드 | 한 화면에 폰트·스티커·표지·속지·프리셋 요약을 모두 노출 | 기존 화면과 유사 | 처음 들어왔을 때 전체 기능을 알기 쉽다 | 같은 종류의 카드가 계속 쌓여 무겁고, 저장 항목이 늘수록 산만하다 |
| B. 내부 사이드바 + 상세 화면 | 태블릿에서 공방 안에 두 번째 세로 메뉴를 두고 우측 상세를 표시 | Goodnotes류의 라이브러리 패턴 | 넓은 태블릿에서는 빠르다 | 앱 공통 왼쪽 레일과 겹쳐 이중 내비게이션처럼 보이고, 폰 전환 비용이 크다 |
| **C. 가로 분절 메뉴 + 단일 컬렉션 화면** | 상단에서 종류를 전환하고, 아래에는 선택한 컬렉션 하나만 보여 준다 | 경쟁 앱의 컬렉션 한 겹, NN/g의 공통 영역, Material 3 Expressive의 분절 전환 | 카드 더미를 없애고, “내 물건을 둘러보는 공방” 느낌이 난다. 폰·태블릿 모두 같은 정보 구조를 쓴다 | 처음에는 다른 종류가 화면 아래에 보이지 않는다 |

**추천: C. 가로 분절 메뉴 + 단일 컬렉션 화면.**  
공방은 “설정 페이지”가 아니라 사용자 소품 보관함이다. 따라서 각 종류를 큰 카드로 쌓지 말고, 한 번에 한 컬렉션만 열어 선반·격자로 보여 준다. 새 항목은 항상 마지막 `+` 칸에서 만든다.

### 내 공간

| 안 | 구성 | 조사 근거 | 장점 | 단점 |
|---|---|---|---|---|
| A. 프로필 카드 + 통계 카드 + 설정 카드 | 현재 구조를 다듬는 방식 | 일반 마이페이지 | 익숙하다 | 방문할 때마다 카드 경계가 너무 많고, 숫자가 “성과 카드”처럼 보인다 |
| B. 큰 캐릭터 히어로 + 트로피 선반 | 감성 일러스트 중심 | Finch·Duolingo식 캐릭터 홈 | 브랜드성이 강하다 | 기록 앱보다 게임처럼 보일 수 있고, 실제 설정 정보가 밀린다 |
| **C. 정체성 스트립 + 숫자 한 줄 + 조용한 목록** | 프로필은 한 줄 정체성 영역으로, 정보·설정·위험 행동은 구분선 목록으로 정리 | Airbnb/Day One류 계정 정보, 토스식 목록, “그래픽은 한 화면에 하나” 원칙 | 차분하고 성숙하며, 게스트 로그인 전환도 명확하다 | 장식량이 적으므로 캐릭터와 테이프 위치를 엄격히 제한해야 한다 |

**추천: C. 정체성 스트립 + 숫자 한 줄 + 조용한 목록.**  
내 공간은 꾸미기 화면이 아니라 계정과 앱 환경을 관리하는 화면이다. 모아는 정체성 영역에만 한 번 쓰고, 나머지는 넓은 여백과 목록으로 정리한다.

# 2. 추천안 상세 사양

## 공통 화면 골격

- 앱 바탕: `surfaceSoft #F3F3F7`
- 콘텐츠 최대 폭: 1120dp. 1280dp 가로 태블릿에서는 좌측 레일 78dp 뒤에 중앙 정렬한다.
- 화면 제목: `30dp / 800 / #0B1766`, 제목 아래 24dp 여백.
- 태블릿 가로 콘텐츠 좌우 여백: 30dp.
- 태블릿 세로 콘텐츠 좌우 여백: 28dp.
- 폰 콘텐츠 좌우 여백: 20dp.
- 큰 영역은 흰 카드 테두리로 감싸지 않는다. `surface #FFFFFF` 위에 제목·컬렉션·구분선만 배치한다.
- 목록/영역 구분은 `border rgba(11,23,102,0.16)` 1dp 선과 24~32dp 여백을 우선 사용한다.
- 조작 가능한 외곽선은 최소 `primary #818AC3` 1dp를 사용해 흰 바탕에서 3:1 이상 경계를 확보한다.
- 본문은 `text #0B1766`, 보조 정보는 `textMuted rgba(11,23,102,0.68)`만 사용한다.

## 꾸미기 공방

### 화면 구조

위에서 아래 순서다.

1. `꾸미기 공방` 제목
2. 종류 전환 가로 분절 메뉴
3. 선택한 종류의 제목·개수·관련 액션
4. 선택한 종류의 컬렉션 선반 또는 격자
5. 비어 있을 때만 캐릭터 빈 상태

분절 메뉴 항목은 다음 순서로 고정한다.

- `내 폰트`
- `내 스티커`
- `내 표지`
- `내 속지`
- `내 프리셋`

선택 상태는 앱을 다시 열어도 마지막 선택을 유지한다. 기본 진입은 `내 스티커`가 아니라 사용자가 마지막으로 본 종류다. 첫 진입만 `내 폰트`로 둔다.

### 종류 전환 방식

- 분절 메뉴 전체 높이: 56dp.
- 실제 버튼 높이: 48dp.
- 항목 최소 폭: 148dp, 좌우 패딩 18dp.
- 태블릿 가로에서는 다섯 항목을 한 줄에 모두 보인다.
- 태블릿 세로와 폰에서는 가로 스크롤이며, 오른쪽에 다음 항목이 28~40dp 보이게 한다.
- 선택 항목: `primaryStrong #606BB2`, 흰 글자.
- 비선택 항목: `surfaceMuted #F0F1F9`, `primaryText #525FAD`.
- 외곽선은 사용하지 않고, 선택 항목만 2dp 아래쪽 그림자 또는 `primaryText #525FAD` 2dp 하단 깊이선을 둔다.
- 메뉴 아래 여백: 28dp.

### 선택 종류 헤더

- 제목: `22dp / 800 / text`.
- 저장 수량: 제목 오른쪽, `14dp / 700 / textMuted`.
- 헤더 높이: 48dp.
- 우측 액션은 한 화면에 하나만 채움 버튼으로 둔다.
- 예: `내 폰트`에서는 `폰트 관리`, `내 스티커`에서는 `사진 속 대상 오리기`.
- 컬렉션 제목과 첫 선반 사이 여백: 16dp.

### 내 폰트

- 우측 `폰트 관리`: 토널 버튼.
- 상단 제작 도구: `내 폰트 만들기` 채움 버튼 하나.
- 저장 폰트는 카드가 아니라 1dp 구분선 목록으로 표시한다.
- 각 폰트 행: 높이 76dp.
  - 좌측: 글꼴 미리보기 이름, `18dp / 700`.
  - 우측: 더보기 또는 삭제 아이콘 버튼 48×48dp.
- 태블릿 가로: 2열 목록, 열 사이 24dp.
- 태블릿 세로·폰: 1열 목록.
- 빈 상태: 중앙에 모아 86×98dp, 그 아래 `아직 저장한 폰트가 없어요.` 한 줄만 `16dp / 700`. 설명·보조 문구는 넣지 않는다.

### 내 스티커

상단의 도구는 별도 카드 두 장이 아니라 한 줄짜리 `공방 도구함` 영역으로 묶는다.

- 도구함 면: `surfaceMuted #F0F1F9`, 높이 80dp, 모서리 20dp.
- 좌측에는 `사진 속 대상 오리기` 채움 버튼.
- 우측에는 `스티커 시트 분리` 토널 버튼. 준비 중 상태는 비활성 처리하되, 접근성 이름은 유지한다.
- `미리보기`는 버튼 아래 설명이 아니라 `사진 속 대상 오리기` 버튼 안의 작은 라벨로 표시한다.
- 태블릿 가로에서는 버튼 2개를 한 줄 배치한다.
- 태블릿 세로·폰에서는 두 버튼을 세로로 쌓고, 도구함 높이를 128dp로 늘린다.

스티커 폴더는 표지 카드가 아니라 “서랍 전면”처럼 얕은 타일로 쓴다.

- 폴더 타일: 172×132dp, 모서리 18dp, `surface #FFFFFF`, 1dp `cardBorder #D9DCEF`.
- 폴더 미리보기: 내부 64×64dp, 모서리 12dp.
- 폴더명: `15dp / 700`.
- 스티커 수: `13dp / 600 / textMuted`.
- 태블릿 가로: 5열.
- 태블릿 세로: 3열.
- 폰: 2열.
- 마지막 타일은 항상 `+` 추가 칸이다. 아이콘은 24dp, `primaryText`.
- 폴더 내부 스티커는 88×88dp 타일, 12dp 간격, 마지막에 `+` 타일을 둔다.
- 폴더 삭제는 폴더 상세 헤더의 우측 아이콘 버튼으로만 둔다. 타일 위에 상시 휴지통을 올리지 않는다.
- 빈 상태: 모아 86×98dp + `아직 저장한 스티커가 없어요.` 한 줄만.

### 내 표지

- 표지는 가로 스크롤 선반으로 배치한다.
- 표지 썸네일: 116×154dp, 모서리 14dp, 1dp `cardBorder`.
- 썸네일 사이 간격: 14dp.
- 태블릿 가로에서는 첫 줄에 7개와 다음 항목 36dp가 보이도록 한다.
- 태블릿 세로에서는 4개와 peek, 폰에서는 2개와 peek를 보인다.
- 제목은 썸네일 아래 14dp/700, 한 줄 말줄임.
- 삭제는 표지를 길게 누르거나 상세 보기에서만 노출한다. 평상시 썸네일 위에 삭제 버튼을 띄우지 않는다.
- 마지막은 같은 크기의 `+` 표지 칸이다.
- 빈 상태: 모아 86×98dp + `아직 저장한 표지가 없어요.` 한 줄만.

### 내 속지

`기본 속지 설정`을 큰 카드로 감싸지 않는다. 제목 아래 두 개의 설정 행과 글꼴 선택 선반만 둔다.

- 섹션 제목: `18dp / 800`.
- 설정 행 높이: 56dp.
- 좌측 라벨 폭: 76dp.
- `종이 색`, `선 · 글자`는 40×40dp 터치 셀 안에 28dp 색상 칩을 둔다.
- 선택 칩: 28dp 색상 원 + `primaryStrong` 2dp 외곽선 + 바깥 4dp 여백.
- 추가 칩: 28dp 점선 원, `primary #818AC3`.
- 색상 견본은 사용자 콘텐츠 견본으로 기존 색상 범위를 유지할 수 있다.
- 글꼴 선택은 48dp 높이의 가로 스크롤 칩 선반이다.
- 선택 글꼴은 흰 바탕, `primary #818AC3` 1dp 테두리.
- 비선택 글꼴은 `surfaceMuted`.
- 저장한 속지는 표지와 같은 116×154dp 선반으로 표시한다.
- 빈 상태는 저장 속지 선반 위치에만 모아 86×98dp + `아직 저장한 속지가 없어요.` 한 줄을 둔다. 기본 설정은 빈 상태에서도 위에 남긴다.

### 내 프리셋

프리셋은 네 장의 카드가 아니라 네 개의 가벼운 구분 영역으로 구성한다.

- 순서: `펜` → `형광펜` → `마스킹 테이프` → `글자`.
- 태블릿 가로: 2열, 열 사이 32dp, 행 사이 24dp.
- 태블릿 세로·폰: 1열.
- 각 영역: 최소 높이 132dp, 위아래 20dp 패딩, 하단에만 1dp 구분선.
- 제목: `17dp / 800`.
- `기본 색상`, `내 색상`: `13dp / 700 / textMuted`.
- 색상 칩: 터치 셀 44×44dp 안에 30dp 원형 견본.
- 기본 색상은 최대 7개까지 한 줄, 넘치면 가로 스크롤한다.
- `내 색상`이 없으면 빈 문구 대신 줄 자체를 숨긴다.
- 저장 색상은 길게 눌러 삭제하거나, 선택 시 48×48dp 삭제 아이콘 버튼을 오른쪽에 표시한다.
- 마스킹 테이프는 36×28dp의 짧은 테이프 견본으로 표시하되 터치 영역은 48×48dp를 유지한다.
- 글자 프리셋은 원형 견본 대신 36×36dp 정사각형 안에 `가`를 표시한다.

### 공방 장식

- 저장 항목이 있는 화면에서만 도구함 좌상단에 버터 테이프 1개를 붙인다.
- 테이프 크기: 32×12dp.
- 회전: -6°.
- 색: `butterTape #FBE5A3`.
- 도구함 좌상단에서 12dp 안쪽, 모서리를 4dp만 넘기게 배치한다.
- 빈 상태에서는 테이프를 숨기고 캐릭터만 사용한다.
- 한 화면에 캐릭터와 장식 테이프를 동시에 크게 쓰지 않는다.

## 내 공간

### 화면 구조

위에서 아래 순서다.

1. `내 공간` 제목
2. 정체성 스트립
3. 통계 한 줄
4. 태블릿 가로에서만 2열 설정 영역
5. 앱 정보 목록
6. 회원일 때만 로그아웃

프로필·통계·정보를 각각 카드로 분리하지 않는다. 흰색 영역과 얇은 구분선으로 묶고, 영역 사이에는 28dp 여백을 둔다.

### 정체성 스트립

- 면: `surface #FFFFFF`.
- 높이: 태블릿 116dp, 폰 104dp.
- 바깥 테두리 없음. 하단에만 1dp `cardBorder`.
- 좌측 아바타: 72×72dp, 모서리 22dp.
  - 회원: 프로필 사진.
  - 게스트: `D` 모노그램.
- 아바타 위 버터 테이프: 28×11dp, -7° 회전, 상단에서 4dp 겹침.
- 이름: `22dp / 800 / text`.
- 문구: `○○님의 기록 공간`은 이름 바로 아래 `15dp / 700 / primaryText`.
- 우측에는 `로그인·회원가입` 또는 `프로필 수정` 버튼 하나만 둔다.
- 모아 캐릭터: 정체성 스트립의 가장 오른쪽에만 64×73dp로 배치한다. 버튼과 겹치지 않게 버튼 왼쪽 16dp 간격을 둔다.
- 폰에서는 모아를 숨기고 버튼을 이름 영역 아래 전폭으로 이동한다. 프로필 사진이 정체성 시각 요소를 충분히 맡는다.

### 통계 한 줄

- 정체성 스트립 아래 20dp.
- 높이: 72dp.
- 면: `surface #FFFFFF`.
- 두 항목을 1:1로 나눈다.
- 중앙 구분선: 높이 32dp, 1dp `cardBorder`.
- 숫자: `26dp / 800 / text`.
- 라벨: `14dp / 700 / textMuted`.
- 항목은 `만든 다이어리 N`, `즐겨찾기 N`을 유지한다.
- 기존 SVG 소품은 제거한다. 숫자와 라벨만 남겨 정보 밀도를 낮춘다.
- 각 항목은 상세 목록으로 이동하는 48dp 이상 터치 영역이다.

### 환경 설정

태블릿에서만 표시한다.

- 태블릿 가로에서는 앱 정보와 나란히 놓는다.
  - 좌측 앱 정보: 7/12 폭.
  - 우측 환경 설정: 5/12 폭.
  - 열 사이: 32dp.
- 태블릿 세로에서는 앱 정보 아래로 한 줄 전체 폭으로 내린다.
