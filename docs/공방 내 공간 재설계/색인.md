# 꾸미기 공방 · 내 공간 재설계 (2026-10-31)

"카드가 너무 많다"는 요청으로 두 화면의 배치와 버튼을 다시 짰다. 색 규칙(UI 색상 계열 + 버터 노랑)만 지키고 나머지 가이드 규칙은 새로 정했다. 확정한 규칙은 [디자인 가이드](../디자인%20가이드.md)의 '꾸미기 공방' · '내 공간' · '버튼 체계'에 옮겼다.

## 진행

1. 조사 세 갈래(동시 진행, 지난 [앱 감성 리뉴얼](../앱%20감성%20리뉴얼/색인.md) 조사와 겹치지 않게)
   - [A 경쟁 앱 배치](./조사%20원자료/A%20경쟁%20앱%20배치.md): Goodnotes · Notability · Day One · Canva · Picsart · Edits 등 16개. 보관함 · 설정을 카드로 쌓지 않는다(컬렉션 한 겹 + 끝의 '+', 분절 메뉴, 묶음 목록).
   - [B 감성 앱 배치](./조사%20원자료/B%20감성%20앱%20배치.md): Airbnb · Finch · Duolingo · Structured · 토스 가이드 등. 숫자 한 줄, 트로피 선반, 도구함 하나, 그래픽은 한 화면에 하나, 위험 · 정보는 맨 아래.
   - [C 트렌드와 근거](./조사%20원자료/C%20트렌드와%20근거.md): NN/g(카드 · 공통 영역 · 캐러셀), Liquid Glass 구조, Material 3 Expressive, 터치 48 · 대비 3:1.
2. [코덱스 설계안](./코덱스%20설계안.md): 화면마다 배치안 3개 비교 → 추천(공방 = 분절 메뉴 + 한 종류씩, 내 공간 = 정체성 띠 + 숫자 한 줄 + 조용한 목록)과 수치 표.
3. Claude 구현 → [코덱스 검수](./코덱스%20검수.md) → 분절 메뉴 폭 보정.

## 설계와 다르게 한 것 (Claude 판단, 코덱스 검수에서 반대 없음)

| 설계 | 구현 | 이유 |
|---|---|---|
| 앱 바탕 회색 위 배치 | 두 화면 바탕을 흰 면(`surface`) 한 장으로 | 설계 표의 '기본 콘텐츠 면 surface'. 회색 바탕에서는 `surfaceMuted` 탭 · 도구함이 안 보였다 |
| 표지 · 속지 지우기는 길게 누르기 | 이름 옆 48 아이콘 버튼 유지 | 발견성 · 화면 읽기 접근성 |
| 모든 종류 끝에 '+' 칸 | 스티커 폴더 끝에만 | 공방 안에 표지 · 속지를 만드는 흐름이 없다 |
| 폰트 행 더보기 · 삭제, 통계 누르기 | 넣지 않음 | 연결할 기능이 없다 |
| 분절 메뉴 최소 폭 148 | 120(폰 100) | 검수: 태블릿 세로에서 첫 칸이 잘리고 폰에서 네 · 다섯째가 안 보였다 |
