1. **P0 — 세로 태블릿에서 공방 탭 첫 항목이 38dp로 찌그러짐**  
   `내 폰트`가 텍스트 없이 잘려 보인다. 탭은 축소하지 말고 가로 스크롤로 전환: `flex: 0 0 112dp`, gap `8dp`, 좌우 inset `18dp`.

2. **P0 — 폰에서 `내 속지`·`내 프리셋` 진입점이 없음**  
   현재는 세 탭만 보여 기능이 사라진 것처럼 보인다. 다섯 탭을 가로 스크롤로 유지하고, 첫 화면에 다음 탭 `20–24dp`가 살짝 보이게 탭 폭을 `104dp`로 조정하거나 3+2 줄바꿈 그리드로 전환.

3. **P1 — 태블릿 가로 표지 9개 행이 우측에서 거의 잘림**  
   마지막 표지/삭제 아이콘이 화면 끝에 너무 붙는다. 카드 폭 `115dp → 112dp`, gap `16dp`로 하면 9개가 콘텐츠 폭 안에 안정적으로 들어온다. 또는 끝 padding `24dp`를 보장한 가로 스크롤로 처리.

4. **P2 — 삭제 아이콘의 터치 영역을 명시적으로 보장할 것**  
   시각 아이콘은 지금처럼 작아도 되지만, 표지·속지의 삭제 버튼 hit area는 최소 `44×44dp`(요청대로라면 `48×48dp`)여야 한다. 인접 이름과의 간격은 `8dp` 이상.

변경점 1~6에는 반대 없음. 특히 흰 surface 전환, 발견 가능한 삭제 버튼, 기능 없는 `+`/아이콘 제거, 비버튼 통계, 두 줄 정체성 띠 모두 타당하다. 눌림 상태의 scale은 `0.96–0.98`, `120–160ms` 정도면 과하지 않다.

색 규칙 위반은 앱 크롬에서는 보이지 않는다. 단, 속지·프리셋의 종이/펜/형광펜 색칩까지 UI 색 규칙에 포함한다면 민트·핑크·주황·초록·보라가 위반이다. 이들은 “꾸미기 대상 색상”이라는 예외로 명시하면 문제없다.
