# 코덱스 요청 — 보관함 '한눈에 보기' 태블릿 가로 ↔ 세로

도구 호출(파일 읽기 · 셸) 하지 말고, 첨부 이미지 1장과 이 글만으로 최종 답을 써라. 웹 검색은 써도 된다.

## 앱
DIO: 1020이 친구들과 쓰는 공유 다이어리 앱(Expo React Native). 보관함(내 다이어리) 화면에 보기가 셋: 펼쳐서 · 스와이프 · **한눈에(표지 격자)**. 주 테스트 기기는 안드로이드 태블릿(갤럭시 탭, 1280×800 dp), iPad 에서도 반드시 동작해야 한다. 태블릿은 회전하면 가로 ↔ 세로가 바뀐다.

## 첨부 이미지(지금 화면, 왼쪽부터)
1280×800 가로 · 800×1280 세로 · 1194×834 가로 · 834×1194 세로 · 1024×1366 세로 · 744×1133 세로. 세로 표지와 가로 표지(레시피 · 제주 여행 일기)가 섞여 있다.

## 지금 코드의 실제 값(이미지에서 읽지 말고 이 값을 믿어라)
- 좌측 바 접힘 78, 본문 좌우 여백 30 → 격자 폭 = 창 폭 − 138
- 칸은 정사각형, 세로 표지는 칸 높이에 맞고(폭 ≈ 0.74배), 가로 표지는 칸 폭에 맞으며 아래 선을 맞춘다(선반 배치). 표지 아래 이름 · 쪽수 두 줄 + 오른쪽 ⋯ (정보 줄 높이 58)
- 열 수 = max(2, floor((폭 + 32) / (208 + 32))), 칸 = min(264, floor((폭 − (열−1)·32) / 열)), 칸 간격 가로 · 세로 32, 왼쪽 정렬
- 결과: 1280 가로 → 4열 칸 261 | **800 세로 → 2열 칸 264, 격자 폭 560, 오른쪽 102 빔** | 1194 가로 → 4열 240 | 834 세로 → 3열 210 | 1024 세로 → 3열 264, 오른쪽 54 빔 | 744 세로 → 2열 264, 오른쪽 46 빔 | 1366 가로 → 5열 237 | 1133 가로 → 4열 225
- 폰은 퍼센트 2열(이번 범위 아님)
- 회전하면 ScrollView 의 y 위치가 그대로 남아 보던 다이어리가 다른 줄로 밀린다(보던 항목 유지 없음)

## 굿노트 · 삼성 노트 · 그 밖의 앱 조사 결과(클로드 정리)
공식 문서에는 어느 앱도 가로·세로 열 수를 밝히지 않는다. 숫자는 굿노트 피드백 포럼 첨부 스크린샷에서 직접 셌다.
- 굿노트(iPad) 페이지 썸네일: 세로 전체 화면 4열, 11인치 가로 Split View 반쪽 창 3열. 썸네일 크기는 거의 그대로(약 122~133pt)이고 열 수만 폭에 따라 정수로 바뀐다. 남는 폭은 칸 사이 간격으로 고르게 나눈다(가운데 몰기·표지 키우기 아님). 13인치 iPad에서 12.9인치 4열 → 13인치 5열로 바뀌었다는 사용자 보고(2026-03). 사용자들이 2019~2025년 내내 "썸네일 사이 빈 공간이 너무 크다 · 열 수/크기 설정을 달라"(23표, 공식 답 없음), 2025-02 "업데이트 뒤 보관함 아이콘이 작아졌다"고 요청. 크기 조절 설정은 없다. 보관함은 격자/목록 전환(우상단 4칸 아이콘)만.
- 삼성 노트(갤럭시 탭): 보기 = 목록 / 격자 / 간단히 목록. 2021년 업데이트 공지에 격자 크기 '작게/중간/크게' 3단계가 있었다는 검색 요약(본문 403으로 미열람), 2023년 "격자로 해도 가장 크게가 작다" 불만 글. 열 수는 미확인.
- 노터빌리티(구버전, 2020, iPad 10.5 가로): 보관함 4열. 가로 노트와 세로 노트가 섞여도 같은 높이 칸 안에서 세로 가운데 정렬, 제목·날짜는 줄마다 같은 높이에 맞춘다.
- Noteful: 보관함 미리보기를 두 손가락 핀치로 키우고 줄인다. Google Play 북: 목록 / 작은 격자 / 큰 격자 칩(비공식 보도). Apple Files: 아이콘 / 목록 / 열 보기 전환, 아이콘 크기 조절은 못 찾음.
- 회전할 때 스크롤 위치(보던 항목) 유지 여부, 사이드바 자동 접힘은 어느 앱도 확인 못 함.


## 지켜야 할 규칙
- 색은 UI 계열(H≈232°, 네이비 #0B1766 · 페리윙클)과 버터 노랑 #FEF0BF 만. BI 색 바꾸지 말 것
- 사용법 안내 문구 금지, 눌림 효과 금지, 팝오버 페이드 · 슬라이드 금지
- 이미 정한 것: 칸 간격 32, 칸 최소 208 · 최대 264(원 페이저 02, 2026-11-01). 바꾸려면 이유를 적어라

## 묻는 것
1. 굿노트 · 삼성 노트 방식과 비교해 지금 규칙(같은 칸 크기, 열 수만 바뀜)이 맞는가? 갤럭시 탭 세로 2열 문제를 어떻게 풀까? (예: 세로 최소 칸을 낮춰 3열, 열 수 대신 칸 크기 우선, 남는 폭 가운데 정렬, 간격 늘림 등 — 숫자로)
2. 가로 · 세로 각각 몇 열, 칸 몇 px, 간격 몇 px 가 1020 다꾸 앱에서 예쁜가? 위 8개 창 크기 표로.
3. 회전할 때 무엇을 지킬까(보던 다이어리 유지, 맨 위 줄 기준 등)? 애니메이션은?
4. 표지 크기 사용자 조절(핀치 · 크기 버튼)을 넣을 가치가 있는가? 넣는다면 최소안.
5. 머리줄(제목 · 보기 전환 · 칩 · 검색)은 세로에서 그대로 둬도 되는가?
마지막에 '최종 규칙'을 코드로 옮길 수 있는 식 하나로 정리하라(열 수 · 칸 · 간격 · 정렬).
