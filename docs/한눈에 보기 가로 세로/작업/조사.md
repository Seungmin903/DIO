공식 문서에는 어느 앱도 가로·세로 열 수를 밝히지 않는다. 숫자는 굿노트 피드백 포럼 첨부 스크린샷에서 직접 셌다.
- 굿노트(iPad) 페이지 썸네일: 세로 전체 화면 4열, 11인치 가로 Split View 반쪽 창 3열. 썸네일 크기는 거의 그대로(약 122~133pt)이고 열 수만 폭에 따라 정수로 바뀐다. 남는 폭은 칸 사이 간격으로 고르게 나눈다(가운데 몰기·표지 키우기 아님). 13인치 iPad에서 12.9인치 4열 → 13인치 5열로 바뀌었다는 사용자 보고(2026-03). 사용자들이 2019~2025년 내내 "썸네일 사이 빈 공간이 너무 크다 · 열 수/크기 설정을 달라"(23표, 공식 답 없음), 2025-02 "업데이트 뒤 보관함 아이콘이 작아졌다"고 요청. 크기 조절 설정은 없다. 보관함은 격자/목록 전환(우상단 4칸 아이콘)만.
- 삼성 노트(갤럭시 탭): 보기 = 목록 / 격자 / 간단히 목록. 2021년 업데이트 공지에 격자 크기 '작게/중간/크게' 3단계가 있었다는 검색 요약(본문 403으로 미열람), 2023년 "격자로 해도 가장 크게가 작다" 불만 글. 열 수는 미확인.
- 노터빌리티(구버전, 2020, iPad 10.5 가로): 보관함 4열. 가로 노트와 세로 노트가 섞여도 같은 높이 칸 안에서 세로 가운데 정렬, 제목·날짜는 줄마다 같은 높이에 맞춘다.
- Noteful: 보관함 미리보기를 두 손가락 핀치로 키우고 줄인다. Google Play 북: 목록 / 작은 격자 / 큰 격자 칩(비공식 보도). Apple Files: 아이콘 / 목록 / 열 보기 전환, 아이콘 크기 조절은 못 찾음.
- 회전할 때 스크롤 위치(보던 항목) 유지 여부, 사이드바 자동 접힘은 어느 앱도 확인 못 함.
