# 꾸미기 공방

2026-10-30 · S15P31F106-374·375·376 · 각 2 SP · feature/fe/decoration-studio

## 역할과 진입

홈 사이드 메뉴와 폰 하단 메뉴에 꾸미기 공방을 추가한다. 다이어리를 열지 않고 여러 기록에 사용할 폰트·스티커를 제작하고 보관함을 확인하는 공간이다. 편집기 툴바는 캔버스 편집에 집중하며 독립 폰트 제작 아이콘을 추가하지 않는다. 텍스트 설정의 기존 폰트 생성·적용과 스티커 폴더 ＋의 기존 제작 경로, 내 공간의 폰트 제작 진입은 유지한다.

## 제작과 보관

- 내 폰트 만들기: 기존 HandwritingStudio/studioBus를 재사용한다. 공방에서는 특정 텍스트에 적용하는 onUse 콜백을 전달하지 않는다. 닫은 뒤 목록을 새로 읽으며 글꼴 로드 실패·빈 목록·조회 오류를 구분한다. 폰트 관리는 기존 제작기의 파일 가져오기·내보내기 기능을 사용한다.
- 스티커 시트 분리: 기존 StickerSplitModal과 useCustomDecor.saveGenerated를 재사용해 새 폴더에 저장한다. 폴더 이름 중복을 허용하며 폴더 ID로 구분한다. 처리 모듈이 없는 웹·Expo Go에서는 기존 지원 사유를 표시하고 진입을 비활성화한다.
- 사진 속 대상 오리기: 기존 StickerCutoutModal로 연결한다. SAM 추론·업로드·PNG 생성·실제 저장 미연결 상태는 그대로 명시한다. 진입만으로 폴더를 생성하지 않는다.
- 내 스티커는 편집기와 같은 기기 보관함이다. 폴더를 열어 항목을 확인하고 삭제할 수 있다. 스티커·폴더 삭제는 확인창을 거치며 이미 다이어리에 붙인 요소는 수정하지 않는다. 삭제 시 파일을 직접 지우지 않는다. 저장 실패는 공용 DecorSaveNotice와 재시도를 사용한다.
- 저장 키·계정별 서버 보관 정책·마이그레이션은 바꾸지 않는다. 현재 폰트·스티커는 기존 기기 공통 저장소를 그대로 사용하며 서버 동기화를 추가하지 않는다.
- 폰트 제작기는 공용 EditorModal을 사용해 가로/세로 방향을 허용한다. 생성 모델과 네이티브 추론 로직은 수정하지 않는다.

## 배치

화면은 내 폰트 · 내 스티커 · 내 표지 · 내 속지 · 내 프리셋 다섯 구역을 세로로 쌓고(제목 아래 장식 카드 없음) 본문을 스크롤한다. 만들기 도구(폰트 만들기 · 스티커 시트 분리 · 사진 속 대상 오리기)는 해당 구역 안의 줄이다. 태블릿은 도구 줄과 프리셋 묶음을 가로로, 폰은 세로로 놓는다. 내 속지 구역 맨 위에는 기본 속지 설정(종이 색 · 선 · 글씨 색 · 속지 글꼴, `useDefaultPaperStyle`, 저장 키 `dio:diary:paper-style-default:v1`)이 있어 새 다이어리의 처음 값이 되며 이미 만든 다이어리 · 속지는 바꾸지 않는다. 내 표지 · 내 속지는 새 다이어리 화면에서 쌓은 기기 보관함(`useMyLibrary`)을 보여 주고 확인 뒤 지우며, 내 프리셋은 편집기 색 저장소(`useColorPresets`: 펜 · 형광펜 · 테이프 · 글자)의 기본 색과 저장한 색을 보여 준다. 하단 공방 탭은 긴 이름을 두 줄로 표시한다. 새 조작은 최소 44px, 색·모서리는 공용 theme 토큰, 글자 크기는 디자인 가이드 표를 사용한다.

## 실기기 확인

1. Expo Go 리로드 → 게스트 → 홈 메뉴에서 꾸미기 공방 진입.
2. 내 폰트 만들기 → 기존 손글씨 작성 화면 확인 → 닫기로 공방 복귀.
3. 사진 속 대상 오리기 → 사진 선택 → 칠하기 → 다음 → 선택 수정 → 닫기 확인 후 공방 복귀.
4. 스티커 시트 분리는 Expo Go에서 사용 환경 안내와 비활성 상태인지 확인. 기존 네이티브 개발 빌드에서는 분리 후 새 폴더 저장·편집기 보관함 표시를 별도 확인한다.
5. 테스트용 스티커 폴더가 있다면 열기 → 삭제 취소로 유지 확인 → 테스트 항목만 삭제 확정 → 편집기의 같은 폴더에 반영되는지 확인한다. 개인 자료를 검증용으로 삭제하지 않는다.
6. 공방에서 다이어리 보관함·내 공간으로 이동 후 다시 돌아온다. 폰 세로/가로·태블릿에서 카드와 하단 메뉴가 잘리지 않는지 확인한다.

실기기 결과는 사용자 확인 후 별도로 기록한다.

- 공방 제작 카드는 아이콘·제목·짧은 기능 설명과 화살표로 구성한다. 반복되는 만들기 문구와 보관함 설명은 제거하고, 카드 높이·아이콘·제목을 키워 제작 진입을 강조한다. 미지원 환경과 사진 오리기 미연결 안내는 유지한다.

- 공방 제작 카드는 높이 184와 아이콘 영역 68로 강조한다. 제작 화면의 기존 표시 방식은 유지한다(폰트·시트 분리: 전체 화면, 사진 속 대상 오리기: 팝업).

- 큰 제작 카드의 아이콘과 제목은 위아래로 배치해 좁은 화면의 글자 끊김을 줄이고, 안내 영역을 포함한 카드 전체를 누를 수 있게 한다. 내 폰트는 실제 글꼴 미리보기와 별도 폰트 관리 진입을 제공한다. Android 뒤로가기는 스티커 폴더 내부에서 목록으로 먼저 돌아간다. 제작 모달 표시 방식은 변경하지 않는다.

## 리뷰 보완 및 QA 실행 조건

- 팀 합의로 스티커 폴더 이름 중복을 허용한다. 공방·편집기 폴더 생성/이름 변경·분리 저장과 공통 저장 함수에서 중복 검사를 하지 않는다. trim과 빈 이름 검사는 유지하며 기존 폴더에 추가할지는 이름 대신 ID로 결정한다.
- 글자 크기별 역할과 카드 크기는 디자인 가이드의 꾸미기 공방 표를 따른다. 현재 공용 theme에는 글자 크기·간격 토큰이 없다.
- 브라우저 QA는 frontend에서 실행한다. 먼저 별도 터미널에서 `pnpm exec expo start --go --lan`으로 Metro를 실행한다. 포트가 8081이 아니면 `EXPO_QA_PORT`를 설정한다.
- `PLAYWRIGHT_EXECUTABLE_PATH`에 설치된 Chromium 계열 브라우저(Chrome·Edge·Chromium)의 실행 파일 절대 경로를 지정해야 한다. 없거나 파일이 존재하지 않으면 서버를 열기 전에 안내하고 종료한다. 브라우저를 자동 설치하지 않는다.
