# DIO 디자인 가이드 (BI · CI · 인앱 UI)

> 기준일: 2026-10-22 · 기준 코드: `feature/fe/layer` (`debd396`)<br>
> 새 화면과 기능은 이 문서 하나만 보고 만들 수 있게 썼다. 다른 문서(`MVP1 화면 명세.md`, `도구 옵션 화면.md` 등)와 값이 다르면 **이 문서와 실제 코드가 우선**이다.

## 0. 이 문서 쓰는 법

1. 새 UI를 만들기 전에 **12장 체크리스트**부터 본다.
2. 색·모서리·그림자는 반드시 `src/shared/theme.js` 토큰을 쓴다. 토큰에 없는 값이 꼭 필요하면 이 문서의 "보조 값" 표에 있는 값만 쓴다.
3. 이미 있는 공용 컴포넌트(9장)를 먼저 찾아 쓴다. 비슷한 것을 새로 만들지 않는다.
4. 이 문서에 없는 새 규칙을 만들었다면 이 문서에 먼저 추가하고 같은 커밋에 넣는다.

## 1. 브랜드 (BI)

### 1.1 이름과 성격

| 항목 | 내용 |
|---|---|
| 서비스 이름 | **DIO** (앱 이름 표기도 `DIO`) |
| 한 줄 소개 | 하루 한 장의 사진을 캔버스 삼아 친구들과 함께 꾸미는 공유 다이어리 |
| 성격 | 차분함 · 손글씨 같은 따뜻함 · 꾸미는 재미. 화면은 조용하게, 꾸민 내용이 주인공 |
| 말투 | 친근한 해요체 (8장) |

### 1.2 로고

- 원본: `frontend/assets/brand/dio-logo.svg` (746 × 836, 투명 배경)
- 앱 안에서는 `src/shared/BrandLogo.js` 컴포넌트만 쓴다. PNG를 따로 넣지 않는다.
  - `size`는 **높이**다. 너비는 자동(`size × 746/836`).
- 구성: 둥근 마감의 **D 심볼**(먹색) + 오른쪽 위 **테마 원**(하늘색). D 안의 두 줄은 다이어리의 글줄을 뜻한다.

| 요소 | 값 |
|---|---|
| D 심볼 · 글줄 (Brand Ink) | `#242424` |
| 테마 원 (Brand Accent) | `#9FB6D9` |

로고 규칙

- 색을 바꾸지 않는다. 어두운 바탕 위가 아니면 항상 원래 두 색으로 쓴다.
- 늘이거나 눌러 비율을 바꾸지 않는다. 회전·그림자·테두리를 넣지 않는다.
- 로고 주변에 최소 **로고 높이의 25%** 여백을 둔다.
- 쓰는 크기: 다이어리 홈 사이드 레일 **32**, 편집기 상단 바(태블릿) **30**, 폰 상단 바 **24**.

### 2.3 색 쓰는 규칙

- 흰 바탕 위 글자 · 아이콘은 `text`가 기본이다. 회색 글자는 `textMuted`.
- 채운 주요 버튼은 `primaryStrong` 위 흰 글자를 쓴다. `primary`는 선택 테두리·슬라이더 등 기존 선 색을 유지한다. 넓은 앱 배경은 `surfaceSoft`, 선택된 도구·메뉴 바탕은 `primarySoft`로 구분한다.
- 흰 바탕의 파란 UI 글자는 `primaryStrong`을 쓴다(일반 크기 대비 4.5:1 이상). 기본 글자는 `text`, 보조 설명은 `textMuted`를 사용하며 `primary`는 글자색으로 쓰지 않는다.
- 선택 상태는 색만 바꾸지 않고 **테두리 또는 그림자**를 같이 준다.
- 빨강(`danger`)은 지우기 · 영구 삭제 · 오류에만.
- 다크 모드는 지원하지 않는다(`userInterfaceStyle: light`).

## 3. 글자 (타이포그래피)

### 3.1 서체

- **UI 글자는 시스템 서체만** 쓴다. UI용 웹폰트를 넣지 않는다.
- 사용자 텍스트(캔버스)용 서체: 기본 고딕 · 기본 명조(시스템), 나눔고딕, 나눔명조, 나눔손글씨 펜, 푸어스토리. 새 서체는 `services/textFonts.js`와 `utils/text.js`의 `TEXT_FONTS`에 함께 넣는다.

### 3.2 크기 단계

| 역할 | 크기 / 굵기 | 색 |
|---|---|---|
| 홈 화면 제목 | 29 / 800, 자간 -0.6 (폰 30, -0.6) | text |
| 만들기 대화상자 제목 | 22 / 800 | text |
| 레이어 패널 제목 · 빈 화면 제목 | 19 / 700 | text |
| 전체 화면 제목 | 17 / 700 | text |
| 대화상자 제목 | 16 / 700 | text |
| **패널 제목** (도구 옵션 · 더보기 · 보관함) | **15 / 700** | text |
| 큰 버튼 · 주요 버튼 | 14 / 700 | 흰색(primaryStrong 위) |
| 카드 제목 · 메뉴 항목 | 14 / 700 | text |
| 상단 바 버튼 · 탭 제목 · 토스트 | 13 / 700 | text · 흰색(토스트) |
| 본문 · 안내 · 세그먼트 · 칩 | 12.5 / 600–700, 줄간격 19 | text · textMuted |
| **섹션 제목** (패널 안) | **12 / 700** | textMuted |
| 페이지 번호 · 작은 탭 | 11–11.5 / 700 | textMuted |
| 메타 정보 · 보조 표기 | 10.5 / 600 | textMuted |

규칙

- UI 굵기는 **600 · 700 · 800**을 쓴다. 기존 900 제목은 800, 일반 800 버튼·메뉴는 700으로 낮추고 선택 상태는 800을 유지한다. 표지 인쇄·사용자 글자 서식은 별도이며 이 변경으로 바꾸지 않는다. 650 · 750 · 850 같은 중간 값은 기기마다 반올림되어 다르게 보인다.
- 선택된 상태는 굵기를 한 단계 올린다(예: 세그먼트 600 → 800).
- 숫자 입력칸은 13 / 700, 단위는 11 / 700. 자간 · 줄간격 같은 비율 값에도 `%`를 붙이지 않는다.

## 4. 간격 · 크기 · 모서리 · 그림자

### 4.1 기본 단위

4의 배수를 기본으로 쓴다: **4 · 8 · 12 · 16 · 20 · 24**. 패널 안 여백 16, 요소 사이 12, 붙은 요소 사이 8.

### 4.2 누르는 영역

| 대상 | 크기 |
|---|---|
| 폰 버튼 · 캔버스 최소 터치 | **44** 이상 |
| 태블릿 리본 도구 | 42 × 42, 모서리 11 |
| 상단 바 토글 | 높이 40, 모서리 12, 좌우 10 |
| 패널 닫기 | 40 × 40, 모서리 10 |
| 대화상자 버튼 | 높이 42, 최소 폭 76, 모서리 12 |
| 홈 아이콘 버튼 · 큰 버튼 | 48, 모서리 14 |

작은 아이콘(20 이하)만 누르게 할 때는 `hitSlop`으로 44를 맞춘다.

## 5. 화면 배치

### 5.1 기준 프레임

| 항목 | 값 |
|---|---|
| 데이터 좌표 | 1280 × 800 (모든 플랫폼 공통 저장 · 내보내기 기준) |
| 화면 프레임 | 태블릿은 안전 영역 전체 폭·높이 사용. Android·웹 1280×800, iPad 1024×768은 검증 기준 크기이며 앱 비율을 제한하지 않음 |
| 폰/태블릿 구분 | 창의 짧은 변 **600 이상이면 태블릿** (`formFactorFor`). 기기 종류가 아니라 창 크기로 판단 |
| 방향 | 태블릿은 **가로 고정**. 폰은 세로 고정, 편집기에서만 가로 허용 |
| 상태 바 · 내비게이션 바 | 숨김. 안전 영역은 옆 화면 색으로 칠한다 |

### 5.2 편집기 (태블릿)

- 폰·태블릿 편집기 최초 진입 시 손 도구를 기본 선택한다. 레이어 패널 열기·닫기와 페이지 이동은 현재 도구를 유지한다. 사진·꾸미기 추가 등 명시적인 선택 도구 전환은 기존 동작을 따른다.

| 영역 | 위치 · 크기 | 내용 |
|---|---|---|
| 상단 바 | 맨 위, 높이 64 | 왼쪽 `< 로고` + "페이지" 토글 · 가운데 다이어리 탭 · 오른쪽 레이어 · 내보내기 · 저장 상태 |
| 페이지 목록 | 왼쪽, 폭 156 (썸네일 124) | 같은 다이어리의 페이지. 위에 전체 / 북마크 탭 |
| 리본 | 캔버스 위 가운데, 위 12 | 도구 아이콘 |
| 캔버스 | 가운데 | 흰 종이 |
| 실행 취소 · 확대 바 | 캔버스 아래 가운데, 아래 12 | 되돌리기 · 다시 실행 · 배율 |
| 레이어 패널 | 오른쪽, 폭 280 | 오브젝트 순서 · 보이기 · 잠금 |
| 바탕 | 전체 | `surfaceSoft`, 바깥 여백 16 · 영역 사이 16 |

- 상단 바 왼쪽 묶음 폭 = 페이지 목록 폭. "페이지" 토글의 오른쪽 끝을 페이지 목록 오른쪽 끝에 맞춘다.
- 도구 옵션 패널은 누른 도구 아이콘 아래 **8** 띄워 열고, 아이콘 가운데에 맞추되 편집 영역 좌우 8 안으로 제한한다. 아래쪽 64는 비워 둔다.

### 5.3 편집기 (폰)

- 세로: 짧은 상단 바(60) + 가로 도구 막대. 순서: 손 · 선택 · 올가미 | 펜 · 형광펜 · 지우개 · 텍스트 | 스티커 · 테이프 · 사진 | 보조선.

### 5.4 읽기 모드

- 편집 화면 오른쪽 아래에 화면 맞춤과 눈 아이콘을 나란히 둔다. 읽기 모드에서는 화면 맞춤·편집 전환을 하단 페이지 메뉴 안으로 통합하고 별도 플로팅 버튼은 표시하지 않는다.
- 읽기 상단은 높이 56이며 왼쪽 홈 버튼, 중앙 다이어리 제목, 오른쪽 빈 영역으로 구성한다. 제목 양쪽의 영역 폭을 같게 해 제목을 가운데 정렬한다.
- 하단은 하나의 surface 배경 안에 왼쪽 현재/전체 페이지, 중앙 이전·진행 슬라이더·다음, 오른쪽 화면 맞춤·편집 전환을 배치한다. 모든 조작의 터치 영역은 44 이상이다. 이전·다음 버튼은 짧게 누르면 한 장 이동하고 350ms 누르고 있으면 90ms 간격으로 한 장씩 넘긴다. 손을 떼거나 취소·메뉴 해제·앱 비활성화·첫/마지막 페이지 도달 시 연속 넘김을 멈추며 순환하지 않는다. 폰 가로 편집 도구 레일은 아래 76을 비운다.
- 상·하단은 오버레이로 표시하고 중앙 탭으로 함께 숨기거나 표시한다. 자동 숨김은 없다. 메뉴 표시 전환으로 캔버스를 재배치하지 않는다. 화면 맞춤 계산은 위 64·아래 76·좌우 12를 비워 원본 비율을 유지한다.
- 좌우 각 20%의 짧은 탭은 이전/다음 페이지, 중앙 60%는 메뉴 전환이다. 화면 맞춤 이하 배율에서는 기존처럼 수평 48dp 이상, 수평 이동이 수직 이동의 1.5배 이상이면 속도와 무관하게 한 장 넘긴다. 확대 상태에서는 같은 거리·방향 조건에 더해 250ms 이내·평균 수평 속도 0.5dp/ms 이상일 때만 스와이프로 한 장 넘긴다. 느린 드래그나 세로 이동으로 판정되면 해당 터치가 끝날 때까지 화면 이동으로 유지한다. 확대 중 가장자리 탭도 페이지를 넘기며, 두 손가락이 참여한 동작은 페이지 넘김으로 바꾸지 않는다.
- 읽기 화면에서는 편집 리본·문서 탭·페이지/레이어 패널·선택 표시·실행 취소·저장 상태를 숨긴다. 공유·책갈피·별도 보기 설정은 제공하지 않는다. 링크와 하단 컨트롤은 뷰어 제스처보다 우선한다.
- 모드 전환과 페이지 전환 후 화면에 맞춘다. 마지막 열람 페이지는 기존 개인/세션 저장 범위로 기억하며 배율·이동량·읽기 모드 선택은 저장하지 않는다. 편집 권한이 없는 문서는 읽기로 시작하고 편집 전환을 제공하지 않는다.

## 8. 글쓰기 (UX 문구)

- **해요체**로 통일한다. 결과는 과거형(~했어요), 부탁은 ~해 주세요, 없음은 ~없어요, 확인 질문은 ~할까요?
- 짧게 쓴다. 기능 설명 · 도움말 문구는 넣지 않고 제목 · 오류 · 저장 상태 · 한도 안내만 남긴다.
- **친절한 안내 멘트를 넣지 않는다.** 사용법 · 결과 예고 · 다음 할 일을 알려 주는 문장은 버튼 아래 보조 글, 빈 칸 안내, 처음 한 번 뜨는 토스트 어디에도 쓰지 않는다. 화면과 버튼 이름만으로 알 수 있게 만든다.
  - 쓰지 않는 예: "티켓 틀로 붙어요" · "틀 없이 붙어요" · "사진을 두 번 누르면 자를 수 있어요" · "칸에 넣을 순서대로 골라요" · "빈 틀을 넣고 칸을 채워도 돼요"
  - 쓰는 것: 제목 · 버튼 이름 · 오류 · 막힘 안내 · 완료 토스트(아래 표) · 저장 · 진행 상태 · 한도 · 되돌릴 수 없는 작업의 확인

- 띄어쓰기: "붙여 넣었어요", "잘라 냈어요"처럼 보조 용언은 띄운다.

## 11. 기능 패턴

- **내보내기 · 저장**: 결과 · 미리보기 · 진행 화면을 띄우지 않는다. "만들기"를 누르면 말풍선이 닫히고 **작은 진행 알약만** 보이다가 바로 다운로드(기기는 사진첩 · 공유 창)된 뒤 토스트로 알린다. 새 내보내기도 `ExportRunner` 방식으로 붙인다.
- **삭제**: 되돌릴 수 있으면 확인 없이 지우고 "되돌리기로 복구할 수 있어요" 토스트. 되돌릴 수 없으면 `ConfirmDialog`(빨간 버튼).
- **도구 옵션**: 리본 아이콘 아래 떠 있는 패널 하나. 제목 + 섹션(12/700 회색 제목) + 컨트롤. 고정된 왼쪽 · 오른쪽 구분을 쓰지 않는다.
- **빈 곳 메뉴(붙여넣기 · 속지 색)**: 페이지 빈 곳을 움직이지 않고 450ms 누르면 누른 자리에 뜬다. 선택 도구와 손바닥 도구 모두 연다(손바닥 도구는 화면을 옮기는 보는 영역이 길게 누르기를 알려 준다). 메뉴를 띄운 터치는 손을 뗄 때까지 화면을 옮기지 않고, 빈 곳을 누르거나 도구 · 페이지를 바꾸면 닫힌다.
- **리본**: 아이콘만, 글자 표기 없음. 펜 · 형광펜은 아이콘 오른쪽 아래 6pt 원으로 현재 색을 보여 준다.

### 11.1 떠 있는 메뉴의 자리

캔버스 위에 뜨는 메뉴는 `src/editor/utils/popoverPlacement.js` 하나로 자리를 정한다. 새 메뉴도 이 함수를 쓴다.

1. **피할 영역**을 잡는다. 요소면 선택 상자 + 손잡이(꼭짓점 손잡이 반지름 9, **회전 손잡이는 요소를 돌린 방향 그대로**), 누른 자리 메뉴면 그 점.
2. 피할 영역의 **위에 먼저** 16 띄운다. 펜을 쥔 손이 아래쪽을 가리기 때문이다(iOS 편집 메뉴와 같은 순서).
3. 위에 자리가 없으면 **아래**에 16 띄운다.
4. 위 · 아래 모두 없으면 영역 안으로 밀어 넣되 **회전 손잡이의 반대쪽**에 붙인다. 손잡이 · 버튼을 메뉴가 가리지 않는 것이 우선이다.
5. 가로는 대상 가운데에 맞추고, 영역 가장자리에서 8 안쪽으로 민다.
6. **영역**은 메뉴마다 다르다. 선택 바 · 링크 카드 · 순서 메뉴 · 올가미 메뉴는 **화면에 보이는 작업 영역**(작업창에서 태블릿 툴바 아래, 폰에서 작업창 위에 띄운 페이지 목록 · 레이어를 뺀 나머지)이다. 화면을 옮기거나 확대해 요소가 가장자리 · 화면 밖으로 가도 바는 이 영역 안으로 들어오고, 패널을 열고 닫으면 그에 맞춰 다시 놓인다. 옮기거나 확대하는 동안은 숨겼다가 손을 떼면 새 자리에 보인다. 빈 곳 메뉴 · 속지 색 말풍선은 페이지 안이다.
7. 페이지 밖까지 나가는 메뉴는 페이지가 아니라 작업창 위 층(`StageOverlay`)에 그린다. Android · iOS는 부모 밖 버튼에 터치를 전달하지 않는다.
8. 영역이 좁아 바에 버튼이 다 들어가지 않으면 뒤쪽부터 더보기 메뉴로 옮긴다. 앞쪽 버튼(자르기 · 링크 등)조차 다 들어가지 않으면 그것도 이어서 옮긴다.

| 메뉴 | 기준 | 자리 |
|---|---|---|
| 선택 바 (`ContextBar`) | 선택 상자 + 손잡이 | 위 → 아래 → 손잡이 반대쪽 |
| 링크 카드 | 같은 피할 영역 | 선택 바의 반대쪽 |
| 순서 메뉴 · 폰 더보기 메뉴 | 선택 바 | 바 위 · 아래 중 넉넉한 쪽 |
| 빈 곳 메뉴 · 속지 색 말풍선 | 누른 자리 | 위 → 아래 |
| 도구 옵션 패널 | 누른 리본 아이콘 | 아이콘 아래 8, 아이콘 가운데 맞춤 (아래 64 비움) |
| 내보내기 말풍선 | 내보내기 버튼 | 버튼 아래, 오른쪽 끝 맞춤 |

## 12. 새 화면 · 기능 체크리스트

개인 사본 만들기는 공유 모달의 내부 화면으로 연다. 원본 이름, 사본 이름 입력, 원본·참여 유지 안내와 생성/취소 버튼을 배치한다. 완료 안내는 같은 화면 안에 표시하고 사본 열기·공유로 복귀를 제공한다. 세션 미리보기에서는 영구 저장으로 오해하지 않도록 실행 중에만 유지됨을 표시한다.

참여자 관리는 공유 모달의 별도 내부 화면으로 연다. 대상별 사진·닉네임과 소유권 양도·내보내기 버튼을 묶고, 두 작업 모두 대상 이름을 넣은 공용 확인창을 사용한다. 카드 안 작업 버튼은 흰 배경·기본 테두리·같은 너비로 배치하고 높이는 최소 44로 유지한다. 양도는 기본 글자색, 내보내기는 위험색으로 구분하며 양도 확인창은 기본 강조색을 사용한다. 완료·뒤로가기는 공유 기본 화면으로 돌아간다.

- [ ] 색 · 모서리 · 그림자를 `theme.js` 토큰(또는 2.2 보조 값)으로만 썼다.
- [ ] 글자 크기 · 굵기가 3.2 표 안에 있고 굵기는 600/700/800/900이다.
- [ ] 폰에서 누르는 곳이 44 이상이다.
- [ ] 아이콘은 `Icon.js`의 것이고, 없으면 같은 규칙으로 추가했다.
- [ ] 선택 상태가 색 + 테두리(또는 그림자)로 보인다. 비활성은 `DISABLED_OPACITY`.
- [ ] 문구는 해요체이고 짧다. 사용법 · 결과 예고 같은 안내 멘트가 없다(§8). 접근성 이름과 역할 · 상태를 붙였다.
- [ ] 패널 · 대화상자는 9장 공용 컴포넌트로 만들었고 `Modal` 대신 `EditorModal`을 썼다.
- [ ] 태블릿 가로(1280×800, 1024×768)와 폰 세로 · 가로에서 모두 확인했다.
- [ ] 결과 확인용 전체 화면을 새로 띄우지 않는다.
- [ ] 새 규칙이 생겼으면 이 문서에 추가했다.

### 보관함 편집 모드

보관함 옵션 → `편집`으로 진입한다. 선택 개수, 현재 검색·필터 결과의 `전체 선택/전체 해제`, `완료`, `휴지통으로`를 제공한다. 작업 버튼은 최소 높이 44를 유지하고 좁은 화면에서는 줄바꿈한다. 빈 결과에서는 편집 진입을 숨기고, 선택 0개일 때 휴지통 이동을 비활성화한다.

### 페이지 편집과 초기화

페이지 목록·넓게 보기의 선택 모드 진입은 `편집`, 종료는 `완료`로 표기한다. `다이어리 초기화`는 편집 모드에서만 제공하며, 선택·필터와 무관하게 전체 내용을 제거하고 빈 페이지 한 장을 남기는 동작임을 별도 확인창에서 안내한다.

### 로그인·회원가입 화면

기존 surfaceSoft 배경 위 흰 카드(최대 폭 520, 모서리 radius.xl)를 가운데 배치한다. 태블릿은 안쪽 40, 폰은 24와 바깥 16을 사용하며 내용이 길면 세로로 스크롤한다. 소셜 진입 버튼에만 제공자 식별 색(카카오 #FEE500, 구글 다색 심볼, 애플 #191919)을 허용한다. 이메일·비밀번호 입력은 최소 높이 48, 비밀번호 보기와 동의 항목은 최소 터치 영역 44를 유지한다. API 연결 전의 임시 동작과 데이터 유지 범위는 기능 문서에 기록한다.

로그인 시작 화면은 세로 배치로 이메일·비밀번호 입력과 로그인 버튼을 중심에 둔다. 찾기·회원가입 링크 아래에 간편 로그인과 게스트 시작을 둔다. 게스트 링크에는 별도 구분선을 사용하지 않는다. 제목·설명은 간격 6으로 묶고 입력 영역까지 24를 띄운다.

계정 닉네임은 중복을 허용한다. 회원가입·계정 프로필 수정 화면에는 중복 확인 버튼을 두지 않으며, 형식 검증과 필수 동의·저장 중 중복 제출 방지는 유지한다.

실제 이메일 로그인 계정의 비밀번호 변경은 내 공간에서 기존 비밀번호 변경 대화상자를 재사용한다. 현재·새 비밀번호·확인 입력과 변경 후 모든 기기 로그아웃 안내를 제공한다. 다른 회원정보 수정·탈퇴 화면은 해당 서버 API 연결 전까지 확장하지 않는다.

실제 계정의 회원 탈퇴는 기존 ‘탈퇴합니다’ 확인 대화상자를 재사용한다. 소유권 양도 필요 오류를 같은 창에 표시하고 취소·재시도를 허용한다. 탈퇴 때문에 내 정보 수정 폼을 노출하지 않는다.

### 초대·공유 화면

- 초대 상세(368)는 기존 최대 폭 580 모달과 표지 미리보기를 재사용한다. 표지·제목·초대한 사람·참여 인원 다음에 거절/수락을 좌우로 배치한다. 취소·만료·정원 초과 등 사용 불가 상태는 surfaceMuted 안내 판과 목록 복귀 버튼으로 표시하며 수락 버튼을 숨긴다. 기존 받은 카드에는 최소 터치 높이 44의 `초대 확인` 진입을 제공한다.

- 공유 관리(304)는 기존 최대 폭 580의 대화상자와 세로 스크롤을 유지한다. 인원은 `현재/4명`, 역할은 소유자·편집자로 표시한다. 기본 공유 화면에는 이메일로 초대 진입 버튼만 두고 같은 창 안의 별도 이메일 화면으로 전환한다. 이메일 입력은 기존 높이 48 입력칸과 전체 폭 주요 버튼을 사용하며, 보낸 초대는 이메일·상태와 오른쪽 취소 버튼(최소 터치 높이 44)을 배치한다. 정원 안내는 surfaceMuted·radius.md의 판에 표시한다. 유료 이용 준비 안내에 결제 버튼은 추가하지 않는다. 목업 발송과 실제 발송을 문구로 구분한다. 링크 유효기간·제한은 한 줄로 요약하고 전송·취소 결과는 일시적인 토스트로 표시한다. 공통 내보내기 권한과 맞지 않는 허용 토글은 표시하지 않는다.

- 편집기의 공동 작업 진입은 사람 아이콘과 '공유', 파일 출력은 기존 '내보내기'로 구분한다. 보관함 알림은 종 아이콘을 사용하고 응답 가능한 새 초대가 있으면 빨간 점을 표시한다.
- 공유·초대·닉네임 설정은 흰 대화상자(최대 폭 580)로 열고, 좁거나 낮은 창에서는 화면 여백 16과 세로 스크롤을 유지한다. 소유자/참여자 역할에 따라 수정 가능한 동작을 구분한다.
- 다이어리 닉네임은 중복을 허용한다. 참여·프로필 수정에 별도 중복/형식 확인 버튼을 두지 않고 입력 형식만 바로 검증한다. 최종 수락 전까지 참여를 확정하지 않는다. 상세 범위는 [다이어리 초대 공유 화면.md](./화면%20배치/다이어리%20초대%20공유%20화면.md)를 따른다.

- 공유 버튼 옆에는 원형 참여자 프로필을 겹쳐 표시하고, 해당 다이어리 프로필 사진이 있으면 사진을, 없으면 기본 사람 아이콘을 쓴다. 공유 창과 같은 참여자 목록을 사용하며 해제 시 함께 갱신한다. 보기 전용 권한은 제공하지 않는다.
- 공유 창 바깥 터치는 닫기로 처리하고, 카드 내부 터치와 스크롤은 닫기로 전달하지 않는다.

- 다이어리별 프로필 사진은 계정 사진과 독립적으로 변경/초기화할 수 있다. 초대 수락 화면의 원과 공유 설정의 내 프로필 원에서 사진 메뉴를 연다. 사진 선택 취소는 기존 값을 유지한다.

- 참여 후 공유 창의 내 프로필 원은 사진·닉네임 수정 화면을 연다. 변경은 저장 버튼에서 함께 반영하고, 취소 시 기존 프로필을 유지한다. 닉네임 변경 후에는 중복 확인을 다시 수행한다.

- 공유 다이어리는 표지 아래 제목 오른쪽에 작은 사람 아이콘을 표시한다. 표지 위에는 공유 배지를 올리지 않는다. 초대를 수락한 다이어리는 카드 열기와 즐겨찾기를 지원하되 표지 수정·개인 휴지통·개인 일괄 삭제에서는 제외한다.

- 보관함 상단 카테고리는 모든 다이어리·즐겨찾기·공유 다이어리 순서로 표시한다. 공유 목록은 소유·참여 다이어리를 함께 보여 주며, 좁은 폭에서는 카테고리를 줄바꿈한다.

### 알림 수 표시

일반 로그인 사용자의 진입점은 `알림`으로 표시하고 실제 서버의 받은 알림 패널을 연다. 방문자·미리보기의 기존 `받은 초대` 목 흐름과 구분한다. 실제 공유 서버가 연결되기 전에는 로그인 사용자에게 목 수락·거절·공유 생성을 제공하지 않고 연결 준비 안내를 표시한다.


서버의 전체 미읽음 수는 `안 읽은 알림 N개`로 표시한다. 보관함 진입점도 같은 수치를 숫자로 표시하고 접근성 이름에 의미를 포함한다. 좁은 진입점은 아이콘 아래 숫자를 두고 100개 이상은 `99+`로 축약하되 접근성 이름에는 실제 전체 수치를 제공한다. 유효한 미읽음 초대 수가 별도 제공될 때만 `새 초대 N개`와 danger 색 점을 표시한다. 조회 실패 시 이전 값을 유지하고 확인 필요 안내를 함께 표시한다.

알림 종류가 초대로 확인된 경우에만 초대 문구·상태·상세 진입을 제공한다. 일반/미지원 종류는 `알림`과 `새로운 알림이 도착했어요.`로 표시하고 읽음·삭제를 제공한다. 종류 코드나 미확인 payload를 사용자 문구로 노출하지 않는다. 초대 정보가 없는 초대 알림도 읽음·삭제는 가능하다.

알림 오류는401이면 로그인 후 새로고침 안내,403이면 권한 안내,404이면 목록 확인 안내를 제공한다. 이 상태에서는 같은 요청의 직접 재시도 버튼을 제공하지 않는다. 서버/네트워크 오류는 이전 조회 결과와 안내를 함께 표시하고 수동 재시도를 제공한다. 실제 인증 연결 전에는 동작하지 않는 로그인 버튼을 추가하지 않는다.

알림 로딩은 이름 있는 진행 표시와 busy 상태로 전달하고 장식용 스피너는 중복 낭독에서 제외한다. 오류 문구는 alert 역할·polite 알림, 빈 목록은 polite 알림을 사용한다. 재시도 버튼은 오류 문구와 별도로 탐색할 수 있게 둔다. 좁은 가로 화면에서는 내용과 버튼을 줄바꿈하고 목록의 세로 스크롤을 유지한다.

모두 읽음은 API 어댑터가 지원할 때만 표시한다. 서버의 전체 읽음이 분리된 상태에서는 버튼을 숨기며, 기존 목 전체 읽음은 유지한다.

### 마스킹테이프 도구 설정

새 테이프 보관함의 마지막 규격·색상(사용자 지정 바탕색/무늬색 포함)·무늬는 기기 공통으로 기억한다. 패널 닫기·도구 전환·다이어리 이동·앱 재실행 후 복원하고 무늬를 누를 때마다 새 테이프를 붙인다. 설정 복원 자체는 테이프를 삽입하지 않는다. 처음 사용할 때 색상·무늬는 무선택이며, 색상 없이 무늬를 누르면 실제 기본색을 기억한다. 기존에 배치한 테이프의 끝선·불투명도는 요소별 설정이다.

### 새 텍스트 입력창 높이

새 글상자의 입력 높이는 글꼴·줄간격·화면 배율을 따르고 화면 px 기준 고정 최소 높이로 하단 여백을 만들지 않는다. 기존에 사용자가 직접 늘린 상자 높이와 최소 내용 높이 제한은 유지한다.

### 사진 특수 모양의 그림자

하트·별·우표도 공통 그림자 옵션을 제공한다. 실제 사진/프레임의 외곽 경로를 따라 안쪽·바깥쪽 그림자를 표시하고 사각 바탕이 생기지 않도록 한다. 기존 색·방향·거리·퍼짐·흐림·불투명도 설정을 재사용한다.

### 웹 영역 지우기 중 임시 표시

- 회차별 QA 결과와 검증 범위·잔여 위험은 [성능 QA 자료의 최신 확인 상태](./편집%20도구/펜%20성능%20QA%20자료.md)에서 관리한다.

### 필기 도구의 재질 표현

- 펜 종류는 **만년필·펠트펜·붓펜·연필**로 제공하고 형광펜은 별도 도구로 유지한다. 만년필은 기존 필기감과 잉크 표현을 사용한다.
- 펠트펜은 선명한 중심과 부드러운 가장자리를 사용한다. 버전 3은 이전 재질보다 부드러운 가장자리의 비중을 넓히고 획 방향의 미세 잉크 입자를 더한다. 획 전체를 흐리게 하거나 긴 획 끝을 옅게 만들지 않는다. 번짐은 설정한 굵기 안에 포함한다.
- 메뉴 통합을 위해 기존 문서의 종류·좌표·버전을 변환하지 않는다. 기존 볼펜과 버전 1 렌더러는 유지한다. 버전 2 만년필·붓펜은 획 내부 빈틈·끝점 수정과 잉크/페이드 개선으로 외형이 달라진다. 이 의도된 변경은 [펜 QA 문서](./편집%20도구/펜%20재질과%20필압%20QA.md)의 데이터 영향에 따른다.
- 붓펜은 짧은 획을 진하게 유지하고, 긴 획의 뒤쪽만 이동 거리에 따라 서서히 옅게 한다. 새 획은 다시 진하게 시작한다.
- 농도 효과로 획 내부에 구멍을 만들거나 끝을 강제로 뾰족하게 만들지 않는다. 미리보기·저장 화면·출력은 같은 표현을 공유한다.
- 실제 필압 미수신 환경의 속도 보정을 실제 필압 지원으로 안내하지 않는다. 수치와 QA 기준은 [펜 QA 문서](./편집%20도구/펜%20재질과%20필압%20QA.md)를 따른다.
- 신규 만년필·펠트펜은 재질 버전 3을 사용한다. 만년필은 기존 굵기 반응을 유지하며 필압·속도에 따라 잉크 농도를 표현하고, 펠트펜은 위 버전 3 기준의 선명한 중심·부드러운 가장자리·획 방향의 미세 잉크 입자를 사용한다. 버전 3의 새 재질을 기존 버전 1/2 획에 소급 적용하지 않는다. 위 버전 2의 결함 수정과 구분한다.

### 회원정보 수정·회원탈퇴

내 공간에서 회원정보 수정 폼으로 바로 진입한다. 최대 폭 880의 흰 카드(radius.xl)에 프로필 사진·닉네임·이메일·로그인 방식·이메일 비밀번호 변경을 배치한다. 태블릿은 라벨/입력을 가로 배치하고 폰은 세로로 바꾼다. 카드 하단 구분선 아래 왼쪽 회원탈퇴, 오른쪽 취소·변경사항 저장을 둔다. 사진 변경·초기화 전후 배치는 유지한다. 미저장 상태로 나가면 저장하지 않고 나가기/계속 수정하기 확인창을 제공한다. 탈퇴는 탈퇴합니다 문구가 정확히 일치할 때만 활성화되는 대화상자이며 별도 체크박스 페이지는 두지 않는다. 자세한 목업·상태·검증은 [profile-edit.md](./profile-edit.md)를 따른다.
- 내 공간의 프로필 수정은 프로필 영역 오른쪽에 작은 텍스트·화살표로 두고, 폰에서는 이름 아래에 배치한다. 회원 로그아웃은 앱 정보 카드 아래 여백 20을 두고 같은 폭의 별도 테두리 버튼으로 배치한다. 높이 48, radius.md, 흰 바탕·border 테두리·textMuted 글자를 사용한다. 게스트는 프로필 영역에 로그인·회원가입을 표시하고 하단 로그아웃은 숨긴다.

### 회원가입 이메일 인증

회원가입의 이메일·비밀번호 입력 다음에 공통 로그인 카드 안에서 인증번호를 입력한다. 기존 입력칸·버튼·키보드 회피를 재사용하고, 6자리 숫자·남은 시간·재전송 대기·오류·완료 상태를 표시한다. 실제 앱은 서버 발송·확인 API를 사용한다. 개발용 임시 인증은 명시적 테스트 화면에서만 안내하며 배포 화면에서는 제공하지 않는다. 발송 제한의 대기 시간은 기존 발송/재전송 버튼에 표시하고 대기 중 비활성화한다.

- 이메일 인증 완료 시 입력 관련 컨트롤을 공용 체크 아이콘과 완료 안내로 교체한다. 원형 배경은 primarySoft, 아이콘과 글자는 text, 다음 버튼은 primaryStrong을 사용한다.
- 개발 서버 Basic 접근 인증에 막힌 개발 모드에서만 공용 입력칸(ID·비밀번호)과 주요 버튼을 표시한다. 제품의 이메일·비밀번호와 구분해 ‘개발 서버’ 접두사를 쓰고 비밀번호는 가림 처리한다. 배포 모드에는 표시하지 않는다.
- 로그인도 같은 접근 인증 입력을 재사용한다. 계정 입력 아래에 배치하고 주요 버튼은 ‘접속 인증 후 로그인’ 하나를 표시한다. 접속 비밀번호 입력은 제출 후 비우며 기존 로그인 오류·키보드 회피 스타일을 유지한다.

## 스티커 자동 분리 화면

- 묶기 패널에는 직접 묶기와 직접 분리를 함께 둔다. 직접 분리는 여러 원본 조각으로 구성된 카드만 활성화하고, 카드 선택 후 하단 ‘선택한 묶음 분리’로 확정한다. 선택 체크는 저장 포함 여부와 분리하며 취소하면 저장 구성을 유지한다. 확정 후 원래 조각 카드로 돌아가고 실행 취소/다시 실행을 제공한다. 픽셀 자르기 도구로 표시하지 않는다.

- 꾸미기 보관함의 일반 변경 저장에 실패하면 제목 아래에 `danger` 테두리·글자와 `surface` 배경의 안내를 표시한다. ‘다시 저장’ 버튼은 최소 높이 44이며 저장 중에는 비활성화하고 ‘다시 저장 중…’으로 표시한다. 저장 성공 후 안내를 지우며, 실패 안내와 현재 편집 내용은 보관함 재진입에서도 유지한다.

- 이미지 선택 후 배경은 자동 추정한다. 수동 배경 지정과 허용 범위는 ‘배경’ 도구에 접어 둔다. Android의 사용 영역은 이미지 선택 시 전체 이미지로 지정한다. 영역 패널에는 영역 조정 버튼만 두고 전체 영역·다른 영역 추가 버튼은 표시하지 않는다. 내부 이동·8개 손잡이 크기 조정으로 수정하고 손을 떼면 확정한다. 손잡이는 `surface` 채움·`primary` 테두리의 10px 사각형이며 주변 44px 범위에서 잡을 수 있다. 확대·축소 버튼 없이 두 손가락 확대·이동과 화면 맞춤·이미지 이동을 제공한다. 이미지 조작 중에는 결과 목록 스크롤을 차단한다.

- 기존 색·모서리·버튼 토큰을 사용한다. 스티커 폴더의 `+`에서 ‘이미지 그대로 추가’와 ‘이미지 분리해서 추가’를 선택한다. 별도 ‘이미지에서 스티커 만들기’ 버튼은 표시하지 않는다. 같은 `+`를 다시 누르면 메뉴를 접으며 폴더 전환 시에도 닫는다. 미지원 환경은 메뉴 안에서 자동 분리만 비활성화하고 이유를 표시하며 기존 이미지 추가를 유지한다. 메뉴의 터치 영역은 최소 44px, 글자는 14px 이상이다.
- 원본 위를 드래그해서 사용 영역을 지정하고, 수동 배경 지점을 원으로 표시한다. 결과는 체크무늬 배경의 가상화 목록에서 확인하며 선택은 테두리·체크로 구분한다. 작은 장식 필터는 선택 상태를 바꾸지 않는다.
- 처리·저장 상태는 텍스트와 진행 표시로 알린다. 배경·영역 설정이 바뀌면 재분리 후 저장하도록 안내한다. 모달은 안전 영역을 반영하고 기존 화면의 입력을 차단한다.
- Android 개발 빌드의 거리 묶기·브러시 선택은 원본 위에 `primary` 테두리와 번호로 예상 PNG 묶음을 표시하고, 제외한 후보 영역은 `surface` 반투명 덮개와 `textMuted` 테두리로 구분한다. 미리보기 아래에 영역·선택·묶기·배경을 한 줄로 배치하고 한 패널만 펼친다. 처음에는 영역, 분리 성공 후에는 모두 접고 기본 개별 선택으로 돌아간다. 거리 슬라이더(0~5%, 첫 분리에서 20~50개를 목표로 최소 거리 자동 설정)는 묶기, 추가/제외 브러시와 모드별 굵기는 선택에 둔다. 실행 취소·다시 실행은 제목 오른쪽에 둔다. 계산 중에는 마지막 확정 목록을 유지하며 조작·저장을 막고 실패 시 ‘묶음 계산 다시 시도’를 제공한다.
- 브러시 굵기는 화면 기준 8~80(기본 24), 슬라이더 터치 높이는 44, 손잡이는 26이다. 선택 브러시 경로는 `primary`, 제외 경로는 `danger`의 반투명 선과 둥근 끝으로 표시한다. 브러시는 객체 전체에 적용하며 두 손가락은 확대·이동에 사용한다. 원본 픽셀을 지우는 도구로 안내하지 않는다.
- 자동 분리 입력은 Android에서 정지 PNG·JPEG(JPG)·WebP, 출력은 투명 PNG로 안내한다. 미리보기는 이미지와 크기 측정이 준비될 때까지 로딩 표시와 입력 차단을 제공하고, 실패 시 ‘미리보기 다시 시도’를 제공한다. 영역 조정만으로 분석을 시작하지 않으며, 조정한 프레임은 분리하기·다시 분리하기로 분석한다.
- 제목은 ‘스티커 만들기’이며 미리보기 → 접이식 도구 → 최종 묶음 목록 순서를 유지한다. 작은 회색 설명 문단·카드별 해상도를 표시하지 않는다. 이름·설정값·상태·오류는 14px 이상 진한 글자, 버튼 터치는 최소 44px이다. 이미지 이동·화면 맞춤은 미리보기 안에 모으고, 하단에는 현재 단계의 주요 버튼 하나와 폴더 입력/폴더명을 고정한다.
- 최종 묶음 카드는 외곽 면적 내림차순(동률은 분석 순서)이며 원본 번호·목록·저장 순서를 일치시킨다. 체크무늬 위에 구성 PNG를 원래 상대 위치대로 배치하고 번호·포함 체크만 표시한다. 탭은 묶음 전체 제외, 길게 누르기는 확대다. 직접 묶기에서만 임시 묶기 대상을 선택하며 다른 저장 대상을 유지한다. 모두 선택·모두 제외·외곽 면적 64px² 이하 필터는 목록 더보기에 둔다. 필터는 저장 선택을 바꾸지 않는다.

### 페이지 선택 삭제 버튼 모양

선택 삭제와 다이어리 초기화의 기존 위치·순서·선택 진입 방식은 유지한다. 선택 삭제는 흰 바탕·border 테두리·radius.sm에 danger 휴지통 아이콘과 글자를 중앙 배치한다. 선택 개수는 기존 상단 표시를 사용하며 버튼의 접근성 이름에는 개수를 유지한다. 초기화는 surfaceMuted 바탕·textMuted 글자의 보조 버튼으로 낮춰 표시하고 기존 위험 동작 확인창을 유지한다. 삭제·초기화 버튼의 시각 높이는 최소 38, 버튼 간격은 6으로 두며 상하 hitSlop 3으로 터치 높이 44를 확보하고 인접 터치 범위는 겹치지 않게 한다. 선택 삭제·다이어리 초기화 글자는 기존 작은 탭 기준인 11.5/700으로 맞추며 하단 이동이나 더보기 메뉴는 추가하지 않는다.
- 페이지 목록의 `편집` 진입은 기존 위치에서 연필 아이콘·textMuted 글자·흰 바탕·border 테두리의 전체 폭 버튼으로 표시한다. 시각 높이는 32, 모서리 8, 글자 11.5/700·textMuted이며 위아래 hitSlop 6으로 터치 높이 44를 유지한다. 전체/북마크 줄로 옮기거나 기존 길게 누르기 선택 방식을 변경하지 않는다.
- 선택 모드의 `완료`는 기존 선택 개수 줄 오른쪽에 콘텐츠 너비·가로 여백 12·높이 28·모서리 7의 흰 버튼으로 표시한다. 절반 너비로 늘리지 않는다. 글자는 기존 작은 탭 기준인 11.5/700·textMuted를 적용하고 기존 hitSlop 8을 유지한다. 레이어 패널의 해제는 변경하지 않는다.
- 페이지 목록의 전체·북마크 탭과 선택 개수는 기존 작은 탭 기준인 11.5/700·textMuted로 표시한다. 선택된 탭은 text로 강조하고 선택 삭제는 danger를 유지한다. 완료는 작은 탭 기준을 따르며 나머지 버튼 높이·위치·동작은 유지한다.

### 웹 페이지 목록 썸네일 표시

- 무거운 페이지(표시 획 64개 이상 또는 좌표 8192개 이상)의 썸네일은 정밀 완성 획 캐시에서 만든 별도 축소 비트맵을 재사용한다. 문서 객체 참조·순서와 페이지 크기가 모두 일치할 때만 재사용한다.
- 축소 캐시는 최대 256개·총 1M 픽셀의 LRU 보관 예산을 둔다. 화면에서 사용 중인 버퍼는 별도로 살아 있을 수 있다. 캐시가 없으면 최대 2획씩 창 표시 후 700ms 유휴 대기와 작업 사이 32ms 간격을 두어 생성하고, 실패·예산 초과 시 정밀 SVG를 표시한다.
- 원본 필기·저장·Undo/Redo·내보내기 데이터는 변경하지 않는다. 작은 페이지와 네이티브 썸네일은 기존 표시를 유지한다. 임시 간소화된 질감을 썸네일 원본으로 사용하지 않는다.

### 회원 페이지 텍스트 저장 상태

기기 자동 저장 표시와 별도로 현재 페이지 텍스트의 서버 확인/전송/저장/충돌/연결 실패를 표시한다. 최초 양쪽 텍스트와409에서는 기기 내용을 유지하고 자동 덮어쓰기를 중단한다. 서버 연결 실패 표시를 누르면 내용을 유지한 채 재시도하며, 충돌 상태를 재시도만으로 강제 해소하지 않는다. 사진/필기 전체가 서버 저장됐다는 문구는 사용하지 않는다.

## 새 다이어리 · 다이어리 수정 (구역 카드 작업대)

- 두 화면은 같은 틀(`diary/components/Workbench.js`)을 쓰고 화면 전체를 채운다(띄운 창 · 뒤 막 없음): 위 막대(취소 · 제목 · 주요 버튼 높이 44 `primaryStrong`) | 왼쪽 구역 카드(폭 200, 아이콘 판 44 · 이름만, 오른쪽 안쪽 20, 모서리 18, 선택 = 흰색 + 2 `primary`) | 가운데 미리보기 판(모서리 24) | 오른쪽 옵션 패널(폭 420, 안쪽 16). 폰은 구역 카드를 위쪽 가로 알약 줄로, 미리보기를 높이 240 판으로, 옵션을 남은 높이에 둔다.
- 구역은 **'이름 · 방향' '표지' '속지' '속지 색'** 이고 순서 없이 오간다. 미리보기는 지금 고치는 것만 보인다(이름 · 방향 = 표지 + 첫 속지 나란히, 표지 = 표지만, 속지 · 속지 색 = 속지만).
- 메뉴 이름은 고치는 대상을 그대로 쓴다. '판' · '자리' · '적용' 처럼 뜻을 짐작해야 하는 말 대신 '모양' · '위치' · '바꿀 페이지'를 쓰고, 같은 것을 두 이름(무늬 · 패턴)으로 부르지 않는다.
- 요소 줄(`ElementRow`): 높이 52, 모서리 16, 펼치면 테두리 `primary`. 한 번에 한 줄만 펼친다. 켜고 끄는 요소는 스위치를 두고(고무줄은 줄 머리, 소제목은 '제목 · 소제목' 안), 스위치는 펼치지 않는다. 꺼도 설정은 남긴다.
- 화면 안에 사용법 설명 문장 · 캡션을 두지 않는다. 오류와 결과 알림만 짧게 보인다.
- 폭을 잰 뒤 다시 그리는 배치를 쓰지 않는다(처음 그린 버튼이 위아래로 밀린다). 격자는 고정 크기나 비율 폭으로 그린다. 속지 미리보기는 노트까지 실제 속지 SVG 로 그린다. 줄 · 모눈 · 도트는 크기와 상관없이 선은 화면 1px · 점은 지름 2px · 색은 팔레트 한 단계 진하게 그려 또렷하게 보인다. 폭 160 아래 칸은 통째로 줄이면 선이 사라지므로 실제 속지 왼쪽 위 일부(폭 260, 모눈 · 도트는 페이지 끝부터 · 줄은 여백 안쪽부터)를 확대해 보인다.
- 표지는 위 세 갈래(표지 없음 · 색 · 무늬 · 사진)가 배경만 바꾸고, 요소 줄은 **'배경' '고무줄' '제목 · 소제목' '라벨 · 위치' '스티커'** 다섯이다. 한 값은 한 곳에서만 고친다: 글씨(제목 내용 · 소제목 · 글씨체 · 크기 · 색)는 '제목 · 소제목', 모양(종이 라벨 · 띠지 · 없음) · 띠지 색 · 위치(9칸)는 '라벨 · 위치'. 종류를 바꿔도 다른 요소 값은 그대로 둔다.
- 표지 크기는 고무줄을 켜고 끄거나 방향을 바꿔도 같다. 본체는 늘 네 변을 고무줄이 튀어나오는 폭만큼 줄여 그리고, 고무줄은 그 바깥 끝까지 그린다.
- 띠지는 위아래 가장자리 안쪽(짧은 변 200 기준 4)에 제목 색 32% 의 가는 인쇄선 두 줄을 둔다. 소제목이 없으면 위아래 안쪽 여백을 15 → 19 로 늘려 제목 한 줄만으로도 띠 모양을 갖춘다.
- 표지 미리보기에서 라벨을 끌어 옮긴다(띠지는 위아래로만). 끄는 동안만 점선 테두리를 보이고 손을 떼면 지운다. 9칸을 고르면 옮긴 자리를 지운다.
- 표지 위 스티커는 **편집기 캔버스와 같은 손놀림 · 모양**이다: 누르면 고르고 바로 끌어 옮긴다. 고르면 1.5 `primary` 실선 테두리 · 네 모서리 손잡이(18, 맞은편 모서리를 고정한 크기 조절) · 위쪽 회전 손잡이(테두리에서 34, 0 · 90 · 180 · 270° 에서 걸림)가 보이고, 스티커 아래(자리가 없으면 위)에 복제 · 삭제 바가 뜬다. 옮기거나 돌리는 동안은 바를 숨긴다. 끄는 동안은 그 스티커만 다시 그리고 손을 뗄 때 한 번만 표지 값을 바꾼다. 스티커는 편집기 보관함과 같은 분류(즐겨찾기 · 최근 · 출처별 · 내 폴더)를 쓰고, 처음에는 비어 있지 않은 첫 칩(즐겨찾기 → 최근 → 첫 분류)을 연다. 보관함 칸은 128px 썸네일로 그린다.
- 고무줄 색은 견본 줄 맨 앞 '맞춤'을 기본으로 둔다: 색 표지는 바탕(그라데이션은 아래쪽 색)을, 사진 표지는 사진의 대표 색(가장 많이 보이는 색 계열, 무채색 사진은 평균색)을 조금 어둡게 쓴다.
- 속지는 **한 줄 목록**으로 넣는 차례대로 둔다(전체 2000장). 새 다이어리는 비어 있고, 비어 있으면 빈 페이지 한 장으로 만든다. 묶음 · 펼치기 카드는 두지 않는다.
  - 속지는 한 종류씩만 둔다. 표지 · 구분지 · 월간 · 주간을 미리 묶은 세트나 '추천' 표시를 두지 않는다. 미리 골라 둔 속지도 없다.
  - 줄은 `미리보기 · 이름 · ▾ | 위로 | 아래로 | 빼기 | 끌기 손잡이`, 그 아래 넣는 양. 위로 · 아래로는 이웃 속지와 자리만 바꾸고 이어서 · 섞어서 자리는 그대로 둔다. 손잡이를 끌면 줄이 따라오고(그림자, 놓을 자리에 3 `primary` 선), 섞인 판 안에 놓으면 그 판에 들어가고 아니면 혼자 이어서 들어간다. 이름을 누르면 그 줄 아래에 고르기(분류 탭 노트 · 플래너 · 일기, 밑줄 2.5 `primaryStrong` → 속지 타일 3열)가 펼쳐져 그 자리에서 바꾼다. 맨 아래 점선 '속지 더하기'도 고르기를 먼저 펼치고, 고른 속지는 목록 끝에 이어서 들어간다(장수 속지 10장).
  - **섞기는 이웃한 두 속지 사이의 `이어서 | 섞어서` 하나로만 한다**(높이 28 알약 둘, 고른 쪽 흰 바탕 + `primaryStrong`). 섞은 속지들은 한 판(1.5 `primary` 테두리 · `primarySoft` 바탕)에 묶여 보인다. 장수 속지 둘을 섞으면 적은 쪽 장수만큼 번갈아 반복(일기 30 · 사진 10 → 일기 3 → 사진 1 을 10번)하고, 판 아래에 반복 횟수와 넣는 차례 · 장수를 보인다(예: 하루 일기 3장 → 사진 · 스크랩 1장을 10번 반복 · 모두 40장. 장수 뒤에 '장'을 붙여 조사는 늘 '을'이다). 다시 이어서로 나누면 반복만큼 장수로 펼친다.
  - 판에 날짜 속지(구분지 · 월간 · 주간)가 있으면 달마다 위에서부터 넣는다(이어진 주간 · 매주 줄은 주마다 번갈아). 날짜 속지 줄은 '매달 1장' · '매주 1장', 표지는 '처음 1장'으로 맨 위, 다른 속지는 처음 · 매달 · 매주 · 매일 + 장수(10장까지)를 한 줄에 고른다(섞을 때는 매달 1장부터). 판 아래 '기간 2026.01 – 12 ▾'를 누르면 날짜 있음/없이 · 시작(`‹ 2026년 ›` `‹ 3월 ›`) · 개월이 펼쳐진다.
  - 가운데 미리보기는 첫 장을 크게, 그 아래에 처음 8장을 작게 순서대로 보여 섞인 차례를 확인한다.
- 노트 속지의 모눈 · 도트는 여백 없이 페이지 끝까지 깐다. 가장자리에 선 · 점이 한 줄로 붙어 보이지 않도록 네 변의 남는 폭을 같게 나누고, 칸(28)의 1/3 보다 좁으면 한 칸을 더 비운다(세로 20 · 22, 가로 22 · 20). 선 · 점 색은 속지 팔레트 안의 색(모눈 · 줄 `#D7D9DC`, 도트 `#BFC1C4` 반지름 1.4)만 써서 선 · 글자 색을 바꾸면 함께 바뀐다. `frontend/scripts/generate-note-grids.py` 로 다시 만든다.
- 편집기 '페이지 추가'는 작업대 없이 약식 버블이다: 페이지 목록의 '페이지 추가' 옆(폰은 화면 아래 가로로 꽉 차게, 태블릿 폭 340)에 머리(＋ 페이지 추가 · 닫기) + 분류 탭 + 속지 타일 3열(장수 속지만, 실제 속지 미리보기)을 띄우고, 타일을 누르면 지금 페이지 뒤에 한 장을 넣고 닫는다. 바깥을 누르면 닫힌다.
- 숫자는 `− [값] + 단위`(± 40×40 · 값 칸 56×40, 모서리 9)이고 자주 쓰는 값은 칩으로 옆에 둔다.
- 색은 한 줄 **7칸 격자**(`SwatchGrid`, 칸 크기는 폭에 맞춰 최대 44, 선택 고리 2 `primary`)로 고른다: 견본은 한 줄 6색까지 + 맨 끝 칸은 '직접 고르기'(점선 +, 고르면 그 색으로 채움, 누르면 아래에 색 고르기와 HEX 입력이 펼쳐짐). 다음 줄(그라데이션 등)도 같은 열에 맞춘다. 펼치는 색 고르기는 한 번에 하나만 연다.
- 표지 바탕은 첫 줄 단색 6 + 직접 고르기, 둘째 줄 그라데이션 6 + 직접 고르기(위 색 · 아래 색). 다이어리 기본 바탕색은 크림 · 라떼 · 더스티 로즈 · 세이지 · 스카이 · 차콜(기본 스카이)이다.
- 무늬는 지금 바탕색에 무늬를 그린 48 타일 4열 + 이름, 글씨체는 같은 폭 3열 칩에 그 글씨체로 쓴다.
- 펼친 요소 줄이 패널 밖이면 보이도록 스크롤한다. 꺼진 요소(고무줄)의 옵션은 고칠 수 있게 두되 0.45로 흐리게 보인다.
- 다이어리 수정은 바꾼 것이 있을 때만 '저장'을 켠다. 바꾼 채로 취소하면 '저장하지 않고 닫을까요?'를 한 번 묻는다.
- 줄을 넘기는 칩 묶음(`ChipGroup`)은 높이 36 알약, 선택 = 흰 바탕 + 1.5 `primary`, 아님 = `surfaceMuted`.
