# DIO 디자인 가이드 (BI · CI · 인앱 UI)

- **재실행 로그인 복원(F-02):** 저장 로그인 복원 실패 시 게스트 보관함으로 자동 전환하지 않는다. `회원 보관함을 열지 못했어요` 안내와 `연결 재시도`(채움)·`다시 로그인`(윤곽)·`게스트로 계속`(글자) 선택을 제공한다. 회원 다이어리를 아직 불러오지 못한 상태와 게스트 보관함의 차이를 설명한다. 재시도 중 중복 선택은 막고, 로그인 취소 시 복구 화면으로 돌아온다. 폰·태블릿은 같은 세로 배치(최대 폭 480, 좁은 화면 스크롤)를 쓴다.

- **인증 오류 복구(F-36·F-37):** 회원 기능에서 인증이 거절되면 안내와 함께 최소 44dp `다시 로그인` 버튼을 제공한다. 로그인은 기존 화면 위에서 열고 기존 이메일만 채우며 비밀번호는 비운다. 네트워크 단절·서버 오류는 로그인 만료로 표시하거나 세션을 지우지 않고 해당 화면의 다시 시도로 복구한다. 알림 수와 목록이 함께 인증 오류면 같은 안내를 중복 표시하지 않는다.

> **시스템 글자 확대(2026-11-04):** 일반 UI의 공통 글자·입력은 기본 1.3배까지 확대한다. 긴 이용약관과 공용 확인창은 확대 상한 없이 표시하며, 확인창은 내용 스크롤과 최소 높이 버튼을 사용한다. 속지와 캔버스 요소·편집 글자는 문서 좌표와 일치하도록 시스템 글자 확대를 적용하지 않는다. Android·iOS에서 최대 글자 크기 실기기 확인이 필요하다.

> **앱 오류 복구(2026-11-04):** 전체 렌더 오류는 surfaceSoft 바탕·`text` 본문·primaryStrong 채움 버튼의 전체 화면 안내로 표시한다. 오류 화면은 SVG·편집기·세션 Provider 없이 기본 컨트롤만 쓰고 Pretendard 미등록 시 시스템 글꼴로 읽게 한다. 본문 최대 너비 480·안쪽 여백 24·간격 16, 제목 20/700·본문 15/24, 버튼 최소 높이 48·모서리 10·15/800을 기존 버튼 체계에 맞춘다. 안전 영역·세로 스크롤·글자 확대를 유지하고 눌림·페이드·자동 재시도는 없다. ‘다시 시도’만 앱 화면을 다시 구성하며 미저장 변경 가능성을 안내한다. [동작·검증](./app-error-recovery.md).

> **가입 문서 열람(2026-11-03):** 기존 ‘보기’는 내장 문서를 전체 화면으로 연다. 라이선스 화면과 같은 안전 영역·상단 제목/닫기·`text` 본문·세로 스크롤을 쓰며, 필수·선택 동의서는 기존 auth 채움 버튼 모양의 ‘동의하고 돌아가기’를 하단에 둔다. 그 버튼만 해당 항목을 선택하며 닫기·기기 뒤로가기는 기존 선택을 유지한다. 개인정보처리방침은 동의 버튼 없이 ‘닫기’만 제공한다. 폰·태블릿에서 본문·제목·버튼 글자를 줄 수/고정 높이로 자르거나 축소하지 않으며, 태블릿 본문 최대 너비는 800이다. 눌림·페이드 효과는 추가하지 않는다. 문서 본문에 별도의 체크 없는 ‘동의합니다’ 문장은 넣지 않는다.
> **색 창·팔레트 통합(2026-11-03, 사용자 확정):** 앱의 ‘내 색상’ 컬렉션 UI는 제거한다. 기본 팔레트는 ‘팔레트 편집’ 모드에서 기존 칸의 색만 변경하며 추가·삭제하지 않는다. 펜·형광펜은 기본색 7개 옆에 현재 색 직접 지정용 + 원을 별도로 둔다. 최근 실제 사용 색은 8개이며 기본색과 같은 28dp 원·폭 1/8/높이 38dp 칸으로 정렬한다. 색 창은 PresetColorEditor 하나로 통일하고 제목/X·구분선·SV·색상/채도/명도·HEX 오른쪽 스포이드 아이콘을 둔다. 정상 닫기는 확정한다. 앱 스포이드는 전체 화면 캡처와 기존 공용 원형 돋보기·새 색/원래 색 반원 링·상단 알약 연출을 쓴다. 웹은 브라우저 EyeDropper를 사용한다. 아래의 이전 ‘내 색상’·7개 최근색·캔버스 전용 스포이트 규칙보다 이 항목이 우선이다. [사용·저장·검증](./color-picker-unification.md).

> **사진 추가 진입(2026-11-03):** 홈 독립 미디어 메뉴 없이 편집기 사진 버튼에서 ‘새 사진 추가 / 최근 추가한 사진’을 제공한다. 스티커·위젯과 같은 renderPanel 경로를 사용한다. 폰 세로는 PhoneSheet 하단 시트, 태블릿·폰 가로는 toolPopoverStyle 앵커 패널이며 toolPanelStyles.card·ToolPanelHeader를 재사용한다. 폰 시트 내부 높이·너비는 부모가 정하고 제목 드래그로 닫기를 지원한다. 별도 제목줄·중앙 Modal·배경 어둡게 처리는 두지 않는다. 폭 320, 제목 15/700, 공용 안쪽 여백 16·구역 간격 10을 따른다. 선택 항목은 패널 안쪽 너비를 채우는 윤곽 버튼 두 줄로 정렬한다. 앞 아이콘은 두지 않고, 사진 선택 항목 오른쪽 끝에 작은 chevronRight(14px·textMuted)를 둬 다음 단계 이동을 표시한다. 목록은 서버의 생성일 내림차순을 유지한다. 선택 항목은 높이 44·글자 12.5/600의 작은 윤곽 버튼이며 큰 아이콘 박스·설명 문구를 반복하지 않는다. 올린 사진은 패널 내부 2열 격자로 표시한다. 기기 전용 다이어리는 서버 사진 선택을 비활성화한다.


> **회원가입 약관 정리(2026-11-02):** 가입 전 화면은 연령 선택 다음에 ‘약관 및 개인정보’를 둔다. 필수 동의 2개만 ‘필수 항목 전체 동의’로 묶고 개인정보처리방침은 체크 없는 보기 행으로 구분한다. 마케팅 4개 항목은 ‘마케팅 수신 동의 (선택)’ 아래 필수 약관과 같은 테두리·체크박스·행 간격으로 표시하고 각 항목에 [선택]을 붙인다. 연령 확인과 약관 영역 사이에는 cardBorder 구분선을 둔다. 기존 auth 카드·Pretendard·색 토큰을 유지하며 필수 묶음은 cardBorder 1px·모서리 12, 행·보기 버튼 터치는 최소 44다. 약관 제목·행은 `text`, 보기만 primaryStrong을 사용하고 눌림·페이드 효과는 넣지 않는다. 생년월일 미수집·서버 전송 여부 같은 구현 설명은 가입 화면에 노출하지 않는다.

> **인증 메일(2026-11-06):** 가입·비밀번호 재설정 메일은 외부 CSS·JavaScript 없이 인라인 CSS만 쓴다. 바탕은 `surfaceSoft`(`#F8F7FD`), 본문은 흰 카드(`#D9D8EA` 1px · 모서리 16), 인증번호는 `lavender100`(`#DDDAF5`) 카드에 크게 표시한다. 보조 글자는 메일 호환성을 위해 투명도가 없는 `#6B6B6B`을 쓴다. 카드 최대 폭은 480, 안쪽 여백은 28이며, 제목·번호·만료 시간·요청하지 않은 경우의 안내를 텍스트로도 함께 제공한다. HTML을 지원하지 않는 메일 클라이언트에는 같은 내용을 일반 텍스트로 보낸다.

> **2026-10-31 전면 개편 — 1020 감성 B안 '사진부 아카이브'(사용자 선택, [docs/1020 감성 점검](1020%20감성%20점검/1020%20감성%20점검.md)).** 아래 각 장의 옛 값과 다르면 이 상자가 우선이다.
> - **글꼴:** 앱 UI 글자는 모두 **Pretendard**(Regular · Medium · SemiBold · Bold · ExtraBold, `assets/fonts/pretendard`). 화면 코드는 그대로 `Text` · `TextInput`을 쓰고, `metro.config.cjs`가 앱 코드의 것을 `src/shared/dioText/DioText.js`로 바꿔 끼운다. 굵기는 파일 이름으로 고른다(안드로이드 가짜 굵기 방지).
> - **굵기 단계(`uiWeight`):** 적어 둔 굵기를 글자 크기에 따라 낮춰 읽는다. 20 이상 그대로(900 → 800), 16~19는 600 → 500 · 700 → 600 · 800↑ → 700, 16 미만은 600 · 700 → 500 · 800 → 600 · 900 → 700. 새 화면도 지금처럼 700 · 800을 적으면 된다.
> - **정해진 글꼴은 그대로:** 속지 · 특수 속지(날짜 · 플래너 · 디데이 등) · 캔버스 요소 · 사진 틀 글자는 Pretendard를 넣지 않는다. 글꼴을 직접 정한 글자(`fontFamily`)도 그대로 두고, 페이지 그림은 `KeepFont`(`src/shared/fontScope.js`) 안에서 그린다(`PageBackground` · `PageObject`). 입력칸은 `dioFont={false}`로 뺀다.
> - **표지 제목(2026-11-05):** 새 표지의 제목 기본 글꼴은 **Pretendard Bold**다. 이미 저장된 표지 글꼴은 바꾸지 않는다. 글자 도구 · 도형 기본값(나눔고딕)과 속지 인쇄 글자(마루부리)는 그대로다.
> - **바탕 · 모서리 · 그림자:** 앱 바탕 `surfaceSoft` = `#F8F7FD`(옅은 페리윙클 종이, 질감 없음). 모서리 사진 틀 8 · 버튼 10 · 카드 · 말풍선 12 · 큰 판 16. 그림자는 거의 쓰지 않는다(카드 6% · 아래 6 · 흐림 8, 떠 있는 판 10%).
> - **선택 표시:** 칩 · 2분절은 **테두리 칩**(흰 면 + `cardBorder` 1px, 고르면 `primaryStrong` 테두리 · `text` 글자). 보관함 보기 전환만 2026-11-01부터 아이콘 묶음 판이다(아래 '보관함 다듬기' 항목). 회색 판 위 흰 알약 · 네이비 채움 · 아래 깊이선은 쓰지 않는다. 켬 · 끔은 52×32 **스위치**.
> - **채움 버튼:** `primaryStrong` 면만(아래 깊이선 없음). **눌림 효과는 앱 어디에도 두지 않는다**(흐려짐 · 작아짐 · 색 바뀜 모두). 결과 연출(스티커 착지 · 도장 등)도 두지 않는다.
- **뜰 때 페이드 없음(2026-11-01):** 창 · 대화상자 · 말풍선 · 메뉴 · 시트는 뜰 때 서서히 나타나는 효과(`Modal animationType="fade"`)를 쓰지 않는다. 즉시 뜨고 즉시 사라진다(`animationType="none"`). 전체 화면이 아래에서 올라오는 `slide` 모달(손글씨 공방 · 속지 분리 · 라이선스)은 아직 남아 있다.
> - **선택 모드(보관함 · 휴지통 공용, `SelectionBar` · `SelectionButton` · `SelectionMark`):** 들어가는 길은 카드 길게 누르기 하나다(보관함 · 휴지통 모두 `선택` 버튼을 두지 않는다, 사용자 결정). 꾹 누른 손가락을 떼도 고른 카드는 풀리지 않는다(선택 중에도 카드가 `onLongPress`를 늘 넘겨 긴 누름이 눌림을 취소하게 한다). 도구줄은 모서리 16 · `cardBorder` 1px 흰 판에 왼쪽 `n개 선택됨`(13/700), 오른쪽 버튼(높이 40 · 모서리 10 · 12/700, 터치 44는 hitSlop)이다. 순서는 `전체 선택` → **주 동작**(`휴지통으로` · `복원` · `영구 삭제`) → `완료`이고 선택 모드를 끝내는 `완료`는 늘 맨 오른쪽이다. 버튼 색: `전체 선택` · `완료` = 흰 윤곽, 주 동작(`휴지통으로` · `복원`) = `primaryStrong` 채움 + 흰 글자(네이비 채움 금지), `영구 삭제` = 흰 면 + `#F0D5D4` 윤곽 + `dangerStrong` 글자 · 아이콘. 고른 카드는 오른쪽 위 체크 원만 `primaryStrong`으로 차고 표지에 윤곽은 두르지 않는다. 선택 바 아래 첫 줄은 보관함 한눈에 보기와 같은 간격(16 · 폰 28)에서 시작한다. 코덱스 설계(2026-10-31), 영구 삭제 윤곽은 Claude 조정.
> - **빈 상태 제목:** 마침표 없이 쓴다(`휴지통이 비어 있어요` · `아직 만든 폰트가 없어요`). 휴지통 · 보관함 한눈에 보기 표지는 같은 선반 배치(표지 아랫변을 맞추고 가운데로 내려앉히지 않는다)다.
> - **확인 · 안내 창:** 브라우저 `confirm` · OS 기본 경고창을 쓰지 않는다. `shared/dialogs`의 `confirmAction` · `notify`가 앱 맨 위 `DialogHost`를 거쳐 `ConfirmDialog`(폭 320 · 모서리 24)로 뜬다. 확인 버튼은 되돌릴 수 없는 동작(영구 삭제 등)만 `dangerStrong` 채움이고, 휴지통으로 옮기기처럼 30일 안에 되돌릴 수 있는 동작은 `confirmAction({ danger: false })`로 `primaryStrong`이다. `notify`는 `확인` 버튼 하나다.

## 0. 이 문서 쓰는 법

1. 새 UI를 만들기 전에 **12장 체크리스트**부터 본다.
2. 색·모서리·그림자는 반드시 `src/shared/theme.js` 토큰을 쓴다. 토큰에 없는 값이 꼭 필요하면 이 문서의 "보조 값" 표에 있는 값만 쓴다.
3. 이미 있는 공용 컴포넌트(9장)를 먼저 찾아 쓴다. 비슷한 것을 새로 만들지 않는다.
4. 이 문서에 없는 새 규칙을 만들었다면 이 문서에 먼저 추가하고 같은 커밋에 넣는다.

### 2.3 색 쓰는 규칙

- 흰 바탕 위 글자 · 아이콘은 `text`가 기본이다. 회색 글자는 `textMuted`.
- 채운 주요 버튼은 `primaryStrong` 위 흰 글자를 쓴다. `primary`는 선택 테두리·슬라이더 등 기존 선 색을 유지한다. 넓은 앱 배경은 `surfaceSoft`, 선택된 도구·메뉴 바탕은 `primarySoft`로 구분한다.
- 흰 바탕의 파란 UI 글자는 `primaryStrong`을 쓴다(일반 크기 대비 4.5:1 이상). 기본 글자는 `text`, 보조 설명은 `textMuted`를 사용하며 `primary`는 글자색으로 쓰지 않는다.
- 선택 상태는 색만 바꾸지 않고 **테두리 또는 그림자**를 같이 준다.
- **색상군은 둘뿐이다**(색 규칙 v2, 조사 [앱 감성 리뉴얼](./앱%20감성%20리뉴얼/06%20감성%20방향%203안.md) §1.1): ① UI 색상 계열(로고 보라~페리윙클, 색상각 240~250°, 2026-11-05)이 **메인**이고 기본 글자 `text`는 무채색 `#1C1C1C`, ② 캐릭터 노랑(`butter` 계열, 색상각 40~53°)이 **보조 하나**. 핑크 · 민트 · 코랄 · 초록 같은 그 밖의 색상군은 바탕 · 카드 · 칩 · 타일 · 장식 · 그림자에 쓰지 않는다. 노랑은 작은 면 · 칩 · 테이프 · 점 · 고리에만 쓰고 바탕 · 카드 · 배너 · 타일 전체에는 쓰지 않는다. 예외는 사용자 콘텐츠(표지 · 사진 · 스티커, 2.4), 외부 로그인 버튼(카카오 · 구글 · 애플), 그리고 **알림 점의 쿨톤 핑크 하나**(`notifyPink`)다.
- 빨강(`danger`)은 **영구 삭제 · 오류**에만 쓴다. 글자와 흰 글자를 올리는 면은 `dangerStrong`, 아이콘 · 테두리는 `danger`. **알림 점은 `notifyPink`(쿨톤 핑크), 휴지통으로 보내기(30일 안에 되돌릴 수 있음) 아이콘 · 버튼은 `text`(네이비)** 로 칠한다.
- 입력칸 경계는 `primary`(흰 바탕 3:1 이상), 선택 테두리는 `primaryStrong`(앱 바탕 위 5.52:1). `border` · `cardBorder`(1.4:1)는 구분선 같은 장식에만 쓴다.
- 회색 바탕(`surfaceSoft`) 위 보라 글자는 `primaryText`.
- 다크 모드는 지원하지 않는다(`userInterfaceStyle: light`).

### 5.1 기준 프레임

| 항목 | 값 |

### 5.2 편집기 (태블릿)

- 폰·태블릿 편집기 최초 진입 시 손 도구를 기본 선택한다. 레이어 패널 열기·닫기와 페이지 이동은 현재 도구를 유지한다. 사진·꾸미기 추가 등 명시적인 선택 도구 전환은 기존 동작을 따른다.

| 영역 | 위치 · 크기 | 내용 |
|---|---|---|
| 상단 바 | 맨 위, 높이 64 | 왼쪽 `< 로고` + "페이지" 토글 · 가운데 다이어리 탭 · 오른쪽 레이어 · 내보내기 · 저장 상태 |
| 페이지 목록 | 왼쪽, 폭 156 (썸네일 124) | 같은 다이어리의 페이지. 위에 전체 / 북마크 탭 |
| 리본 | 캔버스 위 가운데, 위 12 | 도구 아이콘 |
| 캔버스 | 가운데 | 흰 종이 |
| 실행 취소 · 확대 바 | 캔버스 아래 가운데, 아래 12 | 되돌리기 · 다시 실행 · 배율 |
| 레이어 패널 | 오른쪽, 폭 280 | 오브젝트 순서 · 보이기 · 잠금 |
| 바탕 | 전체 | `surfaceSoft`, 바깥 여백 16 · 영역 사이 16 |

- 상단 바 왼쪽 묶음은 글자가 표시될 때 페이지 목록 폭에 맞춘다. 창이 좁아 페이지 버튼 글자를 숨기면 글자와 내부 간격만큼 묶음 폭을 줄여 홈과 페이지 버튼 사이 간격을 유지하고, 뒤의 다이어리 탭도 함께 당긴다.
- 도구 옵션 패널은 누른 도구 아이콘 아래 **8** 띄워 열고, 아이콘 가운데에 맞추되 편집 영역 좌우 8 안으로 제한한다. 아래쪽 64는 비워 둔다.

### 5.3 편집기 (폰)

- 세로 상단 바의 가운데는 다이어리 이름 한 줄과 연필만 둔다(이름 아래 쪽수 없음). 연필은 오른쪽 44 아이콘과 중심선이 같다.
- 세로: 짧은 상단 바(60) + 가로 도구 막대. 순서: 손 · 선택 · 올가미 | 펜 · 형광펜 · 지우개 · 텍스트 | 스티커 · 테이프 · 사진 | 보조선.
- 가로: 왼쪽 레일(홈 · 페이지 | 회전 · 레이어 · 내보내기 · 집중) + 오른쪽 도구 레일, 각 62.
- 페이지 목록 · 레이어는 캔버스 위에 떠서 열린다(위아래 8, `shadow.float`).

### 5.4 읽기 모드

- 편집 화면 오른쪽 아래에 화면 맞춤과 눈 아이콘을 나란히 둔다. 읽기 모드에서는 화면 맞춤·편집 전환을 하단 페이지 메뉴 안으로 통합하고 별도 플로팅 버튼은 표시하지 않는다.
- 읽기 상단은 높이 56이며 왼쪽 홈 버튼, 중앙 다이어리 제목, 오른쪽 빈 영역으로 구성한다. 제목 양쪽의 영역 폭을 같게 해 제목을 가운데 정렬한다.
- 하단은 하나의 surface 배경 안에 왼쪽 현재/전체 페이지, 중앙 이전·진행 슬라이더·다음, 오른쪽 화면 맞춤·편집 전환을 배치한다. 모든 조작의 터치 영역은 44 이상이다. 이전·다음 버튼은 짧게 누르면 한 장 이동하고 350ms 누르고 있으면 90ms 간격으로 한 장씩 넘긴다. 손을 떼거나 취소·메뉴 해제·앱 비활성화·첫/마지막 페이지 도달 시 연속 넘김을 멈추며 순환하지 않는다. 폰 가로 편집 도구 레일은 아래 76을 비운다.
- 상·하단은 오버레이로 표시하고 중앙 탭으로 함께 숨기거나 표시한다. 자동 숨김은 없다. 메뉴 표시 전환으로 캔버스를 재배치하지 않는다. 화면 맞춤 계산은 위 64·아래 76·좌우 12를 비워 원본 비율을 유지한다.
- 좌우 각 20%의 짧은 탭은 이전/다음 페이지, 중앙 60%는 메뉴 전환이다. 화면 맞춤 이하 배율에서는 기존처럼 수평 48dp 이상, 수평 이동이 수직 이동의 1.5배 이상이면 속도와 무관하게 한 장 넘긴다. 확대 상태에서는 같은 거리·방향 조건에 더해 250ms 이내·평균 수평 속도 0.5dp/ms 이상일 때만 스와이프로 한 장 넘긴다. 느린 드래그나 세로 이동으로 판정되면 해당 터치가 끝날 때까지 화면 이동으로 유지한다. 확대 중 가장자리 탭도 페이지를 넘기며, 두 손가락이 참여한 동작은 페이지 넘김으로 바꾸지 않는다.
- 읽기 화면에서는 편집 리본·문서 탭·페이지/레이어 패널·선택 표시·실행 취소·저장 상태를 숨긴다. 공유·책갈피·별도 보기 설정은 제공하지 않는다. 링크와 하단 컨트롤은 뷰어 제스처보다 우선한다.
- 모드 전환과 페이지 전환 후 화면에 맞춘다. 마지막 열람 페이지는 기존 개인/세션 저장 범위로 기억하며 배율·이동량·읽기 모드 선택은 저장하지 않는다. 편집 권한이 없는 문서는 읽기로 시작하고 편집 전환을 제공하지 않는다.

### 5.5 다이어리 홈

- 태블릿: 왼쪽 사이드 레일(접힘 78 / 펼침 218) + 본문. 본문 여백 30 / 38.
- 폰: 편집기를 제외한 모든 화면에 상단 오른쪽 알림 아이콘(44×44)과 하단 탭 5개(내 기록 · 공유 · 공방 · 휴지통 · 마이페이지, 2026-11-05). 설정은 마이페이지 톱니로 들어가고 제목 왼쪽 `‹`(48)로 돌아가며, 그동안 `마이페이지` 탭이 선택 상태다. 보관함 보기 전환(펼쳐서 · 스와이프 · 한눈에)은 폰에서 `⋮` 메뉴 안, 태블릿에서 머리줄의 글자 있는 분절이다. 게스트는 프로필을 고치지 않는다(수정 입구 없음). 하단 바는 화면 폭을 꽉 채운 흰 면(높이 64 + 제스처 영역까지 연장, 위 `cardBorder` 1px, 모서리 0, 2026-11-05 사용자 결정)이며, 선택 아이콘 뒤에는 `primarySoft` 알약 56×32(모서리 16)을 둔다. 내 공간 제목 줄에는 폰에서만 설정 아이콘을 둔다. 본문은 2열 그리드, 좌우 여백 14 · 위 16, 제목 24/800(줄 44), 보기 전환 34×34 · 검색 · 더보기 40×40(터치 44는 hitSlop)으로 둔다.
- 보관함 필터(모든 · 즐겨찾기 · 내 · 공유): 고른 칩은 `text` 채움 + 흰 글자, 안 고른 칩은 `textMuted`(색만 바꾸지 않고 채움으로 함께 구별). 스와이프 · 한눈에 전환은 그대로 흰 알약이다.
- 스와이프 표지 프레임: 가운데(고른) 표지는 흰 3px 테두리 + 그림자 `0 8px 16px rgba(28,28,28,0.12)`, 옆 표지는 `cardBorder` 70% 2px. 표지 바깥에 그려 카드 레이아웃을 바꾸지 않는다. `⋯`(더보기) 버튼은 표지 위가 아니라 **제목 줄 오른쪽 끝**에 둔다(펼쳐서 보기의 캡션과 같은 위치 · 배경 없는 글자색 아이콘 22 · 터치 40(hitSlop 9)). 표지 위에는 왼쪽 위 즐겨찾기 별만 남는다. 스와이프 옆 카드에는 버튼 자리만 비워 두어 제목 줄 높이가 같다. 코덱스 판단(2026-11-01). 가운데(고른) 표지에만 보이고 한눈에 · 검색 결과 카드에는 모든 카드에 보인다.
- `⋯`를 누르면 **동작 말풍선**(꼬리 없음, 폭 224 · 행 높이 48 · 안쪽 여백 6 · 모서리 20, 흰 면 + `cardBorder` 1px + 그림자 `0 8 24 rgba(28,28,28,0.16)`)이 버튼 옆에 뜬다. 행은 `수정` · `휴지통으로 이동` 두 개(즐겨찾기는 왼쪽 위 별이 맡는다)(글자 `text` 15/700, 행 사이 가는 선, 누르면 `surfaceMuted`)이고 막(scrim) 없이 바깥을 누르면 닫힌다. **버튼 아래에 오른쪽 끝을 맞춰 연다**(간격 8, 카드에서는 제목 밑 페이지 수 줄을 가리지 않게 그만큼 더 아래): 아래에 자리가 없으면 버튼 위, 위도 없으면 화면 안으로 밀어 넣는다. 접근성 이름은 행마다 `○○ 수정` · `○○ 휴지통으로 이동`이고 버튼은 `○○ 더보기`다. 동작은 말풍선을 먼저 닫은 뒤 실행한다. 권한이 없는 행(읽기 전용 구성원의 수정 · 휴지통)은 숨기고, 행이 하나도 없으면 `⋯` 버튼도 두지 않는다. 콜백이 없으면 끈다. 말풍선은 카드 밖에 둔다(안에 두면 눌렀을 때 카드가 열린다).
- **가운데 뜨는 모달 팝업은 되도록 쓰지 않는다.** 고르기 · 바꾸기는 누른 자리 옆 말풍선, 긴 작업은 전체 화면으로 연다(확인이 꼭 필요한 지우기 확인 창은 예외).
- **버튼 옆에 뜨는 작은 메뉴(말풍선)는 모두 같은 면을 쓴다**: `theme.bubble`(모서리 20 · 흰 면 · `cardBorder` 1px · 그림자 `0 8 24 rgba(28,28,28,0.16)`, 꼬리 없음). 홈 `⋯` 동작 · 보관함 옵션(정렬) · 편집기 페이지 작업 메뉴가 쓰며, 버튼과의 간격은 8이다. **바깥(캔버스 · 다른 패널 포함)을 누르거나 뒤로 가기 · 화면 회전이면 닫힌다**: 투명한 전체 화면 모달 + 바깥 Pressable로 만든다(안드로이드 · iOS는 부모 밖 터치를 받지 못해 패널 안 막으로는 부족하다). 첫 번째 누름은 닫기만 하고 아래 버튼은 실행하지 않는다.
- 스와이프 **포커스 프레임**(가운데 표지 흰 3px + 그림자, 옆 표지 라벤더 2px)은 표지 본체에 틈 없이 붙어 두께만큼 바깥을 감싼다. 모서리 둥글기는 표지 본체와 같은 계산(왼쪽 `6×배율` · 오른쪽 `14×배율`, 배율 = 표지 짧은 변 ÷ 200) + 두께라 표지가 커져도(태블릿 세로) 맞는다. 칸 가장자리에 두면 틈으로 표지 그림자가 테두리 안쪽에 비친다.
- 이름 · 페이지 수는 **표지 왼쪽 끝**에, `⋯` 는 **표지 오른쪽 끝**에 맞춘다(태블릿 한눈에 보기의 칸 고정 폭도 같다). 세로 모양 표지는 칸보다 좁아 가운데에 놓이므로 칸 양쪽에서 떨어진 만큼 이름 줄을 같이 들인다(가로 표지는 칸을 채워 그대로). 스와이프 맨 왼쪽 다이어리에서는 왼쪽 화살표, 맨 오른쪽에서는 오른쪽 화살표를 숨긴다.
- 홈 **상판은 단색**이다(앱 바탕 `surfaceSoft`). 시간대 그늘 · 창빛 · 가로등 · 해 방향 그림자는 2026-11-01에 뺐다. 표지 그림자는 고정 한 겹이다.
- 표지는 사용자가 만든 그대로 어느 화면에서나 같은 색이다(빛 · 그늘을 얹지 않는다).
- 스와이프 옆 카드도 실제 표지라 불투명하게 둔다. 옆 카드를 누르면 열지 않고 가운데로 오기만 하고, 다이어리는 가운데 카드에서 연다.
- 스와이프 카드는 한 장으로 합쳐 그리므로(`renderToHardwareTextureAndroid`) **표지 바깥으로 나가는 효과(프레임 · 해 방향 그림자)가 들어갈 여백**을 카드 둘레에 둔다(좌우 48 · 위 28 · 아래 36, 같은 크기의 음수 마진으로 자리는 그대로, 여백이 터치를 가로채지 않게 `pointerEvents="box-none"`). 가로 다이어리 표지는 카드 폭을 가득 채워 이 여백이 없으면 좌우에서 잘린다. 해 방향 그림자는 시간대에 따라 표지 밖으로 왼쪽 약 43 · 오른쪽 약 40 · 위 약 25 · 아래 약 31px 나간다.
- 한눈에 보기의 첫 줄 표지는 필터 · 검색 줄 바로 아래(16, 폰 28)에서 시작한다. 즐겨찾기 별은 표지 왼쪽 위에 배경 · 동그라미 없이 끝이 둥근 별만 둔다(24, 터치 +12). 안 한 별은 윤곽선만, 한 별은 금색으로 칠하며 누르면 켜고 끈다. 윤곽색은 표지가 어두우면 흰색, 거의 흰 표지면 남색이다.
- 빈 보관함: 선 · 상자 없이 캐릭터 `모아` 하나(`assets/characters/moa.png`, 폭 96 · 폰 84) + 제목 "다이어리가 없어요"만 둔다. 휴지통 빈 화면과 같이 가운데보다 약간 위로 올려 둔다(아래 여백 160 · 폰 100). 더 올리면 화면 위쪽에 붙어 보인다. 캐릭터 아래에 선을 긋지 않는다.
- 캐러셀: 가운데 카드만 선명하고(투명도 1, 크기 1.06) 양옆은 흐리게(0.36, 0.84). 개수 표시 "현재 / 전체"에는 새 다이어리 카드를 세지 않는다.
- 다이어리 카드 제목 아래에 총 페이지 수를 `N페이지`로 표시한다. 스와이프·한눈에 보기·검색 결과에서 같은 위치와 보조 글자 색(`textMuted`), 크기 12·줄 높이 18을 사용한다. 정상 값 0은 `0페이지`, 확인 전은 `페이지 수 확인 중`, 조회 실패는 `페이지 수 확인 불가`로 구분한다. 생성 전 표지 미리보기에는 표시하지 않는다.

### 5.6 나만의 폰트 만들기

- 내 공간과 텍스트 도구에서 내 폰트 홈으로 진입한다. 태블릿·웹은 소개와 폰트 목록을 좌우로, 좁은 폰은 세로로 배치한다. 홈에는 뒤로가기·소개·내 폰트 목록·새로 만들기를 제공한다.
- 새로 만들기는 이름과 36자 입력 → 고정 샘플 확인 → 생성 확정 → 상세 순서다. 이름과 필기는 기기에 자동 저장하고, 지원되지 않는 환경에는 실제 생성이 가능한 Android 개발 빌드를 안내한다.
- 36자 필기는 화면 안에 모두 보이는 원고지 격자다. 가로 공간이 부족하면 다음 행으로 줄바꿈하며 행 사이에는 칸 너비의 1/4 여백을 둔다. 정사각형 칸은 화면 크기에 맞춰 최대 100으로 조절하고, 중앙 안내 글자 크기는 실측 입력칸 너비의 1/2로 맞춘다. 칸 아래 번호·입력 글자·작성됨 표시는 두지 않는다. 한 칸에서 필기하는 동안 다른 칸 입력과 화면 스크롤을 막는다. 펜 굵기는 얇게(6)·중간(9)·두껍게(12)로 제공하고 버튼에는 이름을 표시한다.
- 상세는 수정 가능한 이름·고정 샘플·생성 당시 36자 원본을 표시한다. 생성 중에는 단계와 현재/11,172자를, 대기 중에는 대기 순서를 보여 준다. 완료 폰트는 자동으로 내 폰트에 등록한다.
- 입력 수정은 원본을 보존한 독립 초안이다. 샘플을 다시 확인한 뒤 중복되지 않는 숫자 접미사 이름으로 새 폰트를 만든다. 이름 변경은 기존 다이어리의 폰트 ID와 참조를 바꾸지 않는다.
- 생성 대기열은 앱 전역에서 순서대로 처리한다. 다른 화면으로 이동해도 활성 앱에서는 계속 만들고, 백그라운드에서는 저장 후 정지하며 복귀하면 자동으로 이어 만든다. 직접 일시 정지한 작업은 자동 재개하지 않는다.
- 일반 입력칸·동작 버튼은 최소 44 높이 또는 44×44 터치 영역을 사용한다. 원고지 칸은 36칸을 화면 안에 함께 배치할 수 있도록 가변 크기를 사용한다. 파일 가져오기·저장과 간격 보정은 더보기 메뉴에 둔다. 삭제·서버 업로드·가짜 생성 결과는 제공하지 않는다.

### 5.7 휴지통

- 남은 기간 줄: **`n일 후 영구 삭제`**(12/600) 글자만 둔다(진행 고리는 뺐다, 사용자 결정). **3일 이하**는 `butter` 칩(높이 24, 안쪽 9) + `text` 글자 800으로 바꾼다. 적색 글자를 쓰지 않는다. 카드 접근성 이름에 남은 기간을 함께 넣는다(`제목, n일 후 영구 삭제, 복원 또는 영구 삭제`).
- 빈 휴지통: 캐릭터 `디오`(`assets/characters/dio.png`, 모아보다 키가 크다 — 아래 '모아(노란 책) · 디오(파란 친구) 키 비율') + 제목만 둔다. 선을 긋지 않는다.
- **모아(노란 책) · 디오(파란 친구) 키 비율**: 기준은 `docs/캐릭터 디자인/최종시안 svg 변경본.svg`(먹선 포함 모아 2153 : 디오 2475, 모아 키 ≈ 디오의 87%)다. 앱에서는 모아 크기를 기준으로 두고 디오를 `CHARACTER_SCALE.dio`(≈ 1.21, `src/shared/characterScale.js`)만큼 키워 그린다 — 빈 화면과 표지 캐릭터 무늬에 같이 적용한다. 캐릭터 디자인 문서 C-2의 10 : 6.5는 초기 스케치 값이라 따르지 않는다.
- `영구 삭제` 글자 · 아이콘은 `dangerStrong`(흰 바탕 6.0:1)이고 버튼은 채우지 않고 `#F0D5D4` 윤곽으로 둔다. 선택 모드의 `영구 삭제` 버튼도 같다(채운 위험 버튼은 확인 창 한 곳).

- 제목 줄은 위에 고정하고 카드 목록만 스크롤한다. 카드는 홈 한눈에 보기와 같은 폭 · 한 줄 개수(태블릿 가로 4 · 세로 3, 폰 2)에 틀 없이 표지 + 제목 + `n일 후 영구 삭제`만 둔다. 제목 자리도 한눈에 보기와 같다(표지 왼쪽 끝에 맞추고 안쪽 여백 4 · 표지 아래 10, 글자 14/700). 3일 이하로 남으면 이 줄을 `danger` 색으로 바꾼다. 안내 문구 · 삭제 시각은 쓰지 않는다.
- 카드를 누르면 동작 시트(폭 320 · 모서리 24, `ConfirmDialog`와 같은 틀)가 뜨고 `복원`(`primaryStrong` 채움) · `영구 삭제`(`#F0D4DB` 테두리 + `danger` 글자) · `닫기`를 둔다. 카드마다 버튼을 붙이지 않는다.
- 카드 길게 누르기는 보관함 편집 모드와 같은 선택 바(`n개 선택됨` · 전체 선택 · 복원 · 영구 삭제 · 완료)와 카드 체크 원을 쓴다(맨 위 상자 '선택 모드'). 영구 삭제는 한 번만 묻는 `ConfirmDialog`로 확인한다.

- 내 폰트 홈은 소개(버터 칩 + 28/800 제목 + 한 줄, 7)와 `내 폰트` 카드(흰 면 + `cardBorder` · 모서리 12, 5)를 좌우로, 좁은 폰은 세로로 둔다. 새 폰트는 `1 손글씨 입력 → 2 샘플 확인 → 3 생성`, 제목은 `내 폰트 만들기` 그대로다. 손글씨 입력은 회색 작업 판(모서리 16)에 원고지만 두고, 그 아래 흰 바탕에 `펜 굵기` · 편집창 펜과 같은 굵기 막대(`Slider`: − · 막대 · + · 숫자, 6~12 · 처음 9, 최대 폭 420) · 되돌리기 · `다시 쓰기`를 한 줄로 둔다(폰은 이름 줄 아래에 막대). 원고지 높이는 이 줄과 하단 바를 뺀 만큼이라 바 위에 여백이 남는다. 생성기는 획 굵기를 그대로 받으므로 칸을 셋으로 나눌 이유가 없고, 범위는 예전 얇게 6 ~ 두껍게 12를 넘기지 않는다. 획 되돌리기 옆에 획 다시 실행(글자 칸마다 따로, 그 칸에 새 획을 쓰거나 다시 쓰기를 하면 비운다). 하단 줄 왼쪽은 `6 / 36 · 이 기기에 저장됨`, 오른쪽은 `샘플 확인`. 내 폰트 목록에서 작성 중(생성 확정 전)인 폰트는 줄 오른쪽 휴지통 아이콘으로 지운다(`이 폰트를 지울까요?` / `작성 중인 손글씨가 모두 사라져요.`). 폰트 이름은 샘플 확인 카드의 샘플 아래 `폰트 이름` 입력에서 정하고, 하단 줄 `생성 확정`이 이름을 저장한 뒤 생성을 확정한다. `Android 개발 빌드…` 안내 상자와 `파일은 이 기기에 보관해요…` · `다른 폰트를 만들고 있다면 대기열에…` 같은 설명 문장은 두지 않는다.
- 전체 화면 모달의 표시 방식(폰트 · 시트 분리: 슬라이드 전체 화면, 사진 오리기: 투명 전체 화면)은 바꾸지 않는다.

- **모양은 Lucide(ISC)로 통일한다.** `Icon.js`의 각 줄 끝에 Lucide 이름을 적어 두었다. 예외는 Lucide에 없는 **펜 · 형광펜 · 마스킹테이프(`tape`)** 와 점 아이콘(grip · more)으로, 이 선들만 직접 그렸다(코덱스 설계 · 클로드 검증). 출시된 앱이므로 외부 아이콘은 **MIT · ISC처럼 고지만 하면 되는 것만** 쓰고, 고지 원문은 `third-party/lucide-LICENSE.txt`와 앱 오픈소스 목록(`scripts/publish-release-licenses.py`)에 있다. 복사 기준 Lucide 버전은 `third-party/lucide-VERSION.txt` 한 곳에 적고 고지 스크립트가 그 값을 읽는다(일부 경로는 예전 버전에서 가져왔다). 새 아이콘 경로를 넣거나 Lucide 버전을 올리면 목록을 다시 만든다.
- **펜과 형광펜은 한 쌍이다**: 같은 길이 · 같은 각도 · 같은 굵기의 필기구로 보여야 한다. 둘 다 `점(u, v) = (5.4 + 0.7071(u+v), 17.6 + 0.7071(−u+v))` 좌표계(축 45°, 팁 u=0, 끝 u=19, 몸통 폭 4.8, 팁 띠 u=4, 캡 띠 u=14)를 쓰고, 펜은 뾰족한 팁, 형광펜은 납작한 팁 + 밑줄만 다르다. 새로 고칠 때도 두 아이콘의 몸통은 같이 움직인다.
- **마스킹테이프(`tape`)**: **선이 다 이어진 완전한 큰 동그라미** 롤(바깥 반지름 7.5, 구멍 2.8) + 롤 바닥 접선에서 오른쪽으로 나오는 평평한 꼬리(높이 4.5, 윗변은 원 위 x 16.37에서 시작), 끝은 제비꼬리(V 홈). 롤 동그라미는 꼬리 쪽에서도 끊지 않는다.
- **뜻이 다르면 이름도 다르다(돌려쓰기 금지).** 그림만 닮았다고 다른 뜻에 쓰지 않는다. 펜 도구 `pen` / 이름 · 편집 `edit`, 격자 가이드 `guides`(`grid`는 칸 표) / 그룹 `group`(`folder`는 폴더 · 레이어 묶음) / 사진 속 대상 오리기 `scissors`(`crop`은 자르기), 한눈에 보기 `pages` / 속지 `paper`(종이 한 장).
- 휴지통은 앱 전체가 한 모양(`trash`, 좌측 메뉴의 휴지통 통 모양)이다. 메뉴 · 삭제 버튼 · 휴지통으로 이동이 모양을 달리하지 않는다. `AppIcon`의 `bin`도 같은 모양으로 넘긴다.

### 6.1 글자 옆 아이콘 (2026-11-01)

아이콘 옆에 글자(라벨)가 같은 줄에 놓이면 **아이콘 그림 높이를 글자 높이에 맞춘다.** 같은 `size`를 줘도 그림마다 24칸 안에서 차지하는 높이가 달라(레이어 20 · 사람 추가 18 · 내보내기 16) 글자와 어긋나 보였다.

- 쓰는 법: `<Icon name="layers" forText={13} />` · `<AppIcon name="book-open" forText={12} />` — 옆 글자의 `fontSize`를 그대로 넣는다. `size`는 `forText`를 계산할 수 없을 때(기호 아이콘 등)의 값으로만 남는다.
- 계산(`src/shared/iconInk.js`): 글자 그림 높이 = `fontSize × 0.92`(Pretendard 한글), **선 두께까지 합친 아이콘 높이 = 글자 높이 + 1**. 선 두께는 글자 12 미만 1.25 · 12~15 1.5 · 16 이상 1.75(px, 크기와 관계없이 일정). 아이콘 그림이 24칸 가운데(12)에서 치우친 만큼(내보내기는 위로 1) 세로로 보정한다.
- 예(13px 글자): 레이어 14 · 사람 추가 15 · 내보내기 17(칸 크기). 아이콘 그림 높이는 모두 약 11.5로 같다.
- **글자 모양 아이콘 보정(2026-11-02):** T(`text`)는 옆 글자와 바로 비교되고 윗변이 폭을 꽉 채워 같은 높이여도 커 보이므로 그림 높이를 '글자 + 1px' 대신 글자 높이에 맞춘다(`iconInk.js` `OPTICAL_SCALE`, 0.87). 공방 `폰트 추가` · 편집기 텍스트 패널 제목에 적용된다.
- **기호도 글자에 맞춘다(2026-11-02, 코덱스):** 글자와 같은 줄에 놓인 기호(꺾쇠 · 닫기 · 체크 · 더하기 · 화살표 · 줄)도 `forText`에 옆 글자 크기를 넣는다. 기호는 글자보다 작게 곁들이므로 **보이는 그림 높이 = 글자 × 0.64**이고, 칸 크기는 기호마다 24칸 안 그림 높이로 보정한다(꺾쇠 12 · 체크 11 · 더하기 14). 눕힌 ⌄ 는 긴 쪽(12)으로 잰다. 선 두께는 물건 아이콘과 같다. 예: 15px 글자 › 19 · ✓ 21, 13.5px ⌄ · › 17, 12px ↑↓ 13 · 더하기 13.
- 글자에 맞추지 않는 것: 글자 없이 혼자 쓰는 아이콘(닫기 · 뒤로 · 눈 · 휴지통 · 복사 버튼), 네모 칸 · 원 안에 든 아이콘(체크박스 체크, 단계 배지, 도구 묶음 머리 칸), 제목 옆 큰 아이콘, 빈 상태 그림, 점 · 빼기(높이 없음), 좌측 바 메뉴 아이콘(접으면 아이콘만 남아 20 고정).
- 새 아이콘을 `Icon.js`나 `AppIcon.js`에 넣으면 `iconInk.js` 표(그림 높이 · 가운데)도 같이 갱신한다(24px로 그려 path 경계를 잰 값).
- 적용된 곳: 편집기 상단 바(페이지 · 공유 · 레이어 · 내보내기) · 자동 저장 상태 · 보관함 보기 버튼 · 휴지통 시트 · 편집기 선택 메뉴 · 텍스트 막대 · 사진 틀 옵션 · 페이지 목록 메뉴 · 공유 창 등 글자와 나란히 놓인 아이콘 전부. 2026-11-02 전수 점검으로 이름 바꾸기 연필(편집기 제목 · 레이어 · 공방 선반), 도구 패널 제목, 다이어리 카드 공유 표시, 설정 · 드롭다운 · 기간 · 색 칸의 꺾쇠와 체크, 정렬 화살표, 폴더 추가 `+` 까지 맞췄고 `forText` 값이 옆 글자와 달랐던 13곳(문맥 메뉴 · 올가미 메뉴 · 텍스트 막대 · 페이지 목록 메뉴 등)을 고쳤다. 점검 스크립트는 같은 부모 안 아이콘 · 글자 짝을 찾아 `forText`가 없거나 옆 `fontSize`와 다르면 알린다.

## 8. 글쓰기 (UX 문구)

- **해요체**로 통일한다. 결과는 과거형(~했어요), 부탁은 ~해 주세요, 없음은 ~없어요, 확인 질문은 ~할까요?
- 짧게 쓴다. 기능 설명 · 도움말 문구는 넣지 않고 제목 · 오류 · 저장 상태 · 한도 안내만 남긴다.
- **친절한 안내 멘트를 넣지 않는다.** 사용법 · 결과 예고 · 다음 할 일을 알려 주는 문장은 버튼 아래 보조 글, 빈 칸 안내, 처음 한 번 뜨는 토스트 어디에도 쓰지 않는다. 화면과 버튼 이름만으로 알 수 있게 만든다.
  - 쓰지 않는 예: "티켓 틀로 붙어요" · "틀 없이 붙어요" · "사진을 두 번 누르면 자를 수 있어요" · "칸에 넣을 순서대로 골라요" · "빈 틀을 넣고 칸을 채워도 돼요"
  - 쓰는 것: 제목 · 버튼 이름 · 오류 · 막힘 안내 · 완료 토스트(아래 표) · 저장 · 진행 상태 · 한도 · 되돌릴 수 없는 작업의 확인
  - 버튼 이름에 이미 있는 말을 보조 글로 되풀이하지 않는다. 기능이 어렵게 느껴지면 문구를 더하지 말고 배치 · 아이콘 · 동작을 고친다.

- 띄어쓰기: "붙여 넣었어요", "잘라 냈어요"처럼 보조 용언은 띄운다.

## 11. 기능 패턴

- **내보내기 · 저장**: 결과 · 미리보기 · 진행 화면을 띄우지 않는다. "만들기"를 누르면 말풍선이 닫히고 **작은 진행 알약만** 보이다가 바로 다운로드(기기는 사진첩 · 공유 창)된 뒤 토스트로 알린다. 새 내보내기도 `ExportRunner` 방식으로 붙인다.
- **삭제**: 되돌릴 수 있으면 확인 없이 지우고 "되돌리기로 복구할 수 있어요" 토스트. 되돌릴 수 없으면 `ConfirmDialog`(빨간 버튼).
- **도구 옵션**: 리본 아이콘 아래 떠 있는 패널 하나. 제목 + 섹션(12/700 회색 제목) + 컨트롤. 고정된 왼쪽 · 오른쪽 구분을 쓰지 않는다.
- **빈 곳 메뉴(붙여넣기 · 속지 색)**: 페이지 빈 곳을 움직이지 않고 450ms 누르면 누른 자리에 뜬다. 속지 색 창(폭 300)은 `이 페이지` · `모든 페이지`(이 다이어리의 모든 페이지와 새로 추가할 페이지) 범위를 고른 뒤 배경색 · 레이아웃 색 · `글꼴`을 바꾼다. 세 가지가 같은 범위를 따르고, 글꼴 줄은 글자가 인쇄되는 속지에만 붙는다(칩이 줄바꿈하며 글자는 늘 `text`색으로 읽힌다). 마루부리로 되돌리면 글꼴 값을 지운다. 선택 도구와 손바닥 도구 모두 연다(손바닥 도구는 화면을 옮기는 보는 영역이 길게 누르기를 알려 준다). 메뉴를 띄운 터치는 손을 뗄 때까지 화면을 옮기지 않고, 빈 곳을 누르거나 도구 · 페이지를 바꾸면 닫힌다.
- **리본**: 아이콘만, 글자 표기 없음. 펜 · 형광펜은 아이콘 오른쪽 아래 6pt 원으로 현재 색을 보여 준다.

### 11.0 사진 넣기 · 자르기 창 (2026-11-02 통일)

사진을 쓰는 곳은 모두 **같은 흐름 · 같은 창**(`PhotoCropper`)을 쓴다: **사진 고르기 → 자르기 · 확대 · 비율 → 붙은 모습 확인**. 자르기를 닫으면 그 사진은 넣지 않는다.

- 손짓은 어디서나 같다: **한 손가락 = 틀 옮기기**, **두 손가락 = 확대 · 축소**(+ 함께 끌어 이동), **핸들 = 틀 크기**. 비율이 고정이면 꼭짓점 핸들만 두고 끌어도 비율이 유지된다. 확대 막대 · 초기화 · 취소 · 적용 자리도 같다.
- 기능마다 다른 점은 옵션으로만 준다(`fixedAspect` · `aspectRange` · `round` · `extra` · `confirmLabel`).

| 화면 | 비율 | 핸들 | 추가 조절 | 적용 후 |

| 편집기 사진 추가(여러 장이면 한 장씩) | 원본 · 1:1 · 4:5 · 3:4 · 4:3 · 16:9 · 자유 | 고정 비율은 꼭짓점, 자유는 꼭짓점+변 | — | 붙고 선택된다 |

### 11.0.1 미리보기 그래픽 (2026-11-02)

줄여 그리는 그림(보관함 칸 · 레이어 썸네일 · 작은 표지 · 공방 견본)은 **기기 픽셀에 맞춰** 그린다. 소수점 픽셀로 줄인 무늬는 칸 이음매에 가는 줄이 생기고 사선 · 줄무늬가 칸 경계에서 어긋난다(안드로이드에서 더 심하다).

- 무늬(SVG Pattern) 배율은 `snapScale`(배율 × 기기 픽셀 비율이 정수), 자리 · 칸 크기는 `snapToPixel` 로 맞춘다(`shared/pixelSnap.js`). 무늬 칸 크기는 늘 정수 단위로 설계한다.
- 테이프는 미리보기에만 `TapeView crisp` 를 켠다(무늬 배율 · 사진 테이프 조각 폭). 캔버스는 확대 · 축소 중 무늬가 튀지 않게 맞추지 않는다.
- 표지 무늬(`CoverPattern`)는 칸 크기를 늘 맞춘다. 표지를 바깥에서 transform 으로 줄여 그리면(한눈에 보기) 그 배율을 `pixelScale` 로 넘겨 **화면에 보이는 크기**로 맞춘다.
- 같은 간격으로 반복되는 선 · 점(메모지 줄 · 모눈)은 간격이 기기 픽셀 정수가 되게 배율을 맞추고(`snapStepScale`), 선은 기기 픽셀 한 칸보다 가늘게 그리지 않는다(`hairline`). 줄마다 진하기가 달라 보이는 일이 없어진다.
- 질감이 있는 그림(연필 결 등)은 크게 만든 뒤 zoom 으로 줄이지 않고 **보일 크기로 바로 만든다**(펜 설정 견본). 줄이면 결이 픽셀보다 작아져 뿌옇게 뭉개진다.
- **속지 고르기 칸은 대표 그림**(`PaperSketch`, `TemplatePreview sketch`)으로 그린다. 플래너 · 일기는 그대로 줄이면 글자가 얼룩, 선이 흐린 무늬가 된다(애플 HIG 문서 아이콘: 작으면 선을 줄이고 픽셀에 맞춰 굵게, 아주 작으면 뺀다).
  - 쓰는 곳: 페이지 추가 · 새 다이어리의 속지 칸, 속지 줄, 순서 띠, 페이지 추가의 '현재 속지'. **페이지 목록과 큰 미리보기는 실제 속지 그대로**다.
  - 구조는 실제 속지 SVG 에서 뽑는다(`scripts/build-paper-sketches.mjs` → `paperSketches.js`, 속지 양식을 바꾸면 다시 실행). 선은 기기 픽셀 1칸, 글자는 막대(제목 `#666666` · 글자 높이 ×0.75, 작은 글자 `#d7d9dc` · ×0.5, 폭 3px 이하는 뺀다).
  - 선 색: 구조선 `#bfc1c4`, 진한 틀 · 체크 상자 `#aeb3b8`, 글 쓰는 옅은 줄 `#d7d9dc`. 속지 팔레트 색만 써서 속지 색 설정이 그대로 먹는다.
  - 줄 · 모눈 간격은 3px 이상(글 쓰는 줄 4px 이상), 칸 안의 옅은 모눈 결이 그보다 촘촘하면 뺀다. 8칸 이하 칸 나눔(달력 7칸)은 칸 수를 바꾸지 않는다. 3px 안으로 붙은 평행선은 하나만 남긴다.
  - 노트(줄 · 모눈 · 도트) 칸은 왼쪽 위 일부를 확대해 보이는 예전 방식을 두고, 선 색만 `#bfc1c4` 로 맞춘다(코덱스 검수 2026-11-02).

### 11.1 떠 있는 메뉴의 자리

캔버스 위에 뜨는 메뉴는 `src/editor/utils/popoverPlacement.js` 하나로 자리를 정한다. 새 메뉴도 이 함수를 쓴다.

1. **피할 영역**을 잡는다. 요소면 선택 상자 + 손잡이(꼭짓점 손잡이 반지름 9, **회전 손잡이는 요소를 돌린 방향 그대로**), 누른 자리 메뉴면 그 점.
2. 피할 영역의 **위에 먼저** 16 띄운다. 펜을 쥔 손이 아래쪽을 가리기 때문이다(iOS 편집 메뉴와 같은 순서).
3. 위에 자리가 없으면 **아래**에 16 띄운다.
4. 위 · 아래 모두 없으면 영역 안으로 밀어 넣되 **회전 손잡이의 반대쪽**에 붙인다. 손잡이 · 버튼을 메뉴가 가리지 않는 것이 우선이다.
5. 가로는 대상 가운데에 맞추고, 영역 가장자리에서 8 안쪽으로 민다.
6. **영역**은 메뉴마다 다르다. 선택 바 · 링크 카드 · 순서 메뉴 · 올가미 메뉴는 **화면에 보이는 작업 영역**(작업창에서 태블릿 툴바 아래, 폰에서 작업창 위에 띄운 페이지 목록 · 레이어를 뺀 나머지)이다. 화면을 옮기거나 확대해 요소가 가장자리 · 화면 밖으로 가도 바는 이 영역 안으로 들어오고, 패널을 열고 닫으면 그에 맞춰 다시 놓인다. 옮기거나 확대하는 동안은 숨겼다가 손을 떼면 새 자리에 보인다. 빈 곳 메뉴 · 속지 색 말풍선은 페이지 안이다.

## 12. 새 화면 · 기능 체크리스트

사진 속 대상 오리기는 기존 스티커 폴더의 추가 메뉴에 진입을 둔다. 사진 영역과 선택 추가·제외·붓 크기·이력 도구를 제공하고, 태블릿은 좌우·폰은 세로 배치한다. 선택 추가는 파랑·제외는 위험색과 버튼 선택 상태로 구분한다. 모델 미연결 단계에서는 수동 선택 미리보기임을 표시하며 실제 생성·저장 성공으로 안내하지 않는다.

개인 사본 만들기는 공유 모달의 내부 화면으로 연다. 원본 이름, 사본 이름 입력, 원본·참여 유지 안내와 생성/취소 버튼을 배치한다. 완료 안내는 같은 화면 안에 표시하고 사본 열기·공유로 복귀를 제공한다. 세션 미리보기에서는 영구 저장으로 오해하지 않도록 실행 중에만 유지됨을 표시한다.

참여자 관리는 공유 모달의 별도 내부 화면으로 연다. 대상별 사진·닉네임과 소유권 양도·내보내기 버튼을 묶고, 두 작업 모두 대상 이름을 넣은 공용 확인창을 사용한다. 카드 안 작업 버튼은 흰 배경·기본 테두리·같은 너비로 배치하고 높이는 최소 44로 유지한다. 양도는 기본 글자색, 내보내기는 위험색으로 구분하며 양도 확인창은 기본 강조색을 사용한다. 완료·뒤로가기는 공유 기본 화면으로 돌아간다.

- [ ] 색 · 모서리 · 그림자를 `theme.js` 토큰(또는 2.2 보조 값)으로만 썼다.
- [ ] 글자 크기 · 굵기가 3.2 표 안에 있고 굵기는 600/700/800/900이다.
- [ ] 폰 · 태블릿에서 누르는 곳이 48 이상이다.

### 페이지 편집과 초기화

페이지 목록·넓게 보기의 선택 모드 진입은 `편집`, 종료는 `완료`로 표기한다. `다이어리 초기화`는 편집 모드에서만 제공하며, 선택·필터와 무관하게 전체 내용을 제거하고 빈 페이지 한 장을 남기는 동작임을 별도 확인창에서 안내한다.

**편집기 왼쪽 페이지 목록(2026-11-02, 굿노트 흐름 조사 · 코덱스 배치):** 같은 손짓은 고른 페이지든 아니든 같은 일을 한다. 탭 = 그 페이지로 이동, 길게 눌러 끌기 = 순서 바꾸기, 길게 눌렀다 움직이지 않고 떼기 = 그 페이지 작업 메뉴(복제 · 삭제). 여러 장 고르기는 `편집` 버튼으로만 들어가고(길게 누르기로 들어가지 않는다), 편집 중 탭은 체크 넣기/빼기, 길게 눌러 끌기는 고른 페이지를 함께 옮긴다. 배치는 탭 · `편집` · 썸네일 · `+` 의 좌우 끝을 모두 썸네일 폭 128(패널 176 안 양쪽 24)에 맞춘다. 탭은 `surfaceMuted` 판(높이 32 · 모서리 10, 칸 28 · 모서리 8, 12/700, 고른 칸 흰 면 + `primaryText`), `편집` 은 위 8 · 높이 32 · 흰 면 + `border` 1px · 아이콘 16. 편집 중에는 선택 바(높이 40 · 모서리 10 · 흰 면 + `border` 1px, 왼쪽 `n개 선택` 12/700 `text`, 오른쪽 `완료` 12/700 `primaryText`) → `선택 삭제`(흰 면 + `danger` 1px 윤곽, `dangerStrong` 글자) → `다이어리 초기화`(`surfaceMuted`, `text` 글자)를 8 간격 세로로 쌓고 `+` 는 숨긴다. 썸네일 테두리는 `cardBorder`, 지금 페이지는 `primaryStrong` 2px + 번호 `primaryText`, 편집에서 고른 페이지는 `primary` 1px + 오른쪽 위 체크 칸(24 · 모서리 6, 빈 칸 흰 면 + `primary` 1px, 고른 칸 `primaryStrong` 면 + 흰 체크 14). 북마크 · `⋯` 아이콘은 `primaryText`. `+` 는 흰 면 + `cardBorder` 1px · 높이 46 · 모서리 12. 태블릿에서는 레이어 패널과 같이 화면 왼쪽 · 위아래 끝까지 붙이고(모서리 없음) 안쪽 끝에 1px `rgba(28,28,28,0.08)` 구분선을 둔다. 이때 안쪽은 화면 끝 ↔ 내용과 내용 ↔ 구분선을 똑같이 24로 두고, 탭 · `편집` · 썸네일 · `+` 를 모두 그만큼 넓힌 폭 144에 맞춘다. 폰(떠 있는 패널)과 읽기 화면은 그대로다.

**페이지 추가의 `나의 속지`(2026-11-02):** 나의 속지 묶음이 있을 때만 탭을 보인다. 묶음 타일은 흰 카드(모서리 10 · `cardBorder` 1px · 안쪽 8) 3열 · 간격 12에 16:10 미리보기(`surfaceSoft`, 첫 쪽 비율 그대로) + 이름 13/700 `text` + `n장` 11.5/700 `textMuted`(코덱스). 묶음을 누르면 그 안의 쪽을 같은 카드(이름 자리에 `n쪽`)로 펼치고, 위에 `‹ 묶음 이름`(뒤로) · 오른쪽 `전체 넣기`(12/700 `primaryText`) 줄을 둔다. 쪽을 누르면 그 한 장만, `전체 넣기` 는 묶음 전부를 지금 페이지 뒤에 넣는다. 한 장짜리 묶음은 펼치지 않고 바로 넣는다.

### 로그인·회원가입 화면

기존 surfaceSoft 배경 위 흰 카드(최대 폭 520, 모서리 radius.xl)를 가운데 배치한다. 태블릿은 안쪽 40, 폰은 24와 바깥 16을 사용하며 내용이 길면 세로로 스크롤한다. 소셜 진입 버튼에만 제공자 식별 색(카카오 #FEE500, 구글 다색 심볼, 애플 #191919)을 허용한다. 이메일·비밀번호 입력은 최소 높이 48, 비밀번호 보기와 동의 항목은 최소 터치 영역 44를 유지한다. API 연결 전의 임시 동작과 데이터 유지 범위는 기능 문서에 기록한다.

로그인 시작 화면은 세로 배치로 이메일·비밀번호 입력과 로그인 버튼을 중심에 둔다. 찾기·회원가입 링크 아래에 간편 로그인과 게스트 시작을 둔다. 게스트 링크에는 별도 구분선을 사용하지 않는다. 제목·설명은 간격 6으로 묶고 입력 영역까지 24를 띄운다.

계정 닉네임은 중복을 허용한다. 회원가입·계정 프로필 수정 화면에는 중복 확인 버튼을 두지 않으며, 형식 검증과 필수 동의·저장 중 중복 제출 방지는 유지한다.

- 공유 관리(304)는 기존 최대 폭 580의 대화상자와 세로 스크롤을 유지한다. 인원은 `현재/4명`, 역할은 소유자·편집자로 표시한다. 기본 공유 화면에는 이메일로 초대 진입 버튼만 두고 같은 창 안의 별도 이메일 화면으로 전환한다. 이메일 입력은 기존 높이 48 입력칸과 전체 폭 주요 버튼을 사용하며, 보낸 초대는 이메일·상태와 오른쪽 취소 버튼(최소 터치 높이 44)을 배치한다. 정원 안내는 surfaceMuted·radius.md의 판에 표시한다. 유료 이용 준비 안내에 결제 버튼은 추가하지 않는다. 목업 발송과 실제 발송을 문구로 구분한다. 링크 유효기간·제한은 한 줄로 요약하고 전송·취소 결과는 일시적인 토스트로 표시한다. 공통 내보내기 권한과 맞지 않는 허용 토글은 표시하지 않는다.

- 편집기의 공동 작업 진입은 사람 아이콘과 '공유', 파일 출력은 기존 '내보내기'로 구분한다. 보관함 알림은 종 아이콘을 사용하고 응답 가능한 새 초대가 있으면 빨간 점을 표시한다.

- 다이어리 닉네임은 중복을 허용한다. 참여·프로필 수정에 별도 중복/형식 확인 버튼을 두지 않고 입력 형식만 바로 검증한다. 최종 수락 전까지 참여를 확정하지 않는다. 상세 범위는 [다이어리 초대 공유 화면.md](./화면%20배치/다이어리%20초대%20공유%20화면.md)를 따른다.

- 공유 버튼 옆에는 원형 참여자 프로필을 겹쳐 표시하고, 해당 다이어리 프로필 사진이 있으면 사진을, 없으면 기본 사람 아이콘을 쓴다. 공유 창과 같은 참여자 목록을 사용하며 해제 시 함께 갱신한다. 보기 전용 권한은 제공하지 않는다.

- 다이어리별 프로필 사진은 계정 사진과 독립적으로 변경/초기화할 수 있다. 초대 수락 화면의 원과 공유 설정의 내 프로필 원에서 사진 메뉴를 연다. 사진 선택 취소는 기존 값을 유지한다.

- 참여 후 공유 창의 내 프로필 원은 사진·닉네임 수정 화면을 연다. 변경은 저장 버튼에서 함께 반영하고, 취소 시 기존 프로필을 유지한다. 닉네임 변경 후에는 중복 확인을 다시 수행한다.

- 보관함 상단 카테고리는 모든 다이어리·즐겨찾기·공유 다이어리 순서로 표시한다. 공유 목록은 소유·참여 다이어리를 함께 보여 주며, 좁은 폭에서는 카테고리를 줄바꿈한다.

### 알림 수 표시

일반 로그인 사용자의 진입점은 `알림`으로 표시하고 실제 서버의 받은 알림 패널을 연다. 방문자·미리보기의 기존 `받은 초대` 목 흐름과 구분한다. 실제 공유 서버가 연결되기 전에는 로그인 사용자에게 목 수락·거절·공유 생성을 제공하지 않고 연결 준비 안내를 표시한다.


서버의 전체 미읽음 수는 `안 읽은 알림 N개`로 표시한다. 보관함 진입점도 같은 수치를 숫자로 표시하고 접근성 이름에 의미를 포함한다. 좁은 진입점은 아이콘 아래 숫자를 두고 100개 이상은 `99+`로 축약하되 접근성 이름에는 실제 전체 수치를 제공한다. 유효한 미읽음 초대 수가 별도 제공될 때만 `새 초대 N개`와 danger 색 점을 표시한다. 조회 실패 시 이전 값을 유지하고 확인 필요 안내를 함께 표시한다.

알림 종류가 초대로 확인된 경우에만 초대 문구·상태·상세 진입을 제공한다. 일반/미지원 종류는 `알림`과 `새로운 알림이 도착했어요.`로 표시하고 읽음·삭제를 제공한다. 종류 코드나 미확인 payload를 사용자 문구로 노출하지 않는다. 초대 정보가 없는 초대 알림도 읽음·삭제는 가능하다.

알림 오류는401이면 로그인 후 새로고침 안내,403이면 권한 안내,404이면 목록 확인 안내를 제공한다. 이 상태에서는 같은 요청의 직접 재시도 버튼을 제공하지 않는다. 서버/네트워크 오류는 이전 조회 결과와 안내를 함께 표시하고 수동 재시도를 제공한다. 실제 인증 연결 전에는 동작하지 않는 로그인 버튼을 추가하지 않는다.

알림 로딩은 이름 있는 진행 표시와 busy 상태로 전달하고 장식용 스피너는 중복 낭독에서 제외한다. 오류 문구는 alert 역할·polite 알림, 빈 목록은 polite 알림을 사용한다. 재시도 버튼은 오류 문구와 별도로 탐색할 수 있게 둔다. 좁은 가로 화면에서는 내용과 버튼을 줄바꿈하고 목록의 세로 스크롤을 유지한다.

모두 읽음은 API 어댑터가 지원할 때만 표시한다. 서버의 전체 읽음이 분리된 상태에서는 버튼을 숨기며, 기존 목 전체 읽음은 유지한다.

### 마스킹테이프 도구 설정

새 테이프 보관함의 마지막 색상(사용자 지정 바탕색/무늬색 포함)·무늬는 기기 공통으로 기억한다. 규격은 고르지 않는다: 새 테이프는 늘 기본 폭으로 붙고, 붙인 뒤 위아래 손잡이로 폭을 바꾼다(무늬 크기는 그대로, 줄 수만 는다). 패널 닫기·도구 전환·다이어리 이동·앱 재실행 후 복원하고 무늬를 누를 때마다 새 테이프를 붙인다. 설정 복원 자체는 테이프를 삽입하지 않는다. 처음 사용할 때 색상·무늬는 무선택이며, 색상 없이 무늬를 누르면 실제 기본색을 기억한다. 기존에 배치한 테이프의 끝선·불투명도는 요소별 설정이다.

### 새 텍스트 입력창 높이

새 글상자의 입력 높이는 글꼴·줄간격·화면 배율을 따르고 화면 px 기준 고정 최소 높이로 하단 여백을 만들지 않는다. 기존에 사용자가 직접 늘린 상자 높이와 최소 내용 높이 제한은 유지한다.

### 사진 특수 모양의 그림자

하트·별·우표도 공통 그림자 옵션을 제공한다. 실제 사진/프레임의 외곽 경로를 따라 안쪽·바깥쪽 그림자를 표시하고 사각 바탕이 생기지 않도록 한다. 기존 색·방향·거리·퍼짐·흐림·불투명도 설정을 재사용한다.

### 웹 영역 지우기 중 임시 표시

- 웹 캐시를 기다리는 만년필·붓펜 벡터와 영역 지우기로 변경된 묶음은 농도 단계를 최대 8개로 임시 간소화할 수 있다. 원본 좌표 데이터·색상과 이미 준비된 캐시의 질감은 바꾸지 않는다. 캐시 대기 중 임시 표시만 조밀한 좌표를 줄일 수 있으며, 위치 및 압력 반경 오차는 각각 0.12 페이지 단위 이내로 제한하고 급회전·압력/센서 변화·끝점을 유지한다. 정밀 복원은 간소화하지 않은 원본 좌표를 사용한다.
- 손을 뗀 뒤 유휴 시간에 원래 정밀 농도의 캐시로 복원한다. 캐시 불가·실패 시 정밀 SVG로 표시한다. 임시 농도를 저장 문서·썸네일·내보내기 결과로 남기지 않는다. iOS/Android의 기존 표시 정책은 이 웹 최적화로 바꾸지 않는다.
- 회차별 QA 결과와 검증 범위·잔여 위험은 [성능 QA 자료의 최신 확인 상태](./편집%20도구/펜%20성능%20QA%20자료.md)에서 관리한다.

### 펜·형광펜·지우개 선택과 설정

- 다른 도구에서 누르면 설정 창 없이 즉시 선택해 사용한다.
- 이미 선택된 도구를 다시 누르면 설정 창을 열고, 한 번 더 누르면 닫는다. 탭 사이 시간 제한은 없다.
- 태블릿 리본과 폰 도구 막대에 공통 적용한다. 다른 도구로 전환하면 기존 설정 창은 닫는다.

### 지우개 설정

- 첫 줄은 **지우는 방식** `획 전체 / 닿은 부분`, 둘째 줄은 **지울 대상** `전체 / 펜 / 형광펜`을 공통 Segmented로 표시한다. 안내와 크기 슬라이더는 그 아래에 둔다.
- 두 선택은 독립적이고 편집 세션 동안 유지한다. 기본은 획 전체·전체다. 꼬리 처리는 별도 설정 없이 원래 펜촉·필압·재질에 맞춰 적용한다. 형광펜의 round/square 선택도 유지한다.
- 종류가 없는 플래너 셀 기록은 전체 모드에서만 지운다. 상세 동작·저장 영향은 [지우개](./편집%20도구/지우개.md)를 따른다.

### 필기 도구의 재질 표현

- 펜 종류는 **볼펜·캘리펜·붓펜·연필**로 제공하고 형광펜은 별도 도구로 유지한다(2026-11-02 개편). 세 펜은 같은 굵기·불투명도에서도 단색 한 겹의 외곽선 모양만으로 구분되며 필압·속도에 기대지 않는다. 기본은 볼펜(검정/2.5).
  - **볼펜**(`ball`): 원형 끝, 굵기 고정.
  - **캘리펜**(`calligraphy`): 평촉 사각. 긴 변 = 굵기 D, 짧은 변 max(0.75, 0.34D), 모서리 0.08D, 긴 변이 화면 +x 축에서 시계 방향 25°. 가로획은 가늘고 세로획은 굵다. 탭은 0.75D 원.
  - **붓펜**(`taperBrush`): 원형. 시작은 붓을 눌러 생긴 둥근 머리(기필) 1.45D, 몸통 1.25D, 끝은 길게 빠지는 삐침(수필). 머리 길이 min(max(1.2D, 3), 8)·3차 ease-out, 삐침 길이 min(max(7D, 8), 0.42S)·끝 지름 0.5이며 삐침은 1 − u²로 옆선이 볼록하게 모여 끝에 둥근 머리를 남기지 않는다(오목한 )( 모양 금지). 삐침 구간은 0.75 간격으로 나눠 옆선이 각지지 않게 한다. 머리 · 몸통은 획 길이 S와 무관하다(획이 길어져도 앞부분이 바뀌지 않게). 짧은 획(S < max(2.5D, 6))은 끝 굵기만 max(0.85D, 1.1). 몸통 굵기는 max(0.5D, 1)~1.45D. 화면 속도 v(px/ms)로 1.06 − 0.035v(0.78~1.06, 시간상수 45ms)만큼 살짝 가늘어진다(입력 때 정해 저장). 탭은 1.15D 원. 영역 지우기 조각은 굵기를 점에 새긴다(`taperBaked`).
  - 볼펜·캘리펜·붓펜·연필은 모두 같은 곡선(입력 점을 조절점으로, 이웃 점 가운데를 잇는 2차 곡선)으로 잇는다.
    - 끝 꼬리(마지막 점 앞 반 구간)는 앞 두 구간의 꺾임 × 0.8 로 다음 점을 예측한 2차 곡선의 앞 절반으로 그린다. 직선이면 다음 점이 올 때 곡선이 그 점을 비껴가며 꼬리가 움직였다(사용자: 쓰는 중 모양이 살짝 바뀐다. 실제 S펜 획 재생에서 프레임당 이동 중앙값 0.72 → 0.26px). 60° 넘게 꺾이면 예측이 빗나가므로 직선. 점만으로 정해지므로 쓰는 중과 뗀 뒤가 같다.
  - **다시 계산해 바뀌지 않기**(사용자 요청): 그리는 중 끝난 구간(96점)은 다시 계산하지 않고, 미리보기와 저장 획이 같은 곡선 명령 · 같은 진행 거리(입력 점 사이 직선 거리 누적 `inkDistance`)로 모양을 정한다. 손을 뗄 때 바뀌는 것은 끝 갈고리 자르기뿐이다.
  - **지우개 조각**: 남은 조각은 원래 곡선을 촘촘히(1.5) 잡은 표본을 그대로 그린다(`sampled`). 직선으로 다시 잇거나 곡선을 또 펴면 지울 때마다 획이 흔들렸다.
  - **끝 갈고리 보정**(모든 펜·형광펜): 펜을 뗄 때 마지막 구간이 화면 4px 이하·획의 18% 이하이고, 그 앞 10px 진행 방향에서 45° 이상 꺾였고, 꺾임부터 뗄 때까지 100ms 이하(사이 45ms 멈춤 없음)이면 꺾인 점에서 자른다. 화면 20px보다 짧은 획은 그대로 둔다. 시작 갈고리는 붓펜 머리와 겹쳐 보정하지 않는다.
  - **연필 기본 불투명도 80**(2026-11-03 사용자 결정): 종류를 연필로 고르면 불투명도가 80 으로 들어가고(`PEN_DEFAULT_OPACITY`), 슬라이더 10~100 은 그대로라 100 으로 올리면 불투명. 근거: 참고 필기 앱(Notability · 애플 노트) 연필은 순검정이 없고(겹침 p90 ≈ .83) 겹칠수록 진해진다. 다른 펜은 1.
  - **연필**: 획 자체가 결이다(사용자 참고: Clip Studio · Procreate 연필 브러시, Taxe 흑색연필 굵기 비교, 'Combined 1'). 알갱이는 불투명하고 종이 결은 투명한 구멍(evenodd)이라 불투명도 100이면 비치지 않는다. 끝은 볼펜처럼 둥글다.
    - 몸통: 바깥 겹은 구멍 약 40%의 종이 결(tooth). 굵기 4.5 미만은 바깥 tooth + 0.95배 거의 꽉 찬 결(구멍 1% 안팎, 가장자리를 갉는 겹), 4.5 이상은 1 / 0.95(갉는 겹) / 0.54(가운데 겹, 옆으로 흔들림) 세 겹이 쌓여 가장자리는 성기고 가운데는 진하다(코덱스 5판).
    - 필압(앱 도장 연필): S펜 실측 force 대는 순간 0.02~0.05 · 가볍게 0.1~0.15 · 평소 0.2~0.25 · 세게 0.4~0.65 에 맞춰 f = clamp(0.38 + 0.68√(force ÷ 0.2), 0.62, 1.48)(코덱스). 예전 곡선은 0.34 에서 잘려 세게 = 평소였다(사용자: 필압이 안 먹는다). 저장된 force 로 다시 적용해 예전 획도 같다. 아래는 웹 SVG 겹 연필 값: 평소 필압 약 0.15 를 기준으로 f = 0.6 + 0.4√(force ÷ 0.15), 0.6~1.2. **모든 겹이 같은 f^1.1 로** 가늘어진다 — 안쪽 겹만 f² · f³ 로 좁히면 성긴 털 띠 가운데 진한 심 한 줄이 남았다(사용자 지적). 흐려지는 것은 갉는 겹으로: f 가 1 → 0.78 로 내려가면 갉기 0.12W → 0.57W, 자주 갉아(편향 0.75) 군데군데 종이가 비친다. 필압이 없으면 f = 1.
    - 안드로이드 필압 · 기울기는 `modules/dio-stylus`(S펜 MotionEvent 의 필압 · AXIS_TILT · AXIS_ORIENTATION, 네이티브라 개발 빌드를 다시 만들어야 적용)로 받는다. 펜 획은 포인터가 아니라 터치(responder) 경로로 들어오므로 터치 시각(MotionEvent.eventTime)이 네이티브가 본 펜 시각과 맞을 때 붙인다.

    - 굵은 연필의 획 방향 긁힘: 진행 거리 2.5마다 75%로 중심선 ±0.18W 안에 길이 1.4~4.6 · 폭 0.10~0.18 슬롯(±7°)을 몸통 세 겹 · 테두리에서 함께 잘라낸다(clipPath evenodd).
    - 가장자리: 좌우 따로 물결(진폭 0.1 / 0.13 / 0.16, 파장 1.4 / 2.4 / 1.4) + 잔결(0.05 / 0.06 / 0.065, 파장 0.4 / 0.32 / 0.2), 테두리 알갱이 띠(가는 연필만 1.18배, 13% 덮음, 진하게 · 옅게 반반 — 굵은 연필은 윤곽선처럼 보여 없앰), 가루(배율 1.26 / 1.24 / 1.5, 불투명도 0.11 / 0.05 / 0.04). 굵은 연필은 바깥 윤곽도 안쪽으로 잘게 갉는다(0.055W, 파장 0.3 — 사용자: 굵을 때 윤곽이 너무 일정하다). 굵기 2.5 / 5 / 10 기준, 사이는 보간. 곡선 표본 간격 3.

### 회원가입 전 연령·약관 확인 (2026-11-01)

가입 버튼은 이메일 입력 전에 같은 로그인 카드 안의 확인 단계로 연결한다. 기존 `TermRow`·기본 버튼·폰/태블릿 카드 및 테마를 재사용한다. 생년월일·출생연도 입력칸은 두지 않으며, 기본 미선택인 ‘만 14세 이상입니다 / 만 14세 미만입니다’ 단일 선택과 SERVICE/PRIVACY 필수 동의를 각각 받는다. 폰의 연령 확인 제목은 ‘가입 연령을 / 확인해 주세요’ 두 줄로 고정해 단어 중간 줄바꿈을 피한다. 연령 선택은 같은 크기의 행(최소 터치 높이 44)과 20px 원형 표시(선택 점 8px)를 쓰며 `radio`/`radiogroup` 역할로 알린다. 미만 선택 시 임시 입력을 정리하고 가입 불가 안내와 ‘시작 화면으로’ 버튼 하나만 표시한다. 같은 화면에서 답변 재선택을 유도하지 않는다. 소셜 로그인 버튼도 공통 확인 화면을 거친다. 전체 동의는 연령 본인 확인을 대신하지 않는다. 개인정보처리방침은 별도 보기 링크이며 동의 체크박스가 아니다. 최종 프로필 단계에서는 같은 동의 내용을 재검토할 수 있다. 약관 보기만으로 체크 상태를 바꾸지 않는다. 마케팅의 이메일·푸시·야간 동의 기록이 준비되기 전까지 모호한 일괄 마케팅 체크박스를 노출하지 않는다. 문서 미게시 시 이메일 입력 전에 가입 준비 안내를 표시하며 로그인은 유지한다. 실제 연령 인증 완료로 안내하지 않는다.

### 회원가입 이메일 인증

회원가입의 이메일·비밀번호 입력 다음에 공통 로그인 카드 안에서 인증번호를 입력한다. 기존 입력칸·버튼·키보드 회피를 재사용하고, 6자리 숫자·남은 시간·재전송 대기·오류·완료 상태를 표시한다. 실제 앱은 서버 발송·확인 API를 사용한다. 개발용 임시 인증은 명시적 테스트 화면에서만 안내하며 배포 화면에서는 제공하지 않는다. 발송 제한의 대기 시간은 기존 발송/재전송 버튼에 표시하고 대기 중 비활성화한다.

- 이메일 인증 완료 시 입력 관련 컨트롤을 공용 체크 아이콘과 완료 안내로 교체한다. 원형 배경은 primarySoft, 아이콘과 글자는 text, 다음 버튼은 primaryStrong을 사용한다.
- 개발 서버 Basic 접근 인증에 막힌 개발 모드에서만 공용 입력칸(ID·비밀번호)과 주요 버튼을 표시한다. 제품의 이메일·비밀번호와 구분해 ‘개발 서버’ 접두사를 쓰고 비밀번호는 가림 처리한다. 배포 모드에는 표시하지 않는다.
- 로그인도 같은 접근 인증 입력을 재사용한다. 계정 입력 아래에 배치하고 주요 버튼은 ‘접속 인증 후 로그인’ 하나를 표시한다. 접속 비밀번호 입력은 제출 후 비우며 기존 로그인 오류·키보드 회피 스타일을 유지한다.

### 디자인 리뷰 302 — 적용 범위

디자인 트렌드 검토 1·2·4번만 적용한다. 흰 글자 CTA는 primaryStrong, 화면 배경은 surfaceSoft의 중립 회청색, 선택 배경은 primarySoft를 쓴다. 굵기는 화면 제목 800·일반 UI 700·선택 상태 800으로 정리하되 기존 600 본문은 유지한다. 상단 바 구조·터치 영역·다크 모드는 이번 범위에서 변경하지 않는다. 표지 색·인쇄 글자·속지·펜·테이프·도형 팔레트와 사용자 글자 서식은 유지한다. 스플래시 네이티브 설정과 로고는 변경하지 않는다.

### 302 리뷰 보완 기준

- 흰 글자·체크·아이콘을 올리는 채운 면에는 주요 버튼뿐 아니라 개수 배지·체크박스·링크 배지·회전 버튼에도 primaryStrong을 쓴다. 글자 없는 진행 막대·선·손잡이는 primary를 유지한다.
- 강조 칩은 primarySoft를 쓴다. 중립 입력칸·색상 선택기 판·오류 안내 판은 surfaceSoft를 사용할 수 있다.
- 모바일 공통 헤더의 자간도 -0.6이며 일반 UI의 900 굵기는 사용하지 않는다. 표지 인쇄 글자는 사용자 콘텐츠로 기존 굵기를 유지한다.
- 표지색이 없는 기존 데이터의 호환 기본색은 diary/constants.js의 FALLBACK_COVER_COLOR(#D4D7ED)로 관리한다. 신규 표지 팔레트의 기본값(#A9AFD7)과 저장된 표지색은 변경하지 않는다.

## 스티커 자동 분리 화면

- 묶기 패널에는 직접 묶기와 직접 분리를 함께 둔다. 직접 분리는 여러 원본 조각으로 구성된 카드만 활성화하고, 카드 선택 후 하단 ‘선택한 묶음 분리’로 확정한다. 선택 체크는 저장 포함 여부와 분리하며 취소하면 저장 구성을 유지한다. 확정 후 원래 조각 카드로 돌아가고 실행 취소/다시 실행을 제공한다. 픽셀 자르기 도구로 표시하지 않는다.

- 꾸미기 보관함의 일반 변경 저장에 실패하면 제목 아래에 `danger` 테두리·글자와 `surface` 배경의 안내를 표시한다. ‘다시 저장’ 버튼은 최소 높이 44이며 저장 중에는 비활성화하고 ‘다시 저장 중…’으로 표시한다. 저장 성공 후 안내를 지우며, 실패 안내와 현재 편집 내용은 보관함 재진입에서도 유지한다.

- 스티커 제작 모달이 표시된 직후 이미지 선택기를 한 번 자동으로 연다. 취소하면 제작 화면의 이미지 선택 버튼으로 다시 시도하며 선택기를 반복해서 열지 않는다. 이미지 선택 후 배경은 자동 추정한다. 배경 허용 범위는 0~150(5 간격), 초기값은 10이다. 수동 배경 지정과 허용 범위는 ‘배경’ 도구에 접어 둔다. Android의 사용 영역은 이미지 선택 시 전체 이미지로 지정한다. 영역 조정 버튼은 원본 미리보기 안에 두고 전체 영역·다른 영역 추가 버튼은 표시하지 않는다. 내부 이동·8개 손잡이 크기 조정으로 수정하고 손을 떼면 확정한다. 손잡이는 `surface` 채움·`primary` 테두리의 10px 사각형이며 주변 44px 범위에서 잡을 수 있다. 확대·축소 버튼 없이 두 손가락 확대·이동과 화면 맞춤·이미지 이동을 제공한다. 이미지 조작 중에는 결과 목록 스크롤을 차단한다.

- 기존 색·모서리·버튼 토큰을 사용한다. 스티커 폴더의 `+`에서 ‘이미지 그대로 추가’와 ‘스티커 시트 분리’를 선택한다. 별도 ‘이미지에서 스티커 만들기’ 버튼은 표시하지 않는다. 같은 `+`를 다시 누르면 메뉴를 접으며 폴더 전환 시에도 닫는다. 미지원 환경은 메뉴 안에서 자동 분리만 비활성화하고 이유를 표시하며 기존 이미지 추가를 유지한다. 메뉴의 터치 영역은 최소 44px, 글자는 14px 이상이다.
- 원본 위를 드래그해서 사용 영역을 지정하고, 수동 배경 지점을 원과 ‘배경 지정색’ 태그·연결선으로 표시한다. 태그에는 미리보기의 선택 지점 한 픽셀을 확대해 보여주는 20px 색 견본을 붙인다(분리 판정 색을 바꾸지 않음). 태그는 원본 확대·이동에 따라가고 프레임 경계·현재 도구 표시·하단 이동 버튼을 피한다. 자동 배경 전환·화면 밖 핀은 태그를 숨긴다. 결과는 체크무늬 배경의 가상화 목록에서 확인하며 선택은 테두리·체크로 구분한다. 작은 장식 필터는 선택 상태를 바꾸지 않는다.
- 처리·저장 상태는 텍스트와 진행 표시로 알린다. 배경·영역 설정이 바뀌면 재분리 후 저장하도록 안내한다. 모달은 안전 영역을 반영하고 기존 화면의 입력을 차단한다.
- Android 개발 빌드의 거리 묶기·브러시 선택은 원본 위에 `primary` 테두리와 번호로 예상 PNG 묶음을 표시하고, 제외한 후보 영역은 `surface` 반투명 덮개와 `textMuted` 테두리로 구분한다. 도구는 배경 조정 → 포함·제외 → 객체 묶기 → 스티커 확인 순서의 가로 탭 네 개다. 스티커 제작 탭만 사용자 요청의 브라우저 형태를 적용한다. 탭 줄은 surfaceMuted, 선택 탭은 surface이며 상단 모서리 16·측면 cardBorder 1px·하단 열린 모양으로 흰 패널과 연결한다. 탭 높이는 44, 선택 제목은 800으로 구분한다. 선택 탭을 다시 눌러도 접지 않는다. 탭에는 이름만 표시하고 배경 방식·제외 개수·묶기 거리·총 개수는 아래 별도 상태 행(14px 진한 제목 + surfaceMuted 배지)으로 구분한다. 좁은 화면에서는 탭 줄만 가로 스크롤하며 선택 탭이 보이도록 맞춘다. 이미지 선택 후에는 배경 조정, 분리 성공 후에는 스티커 확인 탭으로 이동한다. 탭 전환 시 입력은 기본 확인 모드로 돌아가고 설정·결과는 유지한다. 거리 슬라이더(0~5%, 첫 분리에서 20~50개를 목표로 최소 거리 자동 설정)·직접 묶기·직접 분리는 객체 묶기에, 개별 포함·제외와 추가/제외 브러시·모드별 굵기는 포함·제외에 둔다. 실행 취소·다시 실행은 제목 오른쪽에 둔다. 계산 중에는 마지막 확정 목록을 유지하며 조작·저장을 막고 실패 시 ‘묶음 계산 다시 시도’를 제공한다.
- **스티커 제작 화면 결정(2026-11-02, 코덱스 B안)**: 팀원 구조(4탭 · 좌우 1:1 · 도구 줄)를 유지하고 제작 화면 문법을 절제해 이식했다. 상단 바는 `MakerHeader`(높이 64, 제목 22/800, 왼쪽 `<` 가 이 흐름에서 나가기, 오른쪽 X 없음, 되돌리기 · 다시 실행만), 버튼은 DioButton 48(회색 판 위 `영역 조정 · 이동 · 화면 맞춤`은 흰 면 + 윤곽), 하단은 `MakerBar`(왼쪽 `총 n개`, 오른쪽 끝 주 버튼 하나). **브라우저 탭 모양은 유지**하고 폰에서는 네 탭이 한 줄에 같은 폭으로 들어가 첫 탭이 잘리지 않게 했다(코덱스는 2×2 격자를 제안했으나 브라우저 탭 모양과 맞지 않아 내 판단으로 바꿈). 단계 표시(1 · 2 · 3)는 이식하지 않았다(탭이 순서를 이미 보여 준다).
- 브러시 굵기는 화면 기준 8~80(기본 24), 슬라이더 터치 높이는 44, 손잡이는 26이다. 선택 브러시 경로는 `primary`, 제외 경로는 `danger`의 반투명 선과 둥근 끝으로 표시한다. 브러시는 객체 전체에 적용하며 두 손가락은 확대·이동에 사용한다. 원본 픽셀을 지우는 도구로 안내하지 않는다.
- 자동 분리 입력은 Android에서 정지 PNG·JPEG(JPG)·WebP, 출력은 투명 PNG로 안내한다. 미리보기는 이미지와 크기 측정이 준비될 때까지 로딩 표시와 입력 차단을 제공하고, 실패 시 ‘미리보기 다시 시도’를 제공한다. 영역 조정만으로 분석을 시작하지 않으며, 조정한 프레임은 분리하기·다시 분리하기로 분석한다.
- 제목은 ‘스티커 시트 분리’다(공방 버튼 이름과 같다). 안전 영역을 뺀 폭 768 이상·높이 500 이상에서는 왼쪽 원본 미리보기와 오른쪽 설정·결과를 1:1로 배치한다. 원본은 고정하고 오른쪽 가상화 목록만 스크롤한다. 좁거나 낮은 화면에서는 원본 → 가로 도구 탭과 선택한 패널 → 결과를 한 목록으로 배치한다. 작은 회색 설명 문단·카드별 해상도를 표시하지 않는다. 이름·설정값·상태·오류는 14px 이상 진한 글자, 버튼 터치는 최소 44px이다. 영역 조정·이미지 이동·화면 맞춤은 미리보기 안에 모으고 현재 입력 도구를 원본 위에 표시한다. 하단 첫 줄에는 폴더 입력/폴더명, 둘째 줄에는 왼쪽 총 개수와 오른쪽 주요 버튼 하나를 고정한다. 저장 준비 상태의 버튼에는 ‘저장’을 표시하되 접근성 이름에는 실제 N개를 포함한다. 주요 동작 행 높이는 44로 유지한다. 넓은 화면의 하단 버튼은 오른쪽에 고정한다. 탭을 전환해도 저장 버튼을 숨기지 않는다.
- 최종 묶음 카드는 외곽 면적 내림차순(동률은 분석 순서)이며 원본 번호·목록·저장 순서를 일치시킨다. 체크무늬 위에 구성 PNG를 원래 상대 위치대로 배치하고 번호·포함 체크만 표시한다. 카드 탭은 원본의 해당 묶음 강조이며 저장 선택을 바꾸지 않는다. 원본의 묶음을 누르면 해당 카드가 강조되고 목록이 이동한다. 강조는 primaryStrong 테두리·얕은 채움으로 구분한다. 카드 오른쪽 위 44px 체크 버튼만 묶음 전체를 저장에서 제외하며 길게 누르기는 확대다. 직접 묶기에서만 카드 탭을 별도 대상 선택으로 사용하며 다른 저장 대상을 유지한다. 직접 분리는 객체 묶기 탭에서 브러시로 실행하며 원본의 실제 그림에 직접 닿은 객체만 묶음에서 뺀다. ㄱ·ㄴ·ㄷ 중 ㄱ만 닿으면 ㄴ·ㄷ은 묶음을 유지하며, 중간 연결 객체를 빼도 나머지끼리는 보존한다. 굵기 조절·현재 도구 표시를 제공하고, 손을 떼면 한 번 적용한다. 같은 버튼을 다시 누르면 브러시를 종료한다. 카드 확정 버튼은 두지 않는다. 한 획 실행 취소와 두 손가락 취소를 지원한다. 제외된 원본을 누르면 포함·제외 패널의 ‘이 객체 포함’으로 복구할 수 있다. 모두 선택·모두 제외·외곽 면적 64px² 이하 필터는 목록 더보기에 둔다. 필터는 저장 선택을 바꾸지 않는다.

### 페이지 선택 삭제 버튼 모양

선택 삭제와 다이어리 초기화의 기존 위치·순서·선택 진입 방식은 유지한다. 선택 삭제는 흰 바탕·border 테두리·radius.sm에 danger 휴지통 아이콘과 글자를 중앙 배치한다. 선택 개수는 기존 상단 표시를 사용하며 버튼의 접근성 이름에는 개수를 유지한다. 초기화는 surfaceMuted 바탕·textMuted 글자의 보조 버튼으로 낮춰 표시하고 기존 위험 동작 확인창을 유지한다. 삭제·초기화 버튼은 위의 편집 버튼과 같은 폭 140·시각 높이 32로 맞춘다. 버튼 간격은 12로 두며 상하 hitSlop 6으로 터치 높이 44를 확보하고 인접 터치 범위는 겹치지 않게 한다. 선택 삭제·다이어리 초기화 글자는 기존 작은 탭 기준인 11.5/700으로 맞추며 하단 이동이나 더보기 메뉴는 추가하지 않는다.
- 페이지 목록의 `편집` 진입은 기존 위치에서 연필 아이콘·textMuted 글자·흰 바탕·border 테두리로 표시하고, 폭과 좌우 정렬을 위의 전체/북마크 탭에 맞춘다(176 패널에서 140). 시각 높이는 32, 모서리 8, 글자 11.5/700·textMuted이며 위아래 hitSlop 6으로 터치 높이 44를 유지한다. 전체/북마크 줄로 옮기거나 기존 길게 누르기 선택 방식을 변경하지 않는다.
- 선택 모드의 `완료`는 기존 선택 개수 줄 오른쪽에 콘텐츠 너비·가로 여백 12·높이 28·모서리 7의 흰 버튼으로 표시한다. 절반 너비로 늘리지 않는다. 글자는 기존 작은 탭 기준인 11.5/700·textMuted를 적용하고 기존 hitSlop 8을 유지한다. 레이어 패널의 해제는 변경하지 않는다.
- 페이지 목록의 전체·북마크 탭과 선택 개수는 기존 작은 탭 기준인 11.5/700·textMuted로 표시한다. 선택된 탭은 text로 강조하고 선택 삭제는 danger를 유지한다. 완료는 작은 탭 기준을 따르며 나머지 버튼 높이·위치·동작은 유지한다.

### 웹 페이지 목록 썸네일 표시

- 무거운 페이지(표시 획 64개 이상 또는 좌표 8192개 이상)의 썸네일은 정밀 완성 획 캐시에서 만든 별도 축소 비트맵을 재사용한다. 문서 객체 참조·순서와 페이지 크기가 모두 일치할 때만 재사용한다.
- 축소 캐시는 최대 256개·총 1M 픽셀의 LRU 보관 예산을 둔다. 화면에서 사용 중인 버퍼는 별도로 살아 있을 수 있다. 캐시가 없으면 최대 2획씩 창 표시 후 700ms 유휴 대기와 작업 사이 32ms 간격을 두어 생성하고, 실패·예산 초과 시 정밀 SVG를 표시한다.
- 원본 필기·저장·Undo/Redo·내보내기 데이터는 변경하지 않는다. 작은 페이지와 네이티브 썸네일은 기존 표시를 유지한다. 임시 간소화된 질감을 썸네일 원본으로 사용하지 않는다.

### 회원 페이지 텍스트 저장 상태

기기 자동 저장 표시와 별도로 현재 페이지 텍스트의 서버 확인/전송/저장/충돌/연결 실패를 표시한다. 최초 양쪽 텍스트와409에서는 기기 내용을 유지하고 자동 덮어쓰기를 중단한다. 서버 연결 실패 표시를 누르면 내용을 유지한 채 재시도하며, 충돌 상태를 재시도만으로 강제 해소하지 않는다. 사진/필기 전체가 서버 저장됐다는 문구는 사용하지 않는다.

- 숫자는 `− [값] + 단위`(± 40×40 · 값 칸 56×40, 모서리 9)이고 자주 쓰는 값은 칩으로 옆에 둔다.
- 색은 **격자**(`SwatchGrid`, 칸 36 · 사이 12 이상으로 터치 48, 폭에 들어가는 만큼 한 줄 최대 7칸, 선택 고리 2 `primary`)로 고른다: 견본 + 맨 끝 칸은 '직접 고르기'(점선 +, 고르면 그 색으로 채움, 누르면 아래에 색 고르기와 HEX 입력이 펼쳐짐). 다음 줄(그라데이션 등)도 같은 열에 맞춘다. 펼치는 색 고르기는 한 번에 하나만 연다.
- 표지 바탕은 첫 줄 단색 6 + 직접 고르기, 둘째 줄 그라데이션 6 + 직접 고르기(위 색 · 아래 색). 다이어리 기본 바탕색은 크림 · 라떼 · 더스티 로즈 · 세이지 · 스카이 · 차콜(기본 스카이)이다. 그라데이션 고르는 칸은 6개다: 로즈핑크 · 세이지 · 라일락 · 스트로베리 클라우드 · 피치 셔벗 · 민트 스카이. 뒤의 셋(1020 파스텔, 2026-11-01)은 위 · 아래 두 색 배합이고 다른 프리셋처럼 물감 섞기로 잇는다. 블루그레이(9번)는 칸에서 뺐지만 번호는 남겨 이미 고른 표지는 그대로 그린다.
- 무늬는 지금 바탕색에 무늬를 그린 48 타일 4열 + 이름, 글씨체는 같은 폭 3열 칩에 그 글씨체로 쓴다.
- 펼친 요소 줄이 패널 밖이면 보이도록 스크롤한다. 꺼진 요소(고무줄 · 라벨)의 옵션은 고칠 수 있게 두되 0.45로 흐리게 보인다.
- 다이어리 수정은 바꾼 것이 있을 때만 '저장'을 켠다. 바꾼 채로 취소하면 '저장하지 않고 닫을까요?'를 한 번 묻는다.
- 줄을 넘기는 칩 묶음(`ChipGroup`)은 높이 36 알약, 선택 = 흰 바탕 + 1.5 `primary`, 아님 = `surfaceMuted`.

### 사진 속 대상 오리기 (스티커2)

- 기존 스티커1 진입은 유지한다. 사진 선택 후 `1 대상 고르기 → 2 스티커 확인`으로 진행하며 원본과 결과를 나란히 강제 배치하지 않는다(화면 배치는 §5.8).
- 선택 화면은 원본 위에서 포함 힌트·제외 영역을 보정하고, 결과 화면은 투명 영역을 구분하는 체크무늬 배경을 사용한다. 상단 바 뒤로(이전)와 기기 뒤로가기는 사진·획 이력을 보존한다.
- SAM 포함 붓은 대상 안쪽을 대충 칠하는 힌트다. API 미연결 상태는 붓질 예시임을 명시하며 실제 AI 윤곽·흰 테두리·저장 완료로 안내하지 않는다. 상세 계약은 [스티커2 화면](./sticker-cutout-ui.md)을 따른다.
- 스티커2 첫 진입은 큰 사진 선택 영역 하나로 통합한다. 영역 전체가 버튼이며 사진을 고른 뒤에만 별도의 교체 버튼과 붓 조작부를 표시한다.
- 스티커2 조작부는 포함/제외 전환 판, 현재 값 숫자와 슬라이더, 44px 되돌리기/다시 실행 아이콘으로 나눈다. 사진 교체·초기화는 테두리 없이 표시하고 주요 단계 이동만 채운 파란색으로 강조한다.

### 꾸미기 공방

- **카드를 쌓지 않는다.** 화면 바탕은 흰 면(`surface`) 한 장이고, 제목 아래 **인덱스 탭**으로 한 번에 **한 종류만** 연다. 마지막으로 본 종류는 공방을 다시 열어도 그대로다(앱을 끄기 전까지). 폴라로이드 결과 보드는 두지 않는다.
- **사다리꼴 인덱스 탭**(`폰트 · 스티커 · 표지 · 속지 · 도구`, 앞의 '내'는 쓰지 않는다): 아래가 넓고 양옆이 안쪽으로 기운 사다리꼴(위 모서리 8 둥금, 폭 128 · 폰 100), 이웃과 14 겹친다. 고른 탭이 맨 앞에서 더 높이(50 · 안 고른 탭 42) 서고, 나머지는 왼쪽 탭이 오른쪽 탭을 덮는다. 탭마다 색이 다르다: `lavender100` · `butter` · `#C9CDEE` · `butterTape` · `#E7E8F8`(라벤더와 노랑을 번갈아, Claude 판단). 글자는 모두 `text` 15/700(고른 탭 800). 탭 줄 아래에 고른 탭 색 띠(6)가 깔려 그 탭과 한 장으로 이어진다. 눌림 효과는 없다.
- 종류 머리: 제목 22/800 + 개수 14/700 `textMuted` + 오른쪽 동작(예: 스티커 폴더 안의 `폴더 목록`), 높이 48.
- **도구함**: 만들기 버튼을 한 줄에 묶는 면(`surfaceMuted`, 모서리 20, 높이 80 · 폰은 버튼을 세로로 쌓음). 만들기 버튼은 모두 채움 버튼(`새로 만들기`(폰트 탭) · `사진 속 대상 오리기` · `스티커 시트 분리`, 같은 급의 시작 동작이라 색으로 우선순위를 나누지 않는다). 폰은 제목 아래에 전폭(높이 48)으로 한 줄씩 쌓는다(가로로 이어 붙여 화면 밖으로 잘리지 않게). 쓸 수 없으면 같은 모양을 흐리게만 둔다. `준비 중` · `미리보기` 같은 상태 칩은 두지 않는다(준비 중인 기능은 출시 때 화면에서 뺀다). 저장한 것이 있을 때만 도구함 왼쪽 위에 `butterTape` 테이프 한 조각(32×12, -6°).
- **폰트 목록**: 공방 폰트 탭이 목록을 직접 보여 준다(손글씨 공방의 자체 목록은 거치지 않는다). 항목은 이름 + 상태 한 줄(`12 / 36 작성 중` · `생성 중 · 1,200 / 11,172` · `대기 n번째` · 완성은 실제 글꼴 예문)이고, 누르면 그 폰트 입력 · 상세 화면으로, `새로 만들기`는 바로 새 폰트 입력으로 간다. 작성 중인 폰트에만 삭제(확인 거침)가 있다. 새 폰트 입력에서 아무것도 쓰지 않고 나가면 그 항목은 저장하지 않고 지운다(고쳐 쓰는 폰트는 그대로).
- **내 폰트**: 구분선 목록(행 76, 이름 15/700 + 실제 글꼴 예문 18), 태블릿은 2열(사이 24). **내 스티커**: 폴더는 서랍 앞면 같은 얕은 타일(172×132, 모서리 18, 흰 면 + `cardBorder`, 안쪽 64 미리보기), 태블릿은 줄바꿈 · 폰 2열. 끝의 점선 `+` 칸은 2026-11-02에 뺐다(만들기는 제목 줄 버튼으로만, 표지 · 속지 · 폰트와 같다). 제목 줄에는 `스티커 추가` 버튼 하나(아이콘은 편집기 툴바의 스티커 도구와 같은 `sticker`)를 두고, 누르면 다이어리 카드 `⋯` 와 같은 동작 말풍선(`DiaryActionBubble`: 폭 224 · 행 48 · 아이콘 20 + 글자 15/700 · 행 사이 가는 선, 버튼 아래 오른쪽 끝 맞춤)에 `스티커 시트 분리`(grid) · `사진 속 대상 오리기`(scissors)를 둔다. 편집기 스티커 보관함 폴더 안의 `+` 도 같은 말풍선에 `이미지 그대로 추가`(image) · `스티커 시트 분리` · `사진 속 대상 오리기`를 같은 순서로 둔다(예전 `이미지 분리해서 추가`는 제작 화면 제목에 맞춰 이름을 바꿨다). 쓸 수 없는 항목은 흐리게만 두고 이유는 화면 읽기 이름에 넣는다. 폴더 안은 88×88 타일 + 오른쪽 위 작은 × 지우기, 머리 오른쪽에 `폴더 목록`(고스트) · 폴더 삭제(아이콘 버튼). **내 표지 · 내 속지**: 가로 선반(견본 116×154, 모서리 14, 사이 14, 끝에서 다음 견본이 잘려 보임), 이름 14/700 옆에 지우기 아이콘 버튼(48). **내 속지**는 맨 위 기본 속지 설정(제목 18/800, 글꼴은 **드롭다운**: 지금 글꼴 이름을 그 글꼴로 쓴 칸 + ⌄(아래로 꺾인 화살촉, 열리면 위로), 누르면 목록 말풍선) → 구분선 → 저장한 속지 선반. **내 프리셋**: 편집기 도구(펜 · 형광펜 · 마스킹 테이프 · 글자)가 한 줄로 보여 주는 **색 목록을 여기서 고친다**(`editor/hooks/usePalettes.js`, 최대 12색, 편집기 색 줄 · 선택 바 · 테이프 색이 그대로 따른다. 이미 칠한 내용은 바뀌지 않는다). 카드 없이 도구마다 아래 구분선(태블릿 2열 · 사이 32, 폰 1열). 견본은 모두 원 30(터치 44) — 테이프는 바탕 원 안에 무늬색 작은 원. 색을 누르면 그 견본 바로 아래(왼쪽 끝 맞춤)에 **바꾸기 말풍선**(색 고르기, 테이프는 바탕색 · 무늬색, `지우기` · `완료`)이 뜬다. `+`는 두지 않는다. 맨 아래 줄 밑에는 구분선을 두지 않는다. 바꾼 도구에만 `기본 색으로`(고스트)가 생긴다. 도구에서 따로 저장한 '내 색상'은 여기 보이지 않는다. 견본 색은 사용자 콘텐츠 색이라 색 규칙의 예외다.
- 빈 상태: 홈 보관함 · 휴지통과 같은 빈 화면(모아 + 제목 한 줄, `EmptyState raised`)이 남은 높이 가운데보다 약간 위에 온다. 설명 줄은 두지 않는다.
- 내부 개발 문구("개발 빌드에서 사용 가능", "미리보기 · AI 분리·저장 미연결")는 사용자에게 보이지 않는다. `준비 중` · `미리보기` 상태 칩도 두지 않는다(쓸 수 없으면 흐리게만, 준비 중인 기능은 출시 때 화면에서 뺀다).

- 홈 메뉴의 꾸미기 공방은 내 폰트·스티커 제작과 기기 보관함(표지 · 속지 · 편집기 색 프리셋)을 모은다. 툴바에는 독립 폰트 제작 아이콘을 추가하지 않고 텍스트/스티커 + 진입은 유지한다.
- **내 프리셋**은 편집기 도구가 주는 색을 도구별로 모은 구역이다. 펜 · 형광펜 · 마스킹 테이프 · 글자 네 묶음(태블릿 가로 3열 · 세로 2열 · 폰 1열, 묶음 폭이 색 한 줄 288보다 좁아지면 열을 줄인다)이 각각 위에 기본 프리셋 7색, 그 아래 24 띄워 소제목 `내 색상`(13 / 800 `textMuted`)과 내가 저장한 색을 가진다. 내 색상은 도구마다 **최대 14개**(7개씩 두 줄)이고 맨 끝에 점선 + 칸(가득 차면 없음)이 있다. 빈 상태는 소제목과 + 칸뿐이다. 내 색상 원을 누르면 프리셋과 같은 말풍선에 `지우기` · `완료`가 뜨고(원 위 × 는 두지 않는다), + 는 같은 말풍선으로 새 색을 넣는다. 마스킹 테이프는 바탕 + 무늬 두 색을 원 안의 작은 원(10)으로 그린다. 편집기 도구 설정의 내 색상과 같은 목록이다.
- 기존 기기 저장소와 제작기를 재사용하고 미지원 환경·목업 상태를 표시한다. 삭제는 확인을 거치며 저장 오류는 공용 재시도 안내를 사용한다. 상세 범위와 검증은 [꾸미기 공방](./decoration-studio.md)을 따른다.

- **내 속지** 구역 맨 위에는 **기본 속지 설정**(종이 색 · 선 · 글씨 색 · 속지 글꼴, 새 다이어리 화면의 '속지 색'과 같은 줄)이 있다. 새 다이어리를 만들 때 처음 값이 될 뿐이고(고르기 전에만 채우며, 채운 것은 '바꿈'으로 치지 않아 취소해도 묻지 않는다) **이미 만든 다이어리 · 속지는 바꾸지 않는다**. 저장하지 못하면 줄 아래에 오류 한 줄을 보인다.
- 제작 화면의 기존 표시 방식은 유지한다(폰트·시트 분리: 전체 화면, 사진 속 대상 오리기: 팝업).

- 나의 표지 · 속지 지우기는 확인(`이 표지를 지울까요?` · `이 속지를 지울까요?`, 지워도 이미 만든 다이어리는 그대로)을 거치고 저장하지 못하면 그 구역 안에 오류 한 줄을 보인다. 지우기 아이콘은 `text`이고 적색은 쓰지 않는다. 읽는 중에는 `표지를 불러오고 있어요.` 처럼 구역마다 한 줄, 비어 있으면 `아직 저장한 표지가 없어요.` 한 줄이다. 내 폰트는 실제 글꼴 미리보기를 보이고, 손글씨 공방 진입은 `내 폰트 만들기` 하나다(같은 곳을 여는 `폰트 관리`는 두지 않는다). Android 뒤로가기는 스티커 폴더 내부에서 목록으로 먼저 돌아간다. 제작 모달 표시 방식은 변경하지 않는다.

**버튼 체계(`shared/DioButton.js`, 공방 · 내 공간부터 적용)** — 모두 높이 48 · 모서리 16(아이콘 버튼은 48×48 · 모서리 14), 글자 15/800. **눌렀을 때 모양이 바뀌는 효과(줄어듦 · 내려앉음 · 면 색 바뀜)는 두지 않는다**(사용자 지시, 분절 메뉴 · 타일도 같다).

| 종류 | 모양 |
|---|---|
| 채움 `filled` | `primaryStrong` + 흰 글자 + 아래 2px `primaryText` 깊이선 |
| 토널 `tonal` | `surfaceMuted` + `primaryText` |
| 고스트 `ghost` | 투명 + `primaryText`(필요하면 `primary` 1px 테두리) |
| 위험 `danger` | 투명 + `dangerStrong` 글자 · 1px 테두리 |
| 아이콘 `icon` | 아이콘 22 `primaryText`, 접근성 이름 필수 |

비활성은 같은 모양을 `DISABLED_OPACITY`(0.4)로 흐리게 하며 높이와 접근성 이름은 그대로다.

- 스티커 폴더 이름은 중복을 허용한다. 공방과 편집기에서 같은 정책을 사용하며 기존 폴더 추가·선택·삭제는 이름이 아닌 폴더 ID로 구분한다. 이름 앞뒤 공백 정리와 빈 이름 차단은 유지한다.
