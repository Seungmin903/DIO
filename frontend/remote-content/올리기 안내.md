# 에셋(글꼴·스티커·속지) 올리기 안내

앱을 다시 배포하지 않아도, 이 폴더에 파일을 넣고 병합하면 사용자 앱에 새 글꼴·스티커·속지가 나타납니다.
S3에 직접 올리지 않습니다. GitLab CI가 올립니다. json 형식과 예시는 같은 폴더의 [README.md](./README.md)에 있습니다.

## 1. 어디에 넣나요?

`frontend/remote-content/` 안에 종류별로 폴더를 하나 만들어 넣습니다.

```
frontend/remote-content/
├── fonts/폴더이름/        ← 글꼴
├── stickers/폴더이름/     ← 스티커
├── templates/폴더이름/    ← 속지
└── template-groups.json   ← 새 속지 탭을 만들 때만
```

json은 "이 폴더에 무엇이 있는지" 적는 짧은 설명서입니다. 예를 들어 속지라면:

```json
{ "name": "봄 노트", "group": "note", "landscape": "spring-landscape.svg", "portrait": "spring-portrait.svg" }
```

## 2. 종류별로 넣을 파일

| 종류 | 파일 형식 | 크기 제한 | 같이 넣을 파일 |
|---|---|---|---|
| 글꼴 | `.ttf`, `.otf` | 파일 하나 30 MiB 이하 | `font.json`, 라이선스(`OFL.txt` · `LICENSE.txt` · `LICENSE` 중 하나) |
| 스티커 | `.png`(투명 배경 권장) | 2 MiB 이하, 가로·세로 각 2048px 이하 | `pack.json` |
| 속지 | `.svg`, 가로(1024×768)와 세로(768×1024) 둘 다 | 2 MiB 이하 | `template.json` |
| 속지 탭 | 없음 | - | `template-groups.json` |

- JPG · GIF · WebP · WOFF · PDF는 받지 않습니다.
- 스티커는 PNG 말고 도트 스티커도 됩니다. 그림 파일 없이 `pack.json` 안에 점 좌표로 적으며, 앱의 '디오&모아' 스티커와 같은 형식입니다.
- 속지 SVG는 앱 속지와 같은 형식만 받습니다(흰 종이 + 정해진 회색 선 6가지, 글자는 윤곽선으로). 앱에 있는 속지 SVG를 참고해 만들면 가장 쉽습니다.

## 3. 이름 규칙

| 대상 | 규칙 | 예 |
|---|---|---|
| 폴더 이름 · 스티커 `id` · 탭 `id` | 영어 **소문자**·숫자·`-`만, 40자 이내, `-`로 시작하지 않음 | ✅ `spring-note` ❌ `Spring`, `spring_note`, `봄` |
| 파일 이름 | 영문(대소문자)·숫자·`-`·`_`·`.`만, 띄어쓰기·한글 없음 | ✅ `cherry_01.png` ❌ `벚꽃.png`, `my font.ttf` |
| 설명 파일 | 이름이 정해져 있음 | `font.json`, `pack.json`, `template.json`, `template-groups.json` |
| 화면에 보이는 이름(json의 `label` · `name`) | 자유(한글 가능), 1~40자 | `"name": "봄 노트"` |

- 속지 탭 `id`로는 `note` · `planner` · `diary`를 쓸 수 없습니다(앱 기본 탭).
- 파일 이름 뒤의 해시(예: `.c2f2e52420b84186`)는 CI가 내용으로 계산해 자동으로 붙입니다. 직접 붙이지 않습니다.

### id란?

앱이 에셋을 알아보는 고유 이름입니다. 사용자에게는 보이지 않고, 사용자 문서에 "이 글자는 이 글꼴", "이 스티커는 이것"처럼 저장됩니다.

| 종류 | id를 정하는 곳 | 문서에 저장되는 모양 |
|---|---|---|
| 글꼴 | 폴더 이름(`fonts/hahmlet/` → `hahmlet`) | `remote-hahmlet` |
| 스티커 팩 | 폴더 이름(`stickers/spring/` → `spring`) | - |
| 스티커 하나하나 | `pack.json`의 `"id"` | `remote:spring:cherry` |
| 속지 | 폴더 이름(`templates/spring-note/` → `spring-note`) | 페이지 설정 `remoteTemplate: "spring-note"` |
| 속지 탭 | `template-groups.json`의 `"id"` | 속지 `template.json`의 `"group"`에 씀 |

- 화면 이름(`name` · `label`)은 언제 바꿔도 됩니다.
- **id는 한 번 올리면 바꾸지 않습니다.** 바꾸면 이미 쓴 문서가 그 에셋을 찾지 못합니다(글꼴은 기본 글꼴로, 스티커는 빈 자리로, 속지는 "속지를 불러오지 못했어요").
- **지운 id를 다른 에셋에 다시 쓰지 않습니다.** 예전 문서가 새 에셋으로 바뀌어 보입니다.
- 속지 디자인을 크게 바꿀 때는 같은 id의 SVG를 고치지 말고 새 id로 올린 뒤 옛 것은 `"hidden": true`로 내립니다. 같은 id의 SVG를 고치면 이미 만든 페이지도 모두 바뀝니다.

## 4. 어떻게 올리나요?

1. `frontend` 폴더에서 아래 명령을 실행합니다. 형식이 틀리면 어떤 파일의 무엇이 틀렸는지 알려 줍니다.

   ```bash
   pnpm assets:remote
   ```

2. 커밋하고 MR을 올립니다.
3. develop에 병합되면 개발 서버에 자동으로 올라갑니다.
4. 운영(실제 사용자)에 올릴 때는 master 파이프라인에서 운영 백엔드 배포가 끝난 뒤 `publish-remote-assets-prod` 버튼을 한 번 누릅니다.

## 5. 꼭 지킬 것

- **id(폴더 이름)는 바꾸지 않습니다.**
- **지우지 않습니다.** 내리고 싶으면 json에 `"hidden": true`를 적습니다. 고르는 목록에서만 사라지고 이미 쓴 문서는 그대로 보입니다. 지우면 업로드 안전장치가 업로드를 멈춥니다.
- **S3 콘솔에서 파일을 직접 올리거나 이름을 바꾸지 않습니다.** 앱은 정확한 파일 이름(해시 포함)으로 찾으므로, 손으로 바꾸면 그 파일을 못 찾습니다. 앱 번들에서 뺀 기본 에셋(2026 속지 · 고운돋움 · 고운바탕 · 마루부리)도 같습니다.

## 6. 앱에 자동으로 보이나요?

네, 앱 배포 없이 보입니다.

### 언제 보이나요?

- 업로드가 끝난 뒤 사용자가 **앱을 다시 켜면** 새 목록을 받아 보입니다. 이미 켜져 있는 앱에는 바로 나타나지 않습니다.
- 업로드 직후에는 서버 캐시 때문에 최대 1분 정도 늦을 수 있습니다.
- 글꼴은 처음 고를 때, 속지는 처음 쓸 때, 스티커 그림은 처음 보일 때 내려받습니다. 그래서 처음 한 번은 인터넷이 필요합니다.
- 인터넷이 끊겨 있으면 마지막으로 받은 목록을 그대로 씁니다.

### 보이려면 필요한 것

1. **이 기능이 들어간 앱 버전**이어야 합니다. 그 뒤로 올리는 에셋은 앱 배포 없이 보입니다.
2. 그 빌드에 에셋 주소(`EXPO_PUBLIC_ASSET_BASE_URL`)가 들어가 있어야 합니다. `eas.json`에 이미 넣어 두었습니다.
3. 속지는 서버에도 V34가 배포돼 있어야 회원 다이어리에서 쓸 수 있습니다.

### 어느 앱에 보이나요?

- 개발 서버(develop)에 올리면 개발용 빌드(preview)에서만 보입니다.
- 운영 서버(master에서 버튼)에 올려야 실제 사용자 앱(production)에 보입니다.
