# 추가 글꼴

- 고운돋움 Regular: https://github.com/google/fonts/tree/main/ofl/gowundodum
- 고운바탕 Regular·Bold: https://github.com/google/fonts/tree/main/ofl/gowunbatang

각 폴더의 OFL.txt는 원본과 함께 배포되는 SIL Open Font License 1.1이다. 원본 TTF 세 파일의 합계는 23,841,096바이트이며, 각 파일의 cmap에서 현대 한글 음절 11,172자를 확인했다. 고운돋움은 Regular만, 고운바탕은 Regular와 Bold를 사용한다. 두 글꼴은 Italic face를 제공하지 않는다.

글꼴 ID가 추가된 앱에서 작성한 문서를 구버전 앱으로 열면 구버전에 없는 글꼴은 기본 글꼴로 대체될 수 있다. iPad에서는 편집, 저장·재실행, 다른 기기와 공유, 내보내기 및 한글·영문 렌더링을 실기기로 확인해야 한다.
